# Draw3 link audit

- ARM64 prebuilt modeler path is `Inkeys/additional/ink_stroke_modeler/lib/libArm64`; ARM64 project configurations now include it.
- Debug build reaches link, then fails because the prebuilt modeler is `/MT` and `_ITERATOR_DEBUG_LEVEL=0`, while the product Debug objects are `/MTd` and level 2. Release modeler ABI is compatible.
- After the library path is fixed, remaining Draw2 isolation link failures are 19 unresolved symbols: `HandleMouseInput`, `leftButtonPid`, `rightButtonPid`, `StrokeImageListSm`, `StrokeImageList`, `drawWaiting`, `drawWaitingSm`, `IdtRecall`, `FirstDraw`, `ResetPrepareCanvas`, `rtsDown`, `rtsNum`, `touchNum`, `TouchSpeed`, `TouchPos`, `TouchList`, `TouchTemp`, `touchPosSm`, `touchSpeedSm`.
- Call sites are `Inkeys/Input/MouseHook.cpp` (legacy mouse-up correction), `Inkeys/UI/Bar/Bar.Button.cpp` (`IdtRecall`, `FirstDraw`), `Inkeys/UI/Setting/Setting.cpp` (program-debug/input-test panel and `ResetPrepareCanvas`, RTS globals), and `IdtState.cpp` (Draw2 history globals). The setting tab is at `Setting.cpp` around 8531 and should be hidden/removed as requested.
- Minimal compatibility strategy: keep Draw2 files as None, provide a small facade/stub for legacy globals/functions or route Bar commands to Draw3 bridge; remove legacy mouse-up correction and hide the input-test/debug tab. Do not compile `IdtRts.cpp` or `IdtHistoricalDrawpad.cpp`.
- Host bug: `Host::Start` passes `&styleCallbacks` (the by-value parameter) as `TransparentPresentationCallbacks.context`; `TransparentPresentationController` stores that pointer for later mode changes/resize, so it dangles after `Start` returns. Store `HostStyleCallbacks` in `Host::Impl` and pass its stable address (or make the callback context direct).
- Startup bug: `TopWindow()` still waits for `IdtWindowsIsVisible.drawpadWindow`, whose only writer is the noncompiled `IdtDrawpad.cpp`. After `StartProduct` reports `ProductFirstFrameReady()`, the new path must set this readiness flag or replace the legacy wait; otherwise startup times out after 20 seconds and sets `offSignal`.
