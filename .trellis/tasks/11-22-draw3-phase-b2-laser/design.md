# 阶段 B2 设计

需求与用户确认见 `prd.md`。本文写的是实现合同；标“（Claude 决定）”的条目是 prd “实现时待定”里由 Claude 定下、用户尚未逐条确认的取值，集中列在第 6 节，改动成本都很低。

基线 `refactoring/draw@9a4dda60`。实现顺序：第一点 → 第二点 → 第三点，后一点建立在前一点之上。

## 0. 通用约束

- 着色器保持 SM5.0。改 `inkPixelShader.hlsl` 或新增着色器后，按 `.trellis/spec/shaders/build-and-encoding.md` 重新生成 Win7 受保护着色器。
- 激光主体像素在三点完成后与基线逐字节相同（粒子、飘散遮罩和操作逻辑的有意变化除外）。
- 不为不支持 `ClearView` 的设备新增着色器或拷贝路径。
- 未列出的视觉与行为保持原样，不顺手改进。
- 源文件 UTF-8 BOM + CRLF；不改文件末尾换行；测试不放进未定义宏的 `#if`。

## 1. 第一点：合成路径

1. 三张激光纹理（稳定段、实时尾段、已烘颜色）各记一个“写入外接矩形”和“内容未知”标志。写入时并入矩形；清除后归空。预热（零视口）声明空范围。
2. 清除按写入范围：范围为空则跳过；内容未知或范围面积超过画布 1/16 则整屏清（沿用阶段 B 分界线）；否则只清该矩形（`ClearView` 可用时用它，否则用已有的类型 12 矩形绘制）。
3. 抬笔烘焙：
   - 单指增量批次：原位写入已烘颜色，不备份、不拷贝、不分配副本纹理。
   - 多层批次：只把本批范围备份到副本纹理；中途失败把该范围拷回，已提交颜色保持失败前的状态。副本纹理按需创建。
4. 已烘颜色上屏的绘制范围 = 帧脏区 ∩ 轨迹范围。

不做：淡出期间的大范围重合成（阶段 C）、多指整笔重画。

参考：一次试做的草稿补丁 `%TEMP%\inkeys-codex\phase-b2\point1-draft.patch`（基于同一基线，仅供参考，不保证可直接套用；试做结果见 `research/point1-baseline-and-point2-state.md`）。

## 2. 第二点：操作逻辑

### 2.1 激光“可见”状态

定义 `激光可见 = 生命周期不为 Inactive，或仍有存活粒子`。它取代“选中激光工具”成为激光资源与界面状态的依据。

### 2.2 切到其他笔（需求 1）

- 离开激光工具时，仍按下的激光触点按正常抬起处理（冻结、烘焙、开始留存计时），不再直接清空。
- 激光纹理保留到“当前工具不是激光 且 激光不可见”才释放；回到激光工具时若纹理仍在则直接复用。
- 留存、淡出（或飘散）的时间与当前工具无关，按原有计时走完。
- 笔尖圆点仍只在当前工具为激光时画。
- 翻页、清屏、切换白板或放映、退出：仍立即清空激光（含粒子与撤回记录）。

### 2.3 切到选择（需求 2）

- 控制器向界面发布一个新标志“激光可见”。它在生命周期变化与粒子过期时重新发布（需要一个随时间变化的发布点，不依赖输入事件）。
- 主栏紧凑形态的条件改为：`非白板 且 选择态 且 当前页无墨迹 且 激光不可见`。
- 窗口选择：激光可见时按“有内容”处理（辅助窗接力）；激光不可见后走已有的“辅助窗整帧已验证全透明才隐藏”流程。
- 回到绘制：两段交接的启用条件改为 `当前页有墨迹 或 激光可见`，保证先出完整帧再换窗。
- 选择态下激光可见期间保留 1 ms 高精度计时器，激光不可见后按原样释放。
- 选择态下不接受新的激光触点（与现在相同）。
- 主 ULW 单窗模式：没有辅助窗可接力，主窗照常显示；主栏同样等到激光不可见才收缩。

### 2.4 撤回（需求 3）

- 轨迹存活期间保留每一笔已烘激光的记录：点列、样式、范围、所属批次、操作序号。生命周期回到 Inactive、清空类操作时全部丢弃。
- 激光笔画与文档历史操作共用一个单调递增的操作序号。撤回时：图形构造会话仍最优先；其次比较“最新的可撤回激光笔”与“文档历史栈顶”的序号，撤回较新的那个。
- 撤回一笔激光：删除该记录；清掉该笔范围内的已烘颜色；把其余与该范围相交的记录按原落笔顺序、限定在该范围内重新烘焙。结果必须与“这一笔从未画过”逐字节相同（自检验证）。
- 整组计时与不透明度保持不变。撤掉最后一笔后记录为空，生命周期立即回到 Inactive。
- 不进重做栈，也不清掉文档已有的重做栈。
- 正在书写中的批次（未全部抬起、尚未烘焙）不参与撤回。画布命令沿用基线规则：有活动触点时不处理，撤回等触点全部抬起后执行（实现时复核过，在激光按下期间执行文档撤回或清屏会清 L0/L1、重置栅格指标，风险不值得）。
- 撤回可用性 = 原有条件 或 存在可撤回的激光笔；激光过期时重新发布。
- 飘散进行中撤回：该笔主体与它名下的粒子（已释放与未释放）一起直接移除，不飘散。

## 3. 第三点：粒子

### 3.1 架构

粒子系统拆成两层：

- **模拟层**（与来源无关）：粒子池、计算着色器更新与发射、绘制、脏区登记。输入是“种子”：出生位置、颜色、尺寸、释放延时、随机种子、分组号、种类。
- **来源层**：把具体内容转成种子。本轮只有三个激光来源（行进、点击光波、飘散）。以后的清空、场景切换从像素取色生成种子，接到同一模拟层；本轮不为它们写任何代码。

计算着色器不可用时三种效果全部无效，轨迹按渐隐消失，激光其余功能不受影响。

### 3.2 规模与性能

- 粒子池扩到 32768 槽（Claude 决定）。更新与绘制只覆盖活跃的环形区间，不每帧扫全池；没有存活粒子时不派发、不绘制。
- 一次飘散的粒子总数有上限（默认 16384，Claude 决定）：总数 = min(设计密度 × 轨迹总长, 上限)，超限时按比例降低密度而不是截断后半段。
- 飘散种子由 CPU 一次生成、一次上传，之后的运动、淡出、汇聚全部在计算着色器里完成，CPU 不逐粒子参与、不回读。
- 每像素开销：粒子像素着色器保持常数次运算，不做循环与纹理采样；飘散遮罩在已烘颜色上屏的那一次绘制里完成，不增加额外全范围绘制。
- 脏区：飘散与汇聚期间 = 轨迹范围 ∪ 粒子最坏包络（按风速、寿命、扩散上限保守估计），沿用现有“登记包络 + 过期时刻”的方式。

### 3.3 粒子飘散（随风扫过）

- 触发：留存结束且“粒子飘散”有效时，生命周期进入飘散阶段（取代淡出阶段）。无效时仍是原来的 0.8 秒渐隐。
- 主体：已烘颜色上屏时按“扫过前沿”做遮罩。前沿沿风向从下风一侧推进到上风一侧，边缘带噪声，不是直线。遮罩只在飘散与汇聚期间生效；其他时刻的像素与基线逐字节相同。
- 粒子：沿每一笔的点列按密度采样出生位置，横向在笔宽内随机；颜色取来源处的颜色（芯部近白、外圈激光色）。每个粒子在前沿扫到它时释放，释放前不可见。释放后受风、湍流、阻力作用漂移并淡出。
- 参数起点：`research/laser-effects.html` 里“随风扫过”的默认参数，再按 3.6 降低密集感。
- 飘散阶段时长 = 前沿扫完的时长（Claude 决定：0.9 秒）。扫完后生命周期回到 Inactive（纹理可清、撤回失效）；仍在空中的粒子按自身寿命飘完，期间“激光可见”仍为真。
- **汇聚还原**：飘散阶段内再落笔（整组重新计时）时进入汇聚。前沿反向退回，主体随之恢复；仍存活的已释放粒子被拉回各自的出生位置，到位后消失，由恢复的主体接替；未释放的粒子取消释放。汇聚时长 0.35 秒（Claude 决定），期间新笔画照常书写。汇聚结束时主体像素与飘散前逐字节相同。前沿扫完之后（已 Inactive）再落笔不还原，是新的一组。
- 汇聚中再次抬笔、留存结束：从当前状态重新开始飘散，不跳变。

### 3.4 点击光波粒子

- 判定为点击：从落笔到抬起不超过 250 毫秒，且期间离落笔点的最大位移不超过 6 DIP（Claude 决定）。只在抬起时判定，一次点击触发一次。
- 效果：以点击点为圆心，两圈粒子先后向外扩散（第二圈略晚、略小），每圈粒子沿径向减速、带少量切向旋转，尺寸与透明度随扩散衰减；颜色用激光色，内圈偏白。总寿命约 0.6 秒，最大半径约 28 DIP（Claude 决定）。
- 点击留下的激光点本身照常显示、留存、消失。

### 3.5 行进粒子

在现有实现上调整（Claude 决定，均为 prd 候选项）：

- 静止时不发射（去掉静止发射率）。
- 发射量与初速度跟随笔速；出生方向以运动反方向为主、带小角度散开，不再沿法线向两侧喷出。
- 加阻力，使粒子停在线附近。
- 尺寸范围加大到 0.8–2.2 DIP。
- 去掉与激光颜色无关的粉色辉光；辉光如保留则用激光色。
- “发射后留存不短于粒子最长寿命”的现有规则保留。

### 3.6 降低密集感（Claude 决定）

- 飘散的设计密度取原型默认值的约一半。
- 尺寸差异加大（少量大粒子、多数小粒子），不出现均匀点阵。
- 离出生位置越远越透明，淡出比原型更快。
- 前沿边缘更松散。

所有取值集中在一个参数结构里，便于真机上调整。

### 3.7 设置与配置

- 设置 → 绘图效果：总开关“激光笔粒子效果”，其下三个子复选框“行进粒子”“点击光波粒子”“粒子飘散”。总开关关闭时子项隐藏或禁用。附一行说明：需要显卡支持计算着色器，不支持时自动使用渐隐。
- 配置键（Claude 决定）：总开关沿用 `Drawing.Laser.ParticlesEnabled`；新增 `Drawing.Laser.ParticleTrailEnabled`、`Drawing.Laser.ParticleClickWaveEnabled`、`Drawing.Laser.ParticleDissolveEnabled`。四项默认均为开启。重构分支不兼容旧配置，不做迁移。
- 有效状态 = 总开关 且 子项 且 本代粒子资源可用。去掉现有四处强制关闭。
- 设置变更在生命周期为 Inactive 的边界生效；运行中粒子系统失效时立即撤销粒子并重绘其范围，轨迹改按渐隐。
- 界面文字只加简体中文；其余语言由主 Agent 同步补译。

## 4. 自检

沿用并扩展现有无窗口自检（`--draw3-laser-resources-test`、`--draw3-laser-raster-failure-test`、`--draw3-renderer-upload-test`），新增用例放在这些入口或同类新入口里，必须在现有构建配置下真实执行：

- 第一点：清除、拷贝、分配次数符合第 1 节；单指、留存中第二批、小笔画（矩形清分支）、多层失败重试的像素与参考逐字节相同。
- 第二点：切工具后轨迹与计时保留、纹理在不可见后释放；“激光可见”标志的发布与主栏、窗口、交接条件；撤回的像素与“从未画过”逐字节相同、计时不变、序号比较、不影响重做。
- 第三点：各开关的有效状态；点击判定；飘散进入与结束、汇聚后主体逐字节还原；粒子上限与活跃区间；计算着色器不可用时退回渐隐。

## 5. 不做

- 清空、场景切换的粒子效果。
- 逐笔各自计时的消失。
- 淡出与飘散期间的多脏矩形（阶段 C）。
- 实机验证（与阶段 B 一起留到中期重构最后）。
