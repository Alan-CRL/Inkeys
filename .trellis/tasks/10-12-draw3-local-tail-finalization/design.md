# 设计

增加独立局部终态拟合入口，保留阶段二 API 对照。参考离线 local_tail_preview.py：保留大部分模型轨迹、入口位置方向及 Up 硬约束，以弧长拟合末端三次曲线；原始输入少量有序位置与末端方向按可信度辅助。无辅助点使用排除人工 pin 的模型方向。求解使用有界工作量和原子发布，验证 finite、入口、位移、长度、转角、自交，失败保留旧完成态。

Draw3 在实际 Modeler 输入处记录物理时间和位置，以固定容量、160ms 窗口限制。终态生成复制 realPoints，完成态才拟合；不将新位置伪装成上游 Result 或反馈模型，不改变压力/笔宽来源。最终 taper/几何应基于最终位置。断触等待只保存 raw 窗口，恢复继续更新；确认结束走同一 Stored Stroke 路径。既有完成笔划重绘处理 L1，不重建历史 L2。

参数为原型起点，产品坐标单位需要核实；局部范围选择仍需回放和反例验收。生产边界验证不得用单独离线图替代。

人工反馈后的临时可视化：反色仅作为渲染诊断，原 style 和保存数据不改变。以完成态实际发布后的变化范围标记瞬态元数据，既有 DrawStoredStroke 在完成 L1 和 L2/重绘中统一消费。范围需涵盖改变的边并处理 taper 新增连接点；拒绝/未变化不标记。通过显式常量关闭，日志记录求解及调用方回退阶段，不调算法阈值来强迫显示。

2026-10-13 调查增量：沿用算法参数，新增真实 Modeler 大弧尺度/速度/停顿回放及有界落盘诊断。%TEMP%/Inkeys-Draw3-tail-<pid>.log 记录构建与EXE、各拒绝阶段及有限输入尾窗；最多128笔、2MiB，无Move热路径写入。独立审查覆盖写入失败、短写和追加定位失败。现场精确原因以人工采样日志为准，后续位移预算和模型窗口边界修复另按复现证据推进。

2026-10-13 现场日志已确认8笔全部求解但无发布：3笔候选末端角超10°，5笔位移超3px。待实施修订方案见 research/actual-log-repair-plan.md，源码证据见 actual-log-code-analysis.md；包含受控完成态重采样、属性来源与边界映射、自适应局部位移预算和模型时间窗独立于raw。上述为本轮规划，尚未修改算法或放宽现行合同。

最新设计修订优先于前述位移预算方案：按异常抬笔折线的可见性触发，以重构弧长为主控制量，从小到大尝试有限窗口并选最短合格者。最大位移只记录/软约束，不设替代3px的正常修正硬门；保留有效几何与资源边界。详见 actual-log-repair-plan.md 的C节。

实施中方向修订：自适应候选改为入口方向固定、P3=真实Up、末端控制点P2自由的三次拟合。旧local接口保持不变；新入口不再用固定末向的双手柄限制，通过形状项及连续反曲/曲率验收决定窗口。绿色示意要求落实到第2/8笔真实C++对比及自由末向回归。

2026-10-13 最新效果反馈：第6/8笔可信原始点在模型内侧且早于现有入口，窗口选择需考虑偏离位置，向前预留渐变距离；不能只把最终折角磨圆。raw仍为有限辅助，稀疏或零raw仍可拟合。单个离群/远处微小偏差不应放大到整条窗口，需置信度与有限跨度测试。结束方向自由；最终效果由真实C++输出生成对比图评估，不把手绘绿色示意当作数值基线。

最终形状修订：仅有可信raw侧向提示时，在可靠模型段的中点/端点建立法向半空间，限制与证据相反的外鼓补偿；以原三变量最小二乘矩阵度量有限投影，未满足则扩窗。该约束不固定末向、不强制穿过raw，也不恢复最大位移门。稀疏模型入口向前取整以保留提示点前的过渡余量。曲率数值检查尺度取横向回拉的一半而非完整pin长度。当前实现与运行证据见 research/adaptive-verification.md，历史规划段落仅作变更记录。
