# UI3 以任务栏厚度为缩放基准及配置重置

## 目标与状态
2026-10-19：用户明确要求创建任务、调查并规划，批准后再实现。随后用户明确批准并要求开始实现，已激活为 in_progress。

## 需求
1. 在选项的缩放区域、主栏 UI 缩放附近新增“以任务栏高度作为缩放基础量”，默认开启，支持持久化及运行中切换。
2. 开启时，100% 表示主栏标准主体高度等于系统任务栏厚度：底部/顶部取任务栏矩形高度，左/右取宽度。实际像素尺寸不再额外乘一次系统 DPI；用户倍率仍叠乘。
3. 关闭时恢复现有按 DPI 缩放的基准；切换开关保留用户倍率。
4. PPT 四个分页控件保留各自倍率，并统一叠乘 UI 全局倍率及当前 UI 基准；结束放映按钮继承主栏缩放。设置界面 SettingUI 保持其独立缩放。
5. Inkeys3 main.json 的 UI 倍率改用新条目（拟 UI.Bar.Zoom2），默认 1.0；旧 Zoom 不迁移、不回退读取，使旧用户首次使用新版本恢复默认倍率。仅重置此倍率，保留 PPT 单独倍率、SettingUI 及其他配置。
6. 多显示器规则已获用户确认：按当前屏幕任务栏计算；当前屏没有任务栏则按主屏厚度乘目标屏/主屏 DPI 比折算。PPT 保持现有主屏布局归属，使用其布局屏幕的基准，不改变布局屏选择策略。

## 边界与约束
- 100% 对齐的是主栏 80 DIP 标准主体，不包含透明窗口余量、阴影、动画回弹与弹出面板高度。
- 自动隐藏任务栏使用完整厚度，不能使用隐藏后仅剩的可见边缘；查询短暂失败不得让 UI 缩到 0 或闪跳。
- 任务栏尺寸/位置、DPI、显示拓扑变化后刷新基准；无可用任务栏数据时稳定降级到原 DPI 基准。
- 保持当前用户倍率范围 50%–200% 和小数精度、PPT 可用空间约束、拖动/吸附/位置持久化语义。
- 最小修改，保持各文件原编码和换行，关键逻辑适量中文注释。不改传统未编译 IdtFloating，不提交/push，不启动 GUI。
