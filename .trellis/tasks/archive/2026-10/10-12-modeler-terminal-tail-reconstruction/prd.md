# 阶段2：库内抬笔尾段重构与离线验收

## Goal

保持前向模型不变，实现独立终态尾段补丁模块，比较端点平滑位移与有序raw约束重构，验收固定入口/真实终点/原子回退及离线效果成本；不接Draw3或Touch续接。

## Requirements

- 保留真实Up，允许重构调用方提供的未L1尾段；新增独立opt-in库模块，原Down/Move/Predict/Up、参数、Save/Restore和Result不变。
- 固定连接点与入射方向；输出位置、有序来源、替换区间和Apply/NoChange/Rejected，失败原子回退，不伪造速度/加速度/压感。
- 使用实际Modeler回放比较端点平滑位移对照与有序raw约束重构；报告效果、负样本、失败原因、最大位移、长度与成本。

## Acceptance Criteria

- [x] 原19case/128412assert回放与阶段1源码基线逐字段精确相同，原13源/18头保持。
- [x] 新模块覆盖两预测器、圆弧/快转立即Up、S弯/折返/自交/真实角点、稀疏/重复/停笔、非法输入和预算边界。
- [x] Apply入口/终点精确、finite、范围有效、来源有序，不新增不合理自交/显著长度损失/过大形变；失败不发布部分输出。
- [x] 至少一组实际前向模型产生的末钩可量化改善，负样本不误伤，参数/窗口适用范围及拒绝原因可复现；不满足则报告未通过，不能放宽硬合同。
- [x] 既有solution构建、无窗口测试、基线和有界性能通过，共享源码被三消费者使用。
