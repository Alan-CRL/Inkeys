# 恢复 Inkeys3 笔震动反馈并保障兼容回退

## 目标与用户价值
恢复 draw3 迁入 Inkeys3 后丢失的笔触觉体验：支持震动的笔在书写时按工具类型反馈，用户用笔点击工具/类型按钮时得到一次离散确认；可选触觉能力不可用时，绘制与交互照常运行。

## 背景与证据
- 历史提交 `016ed57b`（2026-07-24）新增 draw3 笔触觉模块；`dfe606c8`（2026-08-04）加固 Win7 动态加载。
- 迁移提交 `fc9a8b86`（2026-08-16）创建产品 Host，却未复制独立入口的触觉初始化与依赖注入。独立入口 `inkStrokeModelerTest/main.cpp:107-122` 有 Initialize/注入/Shutdown，当前 `Inkeys/Inkeys/Drawing/Draw3/Draw3.Host.cpp:1592-1593` 仍省略最后一个触觉参数；`Draw3.DrawingController.cppm:97` 默认值为 nullptr，导致已有连续反馈分支不可达。
- 生产工程已登记 `Draw3.HapticFeedback.cpp/.cppm`（`Inkeys/Inkeys.vcxproj:1050-1051`），不需要重新引入独立测试窗口。
- 用户报告以前按钮反馈可用；本地已检索的 demo/生产 Git 历史没有找到 PlayDiscrete 调用者。离散入口恢复以明确的已接受按钮操作为准，不把状态刷新等同点击。

## 需求
### R1：书写反馈恢复
保持原工具合同：普通/硬笔及图形沿用 InkContinuous，荧光笔用 ChiselMarkerContinuous，橡皮用 EraserContinuous；倒转笔尾沿用已有必需 InkContinuous 特殊处理。Laser 保持无连续震动。Hover 可预设波形，实际书写接触由 RTS 判定。

### R2：工具/类型按钮反馈
仅与当前真实笔操作相关、已被现有 UI3 行为接受的工具及类型按钮操作，发送一次离散 Click。鼠标、手指、取消/拖出/禁用操作、程序化状态同步不触发；保持原有点击合并和业务动作次数。覆盖画笔/橡皮工具按钮与四个笔类型按钮；不扩大为几何类型、滑条或全局 UI 震动。

### R3：兼容与安全回退
Windows/WinRT/Pointer API 缺失、非震动笔、取设备或发送失败都不得阻止启动、输入或绘制；可选波形回退到 InkContinuous/Click，基础能力也不可用时静默无反馈。保持动态系统库加载，不提升 SDK/系统最低版本，不覆盖系统默认强度。

### R4：光标、输入与生命周期安全
RTS 仍为画布唯一输入来源；Bar 保持 WM_TOUCH 翻译及 Pointer 兼容鼠标去重，触觉观察不得更改 capture、光标归属/显隐或消息默认处理。离开、取消、选择/隐藏、Touch Pan 隔离、切换设备、Host 停止/重启时清除连续反馈及过期请求；不能把旧笔控制器用于新鼠标/触摸/另一支笔。跨线程资源与 COM 生命周期必须有唯一明确所有者。

## 验收条件
- A1（R1）：生产 Host 实际创建、初始化并注入触觉对象；控制器按原工具映射触发，Laser 不触发连续反馈。
- A2（R2）：一次有效笔按钮操作最多一次 Click；取消、鼠标/触摸、程序刷新和重复兼容消息均零次；业务动作次数不变。
- A3（R3）：无 API/无设备/波形缺失/发送失败路径可继续运行；动态依赖及基础波形回退通过静态和无窗口测试验证。
