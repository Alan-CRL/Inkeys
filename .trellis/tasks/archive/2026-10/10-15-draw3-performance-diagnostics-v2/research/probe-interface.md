# Resource probe v2 frozen interface

CLI is dispatched before config, UIAccess, product or HWND initialization. `--draw3-resource-probe-list` and `--draw3-resource-probe-test` are CPU only; `--draw3-resource-probe <case_id> <absolute_existing_case_dir> <session_id>` has exactly 5 argv including EXE. Any unknown `--draw3-resource-probe*` prefix exits 2. Session is nonempty ASCII `[A-Za-z0-9_.-]`, max128. Case directory must be absolute and existing; each worker exclusively creates `.draw3-resource-probe.lock` with CREATE_NEW and never overwrites a start/result.

list stdout is UTF8 JSON: schema_version=1, probe_revision=2, capability_marker="INKEYS_DRAW3_DIAGNOSTICS_V2", profile="draw3-resource-v2-fixed", comparison_path="offscreen_embedded_301_302_contract", native_budget_ms=8000, warmup_iterations=1, measured_iterations=4, cold_iterations=1, call_capacity=4096, case_count=40, cases array. Each case: case_id, profile_id (backend independent pair key), requested_backend="hardware"|"warp", resource_bytes, write_bytes, draws_per_iteration, width,height, update_method, constant_write_method. Case_id is `<backend>-<profile_id>`; no other IDs accepted. Parent case timeout=20s and overall matrix deadline<=480s. Workers serial.

Files: `probe-start.json` atomically published before D3D creation; `probe-stage.json` bounded stage checkpoint (initializing, cold, warmup, measure, drain, exporting); `probe-result.json` atomic final publication; raw `calls.csv`, `resources.csv`, `gpu.csv`. Each file only uses case directory. No per-call disk I/O. Probe uses no HWND/swapchain/Host/RTS/config. Lock handle stays alive throughout worker. No retries or fallback backend.

start/result identity fields: schema_version=1, probe_revision=2, capability_marker, profile, comparison_path, case_id, profile_id, session_id, final_pid (integer), process_start_filetime_utc (decimal string), exe_path (absolute), output_directory (absolute), requested_backend. Result also actual_backend (requested on successful D3D creation; empty if unavailable), exit_code (integer), status="complete"|"partial"|"unsupported"|"failed", reason, first_hresult, first_failure_stage, qpc_frequency, start_qpc,end_qpc, thread_cpu_ms, process_cpu_ms, adapter object (description,vendor_id,device_id,subsystem_id,revision,dedicated_video_memory,dedicated_system_memory,shared_system_memory,driver_version,driver_version_available), feature_level, device_creation_flags, caps (query_hresult,map_no_overwrite_dynamic_srv,map_no_overwrite_dynamic_cb), case_definition (same as list entry), shader object (vertex_resource_id=302,pixel_resource_id=301, vertex_bytes,pixel_bytes, vertex_fnv1a64,pixel_fnv1a64; FNV identity is not a cryptographic package hash), cold_iterations_completed,warmup_iterations_completed,measured_iterations_completed, calls_seen,calls_retained,calls_dropped, invalid_intervals, drain_complete, gpu_status. The package manifest EXE SHA links executable identity; native does not rehash own EXE.

Results preserve partial samples on deadline. complete exits0; unsupported exits3; failed exits4; partial exits5; argument rejection exits2. Failed start/result export exits4. Parent checks identity against held worker PID, FILETIME, EXE, case, session and directory. Start is required even if worker fails. Nonzero exit with claimed complete is invalid. There is no separate nonce argv: `(session_id,case_id,exclusive newly created directory,PID,FILETIME,EXE)` is the unique immutable identity.

calls.csv columns: call_serial,phase,iteration,operation,site,resource_id,related_resource_id,start_qpc,end_qpc,valid_interval,hresult_available,hresult,map_type,map_flags,subresource,offset_bytes,size_bytes,vertex_count,instance_count. phase=cold|warmup|measure|drain|initialization; QPC integers, no inferred GPU completion. void calls hresult_available=0. Stage checkpoints are outside timed calls.

resources.csv columns: resource_id,role,resource_kind,byte_width,width,height,format,usage,bind_flags,cpu_access_flags,misc_flags,structure_byte_stride,create_hresult. Exact actual descriptor, creation attempts retained.

gpu.csv columns: phase,iteration,status,frequency,begin_timestamp,end_timestamp,draw_calls,marker_mask. Optional queries are nonblocking during batch; one explicit probe-only Flush and bounded event/GetData DONOTFLUSH drain after the finite batch. Drain/Flush costs are raw separate operations and never presented as production behavior or shader busy. Missing/not-ready/disjoint/query_failed remain unknown.

40 cases = 20 fixed profiles x hardware/WARP: ink_large_discard_idle, ink_small_discard_idle, ink_large_discard_draw, ink_small_discard_draw, ink_large_no_overwrite_draw, ink_large_write4096_draw, constant48_fields_idle, constant48_fields_draw, constant48_memcpy_draw, constant48_volatile_draw, ink_default_update_draw, constant48_default_update_draw, highlighter_large_draw, composite_large_draw, composite_small_draw, submission2_draw, submission3_draw, submission6_draw, target1080_clear_copy, target64_readback. Large ink=3200000B stride16, small=256B stride16, highlighter=4800000B stride24, CB=48B. Default write=32B (highlighter48B); ordinary target64x64, clear/copy1920x1080. Cold1+warmup1+measure4, native wall budget8000ms; any driver call itself may hang so supervisor remains required. NO_OVERWRITE checks capability, first DISCARD initializes then uses fresh disjoint offsets across all iterations, never reuses GPU-visible range.
