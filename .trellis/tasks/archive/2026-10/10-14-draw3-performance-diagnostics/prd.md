# Draw3 性能诊断包与输入延迟分析

## 目标与用户价值

为低性能和非常见电脑上的 Draw3 绘制卡顿、不跟手、低帧率及间歇性长帧提供可交付的一键诊断包。用户运行 CMD 即可启动采集，无须预先在软件中打开调试设置；收集结果能够定位初始化异常、计算/渲染瓶颈和 RTS 输入到成功绘制的延迟。

## 背景与授权

- 用户报告部分设备绘制卡顿和不跟手，兆芯 KaiXian KX-U6780A 曾只有约 1 FPS；该现场尚无本次采集证据。
- 既有 Win7 着色器任务提供 CMD → PowerShell → 软件运行及自动收集日志的参考流程。
- 2026-10-14 用户明确要求开启 Trellis 任务，并批准本任务完成规划、实现至最终；不重复请求规划/实施授权。
- 当前分支为 diagnostic/performance，任务创建前工作区干净。

## 需求

### R1 一键运行和可交付结果

提供 CMD/PowerShell 诊断入口、使用说明和离线分析入口。诊断启用只对被启动的进程生效，不要求用户先勾选实验选项，不静默修改或覆盖用户持久化配置。每次会话有唯一结果目录与身份，包含软件版本/架构、执行参数、起止状态和采集完整性。已运行实例、启动失败、非正常退出、容量耗尽和无法采集的项目必须明确报告。

### R2 设备及初始化环境

记录 CPU、内存、GPU/驱动、Windows/进程架构、显示分辨率/刷新率/DPI 及相关运行环境；记录 Draw3 实际 D3D driver type、feature level、适配器、presenter/回退、RTS 初始化及重要失败结果。无法获得的信息以缺失/错误表示，不用推测值替代。

### R3 帧耗时及波动

采集 Draw3 实际计算、建模/预测、几何/上传/栅格、合成、呈现以及等待/间隔的耗时和帧总耗时，保留阶段口径与嵌套关系。记录输入数量/积压、工具、活动状态、画布尺寸/脏区、重建/重放/失败等与波动相关的事实。分析有效样本分布、长帧、连续活动间隔和成功呈现间隔，闲置后首帧不误判为卡顿；不能把 CPU 提交耗时当作 GPU 执行耗时。

### R4 RTS 到绘制的输入延迟

诊断覆盖真实 RTS 的 Down/Move/Up 与批次输入，记录从回调收到输入、发布/等待、绘制线程消费、处理、渲染到成功 Present 返回的阶段及总延迟。关联必须基于真实输入身份/序号及本帧贡献/成功结果；拒绝、合并、缺失、掉样、失败和无法证明落地的样本分别保留。成功 Present 返回属于软件完成证据，不能宣称物理屏幕像素可见或触笔到光子延迟。

### R5 正常模式性能隔离及诊断成本

默认关闭。未按诊断入口或显式实验性能输出选项启动时，不执行新增时钟读取、统计、追踪、格式化、文件写入、GPU query、线程启动和采样分配；不得为了诊断改变正常输入数据、算法、渲染质量、等待策略或强制持续刷新。诊断模式使用固定有界存储、无热路径文件/控制台 I/O、无逐点日志，输出与分析尽量在采集线程之外或结束后进行；记录掉样和容量，防止长时间测试无限增长。

### R6 实验性能输出选项

沿用现有实验调试选项的配置归属，添加单独且默认关闭的 Draw3 性能数据输出入口。明确重启/下一次会话的生效方式和结果位置；诊断包仍可独立启用，不依赖勾选此项。不得因本任务迁移其他配置或开启耗时的着色器/像素/光标调试。

## 验收标准

- [x] A1 / R1：CMD 可找到或接收 EXE 路径，设置进程内诊断状态并启动正确实例；产出独立可分享结果，失败/提前终止有明确状态。
- [x] A2 / R2：结果同时含硬件采集和软件实际初始化/回退证据；缺失和异常不伪报成功。
- [x] A3 / R3：原始帧数据和报告能区分计算、渲染提交、呈现阻塞与间隔；分母、掉样、失败、idle 边界及阶段嵌套可核查。
- [x] A4 / R4：真实输入链有可验证关联与延迟分解；失败 Present、过期身份、覆盖或无贡献不算成功；Down/Move/Up 或不支持原因显式可见。
- [x] A5 / R5：默认关闭路径无诊断分配、时钟、统计、query、日志和额外线程；固定预算、掉样与异常测试通过；采样不改变业务结果。
- [x] A6 / R6：实验选项默认关闭、配置读写和启动消费者一致；诊断启动覆盖只影响该进程。
- [x] A7：离线分析有可重复的合成数据测试，纯 CPU 计量/关联测试覆盖关闭、阶段计时、容量、错误和成功路径。
- [x] A8：遵守原文件编码/换行和最小修改，git diff --check 通过；完成既有 Solution 的 Debug|ARM64 编译及适当无窗口测试，环境故障单独报告。

## 范围外与验证边界

不优化或更改 Draw3 绘制算法、驱动选择、呈现路线、帧率限制、UI3 调度和其他产品功能；不添加通用遥测服务或自动上传。当前任务不启动可见/隐藏 GUI 或使用 Computer Use；真实兆芯、Win7、低端设备上的实际性能与光学可见性需要用户现场运行诊断包，不能由本机编译或数值测试代替。未经另行明确要求不 commit、不 push、不写 GitHub 远程内容。
