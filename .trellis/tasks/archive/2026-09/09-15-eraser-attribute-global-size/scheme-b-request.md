二、最终设计：方案B

标准朝向从左到右：

[24 / 32 / 40 DIP 三个圆形橡皮] | [清空] | [自动粗细  ▾]

核心要求：
- 清空位于整条属性栏正中。
- 正常空间下，属性栏中心、清空按钮中心、主栏擦除按钮中心对齐。
- 属性栏是独立浮条，高度与主栏相同，
  沿绘制属性规则选择上/下展开、工作区避让和组倒转。
- 三个圆本身就是尺寸选项，没有大矩形底座，没有底部高亮短横条。
- 稳定展开时显示真实24/32/40 DIP，不透明白色实体、灰色轮廓与双竖纹。
- 选中主要使用圆本身的青色内描边及克制的边缘光。
- 自动粗细为一个完整圆角长方形，
  背景、外框、Hover、Pressed、Selected均统一，
  仅主体和小三角的点击动作不同。
- 自动粗细采用专用SVG：原橡皮图形语言，右下角增加路径化“A”标识。
- 灵敏度浮窗只有两层：
  标题行左“灵敏度”、右禁用齿轮；下方低/中/高三个等宽选项。
- 两个浮窗均采用绘制属性同款展开/收起回弹。
  开合允许短暂整体缩放，稳定展开后严格恢复1:1。
  这明确替代旧“开合期间也禁止缩放”的限制。

四、布局、居中、倒转和裁剪

1. 清空处于属性栏几何中心，不只是看起来大致居中。

   分别计算左侧圆形组和右侧自动按钮组的需求，
   两侧采用相同的外部分配宽度，取能容纳两组的合理值；
   清空在中间，两条分割线对称放置。
   自动按钮在自己的分组中居中，不为填满空间强行拉宽。
   不通过恢复三个大矩形底座来凑对称。

   默认UI缩放可参考约360 DIP量级的总宽，
   最终由内容与共享Metrics计算，不写死适用于全部屏幕。

2. 未触及工作区边缘时：

   panel.centerX = mainEraserButton.centerX
   clear.centerX = panel.centerX
   menu.centerX = automaticWholeButton.centerX

   子浮窗锚定完整自动按钮，不只锚定小三角，
   也不与主栏擦除按钮共用中心。

   y位置、间距、上方/下方优先级复用绘制属性的实际规则。
   不新增气泡尾巴、连接小三角或拖动把手。

3. 屏幕边缘优先保证可见，再整体移动到工作区内。
   此时允许属性栏与主栏按钮暂时无法严格中心对齐，
   但清空始终处于属性栏中心。
   菜单独立进行工作区修正。

   极窄空间复用必要的溢出策略，不压扁圆、不缩小稳定态真实预览。

4. 倒转时遵循现有属性体系交换两侧分组，清空仍在中轴。
   不把文字、SVG中的A或橡皮纹理镜像成反字/旋转180度。
   菜单方向在本次展开中保持稳定，
   不随指针轻微移动反复翻边。

5. 面板宽度不能随实时笔速、选中描边和Hover动画来回变化。
   三个预览同时存在，选中哪一档都不改变其他圆的尺寸。

6. 布局、绘制、命中、光源、脏区与窗口范围使用同源几何。
   保留成功呈现后才CommitPresented的原则。


五、24/32/40 DIP预设与旧配置迁移

1. 基础档位改成24/32/40 DIP，默认中档32。
   更新BaseSize、RestoreBaseSize、ResolveSizes、配置校验、
   UI提示、选中判断、点击映射和测试。
   移除16<<index等旧倍增关系，采用明确的预设表/映射。

2. 旧持久化值按档位迁移：
   16→24，32→32，64→40。
   已保存24/40再次读取保持不变，迁移幂等；
   缺失/非法值依现有规则回32。

   不重置五入口类型、penResponse、灵敏度或面积辅助。
   不修改历史文件中已存的逐点半径。

3. 继续以B为standard和固定直径，沿现有派生方式：

   B=24：minimum/standard/maximum=12/24/120 DIP，Touch起点12。
   B=32：16/32/160 DIP，Touch起点16。
   B=40：20/40/200 DIP，Touch起点20。

   固定模式分别使用24/32/40，不回到旧50 DIP默认值。
   只调整尺寸属性；速度门槛、时间参数、精细平台、
   0.85/1/1.15灵敏度增益、物理标尺及面积报告换算都不重调。
   B=32/中灵敏度必须保留已认可的现有行为。

4. 稳定展开时预览像素直径与实际工具一致。
   正常等比DPI下：
   pixelDiameter = presetDip * effectiveDpi / 96。

   先核查实际D2D单位模式、显式换算和父变换，
   沿已有DiameterToCanvasPx/frameZoom方案避免重复缩放。
   主栏自定义UI缩放不能改变工具预览与画布真实直径的对应关系。

5. 圆心竖直居中，超过面板高度只裁上/下，
   不改变圆形、不扩大透明命中、不做缩略图。
   默认三档较小仍需保留超高/特殊缩放路径。


六、圆本身作为按钮：不透明、等边距、青色内描边

1. 删除三个尺寸后方的大矩形背景及底部高亮小横条，
   清理对应旧绘制/动画分支，不是仅把背景alpha降低。
   不常驻加一排数值文字；提示显示“小/中/大号·24/32/40 DIP”。

2. 预览采用擦除Contact外观：
   白色不透明填充、灰色轮廓、双竖圆头纹理；
   继续共享EraserGripVisual的结构比例。

   稳定态预览自身alpha=1。
   开合时只受整个面板的过渡透明度影响，不再额外乘0.5。
   不直接修改共享ERASER_GRIP_OPACITY，
   避免把画布Hover也改成全不透明。

3. 相等间距指圆边缘之间的可见留白相等，不是圆心等距。
   默认UI缩放可先采用16 DIP边缘间隔：

   centerDistance(i,j) = radius(i) + gap + radius(j)

   gap是UI布局量，圆直径是工具尺寸；
   必须换到同一坐标空间计算。
   各缩放下两个可见间隙都应相等。

4. 普通态白/灰；Hover只产生克制边缘反馈，无方形底色。
   选中时将圆自身轮廓改为主题Accent青色，适度向内加粗，
   并应用与主栏协调的边缘光。
   保留白色主体，不额外套更大的装饰环，不把整个圆染青。

   外直径不变。日常按压和选中不能改变真实预览半径，
   按压反馈通过光照/轮廓/对比度表达。
   键盘焦点与选中态保持可区分。

5. 允许合理的不可见命中扩展，方便Touch点中24 DIP圆。
   按相邻控件中间边界、面板可见区域裁剪，不能互相覆盖抢点击。
   不再用旧70 DIP方槽作为可见或无界命中底座。
   同界命中明确，隐藏/被裁掉的区域不挡画布。
   Touch及其兼容Mouse消息不能导致重复选择/写配置。


七、自动粗细一体化与SVG

1. 主体和三角共用一个背景、外框、圆角、按压与悬停动画、
   选中状态及边缘光。
   不再分别画两块底色，再套一个共同圆角clip。

   移除明显内部竖分割线，以留白表达箭头区域。
   Hover任一区域整块效果相同；跨内部边界不重播Hover、
   不出现灰缝、两种底色或不同缩放。
   Pressed也作用于整体。

2. 仍保留两个动作区：
   主体切换全局自动粗细；
   右侧只开/关灵敏度浮窗。
   Mouse/Pen/Touch都采用这套语义，
   不采用系统ToggleSplitButton两侧Touch都弹菜单的默认行为。

   按下时记录动作区，跨内部边界不在释放时改为另一命令。
   沿现有捕获/取消规则处理，避免一次点击同时切换和弹窗。
   三角视觉小，但命中宽度要足够。

3. 自动开启时整块选中，青色边缘光来自主栏同一个Accent解析。
   菜单打开可通过箭头朝向/反馈表示，不让右半边单独变成另一种底色。
   自动关闭但菜单打开时不能伪装成已开启。
   保留全局Mixed状态及“混合点击统一开启”的行为，
   不另设影子总开关。

4. 新建专用自动粗细SVG，不修改通用擦除资源影响其他按钮。
   主体保留当前倾斜橡皮风格，右下角加清晰的A，
   A与橡皮留负空间，不叠加方形徽章底，不使用星光/AI装饰。
   A使用SVG路径，不依赖运行时字体或外部资源。

   使用项目加载器支持的SVG特性，按现有资源方式登记。
   普通/选中/禁用继承主题色，不在SVG硬编码一份独立青色。
   在实际主栏图标尺寸下检查A是否清晰、是否与三角拥挤。

5. 本面板所有选中控件的边缘光统一核验：
   自动按钮、圆形选项、灵敏度选项都应是主栏同款Accent，
   不只是图标/文字青色、边缘却仍为SurfaceFrame灰色。

   非选中、禁用、主表面和分割线仍各用原有主题规则，
   不把整条窗口边框与全部分割线都染青。
   深浅主题、边缘光/动态光开关、设备资源重建保持一致。


八、紧凑灵敏度浮窗

改成两层：
第一层左“灵敏度”，右小齿轮。
第二层低/中/高三个等宽选项。

删除原来底部整行“自动粗细设置”及其额外长分割线和留白。
齿轮继续禁用，提示“自动粗细设置，暂未开放”，
本轮不实现设置页导航，不执行空动作。

自然尺寸可从约180×92 DIP开始，
依据原有字号、行高、触摸命中及缩放合理调整。
紧凑通过合并层次、减少空白实现，不靠缩小文字和点击目标。
不再增加常驻说明行或冗余框线。

菜单以完整自动按钮为中心，按工作区决定上下方向。
选灵敏度后菜单和属性栏保持打开；
自动关闭时也能预选，不因此开启自动或改变基础大小。
低/中/高实际参数维持现有值。


九、两个浮窗的回弹必须与绘制属性一致

1. 对照DrawAttributeBar复用其实际几何动画、紧凑/展开状态、
   EaseOutBack/EaseInBack、时间线、阶段衔接及透明度曲线。
   不能只改曲线名，却仍然只是淡入或10 DIP短平移。

   属性栏从主栏擦除按钮处展开/收起；
   子菜单从完整自动按钮处展开/收起。

2. 明确允许开合期间整组短暂统一缩放。
   稳定展开后精确恢复正常比例，24/32/40 DIP真实大小不变。
   圆形始终等比，不单独压扁。
   日常Hover/Selected不借此改变预览半径。

3. 几何与透明度分离：
   几何允许合法overshoot；alpha有界。
   不把几何进度统一clamp到0..1消掉回弹，
   不因EaseInBack早期负进度就提前判隐藏。
   宽高/缩放必须合法，按正确生命周期判断显示结束。

4. Bounds、脏区、阴影与裁剪覆盖实际动画及回弹越出范围，
   不能只用最终panel/menu矩形把回弹截断。
   区分“内容在当前外壳内裁剪”和“窗口容纳动画外壳/光影”。

5. 子菜单跟随父按钮的当前呈现位置/变换，
   父关闭时子正确收尾，不能留在旧目标坐标或孤立悬空。
   半程反向、连续点击、换边不跳帧、不重新从初始值播放。
   复用统一帧时钟，不每帧重启SetTar造成永不结束。
   全局动画关闭/速度设置有效，稳定后正常休眠。

6. 实际呈现几何和命中快照同步。
   展开动画经过主栏擦除按钮附近时，
   打开面板的同一次按下/释放绝不能同时触发中央“清空”。
   清空必须由新的独立点按触发。
   不以永久禁用全部动画中交互来掩盖所有权问题。
