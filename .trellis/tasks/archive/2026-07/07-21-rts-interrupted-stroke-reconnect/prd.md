# RTS 断触墨迹暂留与续接

## Goal

在绘制线程中把物理 Up 后的墨迹短暂保留为可续接状态；若同一硬件与同一工具状态在末端延伸方向上于 80ms 内重新 Down，则复用原预测模型和渲染资源继续同一笔，修复屏幕瞬时断触造成的笔画断裂。未命中时按既有模型 Up、L2 提交和资源回收流程完成。

## Background

- 当前 `DrawingController::Run()` 在读到 Up/Cancelled 后立即向 `StrokeModeler` 发送 `kUp`，同帧把完成几何提交到 L2，随后回收 contact 和 runtime。
- `StrokeModeler` 接受 `kUp` 后结束当前 stroke，不能再用新 Move 延续；因此续接必须发生在模型 Up 之前。
- contact 池最小容量为 32，runtime 预热 16 个；暂留必须有时间和数量上界，且仅剩候选时不能维持 120Hz 空转。
- `retainPredictionOnUp` 只选择最终尾段来源，不承担断触续接开关语义。

## Requirements

### R1. 暂留与终态

- 新功能默认开启，由 `StrokeModelConfiguration` 中单个 bool 控制，后续外部设置可在构造控制器前覆盖；不增加命令行参数或运行时 Set/Get。
- 仅物理 `Up` 可进入暂留；`Cancelled` 继续立即终结且不得续接。
- Up 先以 `kMove` 保留最终坐标和笔状态，保存原始 Up 快照；80ms 超时后才向同一模型发送 `kUp`。
- 暂留期间保留 modeler、真实点、prediction、L0/L1 CPU 状态、提交游标、宽度估算器和 contact handle。

### R2. 匹配策略

- 覆盖 Touch、Pen、MouseLeft、MouseRight，以及普通笔、荧光笔、橡皮。
- 新旧 `InputDeviceType`、批次选择工具、有效工具、宽度模式、倒转状态和压力屏蔽策略必须一致。
- 间隔不超过 80ms；物理 Up 作为 `kMove` 后立即冻结 prediction，按新 Down 间隔选择预测位置；超出预测时域使用最后预测位置，并记录超出时长。
- 预测有效时把模型 Up 到所选预测位置的位移平移到物理 Up，比较新 Down 与预测落点的误差；预测位移方向只用于诊断和候选排序，不以终点瞬时速度方向硬拒绝曲线。
- 预测落点误差允许 4px DPI 基础余量、预测位移的相对余量和随超出预测时域增长的不确定度；预测桥接距离以 96 DPI 下 64px 为基础下限，按预测平均速度与抬笔前滤波输入速度的较大值自适应，最终不超过 256px，并为边界比较保留不超过 1 个当前渲染像素的数值容差。
- 冻结预测端点失败后，先尝试预测弦加速走廊；曲线使短预测弦滞后时，再以有效的预测末端速度方向作为第二条桥接方向轴。两条走廊都只在目标超过预测时域、所选方向与桥接夹角不超过 35°且速度比位于 `[0.35, 2.75]` 时启用；纵向距离按 `max(预测位移, 参考速度×完整间隔)`，横向与纵向分别限制误差，禁止提高全局角度或扩大圆形落点容差。
- 若新 Down 仍在预测时域内但冻结预测端点失败，只允许预测末端速度方向走一条更严格的补救路径：间隔不超过 35ms、方向夹角不超过 15°、速度比位于 `[0.5, 2.0]`，并继续使用现有动态距离和纵横误差限制；不得让预测弦或普通端点判定共享该放宽。
- prediction 为空、位置/时域无效或工具禁用 prediction 时，回退 96 DPI 下回看 12px、至少 4px 的真实尾方向和滤波原始末速，维持原 32px、35°和速度包络。
- 多个候选同时匹配时，依次选择归一化预测落点误差更小、实际命中走廊的方向夹角更小、距离更短、Up 时间更新者；回退候选继续以速度比例误差作为首排序量。

### R3. 续接、资源与调度

- 匹配成功时回收旧 handle，把新 handle 绑定到原 runtime，并把新 Down 作为连续时间的 `kMove` 输入原模型；禁止 Reset 原模型。
- 未匹配的新 Down 正常初始化新 runtime，旧候选继续等到超时。
- 最多保留 8 个候选；第 9 个进入前立即终结最旧候选。
- 超时或容量淘汰走既有批量完成路径：模型 Up、一次 L2 resolve、活动层重建、指标提交、handle 回收和 runtime Reset。
- 仅剩暂留候选时停止 1ms timer period 和 120Hz 帧循环，等待输入/控制 wake 或最近截止时间。
- resize 从 CPU 状态重建候选几何；clear 延续现有延迟到活动集合为空的语义，新增等待最多 80ms。

### R4. 诊断与兼容

- 启动打印开关、窗口、角度、速度比、距离上限和候选上限。
- 每次成功续接打印设备、工具、运动来源、间隔、实际/预测距离、预测落点误差、预测时域、参考/原始速度、预测位移角度、终点速度角度、实际选择角度和是否使用末端方向走廊；正常模式不逐候选打印拒绝原因，人工测试模式只打印一次最接近候选的拒绝诊断。
- 绘图窗口创建后先保持隐藏，完成透明 presenter 初始化并提交首个透明画布后才显示，避免暴露 HiEasyX 的白色窗口类背景。
- 保持 Windows 7 SP1 + KB2670838、ARM64/x64/x86、L0/L1/L2、指标和 `retainPredictionOnUp` 既有契约。
- 只修改本功能必要的 `draw3`、测试和 Trellis 文档；保持源码 UTF-8 BOM + CRLF，且不修改未跟踪 `Vcpkg/`。

### R5. 断触注入测试开关

- 增加默认关闭的独立编译期测试开关；开启时 RTS 对持续物理 contact 随机合成 Up、丢弃 20–70ms Move，再以首个恢复采样生成新的 Down。
- 每个 contact 在 180–520ms 后随机触发，允许同一长笔画重复触发；使用固定容量状态和合成 contact id，不在同步回调中分配。
- 关闭时编译期移除模拟状态、随机数、锁和日志访问，Down/Move/Up 直接调用原 `ContactInputCoordinator` 发布路径。
- 控制台输出计划丢弃时长、实际恢复间隔和合成 contact id，供人工核对续接窗口。

## Acceptance Criteria

- [ ] 80ms 内满足设备、工具、方向、距离和速度条件的新 Down 复用原 modeler，并生成连续桥接段。
- [ ] 超时、Cancelled、状态不一致、动态距离上限或预测落点误差失败时不续接；真实尾回退仍要求方向和速度条件。
- [ ] 普通笔、荧光笔、橡皮以及四类 `InputDeviceType` 均使用同一判定契约。
- [ ] 暂留候选不超过 8 个；持续快速 Up 不导致 runtime/contact 无界堆积。
- [ ] 仅有候选时绘制线程不按目标帧率空转，最近候选到期后能自行唤醒清理。
- [ ] 多候选选择确定，Up 与新 Down 同帧到达也可匹配。
- [ ] resize、clear、多个完成 contact 的批量 L2 提交和 Present 行为保持正确。
- [ ] 控制台启动提示和成功续接提示包含约定字段，拒绝路径不刷屏。
- [ ] 高置信加速自适应只救回方向与速度连续的候选，超过 35°、速度比范围、动态距离上限或无可靠方向时仍拒绝。
- [ ] 圆弧使预测短弦偏离超过 35°时，若预测末端速度方向、速度比和纵横误差均通过，则使用第二方向走廊命中；末端方向也超过 35°或速度比越界时仍拒绝。
- [ ] 预测仍覆盖新 Down 时，仅有 `≤35ms`、末端方向 `≤15°`、速度比 `[0.5,2.0]` 且纵横误差通过的候选可由时域内终速走廊补救。
- [ ] 首个透明画布提交前绘图窗口保持隐藏，启动时不暴露白色窗口类背景。
- [ ] 断触注入开启时完整经过旧 Up/新 Down/handle 迁移路径；关闭配置可单独完成 Release 构建且输入热路径保持原直接发布分支。
- [ ] 自动测试覆盖 prediction 时域选择、曲线预测位移、落点误差/数值容差、预测/回退距离边界、兼容状态、模型连续生命周期和候选选择。
- [ ] ARM64 Debug/Release 完整解决方案构建、ARM64 测试与 Release 严格运行指标通过。

## Out of Scope

- 不新增命令行选项、设置 UI、运行时 setter/getter 或持久化墨迹格式。
- 不修改第三方 `additional/` 中的 stroke modeler 实现。
- 不让 prediction 进入正式持久化记录。
