# 颜色按钮描边样式

## Goal

保持 UI3 绘制属性栏在 `dev` 中原有的色块尺寸、间距、圆角、布局、资源和交互，仅取消选中态灰色描边加粗，并将普通灰色描边调整得更柔和。

## Requirements

- 仅修改 UI3 Bar，不同步修改传统 `IdtFloating`。
- 11 个色块继续使用原有 `BarUiShapeClass` 圆角矩形、`30×30` 尺寸、`4px` 圆角和 `5px` 间距。
- 保持原有属性栏尺寸、粗细预览尺寸、右侧工具区位置、预设颜色和点击命中行为。
- 保持原版 `colorSelect.svg`、选中判断及鼠标按下切色语义。
- 选中与未选中色块的灰色描边均保持 `1px`，选中态不再加粗描边。
- `SwatchFrame` 使用随主题变化的柔和中性灰：浅色主题 `RGB(176,176,176)`，深色主题 `RGB(80,80,80)`。
- 丢弃此前的超椭圆、缩放动画、Accent 外框、动态勾色、紧凑布局和圆角调整实验。
- 保持文件原有编码、换行和格式，仅添加必要的简短中文注释。

## Acceptance Criteria

- [x] `Bar.Main.cpp` 相对原版只改变 11 个选中分支的描边目标值。
- [x] 色块尺寸、间距、圆角、面板尺寸、粗细区域和右侧工具区位置均与原版一致。
- [x] 选中与未选中描边均为 `1px`，原版 SVG 勾继续正常显示。
- [x] 深浅主题的灰色描边比原来的统一 `RGB(127,127,127)` 更柔和。
- [x] `Bar.Main.cppm` 和 `colorSelect.svg` 与当前分支基线无差异。
- [x] `InkeysRepo.sln` 的 `Debug | ARM64` 完整构建通过。
