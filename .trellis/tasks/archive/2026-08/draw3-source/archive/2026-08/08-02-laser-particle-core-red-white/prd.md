# 激光粒子核心红偏白

## Goal

把激光粒子中间填充从接近纯白改为红偏白，并加入微小随机，使白底背景上仍清晰可辨。

## Requirements

- 粒子核心目标色为红偏白，不得在最亮时变成纯白。
- 每粒核心白度有微小随机抖动，避免整片均匀死白。
- 不改变辉光色、发射率、尺寸与运动语义。
- 同步 CPU helper 与 PS 的 coreColorMix 公式，并更新过期默认值断言。

## Acceptance Criteria

- [x] 用户确认白底上粒子核心仍可见，偏红白而非纯白。
- [x] 用户确认不同粒子核心色相存在轻微差异。
- [x] ARM64 Debug/Release 构建通过，无窗口控制台单元测试与当前默认配置一致。
