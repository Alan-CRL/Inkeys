# 自由画布平移与动态渲染

## Goal

让每页墨迹使用稳定的 Canvas 世界坐标，并提供低延迟的键盘/双指平移、自然惯性、笔接管以及随设备性能自适应的动态清晰渲染，为后续 Inkeys3 白板 UI 提供画布内核。

## Requirements

- `InkViewport.x/y` 表示屏幕左上角对应的 Canvas 坐标，当前 `scale` 固定为 1；视口限制为约 `+/-1048576 DIP`。
- 方向键一次移动可见内容 64 DIP，忽略 autorepeat，不产生惯性；每页独立保存/恢复视口。
- 静止批次从零 Touch 开始，前两指在 180ms 内落下才进入平移；首指已经产生的任意工具 L0/L1 内容必须取消并重建。
- 平移中额外 Touch 不绘制；剩余一指可继续拖动；最后一指抬起后进入惯性。
- 惯性中首指等待 180ms 且不绘制；第二指及时到达则继承动量，超时后首指本次不补画，迟到的其他指仍可绘制但不能再组成平移。
- 重新抓取惯性或触点拓扑变化时，旧速度只作为“没有任何新有效 Move 就释放”的一次性候选；首个有效 Move 立即作废候选，活动/释放速度只等于统一上限裁剪后的新直接速度，绝不叠加旧速度。
- Pen/Mouse 已接触时阻止新双指手势；活动双指跟手平移期间新 Pen contact 忽略到本次抬笔，不能打断平移，也不能显示接触光标或触发触觉。Touch Pointer 只记录事件类型，不接管持久 cursor owner；Touch Pan 期间除非确认真实 Mouse 接管，系统光标始终隐藏。惯性阶段 Pen hover 加强减速，新 Pen Down 立即停止惯性并从固定视口绘制。
- Undo 只改变墨迹，不改变视口；视口变化丢弃屏幕相关热前像，但保留 Canvas-local composition cache。
- 平移时按速度方向预建 tile；性能不足时优先保持输入和帧率，以可信旧快照模糊重投影覆盖已有区域，未知区域允许显示真实透明背景。
- 模糊兜底不得写入 L2、文档、history、热前像或 composition cache；Laser、粒子和光标始终按当前视口重画。
- 双指/惯性产生任意有限小数 viewport 后，新完成的小笔画仍必须捕获并命中热前像；旧 viewport 的热前像继续失效。
- 平移恢复只查询当前/预测区域内实际含内容的 tile；不得因 Resize 重算 Canvas-local footprint，长笔画重建单个 tile 时不得无条件处理整条离区几何。
- 默认惯性使用约 `6000 DIP/s^2` 的克制网页级线性减速度；Pen hover 仍使用 `12000 DIP/s^2`。惯性中重新双指必须立即抓住并继承较小残余速度，惯性阶段的新 Pen Down 必须同帧刹停并开始绘制。
- 主窗口覆盖主显示器但底部保留 `1` 个物理像素并保持 TOPMOST；当前独立测试宿主允许激活，以便用方向键验证平移，接入 Inkeys 后再恢复 NOACTIVATE。
- 暂不实现 pinch、rotation、边界拉伸/回弹和 EDID 物理手掌距离判断。

## Acceptance Criteria

- [ ] 键盘和双指能够平移负坐标及远离原点的画布，绘制结果仍固定在 Canvas 坐标。
- [ ] 180ms 边界、延迟第二指 Down anchor、终态首指 handoff、惯性/拓扑一次性候选、额外触点及 Pen hover/Down 均通过自动或人工验证。
- [ ] 翻页恢复各自视口，离屏 Undo 不移动当前视口，Resize 后能从文档恢复当前视口内容。
- [ ] 低速时可见区逐步保持/恢复清晰；高速或过载时不阻塞输入，可信快照只在覆盖交集内兜底且不会污染权威层。
- [ ] 小数 viewport 下新笔 Undo 命中热前像；平移规划不遍历无关离区墨迹，单 tile 重建只提交相交笔段，Resize 不重算不变的 Canvas-local footprint。
- [ ] 惯性滑行距离达到触摸网页级别，惯性中双指可立即重新抓住且新 Move 不继承旧速度；Touch Pan 不闪系统箭头，真实 Mouse 可显式接管；活动跟手平移中的 Pen 不打断、无接触光标和触觉，Pan 结束后仍在范围内的 Pen cursor 自动恢复。
- [ ] 主窗口高度为主显示器高度减 1 并保持 TOPMOST；独立测试时可取得键盘焦点。
- [ ] ARM64 Debug/Release 完整解决方案构建成功，两个配置的测试程序通过；未具备的真实 Touch/D3D Debug Layer 场景如实记录。
