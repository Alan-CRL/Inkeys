# 注册内置组件并支持 UI3 运行时同步

## Goal

在 UI2 与 UI3 并行期间，以现有 UI2 组件开关为唯一持久化数据源。UI3 启动时把所有已开启的内置组件按固定列表顺序投影到主栏 B 区；设置页修改开关后，UI3 主栏立即同步增减。按钮图标同时支持现有 SVG 与 PNG 资源。

## Background

- `UI.Bar.FixedButtonsA1` / `ExtensionButtons` / `FixedButtonsA2` 已形成 A1 + B + A2 模型，但 B 区持久化编辑尚未正式开放。
- `BarButtomSetClass::RegisterButton` 已建立 `string Id -> BarButtomClass` 的基础映射，但注册元数据不足以描述旧配置字段、设置页名称和稳定枚举顺序。
- `BarUiPNGClass` 已提供资源解码、D2D 位图缓存和绘制能力；按钮图标字段目前仍固定为 SVG。
- UI3 当前隐藏“组件”导航；传统组件页已有 16 个 `setlist.component.shortcutButton.*` 开关、分类、名称和写入逻辑。
- UI2 浮窗只能显示开关列表中的首个有效组件；UI3 B 区没有这一容量限制，可以同时显示所有已开启组件。
- `IdtFloating.cpp` 已包含这些组件的 PNG 资源映射、栏内短文字和点击动作。

## Requirements

- R1：扩展按钮注册接口继续以稳定字符串 ID 映射按钮结构体，并补充以下元数据：
  - 对应的 UI2 配置字段标识；
  - 读取该字段当前开关状态的入口；
  - 设置页分类与名称；
  - 稳定的注册/目录顺序。
- R2：注册表负责持有按钮模板生命周期；运行时重新同步 B 区时，不得产生重复所有权、悬空指针或按钮状态串联。
- R3：按钮图标支持 SVG 与 PNG。现有 SVG 按钮的主题着色、内容切换、动画和缓存行为保持不变；PNG 按钮复用 `BarUiPNGClass`。
- R4：UI3 主栏启动时，在构建运行时布局前注册全部 16 个内置组件。每项至少包含：稳定 ID、旧字段读取器、分类、设置页名称、栏内短文字、PNG 资源、默认尺寸和点击动作。
- R5：内置组件 ID 使用旧字段路径的点分形式，例如 `Component.ShortcutButton.Appliance.Explorer`。当前阶段每个布尔字段在 B 区最多对应一个按钮实例。
- R6：把传统浮窗中的组件动作提取为可复用执行入口；UI2 与 UI3 调用同一实现，避免动作逻辑漂移。
- R7：启用 UI3 时，不读取磁盘或内存中的持久化 `UI.Bar.ExtensionButtons` 来构建 B 区，也不把运行时投影写回该字段或调用新版配置写入。
- R8：UI3 启动时按设置页现有列表顺序扫描全部旧开关，把值为 true 的注册组件组成运行时 B 区。A1/A2 仍沿用现有配置和校验规则。
- R9：设置页在 UI3 下开放“组件”导航，并继续复用现有开关。任一组件开关变化并完成 UI2 配置写入后，立即按完整列表顺序重新同步运行时 B 区：
  - false -> true：按钮出现在其列表顺序对应位置；
  - true -> false：对应按钮立即从 B 区消失；
  - 其他已启用组件的相对顺序不变。
- R10：UI3 下移除“当前只能容纳 1 个组件/将来由 UI3 完善”之类的数量提示，不显示已添加数量；UI2 下原提示和行为保持不变。
- R11：UI3 可同时显示所有已开启的内置组件，不受 UI2 单组件显示能力限制。
- R12：本任务不开放用户自定义 B 区顺序。待 UI2 移除后，再切换到持久化 `ExtensionButtons` 并提供排序能力。
- R13：保留当前工作区中颜色选择器相关的未提交修改，不覆盖或回退无关内容。

## Acceptance Criteria

- [x] 现有官方 SVG 按钮仍能正常布局、着色、动画和点击。
- [x] 使用 `CustomizeIco*` PNG 资源的注册组件能在 UI3 主栏正确显示透明图标、短文字和按钮状态。
- [x] 16 个内置组件均能通过稳定字段 ID 查询，且注册顺序与设置页列表顺序一致。
- [x] UI3 启动时只根据 UI2 组件开关生成运行时 B 区；持久化 `UI.Bar.ExtensionButtons` 的已有内容不会影响结果。
- [x] 同时开启多个组件时，UI3 全部显示，并按固定列表顺序排列在 A1 与 A2 之间。
- [x] 设置页打开一个组件开关后，该按钮立即出现在当前 UI3 主栏；关闭后立即消失。
- [x] 同步开关不会改变 A1/A2 的成员、顺序或配置语义，也不会写入持久化 B 区。
- [x] 新增按钮点击后执行与 UI2 浮窗对应组件相同的操作。
- [x] UI2 的组件开关、单组件显示规则和持久化行为无回归。
- [x] UI3 下“组件”导航可见，旧的单组件数量限制提示不可见。
- [x] `InkeysRepo.sln` 使用 ARM64 MSBuild 完成 `Debug | ARM64` 构建，且 `git diff --check` 通过。

## Out of Scope

- 读取、写入、迁移或编辑持久化 `UI.Bar.ExtensionButtons`。
- B 区拖拽排序、手动插入位置、显隐字段编辑、尺寸修改和重复实例。
- 插件 SDK、跨进程注册协议或第三方资源加载协议。
- 为现有内置组件新增或重绘图标资源。
- 移除 UI2 后的最终 B 区持久化与排序界面。
