# 主栏按钮与笔类型按钮光影

## Goal

让 UI3 主栏中除分割线外的按钮，以及绘制属性中的可用画笔、荧光笔按钮，统一接入现有鼠标第三光源边缘光影。光影由控件当前颜色决定，并与按钮的选中、按下、显隐状态同步。

## Requirements

### 范围

- 覆盖主栏按钮集合中的所有非分割线按钮，包括当前隐藏但已存在的预设按钮。
- 覆盖绘制属性中的画笔和荧光笔；上方刷子、激光笔两个预留按钮保持隐藏，不加入本期光影显示。
- 不修改传统 `IdtFloating`，不新增配置项，不接入 i18n。

### 光影行为

- 仅使用现有第三鼠标光源，沿用动态光源开关和休眠状态机；动态光源关闭时按钮光影不可见。
- 光影颜色由控件决定：未选中使用控件默认前景/边框颜色，选中按钮使用主题青色。
- 按钮的第三光源最大强度为颜色色块边框的 1/2；鼠标距离只决定到达该上限的比例。
- 按下按钮时，按钮本体和光影边框一起按现有按压缩放中心缩小；同时光影透明度降低。
- 保留现有约 3px 向外扩散的 Gaussian 漫反射和对应脏区外扩。
- 不改变按钮未选中时背景透明、悬停/按下/选中背景透明度的现有逻辑。

## Acceptance Criteria

- [x] 主栏所有非分割线按钮均有控件颜色对应的第三光源边缘光影。
- [x] 绘制属性中的画笔、荧光笔按钮有相同光影；刷子、激光笔保持隐藏。
- [x] 光影只受第三光源影响，关闭动态光源后不可见，且最大亮度不超过颜色边框的 1/2。
- [x] 选中态使用主题青色，按下时边框与按钮同步缩小并变暗。
- [x] Gaussian 漫反射继续向外扩展约 3px，动画和脏区覆盖完整。
- [x] 完整 `InkeysRepo.sln` 的 `Debug | ARM64` 编译通过。

## Out of Scope

- 不实现激光笔、刷子的实际绘制能力。
- 不改变第一光源、颜色选择器边框、传统悬浮栏或第三光源休眠机制本身。
