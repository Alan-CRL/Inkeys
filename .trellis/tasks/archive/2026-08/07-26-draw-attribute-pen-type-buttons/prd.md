# 重构绘制属性笔类型按钮布局

## Goal

将 UI3 绘制属性窗口中颜色选择区右侧的笔类型控件重构为四个纵向排列的“图标 + 文字”按钮，使当前笔型选择与主栏按钮拥有一致的视觉和交互行为，并为后续接入激光笔、刷子预留稳定入口。

## Requirements

### 布局与内容

- 笔类型区位于现有颜色选择区右侧，改为单列四按钮布局。
- 从下到上的固定顺序为：画笔、荧光笔、激光笔、刷子；等价的从上到下顺序为：刷子、激光笔、荧光笔、画笔。
- 每个按钮采用类似主栏 1×2 按钮的横向内容布局：左侧 SVG 图标，右侧文字。
- 笔类型区应比现有控件适当加宽，并至少按 `Pen`、`Highlighter`（允许清晰缩写）、`Laser`、`Brush` 这组英文参考标签校核宽度。
- 如现有空间不足，可适当增加绘制属性窗口高度；需要为后续粗细选择器调整保留空间，避免只按当前内容做过度紧凑布局。

### 状态与交互

- 画笔和荧光笔保留现有切换功能、状态更新和命中行为。
- 激光笔和刷子本期仅展示为灰色禁用态，不可悬停高亮、按下或选择，也不得改变当前笔型。
- 可用按钮未选中时无背景填充；悬停时显示与主栏按钮一致的悬停色；按下时产生与主栏一致的缩小反馈；选中时使用现有青色选中样式。
- 删除现有笔型滑槽的黑色背景和青色选中矩形，不保留双重选中指示。
- 鼠标离开、取消按下、窗口收起等场景不得遗留悬停或按压状态。

### 动画

- 绘制属性展开和收起时，四个按钮的外形、图标、文字、间距和命中区域应随窗口统一等比缩放，不得在过程中重叠、跳位或提前显示为最终尺寸。
- 动画曲线、截止时间和首次设色行为沿用现有绘制属性动画合同；布局变化不得破坏上下换边关键帧动画及脏区清理。

### 图标与资源

- 为刷子和荧光笔提供风格一致的 SVG。优先复用/改造仓库现有资源；若采用外部素材，必须明确允许再分发和修改，并记录来源与许可证。
- 图标应支持当前 SVG 主题设色流程，不能将主题前景色硬编码进资源。

### 范围

- 本任务只重构 UI3 绘制属性中的笔类型按钮及其必要的窗口尺寸、动画、输入命中和资源。
- 不在本期接入激光笔或刷子的实际绘制能力。
- 不调整颜色选择器和粗细选择器的功能或完整布局；仅允许为容纳新笔型区做必要的最小位置/尺寸适配。

## Acceptance Criteria

- [x] 展开状态下，从上到下显示刷子、激光笔、荧光笔、硬笔（及后续扩展的软笔）横向“图标 + 文字”按钮；按钮宽度通过中文标签校核，不截断到不可识别。
- [x] 硬笔、荧光笔可正常切换，选中态为青色；其未选中、悬停、按下反馈与主栏按钮一致。
- [x] 激光笔、刷子、软笔为禁用/占位态，不改变当前笔型（软笔为后续扩展项，本期不接入绘制）。
- [x] 原黑色滑槽背景和青色滑块完全移除，选中状态仅由按钮自身表达。
- [x] 展开、收起及绘制属性上下换边过程中，按钮、SVG 和文字同步等比缩放并正确回到目标位置，无重叠、跳变、残影或脏区。
- [x] 刷子/激光/荧光/软笔 SVG 与现有图标风格协调，可由主题颜色驱动（`rgba(10,0,7,0)` 可着色标记）。
- [x] 通过静态检查确认枚举范围、初始化、布局、渲染、脏区、悬停、按压和点击分支覆盖笔型按钮，并且旧滑槽状态与绘制路径已完整删除。
