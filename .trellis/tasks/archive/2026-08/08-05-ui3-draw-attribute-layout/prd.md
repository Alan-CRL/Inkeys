# 调整绘制属性布局与标注线入口

## Goal

调整 UI3 绘制属性窗口的粗细区域布局与 Preview/Slider 状态关系，并把暂不可用的“标注线”入口迁移到当前选中且具备该能力的笔类型扩展菜单中。改动应延续现有布局、动画、第三鼠标光和提示浮窗体系，不改变绘制业务模式。

## Background

- 绘制属性面板展开尺寸为 `370 x 185 DIP`；颜色与粗细位于左侧内容区，五个笔类型按钮位于右侧纵列。
- 当前粗细区使用 `DrawAttributeBar_ThicknessSelect` 的 `240 x 105 DIP` 圆角外框；同一几何还承担预览裁剪、滑块命中和上下换边推导。
- 几何选择窗口的 `GeometryAttributeBar_Divider` 是现有标准分割线：`1 DIP`、圆角 `0.5 DIP`、`SurfaceFrame`、`PointLight`、关闭主光、第三鼠标光强度 `0.30`。
- `PenModeSupportsAnnotationLine(PenModeSelectEnum)` 是现有唯一能力判断；当前只对硬笔 `IdtPenBrush1` 与荧光笔 `IdtPenHighlighter1` 返回 true。软笔仍是禁用占位项。
- 当前标注线问号已具备悬停宽限、固定、关闭和提示内容；这些对象应迁移复用，不能另建第二套帮助状态或文案。
- 当前粗细预览为避让标注线徽标而偏移，滑轨中心和“保持并固定粗细”提示也依赖徽标几何。
- 当前 `thicknessPreviewOverflow` 独立于滑块动画，因此 Slider 已出现时仍可能保留溢出提示的视觉或命中。
- `widgetPosition.primaryBar == true` 时绘制属性面板位于主栏下方，远离主栏的展开方向为向下；为 false 时方向为向上。

## Requirements

### R1 粗细区域分割线

- 移除粗细选择器可见外框，但保留必要的内部布局/裁剪几何，避免复制预览与滑块范围状态。
- 在颜色块与“粗细”文字/快捷调节按钮行之间绘制横向分割线；上下换边时关系镜像。
- 分割线外缘到两侧相邻内容均保持 `5 DIP`，线宽为与几何选择分割线共用的 `1 DIP`。
- 分割线覆盖左侧内容区：左端为面板左缘加 `BarDrawAttributeGap`，右端为右侧笔类型列左缘减 `BarDrawAttributeGap`。当前颜色块与粗细控件同属左侧内容区，因此端点必须从面板、笔类型列和共用间距关系推导，不能复制孤立坐标。
- 分割线完整复用几何选择分割线的 `SurfaceFrame`、`PointLight`、主光关闭、第三鼠标光强度和动画路径；不新增 shader、光照模型或独立缓存。

### R2 恢复完整粗细预览区

- 删除粗细区中的标注线徽标及其布局占位；标注线业务能力和既有帮助浮窗对象保留给笔类型菜单复用。
- 预览墨迹、滑轨中心、滑轨范围和 hold-lock 提示均从完整可用预览区推导，不再依赖标注线徽标边界。
- 普通预览墨迹在完整预览区竖直居中；滑块也使用同一可用区域中心，不保留旧徽标避让偏移。
- “保持并固定粗细”提示改用预览区内容内边距作为稳定锚点，不依赖某个笔类型是否支持标注线。
- 粗细预览/滑块的既有触发、固定、拖动、提交、hold-lock 和上下换边逻辑保持不变。

### R3 Preview、Slider 与 Overflow Hint 互斥

- 粗细溢出条件成立时，溢出提示按钮只允许出现在 Preview 状态。
- Slider 进入目标一旦建立，立即撤销溢出提示的 hover、固定、关闭按压和 hit-test；视觉按现有动画风格退场。
- 溢出提示及其浮窗完全退场后才允许滑轨开始出现；Slider 退出时继续遵守“圆点先消失、轨道后恢复”，轨道恢复为 Preview 后才允许溢出提示重新淡入。
- 快速反向切换应从当前动画值续接，不闪现旧 alpha、不同时显示两个控件，也不保留不可见命中区或过期宽限定时器。

### R4 笔类型按钮与扩展入口

- 所有笔类型文字改为带现有视觉内边距的左对齐，不改变按钮纵向顺序、整体尺寸或禁用状态。
- 仅当当前选中笔类型通过 `PenModeSupportsAnnotationLine` 时，在该按钮右侧显示“分割线 + 小三角”扩展区；未选中或不支持的按钮不显示、不命中。
- 扩展区复用现有按钮悬停、按下缩放、主题颜色和动画时长；小三角复用现有 `barThicknessAdjust` SVG 资源及着色路径，不新增等价图标资源。
- 扩展区出现/消失时，视觉可以动画续接，但失效时必须立即撤销 hover、press 和 hit-test。

### R5 自由线/标注线菜单

- 点击小三角切换一个包含“自由线”和“标注线 [?]”两项的浮层；点击浮层外部先关闭，再继续处理同一次底层点击。
- “自由线”保持可选并显示当前对钩；选择后只关闭菜单，不创建重复的“自由线”业务状态。
- “标注线”显示为灰色 Disabled；鼠标、触摸或键盘均不得令其可选或改变绘制模式。其 `[?]` 仍可悬停/固定并显示原有标题与正文。
- 菜单从当前选中按钮朝远离主栏的方向展开：`primaryBar == true` 向下，否则向上。动画位移方向与最终方向一致。
- 菜单打开时锁存展开方向；若绘制属性面板换边、当前笔型失去能力、笔型变化或面板关闭，则先关闭菜单并清理交互，下一次打开再按新方向锁存，避免旧方向动画残留。
- 菜单与帮助浮窗在现有全屏 `floating_window` 中布局和渲染，不创建新 HWND。

### R6 范围与兼容

- 修改仅限 UI3 Bar 相关布局、动画、渲染、命中和必要的瞬态状态。
- 保持 DIP 与现有 UI 缩放/上下换边动画；新增关键状态门控使用简短中文注释。
- 不修改传统 `IdtFloating`、绘制引擎、持久化配置、粗细范围/记忆、颜色选择器业务或笔型枚举。
- 不提前启用标注线绘制功能，不新增 annotation/free-line 业务模式状态。

## Acceptance Criteria

- [ ] AC1 粗细选择器旧外框不再可见；新分割线在上下布局中都位于颜色块与粗细控制行之间，分割线外缘到两侧内容均为 `5 DIP`。
- [ ] AC2 分割线左端距面板 `5 DIP`，右端距右侧笔类型列 `5 DIP`，端点由现有布局关系计算。
- [ ] AC3 分割线与几何选择分割线共用 `1 DIP` 线宽、`0.5 DIP` 圆角、颜色和第三鼠标光配置；展开、收起、换边过程中光影连续。
- [ ] AC4 粗细区不再渲染或命中旧标注线徽标，且不保留其布局占位。
- [ ] AC5 预览墨迹和滑轨使用完整可用区域并竖直居中；hold-lock 提示不依赖标注线几何。
- [ ] AC6 Preview 状态可按原条件显示溢出提示；Slider 目标建立后溢出提示立即失去命中，并在 Slider 开始显现前完全退场。
- [ ] AC7 Slider 退出时圆点先退场、轨道再恢复，恢复完成后溢出提示才可重新出现；快速反向操作无闪烁、重叠、旧 hover、旧 hit-test 或旧 timer。
- [ ] AC8 五个笔类型文字均左对齐且保留一致内边距；按钮顺序、尺寸、禁用状态和可用笔型切换无回归。
- [ ] AC9 只有当前选中且 `PenModeSupportsAnnotationLine` 为 true 的按钮显示并命中右侧分割线与小三角。
- [ ] AC10 小三角可展开/收起菜单；菜单包含“自由线”和灰色“标注线 [?]”，对钩始终位于自由线。
- [ ] AC11 标注线行本体不可点击、不可通过键盘或其他输入选中，且不改变任何绘制业务状态；`[?]` 继续显示原有帮助内容。
- [ ] AC12 面板位于主栏下方时菜单向下展开，位于主栏上方时向上展开；位移动画方向与最终方向一致。
- [ ] AC13 切换支持/不支持笔型、选中/未选中状态、面板换边或快速开关菜单时，无残留浮层、hover、press、hit-test 或错误方向动画。
- [ ] AC14 `git diff --check` 通过，完整 `InkeysRepo.sln` 使用 ARM64 host MSBuild 完成 `Debug | ARM64` 构建；若仓库没有相关自动化 UI 测试，明确记录手工验证范围。

## Out Of Scope

- 实现或启用标注线绘制、方向锁定及其快捷键。
- 为软笔、刷子或激光笔新增实际模式或标注线能力。
- 重做绘制属性面板、颜色选择器、粗细滑块或第三光源架构。
- 新增 shader、独立光照模型、新窗口、持久化字段或新图标资源。
