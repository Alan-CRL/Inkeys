# UI2 最终兼容版发版前适配

## Goal

在仍同时支持 UI2、UI3 与 Draw2 的最后一个版本中，修复 UI3 主按钮的触摸拖动瞬移，收敛两套 UI 的设置入口与绘制联动行为，改善 UI3 调试信息，并完成一次以兼容性为核心的发版前检查。

## Background

- UI2 仍是本版本的正式可执行分支，后续版本才会移除，不能把 UI2 当成死代码处理。
- UI3 的 `WM_TOUCH` 路径会生成带真实触摸客户区坐标的 `ExMessage`；当前主按钮 `Seek()` 却在手势中轮询系统鼠标坐标，启动后首次触摸时容易把两种坐标源混用并产生巨大位移。
- Draw2 已在 UI3 启用时通过 `NotifyCanvasDrawingStarted/Ended()` 发布绘制活动，能够作为 UI3 收起次级面板的既有跨层入口。
- 设置页同时承载 UI2 与 UI3 项目，需要避免隐藏项继续暗中控制 UI3，也不能因隐藏而覆盖用户已有的 UI2 配置。

## Requirements

### 1. UI3 主按钮触摸拖动

- 参考 `Inkeys/IdtFloating.cpp` 中 UI2 拖动时保持同一坐标来源的做法，修复 UI3 主按钮触摸后瞬移到屏幕右下角的问题。
- 触摸手势必须从按下、移动到抬起始终使用 UI3 合成触摸消息的坐标；不得中途改用系统鼠标位置。
- 鼠标拖动保持现有行为、边界限制、点击/拖动阈值与松手后左右方向判断。
- 触摸取消、程序退出和坐标读取失败必须能够安全结束手势。

### 2. UI2/UI3 设置显隐

- UI3 启用时，隐藏尚未适配 UI3 的 UI2 项目；现有主题和语言显隐继续保持。
- UI3 启用时，隐藏以下 UI2 收起选项：
  - 画笔绘制时收起主栏；
  - 橡皮擦除时收起主栏；
  - 拖动主栏时收起主栏；
  - 点击时收起主栏。
- UI2 启用时，上述项目仍可见、可配置且行为不变。
- 隐藏项目不得清除、迁移或覆盖已有持久化值。
- 置顶间隔、右键关闭等 UI3 已支持的通用项目继续可见。

### 3. UI3 绘制开始时收起次级界面

- UI3 不新增用户设置；在 Draw2 开始实际绘制时采用固定行为。
- 首个并发绘制活动开始后，关闭 UI3 主栏之外的次级界面，包括绘制属性、几何属性、更多面板及其附属的笔型菜单、粗细调节、颜色选择器和提示浮层。
- 主栏本身的展开/收起状态不得被改变。
- 多指或多笔并发绘制不得重复发布相同的关闭动作。
- UI2 继续使用原有 `BrushRecover`、`RubberRecover` 等行为，不受 UI3 固定行为影响。

### 4. 光影与 UI3 实验设置

- “启用边缘光影”从“实验选项”移动到前置的“常规 > 外观”分类，并且仅在 UI3 实际启用时可见。
- “动态边缘光影”保留在“实验选项”，仅在 UI3 启用且“启用边缘光影”打开时可见。
- UI3 调试模式、动画开关、动画速度等其他 UI3 实验项目仅在 UI3 开启时可见。
- 任一项目因条件隐藏时，不得覆写其持久化值。

### 5. UI3 调试 FPS 与布局

- 调试文字中的 FPS 改为过去一秒滑动窗口内的平均 FPS，而不是仅用上一帧耗时换算的瞬时 FPS。
- FPS 数值仍随每一帧刷新；脏区边框也继续逐帧绘制。
- 调试文字依据主栏当前左右方向放在主按钮对应一侧，并采用匹配的左右对齐，避免总是向右延伸。
- 调试绘制继续把文字与红色脏区边框纳入提交区域，不影响非调试模式的脏区策略。

### 6. 版本号

- 发布版本保持大版本 `3.0.0`。
- 开发版本更新为 `3.0.0-dev.3981`。
- 日期版本更新为 `3.0.0-20260811a`。

### 7. UI2/UI3 - Draw2 协调检查

- 静态核对 UI2/UI3 启动路由、Draw2 状态切换、落笔通知、旧版收起配置和 UI3 次级面板状态，确认没有交叉污染。
- 覆盖绘制、橡皮、几何、选择/穿透、撤销/重做/清空以及 PPT 联动相关的既有共享状态路径。
- 不迁移两套配置系统，不改变旧组件开关作为 UI2/UI3 并行期间持久化来源的约定。
- 发现与本次改动直接相关且会阻断双框架兼容的问题时做最小修复；无关问题只记录，不扩展范围。

## Out of Scope

- 不处理此前提到的 UI3 主栏与按钮动画曲线偶发不同步问题。
- 不移除 UI2、旧配置字段、旧资源或 `floating_main`。
- 不重构 Draw2 绘制架构、PPT COM 或 UI3 动画系统。
- 不新增 UI3 “绘制时收起次级界面”设置。
- 不进行与本次兼容发版无关的界面、性能或代码风格优化。

## Acceptance Criteria

- [x] 启动后立即用触摸点击或拖动 UI3 主按钮，不再瞬移到右下角；轻触仍切换展开状态，拖动仍受屏幕边界限制。
- [x] 鼠标拖动和点击 UI3 主按钮的既有行为无回归。
- [x] UI3 设置页不显示主题、语言和四项旧版收起设置；UI2 设置页仍显示并保存这些设置。
- [x] UI3 开始 Draw2 绘制时关闭所有 Bar 次级面板，但不改变主栏展开状态；UI2 的旧收起配置仍照常工作。
- [x] “启用边缘光影”只在 UI3 的“常规 > 外观”出现；“动态边缘光影”只在 UI3 + 边缘光影时出现在实验选项；其他 UI3 实验项目也只在 UI3 下出现。
- [x] 隐藏设置前后的持久化值保持不变。
- [x] 调试 FPS 为过去一秒平均值且每帧刷新；调试文字会随主栏方向切换左右位置/对齐；脏区红框仍正常显示。
- [x] 版本字符串为 `3.0.0-dev.3981` 与 `3.0.0-20260811a`。
- [x] UI2/UI3 - Draw2 协调矩阵完成核对，未发现本次改动造成的跨框架兼容回归。
- [x] `InkeysRepo.sln` 在 `Debug|ARM64` 下完整构建通过，`InkeysHeadlessTests` 通过，`git diff --check` 通过。

## Constraints

- 实现遵循最小修改原则，保持原文件编码与 CRLF/LF。
- 新增关键逻辑使用简短中文注释。
- 完整构建使用 ARM64 版 MSBuild，超时不少于 5 分钟。
- 产品代码开始修改前再次检查工作树，避免覆盖并行任务产生的改动。
