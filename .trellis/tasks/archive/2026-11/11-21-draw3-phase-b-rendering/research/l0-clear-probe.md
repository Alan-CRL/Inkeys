# L0 清除方式离屏探针（2026-11-22）

临时外部探针（不在仓库内），离屏 D3D11，无窗口、无交换链。目标是一对 3840×2160 纹理：Add（B8G8R8A8_UNORM）与 Retain（R16_FLOAT）。每个样本先把矩形写脏，再执行一种清除方式，随后画一个 48×48 的尾段并用一次 32×32 的绘制读取两张纹理。四种方式都通过了像素回读：矩形内回到 (0, 1)，局部方式保留矩形外哨兵。

| 方式 | 说明 |
| --- | --- |
| 整屏清 | `ClearRenderTargetView` 两次 |
| ClearView | `ID3D11DeviceContext1::ClearView` 两次，带矩形 |
| 拷贝 | 从 512×512 恒等小块 `CopySubresourceRegion` |
| 绘制 | 关混合、裁剪矩形内输出 (0, 1) |

## 结果（微秒，中位数）

## 结论与限制

- 矩形不超过约 1.6% 屏时，三种局部方式在两台设备上都不慢于整屏清。
- 矩形变大后，拷贝和绘制会输给便宜的整屏清；ClearView 在这两台设备上到 50% 仍未输。
- 其他驱动可能把 ClearView 实现成普通填充，没有数据。用户据此选择保守分界线 1/16 屏，并决定无 ClearView 的设备直接整屏清。
- 未覆盖旧 Intel 核显、兆芯和 Win7 实机。ClearView 在 Win7 平台更新下的限制未对照微软文档核实。
