# 设置绘制光标样式与透明度完善

## Goal

完善“设置 → 绘制 → 光标”页及实际绘制光标，让高亮光标在不同背景下更清晰、细笔时的小圆点高亮填充更易辨认，并提供四种光标样式的独立透明度控制与一致的浅色主题预览。

## Background

- 当前普通和高亮光标的填充不透明度均为 25%（`Inkeys/Inkeys/Drawing/Draw3/Draw3.DrawingController.cpp:200`）；普通灰色边也为 25%，高亮浅色边固定不透明（`Inkeys/Inkeys/Drawing/Draw3/Draw3.PenCursor.cpp:56`）。
- 当前高亮浅色边宽为 1.25 DIP，普通灰边为 0.5 DIP；常量由预览与实际渲染共享（`Inkeys/Inkeys/Drawing/Draw3/Draw3.CursorSettings.h:55`）。
- 设置页预览背景当前固定为深灰色（`Inkeys/Inkeys/UI/Setting/Setting.Pages.cpp:595`）；现有 `SliderResetAction` 已提供百分比、滑块与无文字重置图标（`Inkeys/Inkeys/UI/Setting/Setting.Controls.cpp:1303`）。
- 光标偏好已持久化在 `Inkeys/Config/main.json` 的 `Drawing.Cursor`，并经 Config → State → Bridge → Controller 快照链同步（`Inkeys/Inkeys/Other/Other.Config.cppm:445`、`Inkeys/IdtState.cpp:601`）。
- 新文案必须进入项目现有二十语言 i18n 源与生成链，不能只修改单个语言或生成头。

## Requirements

### R1 高亮光标外框与细笔填充

- 为“画笔（高亮）”和“小圆点（高亮）”的最外圈增加纯黑色外框，宽度为 1 个物理像素而不是 1 DIP；不同 DPI 下仍保持 1 px。
- 黑色外框在既有外轮廓内侧形成，不扩大光标尺寸、不改变热点；黑色外框与其内侧的白色环均保持不透明。
- “小圆点（高亮）”白色环宽使用 `clamp(圆点实际直径 / 8, 1 px, 1.25 DIP)`：细笔下限为 1 个物理像素，约 10 DIP 实际直径达到当前最大宽度。
- “画笔（高亮）”的白色环继续使用当前 1.25 DIP 宽度。
- 同步更新设置页设备行中的光标预览，使其反映相同描边、环宽和透明度。

### R2 普通光标透明度统一

- “画笔”和“小圆点”的灰色边缘与彩色内容使用相同的最终不透明度，不再对灰边额外乘一次填充系数。

### R3 浅色主题预览

- 浅色主题下，光标预览背景使用与卡片/按钮一致的白色，并使用适合浅色背景的边界色。
- 深色主题保留现有预览背景和边界表现。

### R4 四类透明度控制

- 在“数位板支持”下方、“精细控制”上方新增“透明度”分组。
- 分组按“画笔”“画笔（高亮）”“小圆点”“小圆点（高亮）”顺序包含四个条目；每项包含百分比、滑块和无文字重置按钮，不增加解释说明。
- 标题分别为“画笔光标透明度”“画笔（高亮）光标填充透明度”“小圆点光标透明度”“小圆点（高亮）光标填充透明度”。
- 四个滑块均使用 25%–100% 不透明度范围和 1% 步进。
- 普通样式控制整体不透明度；高亮样式只控制彩色填充，不影响黑色或白色边框。
- 默认及重置值依次为画笔 50%、画笔（高亮）填充 50%、小圆点 25%、小圆点（高亮）填充 50%。
- 四项配置独立持久化；拖动时即时更新实际光标和预览，松手、重置或离开页面时保存。

### R5 国际化

- 为“透明度”分组和四个条目标题提供全部二十种支持语言的文案。
- 使用 zh-CN 基准、现有同步脚本和生成键，不手工编辑生成头。

## Acceptance Criteria

- [ ] AC1（R1）：两种高亮光标在设置预览和实际绘制中均有最外圈纯黑、1 物理像素且不透明的外框；多 DPI 下不变成 1 DIP，尺寸和热点不变。
- [ ] AC2（R1）：小圆点高亮白色环严格符合已确认的直径 ÷ 8 公式，覆盖 1 px 下限、增长区间和 1.25 DIP 上限；3 px 等细笔场景的填充区域比直接叠加固定白色环时更大。
- [ ] AC3（R1、R2、R4）：普通灰边与内容等于各自设定值；高亮填充等于各自设定值，而黑色和白色边框始终不透明。
- [ ] AC4（R3）：浅色主题预览背景为白色且边界可见，深色主题颜色无回归。
- [ ] AC5（R4）：“透明度”分组位于指定位置，四个条目的顺序、标题、25%–100% 范围、1% 步进及无文字重置按钮均符合要求。
- [ ] AC6（R4）：修改任一值只影响对应样式，并即时同步到实际光标和预览；重置恢复确认后的默认值，重启后保留用户值，离开页面不会丢失未保存修改。
- [ ] AC7（R4）：缺失配置和重置采用 50% / 50% / 25% / 50%；非法配置类型、超宽整数和越界值恢复对应字段默认值，不影响其他光标偏好。
- [ ] AC8（R5）：二十语言资源、快照和生成键一致，i18n sync/check 通过，窄/宽窗口及目标 DPI 下新增控件不裁切或产生横向滚动。
- [ ] AC9（R1–R4）：配置、快照打包、实际 resolver、触摸路径、设置交互、正式/Win7 guarded shader 与跨 DPI 回归通过；不改变墨迹颜色、透明度、几何、历史或专用工具光标。

## Out of Scope

- 不调整“鼠标”样式、无光标、专用荧光笔矩形、图形、橡皮或激光光标。
- 不改变设备样式选择、数位板识别、小圆点落笔隐藏、输入来源分类或既有光标热点。
- 不修改实际笔迹的透明度、颜色或几何。
- 不迁移配置系统，不新增 GPU shape 类型，不重构光标或设置页架构。
