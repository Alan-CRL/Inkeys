# 画布调试可视化模式

## Goal

参考 Inkeys2 的画布调试(触摸点/触摸面积可视化)与 Draw3 的画布性能文字,为 Draw3 画布提供“画布调试”:在设置中开启后,画布底层常驻一块紧凑的调试背景板(基础性能 + 帧率曲线 + 输入点信息表),并可通过主栏按钮进入“可视化调试”模式,直观查看触摸点位置、触摸面积与压感。目标是方便在真机上调试触摸/笔输入,且不明显影响画布性能。

## Requirements

### R1 设置开关
- 设置 - 软件调试页新增开关“画布调试”,热生效(无需重启),持久化到 `Inkeys::Config`。
- 开关关闭 = 退出一切画布调试(背景板消失、可视化模式退出、主栏按钮隐藏)。

### R2 主栏按钮(A1)
- 画布调试开启时,A1 主栏出现“可视化调试”按钮;关闭时不出现。
- 该按钮只是可视化模式的开关;与选择/绘制/橡皮/几何/穿透等工具互斥:点击其他工具即退出可视化模式(画布调试开关保持开启);再点按钮重新进入。

### R3 可视化模式(仅在按钮开启时)
- 进入后触摸/笔**只显示调试标记,不产生笔迹、不擦除、不触发手掌橡皮动作**。
- 每个活动接触绘制:
  - 绿色实心点(输入点坐标) + 以输入点为圆心的绿色边框小圆(便于手指测试时看到“这里有个点”)。
  - 有触摸面积时:虚线红框实时展示面积;框下方文字 `W*H px`(整数);存在可信 EDID 时追加 `W*H cm`(保留 1 位小数)。
  - 当面积超过手掌橡皮阈值**且手掌橡皮已开启**时,红框由虚线变实线(阈值与手掌橡皮实际判定同源)。
  - 有压感时,绿点与绿色圆框随压力变化大小。
- 标记画在所有笔迹之上。

### R4 调试背景板(画布调试开启期间始终存在,与当前工具无关)
- 位置:紧贴屏幕左边缘、竖直居中;尺寸按内容动态变化(变化无动画),力求紧凑以缩小最终提交脏区。内容超出屏幕时不换行,直接被裁掉。
- Z 序:位于 L2(已提交笔迹)**之下**;板子每帧先绘制进呈现层,L2 再按自身脏区叠加其上;最终提交脏区 = 板子脏区 ∪ L2/其他脏区(可能相交或包含)。
- 性能区:当前帧率、无限制帧率(不含帧间等待)、硬件压力(= 帧负载 + 本进程 CPU 占用);数字约每 0.5s 更新一次,画布渲染本身不被该刷新节奏阻塞。
- 帧率曲线:任务管理器式折线图,展示过去 1 分钟的帧率变化。
- 输入点信息表:列对齐的表格(数字长短变化不得导致错位);每个**活动接触一行**,抬起后短暂保留后消失;列至少包含 类型、坐标、压力、面积、倾斜角,并预留扩展(如速度);需美观。

### R5 性能约束
- 画布调试关闭时,绘制线程不得产生任何额外开销(零分配/零格式化/零额外脏区)。
- 开启时:热路径不做字符串格式化与内存分配;文字与图表数据由 ≤ 2Hz 的快照驱动;允许为性能舍弃部分美观;板子与标记只在自身脏区内绘制,不扩大 L2 的重绘范围。

## Acceptance Criteria

- [ ] 设置-软件调试出现“画布调试”开关(含 zh-CN 及全部 locale 的 i18n),切换后无需重启即生效,重启后保持。
- [ ] 开关打开后 A1 出现“可视化调试”按钮,关闭后消失;按钮默认状态为未选中。
- [ ] 点击该按钮进入可视化模式;随后点选择/绘制/穿透等任意工具即退出可视化模式,画布调试开关仍为开启,背景板仍在。
- [ ] 可视化模式下触摸/笔不产生笔迹或擦除;有触摸面积的设备上可见虚线红框与 px 文字,有可信 EDID 时多出 cm 文字(1 位小数);面积超过手掌橡皮阈值且手掌橡皮开启时红框变实线;关闭手掌橡皮则始终为虚线。
- [ ] 有压感的笔,绿点与绿圆随压力变化大小。
- [ ] 画布调试开启后背景板立即出现(未进入可视化模式也有),贴左边缘竖直居中,内容多少变化时尺寸随之变化且无动画。
- [ ] 性能区显示 帧率 / 无限制帧率 / 硬件压力,约 0.5s 刷新一次;帧率曲线覆盖最近 1 分钟。
- [ ] 信息表各列对齐,多点触摸每个活动接触一行,抬起后短暂保留再消失;宽度超出屏幕时不换行。
- [ ] 板子位于 L2 之下:已提交笔迹压在板子上方而非被其覆盖;板子区域内的 L2 内容显示正确(含透明区域)。
- [ ] 关闭画布调试开关,上述一切消失,绘制线程回到无额外开销的原路径(含脏区)。
- [ ] 在板子区域反复书写/擦除/切换页面无残影、无撕裂;全量 `InkeysRepo.sln` Debug 构建通过。

## Out of Scope

- 旧 Inkeys2 输入测试(`IdtTouchTest`)的复活;Draw3 早期大量性能项(只要 帧率/无限制帧率/硬件压力)。
- GPU 利用率采样(PDH 等)。
- 板子拖动、折叠、可配置位置、动画。
- 速度等“后期”列的实际实现(仅预留列扩展能力)。
- 将调试板导出/保存进文档或截图。
