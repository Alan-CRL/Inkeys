# 国际化扩展技术设计（规划稿）

## 边界

本任务按一个集成任务分阶段交付：翻译、资源、语言映射和排版共享同一套十一语言验收矩阵，不能只交付 JSONC 就视为语言可用。不恢复未编译的 UI2，不重构渲染系统或配置架构，不修改第三方依赖版本。

## 语言身份与兼容

保留已有持久化索引：0=en-US、1=zh-CN、2=zh-TW；新增值顺次追加为 3=zh-HK、4=ja-JP、5=ko-KR、6=fr-FR、7=de-DE、8=es-ES、9=pt-BR、10=ru-RU。设置页、启动加载、合法值验证、资源选择、LANGID 和字体选择必须使用一致映射，避免继续散落三语分支；只集中本次必需的语言元数据，不引入通用插件框架。

持久化继续使用原有整数配置。已有选择优先；首次未保存选择时，对新增八种精确系统语言匹配相应条目。未覆盖地区保留已有主语言/英语回退规则，不擅自将所有法语、葡语等地区绑定到本次某一地区翻译。HK 精确匹配优先于原有繁中归并；既有澳门及其他未覆盖系统语言行为保持。非法保存值仍依现有规则回退英语。

选择后沿用原有加载与确认重启流程；完整字体及缓存刷新仍以重启为生效边界，不新增全程序即时语言切换保证。

## JSONC、嵌入与报告核对

- 以当前 zh-CN 的595条基线为起点；必要新增消费者 key 后总数可增加。
- 先核对报告全部116键，区分真实误译、交互语义、已批准地区化和非缺陷；每条在研究索引保留处理依据。
- 所有十一种 JSONC 保持同一 key 结构，新增语言使用自然、紧凑的完整翻译；zh-HK 使用香港书面中文常用术语，不能仅把 zh-TW 文件改名。技术名、URL、快捷键及合法专名按上下文保留。
- 用户决定：通用品牌/新建快捷方式 zh-CN 为“智绘教Inkeys”，其余为“Inkeys”；用途说明本地化。不主动批量修改用户磁盘上现有快捷方式。
- 主页沿用已批准的地区化标题、标语和版权署名；社区沿 zh-CN→QQ、其余→GitHub Discussions 分流，不照报告机械统一。UIAccess 只准确描述有依据的支持范围，不承诺未经核验的锁屏绘制；UAC/安全软件说明准确化，不改权限功能。
- `Thinkness`、`AutoUpate` 等内部 key 拼写不是本轮迁移目标；翻译修正不顺便重命名。
- 按既有 RC JSON 资源形式追加八种资源和 resource ID，更新必要工程及 Solution 展示项；加载必须选到实际资源，不能记录新语言但静默取到简中。
- 通过 `Scripts/i18n.ps1 sync` 维护基准快照和生成头；其他语言完成后再 check，不手改生成头。

## 字体与所有语言下的语言列表

按 [research/font-sources.md](research/font-sources.md) 从官方固定版本获取 Noto Sans JP / KR，保留授权并记录 hash。优先使用经 DWrite 与现有 ImGui 默认 stb_truetype 后端验证的静态 TrueType Regular/Bold 实例，保持现有标题权重和平台兼容，不把 variable/集合字体支持当作既成事实；Noto 不未经测量直接套用 Harmony 专用的光学校正。

资源接入覆盖 RC、必要项目项、解包/缓存更新、DWrite 注册及 ImGui atlas 构建。日语/韩语使用对应家族与 locale，繁中香港使用 TC 路径并做实际字形检查，西文/俄语复用可证明覆盖目标字符的现有字体。字形缺失时先纠正字体覆盖与回退，不能用删字或错误转写掩盖。

语言下拉在每一种当前语言下均显示所有母语名称、语言码和 Beta；zh-CN 不显示 Beta，其余十种显示 Beta。必须覆盖混合中文、假名、韩文、重音拉丁与西里尔字符，不能只加载当前语言的字形。字体变化沿既有启动、DPI重建、销毁机制管理，不安装系统字体、不要求用户联网。

## format 与布局验证

当前脚本正则检查只能证明占位符文本相符，不能代替 `std::format` 解析和参数类型校验。为当前实际格式化消费者建立参数样本，逐语言执行真实格式化；覆盖索引、类型说明符、数字精度、转义大括号及格式化后的布局。测试须显式暴露格式异常，不能通过生产兜底字符串把异常当作成功。

另外核对仍编译的 `IdtFreezeFrame.cpp:236-237` 使用 `UI/Operate/Recall` 作 `swprintf_s` 格式的路径，避免新译文引入意外百分号转换或突破100字符缓冲；先确认当前可达性，不恢复已退休功能。此类检查不由大括号脚本覆盖。

保留两个主栏短标签既有0/1换行例外，其他换行依脚本合同严格校验；若确需新增局部例外，必须有对应消费者测量依据，不全局放宽检查。固定主栏70 DIP网格不扩张；先采用语义准确的短译文，再针对证实的溢出局部换行、测高、宽度或字号适配，不全局缩小字体。

覆盖活动主栏与附属面板、白板/分页、设置侧栏/卡片/下拉、标准及自定义对话框、提示文字。优先复用真实DWrite测量与ImGui无窗口回放，检查宽/高、边界、缺字以及图标/相邻控件交叠；MessageBox 默认按钮及字体的三语分支也需覆盖新增语言。
