# 编辑框与浮条样式

## Goal

重做刚完成图形的编辑视觉，让它和主栏 UI3 的设计语言、动画、主题、透明度保持一致。范围包括外框、控制点、旋转钮，以及下方的浮动调整栏（含颜色层级）。详细现状见 `../11-05-shape-ux-rework/research/edit-visual-and-floating-bar.md`。

## 现状问题（代码事实）

- **外框**：4 条 1DIP 直线，Accent 70%，直角，紧贴本地包围盒、没有间隙；外框线与缩放点不在同一位置（`Bar.ShapeEditor.cpp:592-604`）。
- **控制点**：12DIP 圆，Surface 填充加 1DIP Accent 描边，所有类型同一外观（`:529-537`）。旋转钮是另一种 32.5DIP 标准按钮，风格和控制点不统一。
- **浮条分隔线**：样式与主栏不同。
- **浮条几何动画**：按距离计速（600DIP/s），没有主栏的 0.4s 批次。
- **浮条出现方式**：只有淡入，没有锚点缩放入场。
- **"从左向右加载"**：有五个成因（research §1.10）：
  - 分隔线从 (0,0) 飞入；
  - 首帧不需要的按钮坐标为 0；
  - `initialized` 跨会话保持；
  - 宽度动画裁剪；
  - 关闭时不清快照。
- **颜色**：在浮条下方展开区域选色，没有独立层级；取色器没有标记点、预览、Hold、RGB。主栏取色器本身也不按屏幕夹紧（`Bar.RenderLoop.cpp:6361`）。
- **浅色主题**：编辑器没有设置 `lightMaterial`/`themeSurface`，浅色下边缘光和投影仍按深色规则解析。
- **常驻透明度**：编辑器没有接入；`SetResidentOpacity` 和主题变化也不会唤醒 `Client::SelectionOverlay` 重绘。

## 已确认决策（2026-11-05 用户）

- V1 控制点：WinUI3 滑块（Slider Thumb）样式，即外圈加强调色内芯。复刻主栏粗细滑块 Thumb 的几何、颜色和动画（`Bar.RenderLoop.cpp:11845-11921`）：
  - 外圈：深色为 Surface 与 TextPrimary 按 20% 混合，浅色为纯白；12% 描边。
  - 内芯：正常 12、悬停 14、按下 10，强调色强度 1/0.9/0.8，过渡 0.12s。外圈不缩放。
  - 抽成可复用的绘制 helper，主栏和编辑器共用。
- V2 外框：加粗、圆角，与图形本体之间留间隙。
- V3 旋转钮：使用滑块外圈，内芯换成强调色旋转图标，尺寸略大于控制点；悬停/按下只改变图标缩放和强调色强度；用一条短连接线连到外框顶边。
- V4 透明度：
  - 浮条、绘制提示属于常驻控件，背景透明度和内容透明度都跟随设置；
  - 外框、控制点、旋转钮跟随内容透明度；
  - 色板层、取色器层按弹层规则，固定 0.95，不受设置影响；
  - 主栏图形面板保持现状。
- V5 深色、浅色两种主题都要适配，浅色接入 lightMaterial 和投影规则。

## Requirements

- R1 外框：
  - 线宽 2DIP，圆角半径 6DIP（实现时可在 ±2DIP 内微调并截图确认）；
  - 外框与图形描边外缘之间间隙 8DIP，即外框基于含线宽的几何包围盒再外扩；
  - 颜色用 Accent，适配深浅主题；
  - 外框随对象 transform 一起旋转；
  - 所有图形都绘制外框，包括直线、折线、圆。外框上是否带点由 edit-interaction 定义。
- R2 控制点与旋转钮按 V1/V3 实现：
  - 视觉外径约 20DIP，命中区仍不小于 44DIP；
  - 旋转钮外径约 28DIP，连接线 1.5DIP；
  - 出现时沿用 Thumb 的 0.28s opacity/scale(0.75→1) 入场。
- R3 浮条按主栏 UI3 规范重做：
  - 浮条有自己的 `BarButtonListClass`（SingleRow），所有按钮走主栏统一的 Configure/Retarget/Advance/Draw；
  - 分隔线用主栏 Divider 模板（`Bar.Button.cpp:225-250`、`Bar.RenderLoop.cpp:2716-2733`）；
  - 按钮显隐、位置用主栏 0.4s 批次与 CanJoin 规则，隐藏按钮锚定到相邻可见成员（`AnchorHiddenBarButton`，`Bar.RenderLoop.cpp:915-951`）；
  - 线型、填充等组的显示与隐藏动画与主栏按钮显隐一致。
- R4 浮条出现/消失：
  - 使用 `BarAttributePanelMotion`（`Bar.EraserAttributeMotion.cppm`），从对象锚点紧凑态以 EaseOutBack 回弹展开，消失时 EaseInBack；
  - 每次进入新的编辑会话都重置布局（首帧所有成员 SetDirect），彻底消除"从左向右加载"和从上一会话位置滑入的现象；
  - 关闭时清理快照。
- R5 颜色层级（同一 SelectionOverlay 窗口，不新增 HWND）：
  - 第 0 层：浮条中的颜色入口，改为圆角矩形色块，显示当前颜色。
  - 第 1 层：点击入口弹出色板层，复用主栏绘制属性的色块排列和视觉：30×30、r=4 圆角矩形，11 预设色加自定义入口，`colorSelect` 选中徽标。
  - 第 2 层：点击自定义入口，在其上方再弹出取色器层，复用 `ColorPalette`/`GetBarColorPickerColor`，补齐标记点、预览和 Tone 切换。
  - 每层都用 BarAttributePanelMotion 从触发点回弹出现；点击外部或 Esc 逐层关闭。
  - 颜色写入当前对象（`ShapeUiAction::SetStyle`），不修改下一笔画笔的颜色。
- R6 屏幕适配：
  - 浮条：放在对象下方，空间不够时放上方，并钳制在工作区内、避开主栏；
  - 色板层、取色器层：优先向浮条外侧弹出，放不下时换边，再不行就按 `FitEraserSurfacePose` 缩放/平移进工作区。
- R7 渲染唤醒：常驻透明度变化、主题切换时，唤醒 `Client::SelectionOverlay` 重绘。
- R8 修复按键截获：
  - Esc 只在 Inkeys 前台或浮条可见时处理；
  - 方向键、Space、Enter、Tab 只在浮条内容拥有焦点时截获，避免影响 PPT 翻页（`SelectionOverlay.cpp:174-191`）。

## Acceptance Criteria

- [ ] 离屏截图（深浅主题 × 1.0/1.5/2.0 倍率）中：外框为 2DIP 圆角，与描边之间留 8DIP 间隙；控制点和旋转钮为 Thumb 样式；悬停和按下的内芯尺寸与强调色强度符合 V1。
- [ ] 浮条首次出现、在两个对象之间切换时：任一成员都不从左上角、左侧或上一会话的位置移入（由测试断言首帧位置等于目标位置）；出现和消失使用回弹动画。
- [ ] 浮条分隔线与主栏 Divider 的颜色、透明度、尺寸一致（像素或参数断言）。
- [ ] 线型、填充组的显隐按 0.4s 批次锚定动画执行，不出现跳变。
- [ ] 颜色：入口→色板层→取色器层可以逐层打开和关闭；屏幕边缘的对象打开时，三层都在工作区内（测试覆盖四个边角和小工作区）。
- [ ] 背景透明度调到 50%、内容透明度调到 60% 时，浮条和提示的背景、内容按比例变化，色板层和取色器层保持 0.95；修改设置后编辑浮条会立即重绘。
- [ ] 浮条可见时，PPT 放映中光标停在对象附近按 →/空格，仍能正常翻页；白板最小化后按 Esc 不被截获。
- [ ] `--ui3-shape-editor-test` 更新后通过。

## Dependencies

- 控制点的集合与外框是否带点由 edit-interaction 决定；本任务负责样式和绘制，两者共享 `Bar.ShapeEditor.cpp`。
- 本地跟手（edit-performance R3）会改变控制点位置的数据来源，绘制 helper 需要接受本地位置作为输入。
