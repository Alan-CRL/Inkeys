# 设置性能页、绘制开关与画布调测信息

## 目标

让用户分别调整共享界面和 Draw3 画布的刷新负载，在设置中控制通用绘图效果与已有激光笔能力，并在软件调测页直接查看真实画布初始化信息。

## 背景与已确认事实

- 用户最新修正：“界面帧率”统一作用于 WARP 管线中的设置、主栏和翻页控件；画布是独立的一套。
- 共享界面当前固定约 60 FPS：`Inkeys/Inkeys/UI/RenderPipeline/RenderPipeline.cpp:52`、`:736`。
- Draw3 已有四套完整建模参数，当前固定使用 120 档：`Draw3.StrokeGeometry.cpp:452`、`Draw3.InkPrediction.cppm:78`。帧率需要连同整套模型参数接入。
- 实验室已有三个待迁移选项：`Inkeys/Inkeys/UI/Setting/Setting.cpp:4001`，它们的偏好只在启动时应用。
- 激光笔多指和粒子已有 controller 能力，但未接入产品设置；通用多指绘制尚无总开关。证据见 `research/draw3-controls-and-canvas-info.md`。
- 用户本轮确认绘制页采用“通用”三项，名称、顺序、默认值和新落笔生效合同以 R3 为准。既有预测分支见 `Draw3.InkPrediction.cpp:246`，既有抬笔完成态修正见 `Draw3.StrokeGeometry.cpp:889`、`:798`；详细接线见 `research/general-drawing-options.md`。

## 需求

### R1：性能页与两套帧率

- 新增独立“性能”设置页，导航位置在“绘制”之后。
- “界面帧率”：仅 30 / 60 FPS，默认 60；统一控制共享 WARP 界面，修改后应用于后续调度批次并保存。
- “画布帧率”：30 / 60 / 120 / 240 FPS，默认 120；首版采用重启生效，并在条目中说明。
- 两项互不覆盖。目标帧率不承诺达到该数值，也不改变输入采样率或动画速度倍率。

### R2：迁移现有性能相关选项

- 从实验室迁入“画布硬件加速”“优先使用 DirectComposition”“兆芯 GPU 兼容模式”。
- 三项均保持默认开启、重启软件后生效；DComp 不可用时仍沿现有回退路径。
- 已有用户偏好不丢失；实验室不再重复显示这三项。

### R3：通用绘图分类

- 绘制主页先显示“绘图环境”（原“绘图效果优化”），再显示“通用”分类，依次包含以下三项，修改后保存，均只对新开始的落笔生效；不显示额外的统一生效提示。

| 条目 | 控件与默认值 | 用户确认的行为 |
| --- | --- | --- |
| 多指绘图 | 开关，默认开启 | 开启时保持现有 Touch 多指能力；关闭后限制新增额外 Touch 绘图准入，Pen/Mouse 保持现有行为 |
| 抬笔笔锋修正 | 开关，默认开启 | 控制现有抬笔异常折线的尾段重算，不是普通笔锋粗细渐变或光标选项 |
| 墨迹预测 | 下拉框：精准 / 快速 / 关闭，默认精准 | 精准复用现有 Kalman；快速复用 Ink Stroke Modeler 的 StrokeEnd 预测；关闭不生成预测笔迹 |

- 同一笔从落笔到完成采用落笔时的偏好；设置变化不得影响已在进行、等待断触接续或尚未完成收尾的旧笔画，不需要重启软件。
- 多指开关不通过关闭 RTS 多指采集实现，必须完整处理已接受或已忽略接触的 Up/Cancel，避免残留活动触点；被忽略的触点不会在其他手指抬起时中途接管。
- 抬笔修正保留已有适用工具范围、异常判定与失败回退；关闭时不额外改变正常笔锋形态、模型或历史笔迹。
- 预测复用既有模型和三种模式，不修改算法或依赖；关闭预测不等于关闭实时建模、平滑、正常笔锋或独立抬笔修正。
- 说明应直接描述用户可感知的书写效果与选择差异，语气正式，不复述标题，不暴露算法类名、枚举或内部参数；生效时机清楚。候选文案见 `design.md`。

### R4：激光笔分类

- 在绘制主页增加“激光笔”分类，“多指激光笔”默认关闭；“激光笔粒子效果”保留为不可操作条目，不显示 toggle。
- 两项说明保留 `BETA`，不重写算法；粒子效果在 Draw3 创建和设置入口均强制关闭，旧配置或启用请求均不能开启。
- “多指激光笔”仅在全局“多指绘图”开启时可见；隐藏保留原偏好，有效值为全局开关与该偏好的合取。显隐随当前偏好变化，旧笔画仍遵守落笔时的设置。
- 粒子旧配置字段可保留兼容读写，但产品不使用其启用值；激光主体与多指激光笔继续按现有能力工作。

### R5：软件调测页的画布信息输出块

- 在现有软件调测页增加只读画布信息块，无需开启控制台或 Draw3 控制台输出即可查看。
- 展示初始化状态、实际 Hardware/WARP 设备、D3D Feature Level、图形适配器名称与设备身份及可取得的驱动/显存信息。
- 展示实际窗口呈现方式（DComp / ULW，必要时说明辅助 ULW 表面）以及交换链配置：尺寸、格式、缓冲数、SwapEffect、AlphaMode、采样和相关 flags / waitable 状态。
- 展示实际 RTS Extended / RTS Basic XY / Win32 鼠标兼容回退模式，并在回退时给出已有可取得的原因或错误码。
- 数据来自 Draw3 当前初始化/恢复代次的实际结果；不能用用户偏好、一次失败尝试或固定模板冒充最终结果。
- 未初始化、停止、查询不可用和失败时明确说明状态；原显示器与 EDID 块保持。
- 不因此开启控制台、不增加逐帧采样、日志刷屏或性能监视器。

### R6：工作与兼容约束

- 用户已于 2026-10-31 明确批准最新规划并要求开始实施，按已批准的需求推进实现与验证。
- 实施保持 minimal diff、原文件编码/换行及必要中文注释；已有配置键和帧率默认行为向后兼容。
- 验证只执行静态、编译、无窗口测试；不启动 GUI / Computer Use，不自动 commit / push。

### R7：2026-11-01 用户继续修改

- 性能和实验选项的侧栏图标对调，页面顺序和路由不变。
- 界面默认60 FPS、画布默认120 FPS和墨迹预测“精准”选项标注“（推荐）”，仅改变显示文案，不改变值或默认行为；用户所写“精致”按现有“精准”处理。
- 绘图环境/通用顺序及移除统一生效提示按 R3；粒子无toggle并强制关闭按 R4。
- 本次明确修改请求授权直接继续实施，保持当前任务与既有未提交修改。

### R8：设置注意事项独立提示行

- 激光笔多指说明去掉“修改后对新开始的笔画生效”；粒子说明去掉“当前版本暂不可用”。这些文字直接移除，不转为提示行；BETA、无粒子toggle及运行时强制关闭保持。
- 对现有设置选项中的特别注意事项进行完整检查：重启/下次启动、明确的权限/依赖前提、数据风险等，从普通解释中分离，放在解释下方的独立信息提示行。
- 提示行采用与对应解释相同字号，蓝色信息i图标、正常前景色文字；不使用独立大警告卡片。支持换行、窄窗、分数DPI和明暗主题，不遮挡操作控件或下一条设置。
- 普通功能解释、模式/按钮名称与独立错误/确认对话框保持语义，不以关键字自动拆句。原先已要求删除的统一新笔提示不恢复。
- 本轮只改设置显示、国际化和必要的控件/布局测试；不改选项实际生效时机、权限流程或绘制逻辑，不启动GUI或提交。

### R9：信息图标与说明块边界（用户最新纠正）

- 条目下的额外注意使用填充InfoSolid（U+F167），不是描边；保持字号、颜色和占位。
- 只有具体条目已有普通解释时，额外注意才显示i。若只有单段说明（如IslandCaller、SecRandom、NamePicker等协议前提），按普通说明显示，不加i。
- 原有类/页级信息框保持原样，恢复快捷键整块说明、ClassIsland联动框、更新通道等原块；不把类级信息拆成单独i行。
- PPT子页顶部重复的支持版本说明去掉；教程/权限说明卡片恢复普通正文，不额外加蓝i，解决方案动作和条件保留。插件主页已有支持说明保持。
- 软件版本页顶部更新状态框标题改为独立的“版本状态”，不改实际更新偏好栏目名。
- 目标更新通道和目标更新架构恢复原呈现；其他具体选项内确属额外注意的重启等提示保持。

### R10：诊断信息复制与全称

- 画布初始化信息和显示器/EDID两个块各自在块下方提供一个右对齐、标准尺寸“复制”按钮，复制对应块完整文本，包括多行和全部显示器，不只复制可见部分。复制值必须与该帧展示的同一字符串一致。
- 画布信息显示完整SDK常量名及原数值：DXGI_FORMAT、DXGI_SWAP_EFFECT、DXGI_ALPHA_MODE、DXGI_SCALING、交换链flags（含FRAME_LATENCY_WAITABLE_OBJECT）；组合/未知值保留真实数值，不伪造枚举。
- SampleDesc明确Count/Quality，Count=1且Quality=0注明无MSAA；Feature Level显示D3D_FEATURE_LEVEL_11_1等完整常量名，避免与API版本混淆。
- Hardware说明为硬件GPU，辅助ULW使用UpdateLayeredWindow全称，RTS输入使用RealTimeStylus全称；RTS尝试状态用明确中文就绪/失败，HRESULT显示符号与8位十六进制，UMD改为用户态图形驱动（UMD）版本。
- EDID区DPI显示X/Y与乘号，保留EDID解析状态并补充Extended Display Identification Data全称。
- 仅改只读文本格式/复制操作和必要测试，不改设备/交换链/输入初始化或回退逻辑，不增加UI线程COM查询。

### R11：ImGui游标边界错误修复

- 用户调试软件页出现SetCursorPos/SetCursorScreenPos扩展边界而未提交item的ImGui报错，需要消除触发原因，不屏蔽错误检查或改第三方。
- 已定位CopyButton末尾恢复cursor：Y含Button后的ItemSpacing而CursorMaxPos不含，若复制按钮为页面最后项，EndChild即触发。
- 保持复制按钮标准尺寸、右齐、左cursor恢复、纵向间距、ID/完整复制行为，采用正确布局登记方式。
- 回归必须真实覆盖复制按钮为child/parent最后项后立即EndChild/End，包括滚动裁剪、非零间距及分数DPI；不能靠后续标题/Dummy清标记掩盖。

## 范围外

- 界面硬件加速、性能页的渲染状态、独立主栏帧率、独立帧率监视器和额外性能预设。
- 移动动画、边缘点光、小数字体或既有调试开关；新增显示器刷新率自动匹配、VSync、缓存/线程参数。
- 重写预测或抬笔修正算法、修改修正阈值、改动激光粒子池/Shader、开放画布平移或新手势、恢复 Draw2、调整依赖或构建系统。
- 自动提交/推送、交互式 GUI / Computer Use / hidden HWND fixture 验证。

## 规划交付与风险

- 交付为本 PRD、`design.md`、`implement.md`、三份研究记录和已验证的上下文清单。
- 关键风险：全局 Touch 门禁与手势登记/断触重连的生命周期、每笔预测/修正偏好锁存、恢复后的诊断代次一致性。技术方案与验证矩阵见设计和实施计划。
- 实施与验证结果见 `validation.md`、`validation-refinement.md`、`validation-attention.md`、`validation-info-scope.md`、`validation-diagnostic-copy.md`、`validation-cursor-boundary.md`；不把源码或无窗口测试结果当作真机多指、粒子视觉或驱动兼容性验证。
