# 白板画布平移与惯性

## Goal

在白板"移动（拖动）"模式下，用鼠标或手指滑动平移画布，带"摩擦耦合"式惯性（惯性中继续滑动可叠加）；根除现有惯性的"突然变大"与停手幻影；白板点阵/网格背景随画布平移。输入、惯性、视口归画布（Draw3）负责；背景纹理默认由 Freeze 窗口（D2D/WARP）按画布视口重绘（不占用画布 GPU），Draw3 shader 方案保留为编译期开关后备。

## Background（已确认事实）

- 平移/惯性内核已在产品内：`Draw3.CanvasNavigation.cpp/.cppm`；控制器接入点 `Draw3.DrawingController.cpp` 的 Touch Down 分支（约 L12142）与 `updateCanvasNavigation`（约 L13523）。目前被两处关闭：`kCanvasNavigationProductIntegrationEnabled = false`（`Draw3.WindowControl.cppm:30`，用于 `Draw3.DrawingController.cpp:12153`）；`TranslateViewport` 在白板下直接丢弃（`Draw3.DrawingController.cpp:16318`）。Inkeys 内没有键盘方向键的 `TranslateViewport` 生产者。
- 白板的"选择"按钮已显示为"移动"（`barMove`/`MoveLabel`，`Bar.Button.cpp:1090-1092`），无需新增 UI；白板 Selection 下输出仍走 PrimaryDrawpad，RTS 的触摸/鼠标 Down 会到达绘制线程，但被 `DiscardSelectionDown` 一刀切丢弃（`Draw3.DrawingController.cpp:3777/13479`）；Win32 鼠标兜底在 `MouseInputState` 内按 selectionMode 隔离（`MouseInput.h:38-42/64-69`）。详见 `research/move-mode-input-routing.md`。
- 现有惯性无法叠加是设计结论而非 bug：`OnTouchDown` 把惯性中的首触点降为 `PanCandidate`，`BeginCanvasPan` 清零旧速度，首个有效 Move 永久切断候选，spec 明文"绝不叠加"（`runtime-and-rendering.md:873/902/914`）。
- "突然变大"的根因（详见 `research/inertia-root-cause.md`，数值来自精确移植+合成输入，无真机日志）：估速器"≥2 样本即出速度"、无最小时间跨度；触点数量变化后基线错位（二指甩释放速度 120 Hz 下 p99 2.11×、最大 2.82×，60 Hz 最大 5.61×）；Down 与首个 Move 背靠背时首个速度顶到 24000 clamp（8×）；距离 ∝ v² 且上限 24000 DIP/s（单次最长 48000 DIP）；100 ms 线性拟合滞后造成停手"幻影惯性"（精准放置几乎必多滑 50–560 DIP）并低估加速甩动（0.42–0.78×）。
- 背景纹理现为独立 Freeze 窗口以 D2D 绘制（`Whiteboard.Theme.h:16-37`，`Whiteboard.cpp:120-143/217-461`），经候选/回执/租约协议提交；逐帧更新上限约 30 次/s，视口无现成通道，不可行。并入 Draw3 合成路径可行，且与今日合成结果数学恒等（`research/background-pattern-ownership.md`）。
- 白板翻页驱逐页面会重建空 `InkPage`（`EvictWhiteboardPage`，`Draw3.DrawingController.cpp:571`），视口丢失；平移不改变页 `revision`。UInk 已能存取每画布 viewport。

## Requirements

**R1 范围与门禁**
- 平移仅在 `白板工作区 && 移动（Selection）模式` 生效；桌面、PPT、绘制工具下均不触发平移，绘制模式不再有双指触发（以后绘制中的双指/手势另行实现）。
- 删除临时门禁 `kCanvasNavigationProductIntegrationEnabled`，改为按工作区+模式的明确判定；`TranslateViewport` 白板分支不再需要该丢弃（无生产者，保持无键盘平移）。

**R2 输入**
- 移动模式下，鼠标左键与触摸（任意触点数，按中心点平移，不限单指，不再需要 180 ms 双指窗口）立即成为平移触点。笔、鼠标右键不是拖动设备（继续被丢弃）。
- 触摸与鼠标同一时刻只允许一类设备持有平移，另一类忽略到终态。
- Win32 鼠标兜底路径同样在白板移动模式下接受鼠标左键拖动（该路径触摸被系统提升为单点鼠标，无多指，属已知降级）。

**R3 惯性动力学（摩擦耦合）**
- 画布与背景之间为较小的"自由摩擦"，自由滑动逐渐停下；手/指与画布之间为较大的"手摩擦"，相对速度趋零即"抓住"，抓住后画布与手 1:1 跟手。
- 惯性中按下不会立即抓住：手静止按住时，画布比自由滑行更快地减到手速再被抓住；手同向加速滑动时画布被带到手速（叠加惯性）；反向滑动时减速更快；速度差消失后进入抓住态。
- 无惯性时按下直接抓住。抓住态抬起：释放速度为手的速度估计，进入自由摩擦惯性；未抓住前抬起：画布保持当前速度继续自由滑行。
- 笔靠近（hover）按手摩擦加快减速，笔落下立即急停；此行为与现状一致，保持不变。

**R4 速度估计（修复"突然变大"）**
- 每触点独立二次最小二乘估速（100 ms 窗口、≥3 样本且跨度 ≥20 ms 才输出、≤2 ms 样本合并、>max(40 ms, 帧间隔+16 ms) 断口清窗）；加减触点只重基线中心点位置，不清估速器；速度上限 12000 DIP/s（叠加后同样封顶）。
- 释放门限用 30→70 ms 软衰减取代 100 ms 悬崖，释放速度 <250 DIP/s 不起滑；停手后抬起不得产生幻影惯性。
- 距离随速度近似线性而非平方：自由滑行为"指数+库仑摩擦"闭式积分（与帧率/卡顿无关）。
- 速度与距离以 DIP 计算，经显示缩放转换为像素，不再把物理像素当 DIP。

**R5 中断与状态**
- 离开移动模式、翻页、切换工作区、白板加载、最小化、笔落笔、窗口 Resize 都立即终止手势与惯性；翻页/切换后不遗留速度。
- 移动模式的平移帧必须保持高精度计时器与活动帧节拍（现状 Selection 会释放 1 ms 计时器）。

**R6 背景纹理跟随**
- 默认（Freeze 归属）：点阵/网格仍由 Freeze 窗口的 D2D/WARP 管线绘制，但随画布视口重绘点/线位置（不是位图滚动）：`phase = (W/2 − viewport) mod step`，`step = 24 × DPI 缩放` 像素，视口为 (0,0) 时与改动前像素一致；允许微小的不同步帧；仅白板且纹理非空白时绘制；主题切换/换页后相位随当前页视口；平移时 Freeze 纹理更新与诊断指标（每秒更新次数、相对视口滞后帧数）仅在显式诊断下输出。
- 后备（Draw3 归属）：S5 已实现的 Draw3 合成路径 under pass 保留，由一个编译期开关选择归属方（默认 Freeze）；开关为 Freeze 时 Draw3 侧纹理路径惰性，开关为 Draw3 时 Freeze 只画纯色、只在 RGB 变化时失效。纹理预览（主栏主题面板）保持不变。

**R7 每页视角**
- 翻页后各页保持自己的视角，包含被驱逐后重载的冷页（会话内记忆，不新增 UInk 写入、不使页变脏）。

**R8 规范与测试**
- 改写 `runtime-and-rendering.md` 的 "Free Canvas Navigation" 契约、`whiteboard.md` 中"平移缩放仍禁用"等条目、`cpu-gpu-contracts.md` 的背景纹理 pass；纯 CPU 单测（估速器、拓扑、惯性、耦合）接入 `InkeysHeadlessTests`。

## Acceptance Criteria

- [ ] AC1（R1/R2）白板移动模式：鼠标左键拖动与 1..N 指触摸拖动平移画布，抓住后内容保持在指下；桌面/PPT、绘制工具、笔、鼠标右键均不平移；触摸与鼠标不互相污染。

- [ ] AC3（R4）确定性流测试：恒速估计偏差 ≤8%；加速抬起 0.85–1.10×；平台型 ≤1.20×；二指错开抬起（0–60 ms，60/120/240 Hz）释放速度 0.9–1.15×；背靠背 Down+Move 不超过 1.2×、不触及上限；停手 ≥70 ms 抬起恰为 0 惯性、50 ms <250 DIP/s；NaN/倒退时间/重复 QPC 不改变状态；3000 DIP/s 滑行距离与 12000 DIP/s 滑行距离符合闭式（684±1 / 3266±2 DIP，参数以最终标定为准），2× 速度误差距离放大 ≤2.5×。

## Key Decisions & Assumptions（待最终评审确认）

- D1 摩擦耦合模型即用户描述的"叠加惯性"：同向加速时画布速度被带到手速（上限 12000 DIP/s），而非 Chromium 式"新速度 + 上次起滑速度"相加；若评审希望后者，仅改释放规则。
- D2 惯性曲线由"恒减速 6000 DIP/s²"改为"指数+库仑摩擦"（τ=0.30 s，c=1000 DIP/s²），3000 DIP/s 手感基本不变（684 vs 750 DIP），低速略长、高速显著收敛；手摩擦初值 τ_h=0.06 s、c_h=6000 DIP/s²；全部为待真机标定的集中常量。
- D3（2026-11-06 修订）背景纹理默认仍由 Freeze 窗口（D2D/WARP）绘制并按画布视口重绘相位，目的是不占用画布 GPU、UI 层不打扰画布；原先"迁入 Draw3"是实施方在调研后自行写入的决定，用户明确原需求并未要求用 HLSL。已实现的 Draw3 shader pass（S5）保留为编译期开关后备（默认 Freeze）；若真机体验不佳，再切换到 Drawpad 窗口承担。
- D4 每页视角仅会话内记忆（不写 UInk、不变脏）。
