# 场景进入自动居中底栏与位置设置页

## Goal

让用户决定主栏在 桌面启动 / 进入 PPT 放映 / 进入白板 时落在哪里：新增“通用 → 位置”设置页；PPT 与白板可按“进入前的主栏状态”勾选条件自动进入居中底栏，并可指定展开方向；桌面场景承接并扩展原“启动后位置”。

## Confirmed Facts（来自代码与 spec）

- 现行进入契约：Desktop→PPT/白板时，仅“已展开且 BottomDocked”的主栏贴目标屏幕底边上 5 DIP，居中/自由原样保留（Free 不居中），悬浮、折叠不变，PPT 不主动展开。`Bar.RenderLoop.cpp:13575-13623`、`:2902-2905`；契约 `.trellis/spec/native-desktop/rendering-and-ui.md:993`。本任务会替换其中“不改变形态/不展开”的部分（仅对勾选命中的状态）。
- 退出放映/白板回到进入前的桌面基线（位置、方向、fold、dock/center、显示器）；PPT↔白板互切不重拍基线。该还原逻辑已存在，本任务不改（用户确认）。
- 白板最小化会把已有展开底栏临时置为 Centered，恢复时还原（`Bar.RenderLoop.cpp:13631-13650`）。
- 现“启动后位置”位于 通用 → 基础（`Setting.Pages.cpp:1332`），配置 `UI.Bar.StartupPlacement`（int 0/1/2，默认 0），枚举 `UI/StartupPlacement.h`；`StartupPreview`、`Bar.Initialization.cpp`、`Bar.RenderLoop.cpp:2856-2900`、`:13722` 消费它。
- 设置页分区 `GeneralSection`（`Setting.Design.h:74`），侧栏子项数组 `Setting.Shell.cpp:162` 以 `static_assert` 绑定数量。
- 现成“下拉 + 内联复选项”样式：`RenderPptIdleFadeRow`（`Setting.Pages.cpp:1225`）；内联下拉 `InlineCombo`。

## Requirements

1. 通用新增子页“位置”，三个分类：**桌面场景**、**PPT 场景**、**白板场景**。
2. **桌面场景**：“启动后位置”迁入此处，改为“类型 + 位置”两个下拉，位置随类型联动，共 7 种，默认“居中底栏（向右展开）”：
   - 类型“居中底栏”/“居中顶栏” → 位置：向右展开 / 向左展开
   - 类型“悬浮窗” → 位置：左下角 / 右下角 / 底栏居中
   - 居中顶栏：悬浮形态，水平居中，上沿贴工作区最上端（上方有任务栏则贴任务栏）；不引入顶栏模式、不吸附、不参与底栏捕获。
   - 仍只影响下次启动，保持当前“下次启动生效”提示；已有配置值 0/1/2 含义不变。
3. **PPT 场景 / 白板场景**（结构一致）：
   - 标题“开始放映时自动进入居中底栏模式”（白板场景使用对应白板文案）。不是开关；下方内联四个复选框：底栏状态（含居中底栏）、底栏状态（折叠）、悬浮窗状态、悬浮窗状态（折叠）。默认仅“底栏状态”勾选。
   - Desktop→该场景进入时，若进入前主栏状态命中已勾选项：变为居中底栏，水平居中于目标屏幕，底沿距屏幕底 5 DIP；**折叠态命中则同时自动展开**（用户确认）。
   - 未命中的状态沿用现行行为（展开底栏贴底并保留居中/自由；其余不变）。
   - 内联下拉“主按钮方向”：不改变（默认）/ 向右展开 / 向左展开，仅在命中时生效；“不改变”保持当前展开方向。
   - PPT↔白板互切不重新套用（沿用既有“互切不重拍基线”）；退出场景后由既有基线还原覆盖全部改动。
4. 设置即时生效并持久化；新增文案同步全部语言（沿用 i18n 生成链）。

## Acceptance Criteria

- [ ] 通用侧栏出现“位置”子页，含 桌面/PPT/白板 三个分类，布局与现有内联卡片风格一致。
- [ ] 桌面场景：类型下拉切换时位置下拉选项联动；7 种组合下次启动落点正确（底栏居中、顶栏居中贴顶/任务栏、悬浮左下/右下/底栏居中），展开方向符合文案；旧配置 0/1/2 升级后行为与原来一致；默认居中底栏向右展开。
- [ ] PPT/白板场景：四个复选框默认仅“底栏状态”勾选，修改即时保存；全不选时不做任何自动调整（保持现行贴底行为）。
- [ ] 进入 PPT/白板：四种进入前状态 × 勾选/未勾选，行为符合需求 3（含折叠命中自动展开、居中于目标屏幕、主按钮方向三选项）。
- [ ] 退出后主栏回到进入前状态（位置、方向、fold、dock/center、显示器）。
- [ ] 既有 PPT/白板场景测试（`--ui3-workspace-centering-test` 等）更新后通过；新增纯函数单元/离屏用例覆盖策略判定与顶栏落点。
- [ ] `.trellis/spec` 中被替换的契约（rendering-and-ui.md:993、whiteboard.md:28、native-session-ui3.md:52）同步更新。

## Out of Scope

- 顶栏吸附/顶栏模式、顶栏拖动捕获与提示。
- 拖动吸附、居中捕获的既有手势规则。
- 运行中即时重置桌面位置（启动位置仍仅下次启动生效）。

## Assumptions（可由用户推翻）

- 子页名称“位置”，排在“基础”之后；白板文案为“进入白板时自动进入居中底栏模式”。
- PPT↔白板互切不重新套用策略。
