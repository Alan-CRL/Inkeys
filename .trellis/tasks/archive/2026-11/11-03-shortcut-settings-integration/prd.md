# 快捷方式功能整合到 Inkeys3 设置

## Goal

将桌面快捷方式的手动创建、名称选择和启动保障集中到“设置 > 通用 > 快捷方式”，让用户可使用简短预设或自定义名称，并以两个独立开关管理保障行为。用户已在本会话明确批准完整规划并要求开始实现；后续问题使用会话提问控件。

## Background and Evidence

- 现有助手的 `correctLnk`（修正已有名称/目标）和 `createLnk`（缺失时创建）位于 `Inkeys/IdtConfiguration.h:140`，实现入口为 `Inkeys/IdtPlug-in.cpp:1888`。
- 启动调用位于 `Inkeys/IdtMain.cpp:3245`；旧缺省为修正开启、补建关闭（`Inkeys/IdtMain.cpp:2994`）。
- 旧助手详情页位于 `Inkeys/Inkeys/UI/Setting/Setting.cpp:4024`；手动创建通过设置业务队列执行（`Inkeys/Inkeys/UI/Setting/Setting.cpp:1122`）。
- 详细现状和文件锚点见 `research/current-behavior.md`；它记录现有代码事实，不替代下列已确认需求。

## Requirements

### R1 导航与入口整合

在“通用”的“快捷键”下方新增“快捷方式”子页；原基本页的创建条目、更多选项按钮、插件总览的快捷方式助手卡片和原助手详情内容统一归入新页，旧位置不重复展示。其他插件与设置路由保持。

### R2 应用程序类与内联布局

第一类标题为“应用程序”，包含“创建快捷方式”条目和一个“创建”按钮。名称选择区必须内联于同一张创建卡片的下半部分，以分隔线与上方创建条目连接，复用图二 CheckboxGroup 的单外框视觉语言；右侧放名称下拉框，选择自定义后左侧显示文本输入框。窄窗、DPI 和翻译长度变化不得导致输入框/下拉框相互覆盖。

### R3 名称选项与 i18n

简中依次提供 `智绘教Inkeys`、`Inkeys`、`Inkeys(批注)`、`Inkeys(批注工具)`、自定义；其他语言隐藏品牌专用项，并本地化用途文本和界面文案。预设统一采用英文半角括号，Inkeys 与括号之间、括号紧邻内侧不额外插入空格；不通过布局截断、改写预设实际文件名。

### R4 自定义名称与生效时机

从预设切换到自定义时，以切换前所显示的名称填充输入框；用户可修改并保存，重新打开页面/软件后恢复已保存的自定义值。再次从预设进入自定义仍以当时预设为初值。切换预设或提交有效自定义名称只保存配置；点击“创建”或下次启动保障时使用新名称，不因名称变化立即重命名、创建或删除桌面快捷方式。手动创建仅创建所选名称，旧名称由启用的修正保障按原语义处理。

### R5 两个独立保障开关

第二类为“快捷方式保障”，保留“修正桌面快捷方式指向和名称”和“缺失时创建桌面快捷方式”两个独立开关，不合并。缺省修正开启、补建关闭；说明分别表达软件启动时修正已有快捷方式、缺失时补建。两个行为均使用当前名称设置。开关本身沿用已有即时应用语义，但实际文件操作通过业务队列执行；R4 的仅保存约束针对名称变化。

### R6 配置归属与兼容范围

名称选项、自定义文本和两个开关全部归入 Inkeys3 的 `Inkeys/Config/main.json`。活动逻辑不读取或双写旧 `deploy.json` 助手字段；不实现旧值迁移。缺少新字段的旧用户与新用户采用相同缺省值；保存旧配置时清理已退出活动合同的旧助手字段。

### R7 工程与过程约束

最小化修改、保持原文件编码/换行、关键逻辑添加适量中文注释；复用既有设置控件、业务队列、配置系统与构建系统。不启动 GUI，不使用 Computer Use，不提交 commit 或 push。任务在当前规划审阅通过前不执行 `task.py start` 或产品代码修改。

### R8 缺省名称与语言切换

所有语言默认 `Inkeys`。用途预设随界面语言翻译，自定义原文保持不变。已选简中品牌预设切换到其他语言时回退并保存为 `Inkeys`；语言变化同样遵守 R4，不即时修改桌面文件。

### R9 输入边界

自定义输入按 Windows 文件名要求校验；空白、非法字符/路径内容、保留名称及无法创建的长度应显示就地提示。无效编辑保留在输入缓冲中供修正，不覆盖最后有效配置，创建按钮在无效时不可用；不擅自清洗或截断用户文本。有效编辑在 Enter、失去编辑焦点或离页/关闭设置时提交。手动损坏的新配置回退为有效缺省 `Inkeys`，不执行无效路径的文件操作。

### R10 用户截图反馈：下拉弹层与说明

名称下拉弹层从按钮下方出现，不遮挡左侧文字；打开和关闭都有类似设置块的显隐动画，遵守全局动画开关/速率，退出阶段不可交互。下方补建开关的说明须明确“启动时”；上方手动创建说明去除已不存在的“更多选项”引导。当前用户已直接要求此修正，不另建任务或重复请求实现批准。

- [x] AC1（R1）：导航在快捷键之后显示快捷方式，基本页和插件总览不再有旧入口，其他页面路由正常。
- [ ] AC2（R2、R3）：应用程序类具有单个创建按钮及指定内联布局；简中有五项、其他语言四项，实际名称遵守半角括号及空格约定。
- [x] AC3（R4）：任一预设切换到自定义时输入框填入当前名称；保存/重开恢复；编辑和切换预设不触发任何桌面文件动作。
- [x] AC4（R5）：两个开关缺省 true/false，独立保存，启动及已有开关即时应用行为使用同一当前名称，文件操作不阻塞共享渲染线程。
- [x] AC5（R6）：全部活动读写归 main.json；缺少、类型错误或非法字段有确定回退；旧助手配置不迁移、不双写。
- [ ] AC6（R7）：diff 无无关大面积改动、原编码换行保持；i18n 检查、相关无窗口用例及完整 `InkeysRepo.sln Debug|ARM64` 构建通过或准确区分环境阻塞。
- [x] AC7（R8）：全部语言首次默认 Inkeys；切换语言更新用途预设、保留自定义原文、使品牌项在非简中回退 Inkeys；桌面文件保持原状直至创建/保障动作。
- [x] AC8（R9）：无效自定义输入不覆盖有效持久化状态、不允许创建；有效提交后可恢复；非法磁盘配置不会形成无效路径操作。

- [ ] AC9（R2、R10）：名称区与上方创建条目共享外框/分隔线；弹层在按钮下方打开，不遮挡左侧文案，打开/关闭/反向/禁动画及退出无交互均经真实无窗口控件验证；各语言两处创建说明准确。
