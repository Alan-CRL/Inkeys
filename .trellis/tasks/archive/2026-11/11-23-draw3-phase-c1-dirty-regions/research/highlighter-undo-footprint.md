# 粗荧光笔撤回残留与重做重叠（2026-11-23）

用户在取脏区统计数据时发现：对角线粗荧光笔撤回后，笔画两侧留下一串阶梯状三角形残留；重做后这些位置颜色加深。用户确认 1109a 版本同样存在，荧光笔较粗时才出现。与本任务的统计改动无关。

只读调查，未改代码。路径省略前缀 `Inkeys/Inkeys/Drawing/Draw3/`。

## 原因 [读]

历史系统给每条笔画算一份瓦片足迹（它碰到了哪些瓦片），撤回的前像拷贝、历史合成缓存都只处理足迹内的瓦片。

- 荧光笔实际绘制的笔尖尺寸随笔宽变化：半高 = 该点半径，半宽 = 半高 / 8（`Draw3.StrokeGeometry.cpp:605-610`，`kHighlighterNibAspectRatio = 8`，`Draw3.InkPrediction.cppm:88`）。存储点的 `width` 是直径（`Draw3.StrokeGeometry.cpp:1160`、`:1182` 以 `width * 0.5f` 还原半径）。
- 足迹计算却用写死的尺寸：半宽 1.25、半高 25（`Draw3.InkHistory.cpp:23-24`），用在两处：逐点外扩量（`:500-505`）和整笔外接范围（`:596-603`）。这两个常量只在本文件出现，是荧光笔固定 50 像素高时期留下的。

荧光笔直径超过 50 像素时，实际覆盖比足迹宽。笔画边缘伸进了足迹之外的瓦片，这些瓦片：

- 抬笔时没有拷贝前像，撤回时不恢复，留下残留（图一）。残留呈阶梯状，台阶就是瓦片边界。
- 重做时整笔重新画进 L2，残留处被再叠一次，颜色加深（图二）。

对角线最明显，因为笔尖是竖长条，斜向移动时上下两端扫过的瓦片最多。直径不超过 50 像素时足迹反而偏大，只是多拷贝，不出错。

## 修法（未实施，需用户批准）

`Draw3.InkHistory.cpp` 两处把写死的半宽、半高改为按该点 `width` 计算：半高 = `width × 0.5`，半宽 = 半高 / 8，各加原有的抗锯齿余量；删掉两个常量。改动约十行，只在这一个文件。

已保存的文档不受影响：足迹在运行时由存储点重新计算，不写入文件（待实现时确认）。

## 与 C1 的关系

答复 6 要把 L2 写入、撤回、重做改成分段矩形，那份分段数据同样来自笔画的真实几何范围。这个缺陷说明足迹与实际绘制范围必须出自同一处计算，设计时应合并成一个来源，而不是两份各写各的尺寸。
