# 页码延迟显示的环形加载指示器

## Goal

将现有PPT页码右上角三点替换为小型WinUI3风格环形加载指示器：短加载不打扰，长加载有清楚且平滑的反馈。

## Background

现角标在Page id3右上角，前后翻页共用一处；来源为命令等待及页面Pending/Recovering准备。恢复控制态、稳定显示数字、错误/Retry与真实Present/UI ACK已分离。本任务只改变这个角标，不继续已归档任务的性能调查。

## Requirements

- R1 外观：保留同一角标区域/左右方向共用，灰色整圈轨道取SurfaceFrame主题角色，较粗圆头旋转弧取TextPrimary；小而协调，不遮当前/总页数，不移动数字、字号或布局，不显示百分比。
- R2 延迟：连续等待满500ms且仍在等待才开始显示；未满0.5秒结束不得迟到闪现。重复true/同段方向变化不重计，false后新段重新计时；不跨无等待事实的空档拼接。
- R3 动效：显隐同时透明度与非线性缩放，从当前呈现值可打断续接；不强制最短可见时间。显示期间旋转，退场结束停止，遵循现全局动画开关/速度（关闭时静态弧、显隐即时），但0.5秒门槛不受动画速度影响。
- R4 生命周期：隐藏、白板/工作区切换、换session与注销退休旧状态与截止时间。指示器不保留隐藏窗口、不改变输入锁、页码、控制身份、ACK或错误/Retry动作。
- R5 实现约束：复用共享主题/曲线/原有InputWorker deadline通路；不在等待门槛前持续重画，不新增线程、WinUI运行时或全局设置。资源初始化/释放遵循现设备epoch，原生COM/D2D资源正常配平，不改PptCOM.cs。
- R6 验证范围：AI仅无窗口验证；实际视觉操作由用户完成。保留源码编码/换行、minimal diff、中文关键注释；没有单次明确授权不commit/push。

## Acceptance Criteria

- [x] AC1（R2）：可注入时间下499ms不可见，500ms持续等待才入场；结束/过期wake不闪出。
- [x] AC2（R1）：指定主题角色色、圆头粗弧与完整轨道；四surface/三倍率/最大位数字体下不遮字、单角标不改变命中。
- [x] AC3（R3）：旋转和入退场透明度/非线性scale连续，取消/重启/同目标通知不跳回初值或错误重计；全局禁动画仍遵守0.5秒门槛。
- [x] AC4（R4/R5）：延迟期渲染可Idle，到期沿原InputWorker仅唤醒当前状态；退出/隐藏/注销后无过期访问、无无限续帧/窗口滞留。
- [x] AC5（R4）：原稳定数字、正常Numeric即时更新、故障文案/Retry、旧ACK拒绝和输入/业务门均不回归。
- [x] AC6（R5/R6）：完整Debug|ARM64、定向及真实离屏/partial=full/资源重建/动画开关验证通过，再交用户人工确认；COM源/二进制不变，未测平台明确列出。
