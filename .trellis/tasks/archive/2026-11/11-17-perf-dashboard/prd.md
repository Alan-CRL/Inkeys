## Goal

在设置 → 性能页最顶端提供一个美观的“设备性能”看板，让用户直观看到这台设备绘制画布是否轻松：大号负载百分比、文字结论与帧率建议、可展开的各工具详细百分比。数据来自日常使用中的低开销记录（不是专门跑分），按天存在本地，取最近 7 个使用日现算，用得越多越准。

### R1–R4（2026-11-18 用户批准“按建议来”）

- **R1 采样方式改为逐帧累加**：原预告是“每段只记前几帧、多了不记”。建议改为每个计数帧向固定计数器做几次加法（无分配、无锁，比环形缓冲更省），抬笔空闲时整体移交。理由与开销对比见 design §3。
- **R2 档位阈值**：建议 绿 < 50%、灰 50–80%、黄 80–100%、红 ≥ 100%；另外超预算帧占比 > 10% 时至少为黄（平均值掩盖卡顿）。
- **R3 原“周期可选、可关闭”**：建议去掉周期长度选项（固定 7 个使用日），保留“记录设备性能数据”开关（默认开）与“清除数据”按钮，放在展开区底部。
- **R4 设置签名包含哪些项**：建议包含画布帧率、实际设备（硬件/WARP）、实际呈现模式（DComp/ULW）、waitable 等待、ULW 异步读回、ULW 合成对齐、兆芯兼容；不含界面帧率与“绘制时鼠标移动不受画布帧率限制”。

## Requirements

### 记录
- 只记录真实绘制的帧循环：属于以上 6 个维度之一的帧；无脏区的帧只算计算帧；悬停光标、拒收接触节拍帧、设备恢复、输出切换、画布调试可视化开启时的帧不计入（详见 design §2、§14）。
- 三个帧率口径与画布调试一致（design §14）：计算帧率 = 帧循环推进速度；渲染帧率 = 落进新 DWM 合成周期的提交帧；无限制渲染帧率 = 整帧耗时只扣人为等待（帧率等待、DWM 对齐、上一帧 GPU 已完成时的 waitable 显示节拍），保留等 GPU。
- 负载百分比只看帧循环能否按画布帧率推进：耗时占比 = 无限制渲染耗时 / 画布帧间隔；计算帧率低于画布帧率 3% 以上时取 max(耗时占比, 画布帧率 / 计算帧率)。渲染帧率只显示，不定档位。
- 抬笔进入空闲时把本段累加结果移交给后台；后台合并进“今天 × 当前签名”的日桶，刷新看板缓存，并合并写盘（不是每次抬笔都写）。
- 每个签名只保留最近 7 个使用日；签名数量设上限，超出时淘汰最久未用的签名。
- 文件损坏、版本不符或读取失败时不影响绘制和设置页：备份坏文件后从空开始，并记日志。

### 展示
- 位置：设置 → 性能页最顶端，现有各节之前。
- 收起态（2026-11-18 文案轮精简，2026-11-19 帧率口径轮）：标题与档位/状态标签、大号总负载百分比；其右侧为负载标签、“平均渲染帧率 约 N FPS”、小字“计算帧率 约 N FPS · 无限制渲染帧率 约 N FPS”；一句档位结论；结论下方“当前显示器的帧率限制为 N FPS”（实测刷新率范围，如 60–120；未测到不显示）；展开按钮。
- 展开态：动画展开，6 个维度各一行：名称、负载百分比、条形、平均渲染帧率；未使用的维度显示“暂无数据”；样本少的行数值为灰色（不附文字）。底部为“记录设备性能数据”开关（无说明文字）与“清除数据”按钮，同一行靠右显示评估时间。
- 无任何数据：中性卡片 + 引导文案（“画几笔后这里会显示设备性能”）。
- 当前签名无数据但有其他签名数据：显示最近使用的其他签名，并标注“设置变更前的数据，重启后的新设置还在积累”。
- 不显示帧率建议（design §5 的建议规则已在文案轮删除）；所有文案 20 语言本地化。
- 软件调试页“画布”节新增“设备性能看板预览”下拉框：默认 / 无数据 / 充裕 / 适中 / 偏紧 / 超载 / 设置变更前；选非默认时性能页看板显示虚拟数据，只影响显示，不影响记录、统计与文件；不写配置，重启恢复默认。
