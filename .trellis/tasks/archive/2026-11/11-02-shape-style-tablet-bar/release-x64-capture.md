# Release x64 数位板日志采集步骤

## 1. 先开启诊断，再完整退出

启动本轮 Release x64 的 Inkeys.exe。进入 设置 → 实验选项 → 控制台输出，勾选“测试触控反馈”（此前已勾选则保持）。然后通过软件退出功能完整退出，不能只关闭设置窗口；否则命令启动可能交给旧进程，无法采集新版输出。

## 2. 用 CMD 启动并测试

在 Inkeys.exe 所在文件夹的地址栏输入 cmd 并回车，执行：

```cmd
start "" /b /wait ".\Inkeys.exe" > ".\M6-input.txt" 2>&1
```

当前仓库的完整路径写法：

```cmd
cd /d "D:\Project\Inkeys\Repo\Inkeys\Build\x64\Release"
start "" /b /wait ".\Inkeys.exe" > ".\M6-input.txt" 2>&1
```

stdout和stderr都合入M6-input.txt；新程序会保留这两路文件重定向，因此不需要额外弹出的诊断控制台。/wait使CMD等待软件退出，软件主界面仍正常用于手动测试。以上只是提供给用户的启动命令，本次构建不替用户运行GUI。

全程只用高漫M6，按原方式在主栏与左右翻页控件间来回点击；发生失效时继续点同一目标几次，保留失效及恢复过程，不立即重启或更改驱动/Windows Ink。记住大致操作顺序。测试结束后完整退出软件，等待CMD提示符返回。

## 3. 交回日志

发送同目录的M6-input.txt，并说明大致点击顺序、哪些控件何时无响应、是否把笔移出感应范围后恢复。日志应包含event=ui_schema v=1与event=ui_input v=1；保留从启动到结束的全部内容，不只贴最后几行，也不要只发送普通log/idt文件。

此命令每次会覆盖同名日志；如需再次采集，先保留/发送旧日志，或将文件名改为M6-input-02.txt。
