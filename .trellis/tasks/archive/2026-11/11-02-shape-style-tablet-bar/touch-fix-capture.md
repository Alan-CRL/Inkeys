# 五窗 Touch 修复版：一次实机复核

本轮修复对应持续感应跨窗时 WM_TOUCH 仍投递旧窗，以及分页兼容鼠标 Down/Up 分类变化遗留会话的问题。自动回归不能代替设备验证。请用同一块之前已复现的数位板完成下面一轮测试，中途不改驱动设置。

## 1. 开启输出并退出旧进程

使用 Build/x64/Release/Inkeys.exe。设置 → 实验选项 → 控制台输出中的“测试触控反馈”应已勾选；若未开启，勾选后完整退出软件。若此前已开启，直接完整退出旧进程即可。不能只关闭设置窗口。

测试 PPT 长按时，确认“启用翻页按钮长按翻页”已开启，并使用页数足够的测试幻灯片。

## 2. 用 CMD 启动

在 CMD 中执行：

```cmd
cd /d "D:\Project\Inkeys\Repo\Inkeys\Build\x64\Release"
start "" /b /wait ".\Inkeys.exe" > ".\M6-touch-fix.txt" 2>&1
```

stdout/stderr 都保存到同目录 M6-touch-fix.txt。不要用 PowerShell 直接粘贴这条 CMD 启动命令。此文件名与上一轮 M6-input.txt 分开；重复本轮时请先保留已有 M6-touch-fix.txt。

## 3. 连续完成这一轮

1. 保持笔在感应范围内，悬浮移动到主栏、左侧分页、右侧分页并依次点击，往返几轮；尽量覆盖当前显示的四个分页窗口。重点是不把笔移出感应范围。
2. 在 PPT 中静止按住翻页箭头约 2 秒：应立即翻页，随后按原长按设置连续翻页，抬笔停止。另做一次按住后移出箭头，移出应停止，移回不自行重新开始。
3. 在白板中按住箭头后抬笔：应只在有效抬起时翻一页。分别验证左右分页，再返回主栏点击。
4. 在主栏打开画笔属性，点击颜色并拖动粗细，再拖动主栏；确认连续操作能正常结束，随后仍能点击分页。
5. 如仍有点不动，先在同一目标继续点两三次，再把笔移出感应范围后返回，比较是否恢复。保留失败前后输出，不立即重启。测试结束后完整退出，等待 CMD 提示符返回。

## 4. 交回

交回完整 M6-touch-fix.txt，附设备型号和大致操作顺序，说明是否出现无响应、当时目标和离开感应范围是否恢复。新日志保留 ui_schema/ui_input v=1，并增加 touch_select、touch_probe、touch_deliver、route_down、route_cancel 等阶段，可关联 origin 与逻辑目标 HWND、registration 和 route_generation。不要只交普通 log/idt 或最后几行。
