# 修复候选版：Pointer 输入（一轮验证）

这一版是**修复候选版**，不是探针：手指和笔（含只发 Pointer、不发 WM_TOUCH 的数位板）直接用系统的 Pointer 输入点击主栏与白板/PPT 翻页，长按和笔震动保持原样。同时包含两个缺陷修复：

1. 手指在白板书写后，第一下点翻页按钮无效。
2. Surface 笔在“更多”展开时点主栏，第一下只收起菜单、不执行按钮。

请用你之前出问题的设备完整测一轮。如果这一轮一切正常，就不需要再测了。

## 1. 日志（建议开启）

设置 → 实验选项 → 控制台输出，勾选“测试触控反馈”，完整退出软件后再启动。不开也能使用；开启后日志里会有 `pointer_route`、`touch_dropped` 等记录供我核对。

```cmd
cd /d "D:\Project\Inkeys\Repo\Inkeys-draw\Build\x64\Release"
start "" /b /wait ".\Inkeys.exe" > ".\<设备名>-candidate.txt" 2>&1
```

文件名按设备区分（如 m6-candidate.txt）。

## 2. 操作清单（每台设备）

1. 进入白板（或打开 PPT）。
2. 点主栏几个按钮；点左右翻页按钮，每个至少 3 次，包括**在白板书写之后**立刻点翻页。
3. 展开翻页控件的“更多”，再点主栏按钮：应当一次点击就执行按钮，同时菜单收起。
4. 在按钮上按下，拖出按钮再抬起；在按钮上长按约 2 秒（PPT 翻页开启长按时应持续翻页）。
5. 笔：点主栏按钮，留意震动（主栏应有，翻页控件本来没有）。
6. 笔悬停着在主栏、翻页控件和画布之间移动，再接触点击。
7. 鼠标点几下确认正常。

## 2b. 本版新增（第二轮候选）

- **白板翻页转圈**：白板翻页超过约 0.3 秒仍未完成时，页码按钮右侧出现一个旋转圆环，翻页完成后消失；短暂切换不应出现。请在 Surface 上连续翻页，留意慢的那几次是否出现圆环、圆环是否流畅旋转、是否残留。
- **笔震动偶发丢失**：笔点击后紧接着离开感应范围的快速点击，之前约 10% 会没有震动；请连续快速点主栏按钮二三十次，留意是否还有漏震。

## 3. 回传

日志文件 + 简短描述：哪台设备、操作中有没有出现“点不动 / 要点两下 / 误触发 / 长按圆圈 / 右键菜单”。

## 4. 如果这一版整体不工作（应急）

先完整退出，然后在 CMD 里设置环境变量再启动，会回到旧的 WM_TOUCH 来源：

```cmd
set INKEYS_UI_TOUCH_LEGACY=1
start "" /b /wait ".\Inkeys.exe" > ".\legacy.txt" 2>&1
```

把两份日志一起发回即可。
