# 绘制步骤提示

## Goal

把多步绘制（圆弧、扇形、立体图形、折线、多边形）时的主栏提示改成和「底栏模式」提示一致的外观和动画，让用户知道当前在第几步、这一步要做什么，并提供标准图标按钮来完成上一步、下一步、结束绘制、取消。现状与差异见 `../11-05-shape-ux-rework/research/construction-prompt.md`。

## 已确认决策（2026-11-05 用户）

- P1 外观对齐底栏模式提示：
  - 圆角 6；
  - 常驻表面材质：Dark 基色加 `themeSurface/residentSurface/lightMaterial`，主光源开启，鼠标光 1.0；
  - 13DIP 粗体文字；
  - 出现/消失用 0.4s EaseOutBack/EaseInBack 缩放加透明度；
  - 换文案时按「扩框 → TransitionToString(0.4,0.5,0.8) → 缩框」三阶段（`Bar.BottomDock.h:134-152`、`Bar.RenderLoop.cpp:7683-7760`）。
- P2 步骤进度：
  - 固定步数的工具：左侧是环形进度（复用 `DrawProgressRing` 或对其做公开封装），环内写「n/N」；
  - 文案为「第 n 步 · 本步说明」，例如「第 1 步 · 确定底面」；
  - 折线和多边形步数不固定，不显示环，文案为「已确定 k 个点 · 落笔确定下一顶点」。
- P3 按钮：全部改为主栏标准 OneOne 图标按钮，不复用撤销和重做的图标（`barRecall`/`barRedo`）。
  - 上一步「‹」：沿用 Back 的语义，回退最近确认的一步。
  - 下一步「›」：新功能，恢复刚刚用「上一步」回退掉的那一步。只要还有可恢复的步骤就可以点。如果在回退之后又落笔确认了新的一步，可恢复的步骤就被清空。
  - 结束绘制「✓」：只在折线和多边形显示，至少有 2 个点（折线）或 3 个点（多边形）时可以点。点击后多边形会首尾闭合，折线直接完成。
  - 取消「✕」。
  - 图标：上一步、下一步用新增的 chevron 图标，或者旋转 `barMore`；结束用 `fluentCheckmark12Filled`；取消用 `barCloseSmall`。
- P4 位置：主栏上方 5DIP，按实际面板高度留出间距；上方放不下时放到主栏下方。
- P5 修复提示消失：多步绘制（ConstructionSession active）期间暂停主栏的「绘制自动收起」（`Bar.Interaction.cpp:1025-1033`）。如果用户手动收起主栏，提示仍要显示，锚定到收起后的主按钮。

## Requirements

- R1 快照补充总步数，或由工具能力推导：
  - 单笔工具 1 步，不显示提示；
  - 圆弧、扇形、立体图形 2 步；
  - 折线、多边形不定步数。
  - 本步说明沿用现有 i18n（`ShapeConstruction.*`），新增「第 n 步」「已确定 k 个点」的文案，以及各按钮的无障碍名称和 tooltip，补齐 20 种语言。
- R2 新增「下一步」：
  - `ConstructionSession` 增加一个可重做步骤栈：Back 时把这一步压栈，确认新步骤时清空栈；
  - `ShapeUiActionKind` 增加 `ConstructionForward`，执行时带身份校验，被拒绝时按现有终结意图的重试规则处理；
  - 全局 Redo 在构造过程中映射为下一步，与全局 Undo 映射为上一步对称。
- R3 按钮显隐和启用状态走主栏 0.4s 批次，与主栏按钮显隐的动画一致；禁用状态用公共的 0.30 内容透明度。物理接触进行中，所有按钮都禁用（沿用现有规则）。
- R4 键盘：Esc 取消，Tab/Shift+Tab 在按钮间正向/反向切换（修复缺少 Shift+Tab 的问题），Enter/Space 执行。只在提示可见时处理。
- R5 适配深浅主题和常驻背景/内容透明度（父任务 V4）。
- R6 指针消息只在落在面板上时才触发重绘（修复 `Bar.ConstructionPrompt.cpp:135` 每个指针消息都 UpdateRendering 的问题）。

## Acceptance Criteria

- [ ] 离屏截图（深浅主题 × 1.0/2.0 倍率）中，提示的圆角、材质、字体与底栏模式提示的参数一致；环形进度和「n/N」正确；折线和多边形显示点数。
- [ ] 出现和消失有回弹缩放；从第 1 步到第 2 步换文案时，按扩框、换字、缩框的顺序执行。
- [ ] 上一步、下一步、结束、取消四个按钮的语义正确，覆盖：回退后再前进恢复同一步；回退后落笔确认新步骤会清空前进；多边形不足 3 点时结束按钮禁用，点击结束后首尾闭合，只产生一个对象和一条撤销记录。
- [ ] 默认配置的浮动模式下画折线，第一笔之后主栏不会自动收起，提示保持可见；手动收起主栏后提示仍然可见。
- [ ] `--ui3-shape-editor-test`、`--draw3-shape-core-test` 增加相应用例并通过。
