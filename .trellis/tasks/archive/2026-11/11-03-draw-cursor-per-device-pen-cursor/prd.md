# 绘制光标:按设备设置、笔光标与高亮模式(父任务)

## Goal

把“绘制→光标”从两个下拉(鼠标/笔)改为专门的光标设置页:按输入设备独立选择光标,新增小圆点光标与笔设备高亮模式,并查清数位板在 Windows Ink / 非 Ink 模式下的识别与高亮问题。

## 用户原始需求(2026-11-03)

1. 光标选择里新增“笔光标”(一个小圆点),两种:高亮、正常。
2. 改为内联设计,下方按设备分行单独设置;触摸默认“无光标”,且“无光标”仅触摸有。
3. 新增“笔设备高亮模式”条目+下拉:关闭 / 仅数位板 / 始终,默认仅数位板。
4. 调查:用户数位板(高漫 M6)已启用 Windows Ink,但笔光标仍不高亮(记忆中数位板曾高亮、屏幕笔不高亮);并看能否把非 Windows Ink 模式的数位板识别为数位板(不显示鼠标光标),不行则用户可手动把鼠标光标改成笔光标。
5. 光标设置做成专页(类似笔速橡皮/手掌橡皮),每种设备条目内可预览光标效果。

## 已确认决策(AskUserQuestion)

- 设备行:4 行 = 鼠标(含触摸板)、触摸、屏幕笔、数位板。
- 选项差异化:鼠标 {系统光标, 画笔图标, 小圆点, 高亮小圆点};屏幕笔/数位板 {圆形(默认), 画笔图标, 小圆点, 高亮小圆点};触摸 {无光标(默认), 圆形, 画笔图标, 小圆点, 高亮小圆点}。
- 高亮语义:“笔设备高亮模式”只控制屏幕笔/数位板的圆形、画笔图标、小圆点的外描边;“小圆点”固定普通、“高亮小圆点”固定带高亮描边,不受模式影响。
- 组织:本父任务 + 子任务 A(数位板识别调查)+ 子任务 B(设备光标模型/专页/小圆点/高亮模式)。B 先行,A 结论后再接入。
