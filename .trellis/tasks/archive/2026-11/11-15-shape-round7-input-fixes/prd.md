# 形状第七轮输入与控件回归修复

基线：bc42dd03，延续 11-05-shape-ux-rework，第六轮之后用户报告的六项修复。

## 需求与验收
1. 第一笔完成后的首次控制点按下即可拖动，不需重复按下。
2. 3D 控制点连续拖动无旧样本积压；保留预测、真实终点、取消及单次历史。
3. 几何展开面板类型、图形、关闭及属性按钮均可触摸，主栏原有来源仲裁不回退。
4. 圆隐藏水平/竖直翻转；矩形及其他旋转后翻转结果可变化的图形保留。
5. 翻转不让顶部控件随镜像落到底部，不改变胶囊左右顺序；仍支持跟随真实旋转及超屏换边。
6. 控制点优先于框内平移，四角缩放可用，保留中心区域多指行为。

保持已有存储与模型约束。禁止交互 GUI、Computer Use、自动提交、推送或归档。
