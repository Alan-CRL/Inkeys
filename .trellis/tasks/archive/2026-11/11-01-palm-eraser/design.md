# 手掌橡皮技术设计

状态：用户已批准并完成本期代码实现/无窗口验收，结果见[验证记录](research/validation.md)；GUI/实机未执行。需求以[prd.md](prd.md)为准。已停止的真实时间Z序研究不参与本设计。

## 1. 最小行为差距与修改边界

当前已有Touch面积元数据、显示标尺、独立Runtime、笔尾/右键有效工具覆盖、共享层重建和整笔完成历史；缺少按触摸面积自动将本触点转为手掌橡皮的状态机，以及对应偏好和详情页。

本期在DrawingController的触点生命周期处补足识别/转换，沿用现有固定橡皮几何与整笔完成路径。最终Z序沿用既有抬笔/完成提交顺序；同帧仍按既有完成处理顺序。不新增真实时间操作日志、文档/历史节点、UInk协议、Shader或输入后端，不做无关重构。

## 2. 数据与线程所有权

```text
main.json/设置草稿 → 现有设置保存FIFO（冻结配置）
                 → Host偏好快照/合并控制唤醒
                 → Host绘制owner应用Controller偏好
RTS/鼠标归一化 → 既有ContactInputCoordinator
                 → 成功断触接续优先
                 → 新独立Touch锁存手掌偏好/显示标尺
                 → 面积识别/邻域仲裁/原工具到本触点橡皮覆盖
                 → 既有L1/L0重建、整笔完成、history、UInk
```

- RTS只保持现有解码与合并发布，不增加COM查询、同步I/O、D3D或原始包队列。
- Controller是识别状态、modeler、CPU几何和D3D的唯一写者；设置线程不读取Runtime或操作GPU。
- Host偏好在bridge revision去重之外同步，方式参考Host::SetGeneralDrawingOptions/PumpBridgeState；重复设置幂等，不每帧重复唤醒。
- 每个新独立Down锁存Enabled、七工具偏好、时间窗、阈值倍率、边擦边写及完整已应用DisplayScale。运行中修改只作用后续独立接触；成功续接保留旧快照。
- 复用现有严格单Touch与激光多指准入。真正续接仍先尝试；只对新独立Touch执行多指拒收。

## 3. 参数与标尺

| 项目 | 本期值/规则 |
| --- | --- |
| 默认物理面积 | 可信标尺25cm²，即2500mm²；EDID失效仍可用，回退100×100系统DIP，即10000DIP² |
| 倍率 | 按面积1%–400%，整数百分比，重置100% |
| 时间窗口 | 100/150/250/500ms，默认150ms（推荐） |
| 宽高比例 | max(w,h)/min(w,h) ≤ 3.5，按已验证画布像素跨度判断 |
| 最终尺寸统计 | 本窗口已消费有效面积的最大值；不采用平均，不随之后重压呼吸 |
| 擦除轮廓 | 沿用现有圆形橡皮，直径dPx = 2×sqrt(maxAreaPx/π) |
| 相邻抑制 | 当前擦除圆半径r外扩max(0.15r,4px)；无独立设置项 |

阈值解析独立于笔速橡皮运动曲线和面积辅助上限。只有ContactAreaUnits::CanvasPixels、宽高有限且为正并通过比例检查的真实Touch样本才参与；明确TouchPad、Mouse/Pen及未知/非法面积不参与，不能用压力或DPI伪造接触面积。

显示标尺优先消费Host已应用的可信物理映射；可用的现有手动标定沿既有旋转/monitor/密度校验。可信时，面积Amm² = wPx×hPx×mmPerPixelX×mmPerPixelY，与2500×倍率比较。EDID/物理标尺不可用时不禁用识别，不伪造毫米密度：改为系统DIP面积wPx×hPx×dipPerPixelX×dipPerPixelY，与用户确认的10000×倍率比较。100DIP在100%系统缩放是100px，在150%是150px；设置自身UI缩放不改变该输出阈值。缺省大屏仍默认开启，Warning明确仍可使用但实际厘米效果可能偏离。

可复用SpeedEraser的DisplayScale、单位转换/映射校验及只读Warning判定，不复用其2..96DIP面积上限、运动确认、速度控制器或16..160DIP尺寸上限。显示快照未发布时不推断EDID错误；未确认面积单位时正常绘制继续，手掌识别不可用。

采样口径明确为既有合并输入中Controller实际消费的Down/Move快照，按sequence去重、QPC限定窗口；不是全部硬件包的峰值保证。这与原需求允许近似最大值的定尺相符，本期不为峰值重写RTS/Coordinator。Up的零面积不进入统计，窗口后新的大面积不能补触发。

## 4. 触点状态机

每个逻辑Runtime增加小型手掌状态：原始Down/截止QPC、锁存配置/标尺、原工具分类、是否可识别/邻域禁止、最大有效面积与当前直径、是否已激活/锁尺、是否仅观察而不绘制、是否为成功续接。

1. **先续接**：按第7节处理；成功不走新识别路径。
2. **新独立输入准入**：选择/平移等非绘图归属不进入手掌；普通单指/激光多指规则继续生效。
3. **候选**：工具允许且Enabled时，原工具立即按原流程绘制。面积判断放在consumeLatestSnapshot的位置/笔状态未变早退之前，原地摊掌也可触发；无有效面积保持原工具。
4. **激活并采样**：窗口内面积达到阈值且比例合格、邻域允许时，立即转为本触点圆形橡皮，不等窗口结束。之后若有更大有效面积，更新暂定直径，只用于此后新增的擦除几何，旧点半径不改。
5. **锁尺**：截止时或提前物理Up时冻结已接受最大值；后续同次逻辑笔划和成功续接均使用此尺寸。尚未激活的候选到截止后仅保留原工具，不再升级。
6. **结束/等待续接**：沿既有终态/续接协议；真正完成、取消、页边界或pool复用时清理本触点状态。不得串到新generation。

截止时间在帧循环中检查，不依赖新Move。复用现有活动帧；如进入idle等待，将最近手掌截止纳入原deadline并保持ArmIdleMoveWake/sequence复查握手，不修改普通笔速橡皮的静止语义。

## 5. 转换事务与尺寸几何

- 只改变Runtime.tool，保留selectedTool、原全局选择、同批后续输入的原工具及样式记忆。
- 准备橡皮模型/起始点成功后，再移除本触点原工具CPU几何、Shape预览及其自有Laser层/发射状态；失败保留可正常收尾的原状态，不先清墨迹再宣称激活成功。
- 原工具为绘制/Shape/Laser时，橡皮从激活位置开始，不把旧绘制轨迹变成擦除路径；保留原Down的接触身份/QPC基准，模型重置与新起点时间必须单调。
- 原实际工具已为橡皮时，保留已接受的擦除点和效果，仅将后续尺寸控制转为Palm Fixed；不得清空旧擦除操作、恢复已经擦掉的内容。两种转换都不回写旧点半径。
- 更新后从其他Runtime的CPU真值重建共享L1/L0，脏区包含本触点旧可见范围及新的橡皮/光标；不对整个画布执行Clear，也不把其他接触的CPU几何删除。
- Palm使用StrokeWidthMode::Fixed，已有ConvertModeledResultToInkPoint直接读取baseDiameter。窗口内仅更新该触点的后续几何直径，需要时在当前真实位置追加尺寸锚点，确保原地增长也显示/擦除；不修改历史realPoints半径、不实例化SpeedEraserOcController、不新增宽度枚举。
- 每触点橡皮光标直径与实际几何一致。Up后不保留手掌Hover光标；原selectedTool与全局工具不被临时覆盖污染。
- 最终仍生成普通StoredInkType::Eraser，沿既有逐Stroke提交和history处理，不改InkDocument/UInk结构或Undo粒度。

## 6. 相邻限制与并行擦写

- 多指开启且边擦边写开启时，其他已准入绘制继续；远离活动手掌的Touch可独立成为新的手掌。
- 新Down位于活动手掌外扩区时，锁存“该接触禁止手掌”；其原工具绘制继续受其他准入规则控制。移动离开后不重新升级，避免同一手背分裂后延迟激活。
- 激活仲裁也检查已经存在的候选，防止同帧两个相邻大触点一起激活。先激活者优先，同批同时达标者按既有Down接收顺序确定，不影响普通完成Z序。已激活且起初不相邻的两个手掌后来靠近，不反向取消。
- 等待真实断触接续的手掌保留有限邻域预约，避免短断触被邻近新手掌重复激活；不显示擦除光标或在空缺期间制造几何。真正接续继承预约，失败/超时解除。
- 边擦边写关闭时，激活手掌将其他正在绘制的笔划按真实末点正常完成（保留墨迹、清预测、禁止断触恢复该强制收尾），物理route隔离到Up/Cancel；不丢弃已画内容。
- 手掌物理活动期间的新绘制不被接收；多指开启时，新Touch可仅观察面积，合格且非相邻者加入擦除，其他触点到窗口结束后隔离至终态。Pen/Mouse不能转手掌，直接按新绘制拒收。仅观察接触不调用普通modeler或生成墨迹。
- 所有物理活动手掌结束后解除“禁止新增绘制”门；先前被拒收/收尾且仍按住的触点不自动恢复，必须抬起重落。续接成功重获手掌物理活动时重新遵守旧快照的擦写门禁。

全局多指关闭始终拒绝额外新独立Touch（含大面积触点）；边擦边写不能绕过。Pen/Mouse沿原多指合同，不被误当第二个Touch。新增识别不干预平移/电脑操作的输入所有权。

## 7. 成功断触接续继承（用户新增合同）

- 成功续接保留原实际工具、是否手掌、尺寸、原样式/偏好和同一逻辑笔划；不是新的Down识别机会。
- 原绘制继续原绘制，接续Down面积很大也不改成橡皮；原手掌继续手掌，面积变小/变大或设置已修改都不改变旧尺寸。
- 物理Up关闭本轮识别窗口；已激活手掌即便在窗口结束前Up，也先冻结目前已接受尺寸。因此成功接续不需重新计时、采样或临时改变大小。
- 现有incoming identity由新Down的原工具生成，会与旧手掌的Eraser/Fixed身份不一致（DrawingController.cpp:11190、InkPrediction.cpp:850）。对已有手掌候选，用旧手掌的有效工具/宽度身份参与候选匹配，同时保留真实设备、原selectedTool及既有时间/轨迹/角度条件；不按新面积决定是否匹配，不放宽接续算法的距离/时间门槛。
- 普通Laser/Shape仍沿既有不续接规则；已经转成手掌的Laser/Shape来源候选，按实际Touch Eraser身份参与上述继承，不借此扩展普通工具接续。
- 只有模型接续成功才转交handle/状态；失败保留旧候选并将新接触按正常独立准入/新窗口处理。不能失败后丢失旧笔划，或给新接触误继承旧尺寸。
- 成功续接仍只产生一个最终Eraser或原绘制history动作；超时/未匹配则分别正常完成旧动作并建立新动作。

## 9. 实尺预览

使用当前绘图屏幕已应用标尺和同一面积阈值解析。可信时Apx = 2500×倍率/(mmPerPixelX×mmPerPixelY)；失效回退时Apx = 10000×倍率/(dipPerPixelX×dipPerPixelY)，不依赖EDID有效位阻止显示。四种可选等面积像素示例，默认1:1：

- 1:1：宽高sqrt(Apx)。
- 4:3：宽sqrt(4Apx/3)，高sqrt(3Apx/4)。
- 2:1：宽sqrt(2Apx)，高sqrt(Apx/2)。
- 1:2：宽sqrt(Apx/2)，高sqrt(2Apx)。

图形宽高直接用物理像素绘制，不乘设置UI的Pixels()/DPI/字体倍率；文本和留白仍用正常UI缩放。左上角比例下拉悬浮覆盖边框且不占用图形布局空间，示例超宽时仅预览块可横向查看，不缩小图形冒充1:1。预览完整高度参与外层页面布局。

设置窗位于另一台屏幕时仍显示当前绘图输出所对应的像素阈值，明确目标屏幕/像素口径，不能声称两台屏幕具有相同厘米效果。DPI回退标为估算；显示快照未就绪时不绘制虚构的实尺。

## 10. 验证、风险与回滚

- 先做纯策略与真实Controller共用helper的无窗口验证，再接完整设置；不以重写时间Z序作为前置。
- 核心验证：原地面积变化、窗口边界/定尺、原工具临时墨迹完全撤回但其他接触不丢、Laser/Shape清理、多手掌邻域/单指、边擦边写关闭、普通/手掌成功续接与失败分流、普通Undo/Redo/保存恢复。
- 使用真实ImGui/字体/DrawData回放验证三语、浅深、窄宽和多个DPI，七项含刷子可编辑、默认推荐后缀、像素尺寸和重置事件正确；不创建HWND。
- 真实硬件触摸面积可能缺失或抖动，DPI估算可能偏离物理尺寸；本期用倍率和Warning处理。没有用户授权不启动GUI，硬件手感不以无窗口测试冒充。
- 新逻辑被Enabled旁路时，保持原绘制/橡皮路径；不修改公共文档格式，可回退本功能配置/代码。失败路径优先保留原可收尾几何与旧候选，不能产生半转换。
- 最终检查包含编码/EOL与minimal diff；构建主产品必须用完整InkeysRepo.sln Debug|ARM64、原生ARM64 MSBuild、同PowerShell invocation的PATH规整，至少5分钟预算。
