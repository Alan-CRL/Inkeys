# 技术设计（已批准并实施）

- 使用现有 main.json 的 UI3.Debug 配置体系新增默认 false 的原子布尔字段，调试页沿用 ToggleRow 与既有保存流程；国际化沿用现有生成链。
- 启动 mini-read 纳入开关，在现有 ReportStartupMilestoneForManualTest 的启用判断接入，保留命令行/环境变量入口和原有阶段时长；不触碰失败注入；不为 SuperTop/提权/重启链路新增适配，只提供普通启动的观察入口。
- 在 PageControl 主动点击翻页入口暂存带身份的翻页意图，先向控件快照投影现有 loading 状态，10 秒单调时钟期限到达后再发送真实请求。复用现有交互 worker 的期限调度，不在渲染、WndProc 或公共 worker 上 sleep。
- 延迟记录绑定原页、PPT 会话或白板 generation，取消、隐藏、退出及身份改变时废弃；到期重新校验准入。观察期间不发真实请求，因此不消耗真实操作故障预算，也不伪造业务 ready；真实失败保持原结果。重复点击不堆积或无限续期，结束放映不纳入翻页延迟。
- 不改页面存储、COM 协议、工作区协调或动画绘制算法。
- 当前方案：翻页在接纳时读取开关；切换开关影响后续请求，已接纳请求保持原观察期限。启动取当次启动配置。
- PPT 页面准备与导航等待共用指示器，但不得在公共 loading 状态上无差别注入；外部恢复、快捷键、滚轮等其他入口保持原样。
