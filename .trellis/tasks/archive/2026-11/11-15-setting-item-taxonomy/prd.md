# 设置项分类树重构

## Goal

重新设计设置页的分类树：设置项分类不清导致用户难以查找，且后续设置项会持续增加，现有分类（尤其「通用」「绘制」）容易被挤满。本任务只调整「设置项归属哪个页面、页内顺序如何」，**不改任何配置键、默认值与业务行为**。

## 现状盘点（2026-11-15，来自 Setting.Pages.cpp / Setting.cpp / zh-CN.jsonc）

侧栏：主页、语言 | 通用(▸基础 / 位置 / 外观 / 交互 / 存储 / 快捷键 / 桌面快捷方式 / 状态指示器) | 绘制 | 性能 | 联动 | 插件 | 组件 | 实验室 | 版本 ；标题栏：调试；底部：赞助、反馈。

- 通用·基础：选择与穿透(合并式/分离式)、主栏图标顺序、主栏展开方向、开机自启
- 通用·位置：启动位置、PPT 自动停靠、白板自动停靠
- 通用·外观：主栏/设置主题、背景/内容透明度、动画(启用、启动加载动画+效果、设置开屏动画)、边缘光影、任务栏缩放基准、主栏 UI 缩放
- 通用·交互：自动收起(4 项)、置顶间隔、右键关闭、崩溃处理方式、允许重复启动
- 通用·存储(配置与保存)：配置清理、画布自动保存
- 通用·快捷键 / 桌面快捷方式 / 状态指示器
- 绘制(单页)：绘图环境(大屏触控/桌面交互模式) → 通用(多指、笔锋修正、墨迹预测、白板拖动惯性) → 橡皮擦(笔速/手掌入口) → 光标(入口) → 激光笔(多指、粒子) → 触摸(断触接续) → 触觉反馈
- 性能：帧率(界面/画布)、渲染与兼容(硬件加速、DirectComposition、兆芯)
- 实验室：动画速率、允许小数字号；调试页(标题栏)：UI3 渲染调试、画布调试、状态指示器测试、控制台输出

## Requirements（用户已确认的方向）

1. **通用**：只放最重要、最常用的内容；操作模式「选择与穿透(合并式/分离式)」置顶，并把绘制页里的「选择交互模式(大屏触控模式/桌面交互模式)」迁入（防止用户找不到）。
2. **绘制** 拆为两个子类：
   - **绘制效果**：抬笔笔锋修正、墨迹预测、激光笔粒子效果（及后续荧光笔等效果）。
   - **交互与手势**：多指绘图（及多指激光笔）、断触接续、橡皮擦（笔速橡皮、手掌橡皮）、光标、白板拖动惯性（后续白板双指手势）、手写笔触觉反馈。重要常用的在前。
3. **窗口与显示器**（新增，三个子页）：窗口（启动位置、PPT/白板环境位置、主栏布局、缩放）、行为（自动收起、置顶、右键关闭）、显示器（后续手动指定 EDID、多显示器；首版仅标题，无内容）。
4. **按键与快捷键**（新增，侧栏顶层）：承载现有固定快捷键，并为后续键盘辅助、更多快捷键预留。
5. **日志与配置**（新增，两个子页）：日志（首版仅标题，无内容）、配置（配置清理、画布保存）。
6. 每个页面都要重新思考条目顺序：有逻辑关联的相邻、重要常用的靠前、低频/高级/诊断类靠后。

## 已确认的决定（2026-11-15 对话）

- 「窗口与显示器」「日志与配置」「按键与快捷键」均为**侧栏顶层页**。
- 「日志与配置」首版配置页只迁入：配置清理、画布保存；**不动**崩溃处理方式（留在通用）、**不迁**控制台诊断开关。
- 「窗口与显示器」拆为 窗口 / 行为 / 显示器 三个子页；主栏自动收起(4 项)、置顶间隔、右键关闭 → 「行为」。
- 「显示器」「日志」两个子页**保留入口、仅显示页标题、无任何内容**（与预留位置等价，无占位文案）。
- 动画速率**保留在实验室**。
- 通用·外观顺序：主题 → 动画 → 边缘光影 → 透明度（透明度置底）。
- 「组件」调到「插件」前面；「日志与配置」位于「按键与快捷键」与「性能」之间。

## 目标分类树（页内数字 = 顺序，靠前 = 更重要/常用）

```
主页 / 语言
通用  ▸ 基础：①选择与穿透(合并式/分离式) ②交互模式(大屏触控/桌面交互，自绘制页迁入)
              ③启动：开机自启、允许软件重复启动 ④崩溃处理方式
        外观：①主题(主栏/设置) ②动画(启用、启动加载动画+效果、设置开屏动画)
              ③边缘光影(+动态) ④透明度(背景/内容)
        状态指示器 / 桌面快捷方式
绘制  ▸ 绘制效果：①墨迹预测 ②抬笔笔锋修正 ③激光笔粒子效果(暂不可用，置底)  [预留：荧光笔等]
        交互与手势：①多指绘图+多指激光笔+断触接续 ②橡皮擦(笔速橡皮、手掌橡皮入口)
                    ③光标(入口) ④白板(拖动惯性)[预留：双指手势] ⑤手写笔触觉反馈
窗口与显示器 ▸ 窗口：①缩放(任务栏缩放基准、主栏 UI 缩放) ②启动位置 ③环境窗口位置(PPT、白板)
                    ④主栏布局(图标顺序、展开方向)
              行为：①主栏自动收起(×4) ②置顶间隔 ③右键关闭
              显示器：（仅标题，预留 EDID / 多显示器）
按键与快捷键：①全局 ②编辑(撤销/重做/清空) ③辅助(冻结)  [预留：键盘辅助、更多快捷键]
日志与配置 ▸ 日志：（仅标题，预留）
              配置：①配置清理 ②画布保存
性能 / 联动（内容与顺序不动）
组件 / 插件（组件在前，内容不动）
实验室(动画速率、小数字号) / 版本
```

侧栏顶层顺序：主页、语言｜通用、绘制、窗口与显示器、按键与快捷键、日志与配置、性能、联动、组件、插件、实验室、版本（中部项由 8 → 11）。

## 不在本任务范围

- 光标子页、笔速橡皮/手掌橡皮子页的**内部**排布不改（仅改它们的入口位置与返回目标）。
- 调试页（标题栏入口）、性能/联动/插件/组件/版本页内容不动。
- 不新增日志功能、不新增显示器功能；「日志」「显示器」仅有空页面（页标题）。

## Acceptance Criteria

- [ ] 每个现有设置项恰有一个归属位置，无丢失、无重复；配置键、默认值、业务回调与保存时机不变。
- [ ] 侧栏与子页导航支持新增的页面/子页（含「绘制」「窗口与显示器」「日志与配置」的子页展开）；空页面只显示页标题，不报错、不闪烁。
- [ ] 旧入口（主页卡片、`SettingOpenTarget`、旧 `PageId::Configuration/HotKeys`、通用旧子页、记忆的上次子页）正确重定向。
- [ ] 各页内顺序符合上面的树，并在 `design.md` 中逐页列出。
- [ ] 新增页/子页名称的三语言（及 20 语言 sync/check）文案齐备；中文 snapshot 同步。
- [ ] 完整 `InkeysRepo.sln` `Debug|ARM64` 构建通过；`InkeysHeadlessTests.exe --no-window` 通过（含更新后的 setting_design_tests 子页循环）。
