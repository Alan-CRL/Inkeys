# 统一主栏与组件 SVG 图标设计语言

## Goal

UI3 Bar 当前图标混用实心剪影（选择、画笔、橡皮、清空、设置、撤销/重做）与细线描边（白板、结束放映、信息、问号等），组件按钮使用不可主题着色的第三方 PNG 品牌图。本任务建立一套以现有实心剪影为基准的统一设计语言，按该语言重绘不一致的图标，为组件按钮和若干状态/面板按钮创建表达按钮行为的专属图标，并保证全部图标通过占位色由程序着色，在深色与浅色主题下都清晰可见。

研究依据：`research/icon-inventory.md`（全部图标使用点清单）、`research/current-icons.html`（现状预览）。

## Requirements

### R1 设计语言（适用于本任务新建和重绘的全部图标）

- 风格基准：主栏「选择 / 画笔 / 橡皮 / 清空 / 设置 / 撤销」的单色实心剪影，内部细节用镂空（负形）表达。
- 单色：仅使用 color1 占位色 `rgba(10,0,7,0)`；不使用 color2、透明度、渐变或任何写死颜色。
- 统一画布、留白、最小线宽、镂空间隙、圆角和端点规则（具体数值见 `design.md`），同一组图标视觉重量一致。

### R2 主栏重绘

按设计语言重绘：白板 `barWhiteboard`、结束放映 `barEndShow`、冻结 `barFreeze`、穿透 `barPierce`、几何 `barGeometry`。

### R3 主栏状态专属图标

主栏按钮切换状态时，下列状态使用新的专属图标而非沿用其他图标：

- 白板按钮「返回放映」（当前复用 `barDismiss`）。
- 白板按钮「回到白板」（恢复已最小化的白板，当前复用 `barWhiteboard`）。
- 选择按钮在白板中的「移动」（当前复用 `barSelect`）。

「选择（清空）」「区域擦除」保持沿用原按钮图标。

### R4 组件按钮专属图标

16 个组件按钮（文件资源管理器、任务管理器、控制面板、显示桌面、锁屏、Esc、Alt+F4、IslandCaller 1/2、SecRandom 1/2/2 兼容、NamePicker、ClassIsland 设置/档案编辑/快速换课）改为主题可着色的 SVG：

- 每个按钮一个互不相同的专属图标，表达按钮行为；点名类即使行为相近也必须可区分（例如角标差异）。
- 不再体现第三方品牌，原 PNG 品牌图不再使用并从产品资源中移除。
- 着色、选中/悬停变色与其他 SVG 按钮一致。

### R5 面板与辅助图标

- 橡皮属性面板：「清空画布」与「极速橡皮设置」项改用专属图标（当前分别复用主栏垃圾桶与设置齿轮）；「自动粗细」图标微调，字母 A 与橡皮的间距收紧。
- 白板「最小化」「主题」图标去除写死的 `#fff`，改用占位色，使浅色主题下可见。
- 辅助小图标按同一设计语言统一：关闭 X、信息、问号、展开箭头（`barMore`、`barThicknessAdjust`）、添加页、白板菜单、最小化、主题。

### R6 资源清理

- 被替换且不再使用的旧 SVG/PNG 资源从 `Inkeys.rc` 与工程中移除。
- 未改动的已合规图标保持原样。

## Out of Scope

- 色板与白板背景预览上的绿色选中勾 `colorSelect`（保留现状）。
- 主按钮 Logo（`logo1` 及其外观系统）、`logo2`、`Frame 94`。
- 绘图属性面板的笔型图标（刷子、激光笔、荧光笔、硬笔、软笔）及几何面板的直线/矩形图标。
- 「选择（清空）」「区域擦除」状态图标；取色器用 `DrawLine` 绘制的关闭 X。
- Alt+F4 标签未国际化等与图标无关的问题；未编译的 `IdtFloating.cpp`。

## Acceptance Criteria

- [ ] R2–R5 列出的每个图标都已按设计语言交付，并在设计预览页中于浅色、深色两种主题及实际尺寸（14/18/20/28 DIP）下经开发者确认。
- [ ] 本任务新建/重绘的 SVG 只含 `rgba(10,0,7,0)` 一种颜色值，无 `#xxx`、`rgb()`、`opacity`、渐变、`clip-path`、`transform`、文本元素；描边仅允许 design 规定的统一线宽与圆角端点；全部为 `24x24` 画布。
- [ ] 白板「返回放映」「回到白板」、白板中「移动」在对应状态下显示专属图标，状态切换仍使用原内容过渡动画。
- [ ] 16 个组件按钮显示各自不同的 SVG 图标，选中/悬停/禁用着色与其他 SVG 按钮一致；More 面板溢出显示正常。
- [ ] 橡皮面板「清空画布」「极速橡皮设置」显示专属图标；「自动粗细」A 与橡皮间距收紧。
- [ ] 浅色主题下白板「最小化」「主题」图标可见。
- [ ] 不再使用的旧资源已从 `Inkeys.rc` / `Inkeys.vcxproj(.filters)` 移除，代码与测试中无残留引用。
- [ ] `InkeysRepo.sln` `Debug | 当前设备原生架构` 完整构建通过；涉及资源名的 headless 测试同步更新并通过。
- [ ] 相关 spec（`rendering-and-ui.md` 中 EndShow 资源描述等）同步更新。
