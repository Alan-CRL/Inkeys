# 第二轮独立源码审查

按 trellis-check 对共享几何、构造会话、产品动作、UI 和持久化链路检查；构建与测试由主代理统一执行，审查不重复启动构建或 GUI。

## 已定位并交由所有者修复

- 斜立体的方向控制点原先仅使用 height 插值，忽略顶面投影偏移；当偏移抵消高度时会落到外框以外。几何代理已改为实际上下中心插值，并将旧棱柱／棱锥投影轴点移入框内，编辑使用增量以避免初次拖动跳变。
- 辅助点按钮固定向右上偏移会让近圆椭圆的中心与 F1 按钮重合；向 UI 代理要求按其他手柄和屏幕边界选择可用位置。显示开关原先只有位置过渡而缺少图标状态过渡，也已通知 UI 代理补齐。

## 交叉核验

- SelectionOverlay::Render 无 construction 过滤，会配置包含构造 preview 的快照；WM_NCHITTEST 依据 surface Hit，构造期返回透明，输入归物理画布，不会双重新增点。
- 构造期 Escape 的 CloseEditor 经现有会话身份分支取消构造，没有误入已完成对象编辑。
- 点工具 Begin/Preview/Confirm、Back/Forward 和取消的所有权均在绘制线程；UI 只发布已确认点的显示。
- 新接触初始化复用步骤间 RenderData，补齐 Down 到首个改变端点之前的预览；首个 Down 则生成单点候选，首拖在 Up 前可显示第一条边。
- v6 构造真值包含选定顶角及斜投影参数；旧 solid.oblique=false 分支保留原投影，属性和编辑候选复用 Replace/journal 链路。
- 闭合虚线 CPU/GPU 共用相位公式，标准格式按八个单调半段降级，未按形状尺寸缩放短线尺度。

此记录不替代编译、离屏像素回归和实体设备验收；最终结果以主代理验证记录为准。
