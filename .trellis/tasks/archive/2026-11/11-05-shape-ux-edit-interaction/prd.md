# 各图形控制点交互

## Goal

按图形重新定义编辑时的控制点、外框和旋转钮，让编辑方式符合几何直觉；同时修正现有的图形编辑逻辑问题。详见 `../11-05-shape-ux-rework/research/edit-interaction.md`。

## 用户原始要求

- 直线：只有两个端点，外框上没有点，外框比外接矩形大一圈，拖动端点可以改变位置。
- 矩形：四个角点；外框比矩形大一圈，框上没有点。
- 圆角矩形：从主栏移除（兼容方式见 toolbar-category D4）。
- 圆：绘制完成后也有外框（与圆之间有间隙）；圆心模式绘制完成后显示圆心；圆上的半径点可以自由拖动，不必保持在水平方向。
- 椭圆：可以显示焦点（可选，由按钮开关），焦点可以拖动。
- 长方体等立体图形：图形上有若干关键点用于调整形状；外框大一圈，四个角各一个点，用于缩放。
- 其他图形：修正现有逻辑问题。

## 统一规则（2026-11-05 用户确认）

- G1 所有图形都有带间隙的圆角外框（样式见 edit-visual R1）。只有立体图形的外框四角带缩放点；其他图形的外框上不放点。原有 8 点框与四边中点全部取消。
- G2 直接拖动图形本体：整体移动。圆心、中心这类点也是整体移动，并作为可见标记显示。
- G3 旋转钮：只保留给方向不能由自身控制点决定的图形，包括矩形、椭圆、三角形、平行四边形、菱形、梯形、折线、多边形和立体图形。直线、箭头、圆、正多边形、圆弧、扇形不显示旋转钮，因为它们的端点、首顶点或角度点已经决定了方向。
- G4 拖动导致退化或无效的形状时（共线、自交、零尺寸），手指抬起后不提交。预览阶段把形状钳在最近的有效状态，避免像现在这样静默失效。
- G5 控制点的位置一律由构造真值推导，消除拖动中跳回原位的问题，例如圆的半径点、正方体的角点。

## 逐图形方案（2026-11-05 用户确认）

| 图形 | 图形上的控制点 | 外框点 | 旋转 | 说明 |
|---|---|---|---|---|
| 直线 / 箭头 | 2 个端点，可自由拖动 | 无 | 无 | |
| 矩形 | 4 个角点；拖动时对角固定，可以非等比缩放，不允许翻转 | 无 | 有 | 圆角半径不再随缩放增大，修正问题 16 |
| 圆 | 圆心（整体移动）+ 圆周上 1 个半径点，可沿任意方向自由拖动 | 无 | 无 | 编辑时两种绘制方式都显示圆心控制点；外接框模式绘制的圆，半径点默认放在右下 45°。画布上是否画出圆心标记由辅助显示「圆心」决定 |
| 椭圆 | 中心 + 长轴端点 + 短轴端点；辅助显示「焦点」开启时，另有 F1/F2 两个焦点控制点 | 无 | 有 | 拖动 F1 时中心与长半轴 a 不变，F2 关于中心对称移动，短半轴 b=√(a²−c²) 随之变化；焦点不能越过长轴端点 |
| 三角形 | 3 个顶点，可自由拖动 | 无 | 有 | |
| 平行四边形 | 4 个顶点；拖动某个顶点时，对角顶点固定，相邻两个顶点联动，保持对边平行 | 无 | 有 | 修正目前只联动一个相邻顶点的问题 |
| 菱形 | 4 个顶点；沿对角线拖动可改变该对角线的长度，另一条对角线保持不变 | 无 | 有 | 允许非等比 |
| 梯形 | 4 个顶点；上下两底保持平行，上底不能拖过下底 | 无 | 有 | |
| 正多边形 | 中心 + 首顶点（同时改变大小和方向） | 无 | 无 | 边数在浮条上调整 |
| 折线 / 多边形 | 每个顶点 | 无 | 有 | |
| 圆弧 / 扇形 | 圆心 + 半径点 + 起点角 + 终点角 | 无 | 无 | 拖动角度时按轨迹连续累计，修正超过半圈后方向翻转的问题 |

| 正方体 | 正面 1 个角点（改变边长，保持正方形）+ 后面 1 个角点（深度） | 4 角，等比缩放 | 有 | |
| 圆柱 / 圆锥 | 底面左右端点（改变 rx）+ 底面前端点（改变 ry）+ 顶面中心或锥顶（改变高度） | 4 角，非等比缩放 | 有 | 不做斜圆锥；顺带修正圆锥母线为锥顶到底面椭圆的切线 |
| 棱柱 / 棱锥 | 底面首顶点（改变大小和方向）+ 顶面中心或锥顶（改变高度） | 4 角，等比缩放 | 有 | 因为正多边形底面无法表示非等比缩放，这里只允许等比 |

## 辅助显示（2026-11-05 用户补充）

- 部分图形新增「辅助显示」开关。开关属于图形的绘制属性：打开后，辅助元素会作为图形的一部分画在画布上，并随文件保存。
- 主栏入口：在图形展开面板的参数行中，构造方式按钮的右侧，先放一条分割线，再放辅助显示开关。圆的构造方式（圆心/外接）右侧加「圆心」开关，默认选中。椭圆、矩形等原来没有参数行的图形，新增一个参数行来放开关。
- 编辑浮条：选中刚画完的图形后，浮条里也有同样的开关，只作用于当前对象。
- 能用图标看懂的按钮只显示图标，不显示文字，以免文字放不下。
- 清单与默认值（用户已确认）：

| 图形 | 辅助项 | 默认 | 画法 |
|---|---|---|---|
| 圆 | 圆心 | 开 | 与描边同色的实心点，直径为线宽的 2 倍，最小 4DIP |
| 椭圆 | 焦点（两个） | 开 | 同上；只有开启时才出现 F1/F2 焦点控制点 |
| 矩形、平行四边形、菱形、梯形 | 对角线 | 关 | 与描边同色、同线宽的虚线 |
| 正多边形 | 中心 | 关 | 实心点 |
| 圆弧、扇形 | 圆心 | 关 | 实心点 |

- 每个开关单独记住上一次的选择，作为下一笔的默认值（与现有图形工具状态一起保存在内存工作区状态中）。

## 多边形 / 折线结束绘制

- 逐点绘制时，底栏绘制提示的最后一步提供「结束绘制」按钮（图标按钮）。点击后，多边形会把末点与首点连起来形成闭合图形；折线则直接完成。这一项由 construction-prompt 子任务实现，本任务提供完成语义（已有 Complete）。

## Requirements

- R1 控制点模型：按上表重写 `BuildEditHandles`/`EditShape`（`shape_interaction.inl:80-289`）。
  - 取消 8 点框；外框缩放只给立体图形，只有四角。
  - 控制点位置从 typed construction 推导（G5）。
  - 圆心、中心这类点等于整体移动（G2）。
  - 命中优先级保持：旋转 → 专属点 → 外框缩放点 → 本体。
- R2 构造真值的补充：
  - 圆在 Drag（外接框）模式下也要能表示半径点的方向。可以在 construction 中补存方向，或者编辑时转成 CenterRadius 但保留外接语义；具体做法在 design 中定。
  - 椭圆的焦点编辑会改变方向，方向写入对象的 transform 旋转。
  - 菱形、平行四边形、梯形的约束保持类型不变（编辑后仍属于对应 preset）。
  - 圆弧、扇形编辑时的角度按轨迹累计，与构造时的 ObserveRaw 一致。
- R3 修正 research §6 记录的逻辑问题：
  - 第 1–3 项（圆半径点、外框不一致、框与点错位）；
  - 第 4 项（弧角跨半圈）；
  - 第 5–8 项（棱柱/棱锥缩放、中心语义、圆柱圆锥控制点不在图形上、正方体跳变）；
  - 第 9 项（圆锥母线切线）；
  - 第 11 项（去重导致点不可达，删除 8 点框后自然消失）；
  - 第 12–16 项（平行四边形、梯形、退化形状、菱形、圆角缩放）；
  - 第 17–18 项（旋转钮范围、中心语义）。
  - 第 10 项（圆柱、圆锥的可见性约定）保持现状。
- R4 辅助显示：
  - 模型：`ShapeStyle` 或 construction 中增加辅助显示标志位。
  - 渲染：作为对象 Compound 的附加部件，或在 RenderData 中派生；与描边同材质，覆盖区域求并集，避免半透明叠色接缝。
  - 命中：辅助元素不参与本体命中，或者按设计中的选择处理。
  - 持久化：`inkeysShape` 升级为 v4，同时能读 v1/v2/v3。UInk10 标准降级时，把辅助点导出为标准 Circle 填充，对角线导出为带 dash 的标准 Line，保证旧版本和第三方软件能看到这些元素且不丢内容。白板冷历史使用同一套 codec。
  - 浮条中的开关只修改当前对象，进入一条编辑历史；主栏中的开关只改变下一笔。
- R5 圆角矩形：只从主栏移除，旧对象照常编辑（见 toolbar-category D4）。
- R6 所有编辑沿用统一的 journal、Replace 历史和 revision 规则（shapes.md 中「编辑历史、修订与持久化补充」）。

## Acceptance Criteria

- [ ] 每种已启用的图形都有共享核心单测：控制点集合与上表一致（数量、类型、位置），拖动每个控制点后的构造真值符合约束，覆盖退化钳制和不提交的情况。
- [ ] 圆在两种绘制方式下都能沿任意方向拖动半径点，拖动过程中控制点不跳回水平方向。
- [ ] 椭圆开启焦点后，拖动 F1：长半轴保持不变，F2 对称移动，椭圆的方向跟随变化；焦点不能越过长轴端点。
- [ ] 圆弧终点从 90° 一直拖到 300°，sweep 为 210°，不翻向。
- [ ] 辅助显示：使用默认值绘制，圆显示圆心、椭圆显示焦点；浮条中切换开关可以撤销和重做；保存后重新打开时开关状态和画面一致；用 v3 读取器（模拟旧版本）打开 v4 文件时，能看到降级后的点和虚线。
- [ ] `--draw3-shape-core-test`、`--draw3-shape-renderer-test`、共享的 `--shape-core-only`、`--uink-file-only` 全部通过，并新增上述用例。
- [ ] 实机（由用户验收）：各图形的控制点手感符合上表。
