# 启动动画多效果、主题与分层透明度

## Goal

启动预览支持可选择的掠光、彩虹晕染、像素拼装三种效果，按 ReadMini 中的主题、背景/内容透明度和缩放正确呈现，并平滑交接到正式主栏或主按钮。

## Background / Confirmed Decisions

- 用户已授权创建本任务；用户明确要求两种新增效果先出样式预览，经本人确认后才开始产品实现。2026-11-04 用户已明确回复“这版可以，开始实现”，批准第四版样式及本任务实施。
- 2026-11-04 用户确认角落启动预览沿用深色材质，即使全局主题为浅色。三种效果均可用于角落，改变的是材质配色，不强制改回旧反光效果。
- 用户要求在“启动加载动画”开启时，于其下方显示内联下拉框选择效果；关闭时折叠该行，保留选择。
- 用户明确彩虹晕染的形态：主栏等大的固定圆角矩形底板，彩虹色晕染与柔和反光在内部动态变化，类似网站 AI 动态材质；不是只用漂浮光团代替底板。角落沿用主按钮轮廓和深色基底。
- 用户最新修正：像素从目标主栏所在区域以混乱分布渐显并先向外散开，再从约定外围区域回收，精确拼成与掠光一致的底板；拼好后静止，青色拖尾逐渐消退，未加载完就接入掠光。即使程序提前就绪也播完外散/回收段，再预览渐隐、正式 UI 渐显。
- 用户指定参考 `D:/Project/HiEasyX/HiEasyX/HiEasyX/HiStart.cpp` 及相关文件，仅复用算法思路，不要求 IMAGE。后续明确允许利用 D2D effects，并要求像素效果透明背景。

## Requirements

- R1 配置：ReadMini 增读现有 `Experimental.Inkeys3.UI3.ThemeMode/BackgroundOpacity/ContentOpacity` 与新增 `StartupPreview.Effect`。默认与非法效果回退“掠光”，保留旧配置行为；不新增独立透明度滑块。启动外观与效果冻结到本次预览。
- R2 设置：名称确定“掠光”（旧反光滑动）、“彩虹晕染”、“像素拼装”。开启动画时向下展开一行内联下拉框，使用既有条件块/ComboRow、现有动效速率及禁动画规则；选择下次启动生效。关闭再开启不丢失选择，按现有配置 FIFO 保存；补齐既有国际化生成链。
- R3 材质：居中主栏随主题为深色或中性雾白；角落固定深色。三种效果均提供适配这些材质的颜色/亮度版本。彩虹晕染保留稳定基底/边框，内部为紧密分布、自由移动/柔和碰撞/变形的局部色块，内侧基本没有无颜色区域，颜色不按竖向条带或固定顺序排列；深浅两种主题的色层都保持较淡的低不透明度，清楚透见底板；取消四周羽化/边框渐变，仅按实际圆角轮廓裁剪；反光也保持低强度；保留掠光并严格裁剪在轮廓内。混色保持明亮协调，避免互补色堆叠发灰、发褐。
- R4 分层透明度：背景包括基底、边框、反光、彩虹晕染、像素和青色拖尾；这些统一消费背景透明度。进度轨道/填充/失败红属于上层内容，独立消费内容透明度。背景 0 表示主题默认，其余归一 30~100；内容默认 100，归一 30~100。沿用正式主按钮 0.6/0.8 比例。整窗淡出另行且只乘一次，不让低透明度被多层效果叠实。
- R5 像素区域：主栏外散区域约宽 2W、高 3H，底部中心与目标底部中心相同，并位于任务栏上方；角落比目标外扩一圈，裁剪屏幕/工作区外侧。外散点随机覆盖整个允许区域，包含目标主栏内部，不得把目标位置排除形成空洞。最终目标取自掠光底板的实际 RGBA：主栏圆角矩形/角落现有超椭圆；只让 alpha>0 的像素参与，保留半透明边框/抗锯齿边缘。回收后完整还原底板，无稀疏网格孔洞；外散区域空白和目标透明角始终透明。
- R6 像素运动：使用启动期固定随机种子；像素先从目标区域内部的混乱位置渐显并向外散开，再回收到各自固定目标。已散布在目标区域内的点也必须在回收时清楚可见地流动，不等同于已经处于最终目标。给内部点分配附近但不同的随机目标，保持较短而非近乎零的位移，并通过轻微弧线回收；远近粒子共用回收起点与完成时刻，距离不同通过速度比例适配，不提前归位或另加等待。按批准样式外散约 0.8 秒、总拼装约 2.4 秒，渐显与外散同时发生。拼好后立即停止移动和新拖尾注入，已有主题青色拖尾继续扩散并约 1.1 秒消退；仍未加载好时直接转入底板掠光，取消原“拼好后微浮”方案。浅色青尾对比清晰，深色亮青柔和。
- R7 时序：进度继续反映真实里程碑，慢启动满 3 秒显示，居中横条/角落圆环，失败可提前立即显示红色。成功交接需同时满足真实完成、正式 Bar 首帧可交接、像素拼装段结束；只限制选择像素拼装时的最短视觉时长。沿用已有先渐隐再渐显的交接时长（未出现进度每段 300ms；已出现进度每段 1000ms）。失败/退出不等待完整拼装。
- R8 缩放：三种效果及基底、像素尺寸/目标网格、外散区域、散射位移、模糊半径、进度尺寸跟随已有 UIBase×Zoom 和 DPI 路径；不二次缩放。扩大粒子绘制窗口不改变正式栏位置或缓存的逻辑总宽度。
- R9 工程：优先复用共享 D2D 的基础图元、GaussianBlur/ColorMatrix/透明合成；保持 BGRA premultiplied 与既有 GDI/ULW 呈现，设备/线程生命周期不变。不阻塞启动主线程或渲染线程等待动画，不引入新渲染系统。
