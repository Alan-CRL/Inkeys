# 按设备光标专页：DPI 与落笔隐藏控制续作

## 目标与背景

延续已于 2026-11-04 验收归档的 `11-03-per-device-cursor-page`，解决用户所见的自绘鼠标光标偏小问题，并把笔设备落笔隐藏行为细分到两种小圆点样式。原功能与决策见原提交 `63f1d0e7`（五种样式）、`2ea7d3d9`（蓝色信息条）、`3d22f108`（原任务归档）；本轮验收以下增量。

## 需求

- R1：软件绘制的鼠标箭头应跟随系统 DPI，尺寸、描边和尖端热点一致；查明实际缩放缺口，避免对已转换为像素的尺寸再次缩放。原生系统鼠标光标继续由 Windows 管理。
- R2：屏幕笔与数位板不再统一在落笔后隐藏光标。箭头、画笔、画笔（高亮）在接触期间继续显示；荧光笔和图形保留专用外观并可在笔接触时显示，橡皮与激光既有生命周期不变。R3 是两种小圆点样式的唯一按设备隐藏例外。
- R3：在设置 → 绘制 → 光标页最下方新增“精细控制”区，条目“小圆点光标落笔后自动隐藏”，下拉顺序为“关闭 / 仅屏幕笔 / 仅数位板 / 屏幕笔和数位板”，默认“仅屏幕笔”。同时作用于“小圆点”和“小圆点（高亮）”，仅软笔/硬笔的设备样式适用；悬停仍显示。配置重启保留，缺失或非法值使用默认。
- R4：蓝色信息条放在“识别驱动注入的数位板”下方，在新精细控制区上方；保留原说明、颜色和分号分行方式。各语言布局顺序一致，新增文案补齐所有 20 种语言及生成产物。
- R5：沿用当前设备分类：Unknown/Conflict 笔按数位板行；开关识别到的非 Ink 注入鼠标按数位板行。真实鼠标与触摸不受新增隐藏模式影响；触摸仍为逐接触显示并在抬起后消失。

- R6（本轮实机反馈）：用户确认自绘箭头大小正确，但黑色边缘比图二原生箭头显著粗。保持已校准尺寸、热点和 DPI 链，仅减细自绘箭头描边并同步预览；画笔、小圆点及高亮边缘不变。
- R7（本轮实机反馈）：设置页底部的下拉框不得超出客户区导致选项无法点击。沿用现有 ImGui 弹层：正常向下；下方不足且上方空间更多时向上；两侧都不足时在较大一侧限制高度并滚动。普通下拉和带动画下拉一致，保持键盘、鼠标选择和开关动画，不新增原生弹窗。用户补充明确：修复作用于所有该控件消费者，包括教学安全选项，不作光标页专用补丁。
