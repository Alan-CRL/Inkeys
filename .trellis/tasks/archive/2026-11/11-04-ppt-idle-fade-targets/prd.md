# PPT 闲置淡化透明度上限与主栏适配

## 目标

PPT 放映时降低悬浮控件对课件的遮挡，同时保留可发现、可操作的界面。闲置淡化使用背景与内容分别的固定不透明度上限，用户可选择作用区域，主栏交互和附属面板展开时保持清晰。

## 背景与证据

本任务是已归档 `.trellis/tasks/archive/2026-11/11-02-ppt-linkage-idle-fade/` 的后续；用户已在对话明确确认最新方案并批准进入实现。

- 四个翻页控件目前整体乘 0.4，且各自计时、支持悬停恢复及外部翻页启动淡化：`Inkeys/Inkeys/UI/PageControl/PageControl.cppm:656`、`:679`，`PageControl.cpp:1307`、`:1318`、`:6057`。
- 主栏与分页已有独立背景和图标/文字透明度，弹出面板另行绘制：`Inkeys/Inkeys/UI/Bar/Bar.Scene.cpp:686`、`:1103`，`Bar.RenderLoop.cpp:11451`、`:11465`、`:11550`；正常值合同见 `.trellis/spec/native-desktop/configuration-i18n-and-assets.md:51`。
- 联动详情的闲置下拉框位于 `Inkeys/Inkeys/UI/Setting/Setting.cpp:4507`；类型选择的内联复选布局见 `Setting.Pages.cpp:862`、`:988`。

完整调查见 `research/current-implementation.md`；本文件仅记录最终需求与验收，不承载实现步骤。

## 需求

| ID | 需求与已确认决定 |
| --- | --- |
| R1 | 三类区域统一使用固定不透明度上限：背景 30%、内容 60%，不新增数值调节入口。内容包含原“内容透明度”所控制的图标与文字。目标为 `背景 min(正常值, 30%)`、`内容 min(正常值, 60%)`，只减不增；例如内容原来 30% 时保持 30%。不修改用户正常透明度偏好，恢复时回到原值。 |
| R2 | 在 PPT 联动详情“闲置时自动淡化”同一张卡片下方直接内联三个复选项，不再有独立的“淡化范围”标题或卡片。选项依次为“两侧底部”“两侧中部”“主栏（仅底栏模式时）”。默认 true / true / false，独立持久化、即时生效，允许全部取消。关闭淡化时保留勾选偏好，三个选项区域以现有条件动画折叠；重新开启时动画展开。退出/未完全展开时禁止点击，父行与时长下拉保持显示。 |
| R3 | 沿用现有关闭 / 5 / 10 / 15 / 30 秒、默认 10 秒的等待设置；每个翻页控件和主栏独立计时。未勾选区域保持正常显示。首次进入有效 PPT 可见态、切换场次或重新启用某区域时，该区域恢复并从头计时。 |
| R4 | 主栏与翻页控件均在有效悬停、点击/按下时恢复；悬停、按下或拖动期间保持正常不透明度。交互结束且没有其他保护条件后重新等待完整时长。淡化不改变命中，第一下点击仍执行原动作。 |
| R5 | 用户已确认主栏只在闲置到期后淡化；外部翻页既不触发主栏淡化，也不重置其计时。四个翻页控件保留原有外部翻页启动淡化及自身交互优先规则，不改现有翻页来源识别。 |
| R6 | 用户已确认主栏所有可交互附属面板均保护主栏，包含画笔、形状、橡皮、撤回、颜色选择器/笔宽等子面板以及“更多”。只要任一展开，主栏恢复并保持清晰；最后一个完全收起后重新计时。附属面板自身不参与淡化。普通无交互提示不单独建立持久保护。 |
| R7 | 主栏淡化仅在底栏模式生效，包含普通底栏和居中底栏；浮动主栏保持正常。退出底栏恢复，重新进入底栏后从正常态完整计时。作用对象仅 PPT 场景内勾选的主栏本体（含主按钮、收起后的主按钮入口）与翻页控件；白板和桌面不增加淡化。退出有效 PPT 可见态后恢复正常，不携带旧计时/外部翻页状态；返回后按 R3 重新开始。 |
| R8 | 淡化与恢复保持现有 0.5s / 0.15s 的节奏，遵循现有动画开关与速率；反向从当前画面续接，关闭动画直接到目标。显隐、收展、禁用与主题材质的原有独立语义继续生效，属性面板不得受连带影响。 |
| R9 | 新选项与说明同步现有全部 20 个 i18n 语言文件及生成项；旧配置缺新字段按 R2 默认值工作，已有等待时长和正常透明度偏好保持。 |

## 验收标准

- [x] AC1 → R1/R8：正常背景 80% 或 88%、内容 100% 时，闲置平滑到 30% / 60%；内容 30% 时保持 30%；等于或低于对应上限的正常材质值不会被加深。恢复精确回到原正常值，配置未被淡化过程改写。
- [x] AC2 → R2/R9：三个复选项直接内联在等待下拉所在卡片下方，无重复标题/图标/独立卡片；三项顺序、底栏模式注释与默认值准确；改变一项只改变对应范围，重启读回一致。关闭时复选区动画折叠、开启时动画展开，父行和下拉常驻、偏好保留，退出/未全开时不可点，全部取消合法；窄窗、长翻译和缩放下布局可用。
- [x] AC3 → R3/R4：四个翻页控件各自计时，主栏也独立；悬停/按下/拖动该区域时恢复并保持，离开/松手后从头等待，其他区域不被顺带重置，第一次点击不被吞掉。
- [x] AC4 → R5：外部翻页仅按原规则触发所选翻页控件的淡化；主栏处于正常、倒计时、淡化或恢复动画中时，都不会因页码变化改变其计时目标。
- [ ] AC5 → R6：逐一展开画笔、形状、橡皮、撤回、更多及子面板，等待超过所选时长仍保持主栏正常；多个保护条件重叠时，最后一个消失后才重新计时。面板及其退场动画的透明度保持原行为。
- [x] AC6 → R3/R7：新场次、白板返回 PPT、暂不可见后恢复、重新勾选区域都从正常态等待；进入白板/桌面、取消勾选或关闭淡化会恢复，不残留旧淡化或立即吃到旧外部翻页信号。
- [x] AC7 → R1/R7/R8：普通底栏/居中底栏启用、浮动模式排除、模式切换重计时、主栏展开/收起、浅深主题、正常透明度变化、动画中途反向及关闭动画均到达正确目标；主按钮不丢失，附属面板和其他 UI 不被淡化，命中/翻页/拖动行为不变。
- [x] AC8 → R9：旧文件缺字段、非法类型回退、有效布尔读写及快照更新得到验证；全部语言 i18n check、最小充分无窗口回归与完整 Debug|ARM64 solution 构建通过，保留真实退出码和未测范围说明。

## 不在范围

- 不修改 PPT/WPS COM 协议、控件翻页归因的既有 3 秒宽限、支持版本或安装方式。
- 不重做材质、边框/选中底板设计、正常透明度滑块、主栏/面板布局或全局输入系统。
- 不把白板独立菜单纳入主栏 PPT 策略，不改变桌面/白板行为或启动预览。
- 不新增常驻轮询线程；不重构无关模块，不修改第三方依赖。
- GUI/真实 Office 手工观感验证仍需明确授权；本轮规划不执行，后续无窗口结果不能冒充该验证。
