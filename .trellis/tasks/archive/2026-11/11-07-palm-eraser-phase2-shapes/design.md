# 技术设计：擦除形状、微光光标与样式设置

位置以基线 babdecf6 为准，实施前复核。路径简写：Draw3 = `Inkeys/Inkeys/Drawing/Draw3/`。

## 1. 形状与尺寸

```text
enum class EraserShape : uint8_t { Circle = 0, Rectangle = 1, Square = 2 };
r = D/2（逐点标量，保持现有 realPoints.r / 持久 width = 2r 语义不变）
Circle    : 半径 r
Rectangle : 半宽 = r·√(π/6) ≈ 0.72360r，半高 = 1.5×半宽 ≈ 1.08540r   （面积 = πr²，宽:高 = 2:3）
Square    : 半边 = r·√π/2 ≈ 0.88623r
```

- 形状是**笔划级**属性（Down 时锁存），逐点仍只存标量 r，笔速/手掌变尺寸照常工作。
- 圆角：光标/预览 6 DIP（2026-11-07 由 3px 改为 DIP，随缩放），不超过短边一半；擦除几何无圆角。

## 2. 擦除几何与着色器（R1、R3、R4）

- 现状：橡皮重放固定 `RoundCapsule + Erase`（Draw3.StrokeGeometry.cpp:1125），PS 变半径胶囊距离 + `fwidth×1.5 + smoothstep` AA，擦除输出 `Add=0, Retain=1−coverage`（inkPixelShader.hlsl:589）。荧光笔已有轴对齐矩形扫掠（StrokeGeometry:585、inkVertexShader:98、inkPixelShader:72），但每段只有一组宽高（两端平均）。
- 新增擦除段类型 `EraseRectSweep`：两端为轴对齐矩形，半尺寸分别 (ax0, ay0)、(ax1, ay1)。**线性插值的轴对齐矩形沿线段的扫掠恰为两端矩形的凸包**（B(t) = (1−t)B0 + tB1，凸组合点必落在某个 B(t) 内），因此 PS 只需计算“点到两矩形凸包（≤6 边凸多边形）”的有符号距离；VS 包围盒取两端矩形并集外扩 2px（沿用荧光笔做法）。单点/零长段退化为单个矩形。
- 不复用荧光笔的“两端平均尺寸”，以保证变尺寸时擦除边界精确。
- AA 与圆形相同的覆盖函数；Erase 输出不变。
- 实时 dirty、历史瓦片 bounds：用两端矩形并集（含 AA 外扩）替代 `±r` 圆界。
- Win7：正式 VS/PS 经 vcxproj 编译 SM5.0 CSO；Win7 WARP 使用 `Draw3.Win7GuardedShader.h`（生成器见 `.trellis/tasks/archive/2026-10/10-18-draw3-cursor-policy/research/Generate-Win7-GuardedShader.ps1`），新增类型须同步门限、CSO 与兼容字节码。

## 3. 存储（R5）

- 持久点保持 `x/y/width`；样式新增 `eraserShape`，仅橡皮笔划写出，缺省 Circle。
- 写入位置：UInk **私有/扩展字段**，要求“当前已发布版本读取时忽略、仍识别为橡皮笔划并按圆形重放”。调查已知：UInk 只接受版本 10；未知字段可忽略；新增 inkType 会被降级为普通笔（禁用）；`ink.extra` 被当前 Draw3 导入拒绝（`inkStrokeModelerTest/draw3/uink_codec.cpp:837/1405`、`uink_draw3_import.cpp:35`）。**实施第一步须确认一个满足上述要求的私有字段位置**（用当前发布版的解析代码写用例验证）；找不到时回到规划，不得选用会被旧版拒读或误判为墨迹的位置。

- 记录：UInk 1.1 将 `eraserShape` 升为官方字段（写入 spec 的 UInk 章节与代码注释）。

## 4. 橡皮光标（R6，2026-11-07 经三轮网页预览定稿）

参考实现（逐像素、与着色器同公式）：`research/eraser-cursor-preview-final.html`（图标）与 `research/eraser-cursor-preview-sparkle-d1.html`（星光 D1）。下列参数以这两份为准。

### 4.1 外观维度
光标外观 = 形状（圆 / 竖长矩形 2:3 / 正方形，同面积）× 纹样（经典抓手〔默认〕/ Inkeys / 星光）× 明暗（浅色〔默认，与应用主题无关〕/ 深色）。纹样与明暗全局共用于所有橡皮（鼠标、笔、触摸、笔速、手掌）；手掌只可另选形状。

- 形状外轮廓：圆；矩形/正方形为圆角矩形，**圆角 6 DIP**（在基准尺寸下随 DPI 缩放，最多短边一半）；实际擦除区域仍为直角矩形。
- 描边：宽 = 短边 S × `ERASER_GRIP_OUTLINE_RATIO`(0.04)；AA = `saturate(0.5 − d)`；整体不透明度 Hover 0.5 / 接触 1.0（沿用现状）。
- 配色：浅色 填充 255、描边 207；深色 填充 40、描边 110。**所有纹样（抓手、星光、Inkeys 图标的屏幕与橡皮）统一用描边灰**（2026-11-07 用户复核修订，原深色纹样 200、图标 RGB 43/白 + 半透明屏幕作废）。

### 4.2 纹样（坐标以短边 S 为单位，y 向下，原点为光标中心）
- **经典抓手**：两条竖胶囊，半径 0.05S、半高 0.24S、横偏移 ±0.12S；始终显示。
- **星光（D1 原版）**：主星中心 (+0.15S, −0.15S)、外半径 0.12S，四角凹星 `u = (|x|/R')^0.5 + (|y|/R')^0.5`，`R' = R − 0.06R`，距离 ≈ `(u−1)/|∇u| − 0.06R`（|u−1| > 0.35 直接判内外）；两道等宽胶囊（半径 0.026S）(−0.27S, 0.17S)→(−0.13S, 0.03S)、(−0.16S, 0.26S)→(−0.06S, 0.16S)；S ≥ 40 时再加小星 (+0.31S, 0)、半径 0.05S；S < 20 不画。
- **Inkeys（方块橡皮版主按钮图标，L-d 下移 5）**：logo 256 视口坐标。屏幕 = 圆角矩形 (59, 77.775, 139×100, r 6)；橡皮沿原笔轴：原点 N0 = (99.28, 198.04)、轴向 u = (0.4399, −0.8981)、横向 n = (0.8981, 0.4399)，局部 (t, s)：橡皮体 t∈[9, 61]、半宽 14、t=9 端圆角 5；纸套 t∈[63.5, 145]、半宽 14、t=145 端圆角 5；屏幕扣除橡皮外扩 6 单位的空隙后再画橡皮。图标锚点 (128.5, 129) 对齐光标中心，缩放 `k = ratio × S / 142`，ratio：圆/正方形 0.48、竖长矩形 0.54；S < 24 隐藏。颜色：屏幕与橡皮均为不透明描边灰（同上），靠 6 单位空隙分隔；无颜色指示器。

### 4.3 缓存渲染（用户要求：不每帧重绘、动态尺寸等比缩放）
- 现状：无光标缓存，每次合成对 N 个光标做 N 次参数上传/常量 Map/Draw（研究：`../11-07-palm-eraser-phase2/research/codex-cursor-cache.md`）。
- 方案：按外观键（形状、纹样、明暗、基准尺寸档、DPI）在 CPU 上一次性栅格化整枚光标精灵（形状/描边/填充/抓手/星光用 4.2 的距离公式；Inkeys 图标用 lunasvg 3.5.0 栅格化同几何的 SVG），预乘 BGRA，CPU 生成 mip 链后上传为 Draw3 自有纹理（Win7 WARP 不能共享 Bar 设备纹理，不依赖 GenerateMips）。绘制时新增精灵采样光标类型，独立线性 clamp 采样器，只做等比缩放的 quad。
- 尺寸：以当前橡皮基准直径烘焙；笔速/手掌动态尺寸只改变 quad 大小（圆角、描边、纹样一起等比缩放）。当绘制尺寸超过烘焙尺寸 1.25 倍时按 2 的幂档位重新烘焙更大一档（只在绘制 owner、RTS 回调之外）。
- 失效：外观设置、基准尺寸、DPI 变化或设备重建时重建；位置移动与动态尺寸不失效。主光标与逐 Touch 光标共享同一纹理。
- 内存：每外观键一张（含 mip），通常同时只有普通橡皮 + 手掌各一张。

### 4.4 光标数据流
主光标与逐 Touch 光标携带外观键与当前绘制尺寸；进行中的橡皮用 Down 锁存的形状；Hover 用当前设置。光标 dirty bounds 按形状半宽高（含 AA 外扩）。
