# 橡皮擦除形状、光标重设计与样式设置（子任务 B-a + C）

父任务：`11-07-palm-eraser-phase2`（决策 D5、D6、D7 见父 prd.md）。调查证据：`../11-07-palm-eraser-phase2/research/codex-eraser-shapes.md`、`codex-settings-config.md`。

## 需求

| ID | 要求 |
| --- | --- |
| R1 | 新增两种擦除形状：竖长矩形（宽:高 = 2:3）、正方形；保留圆形。均为屏幕轴对齐，不随方向旋转。 |
| R2 | 尺寸采用等面积映射：形状面积 = πD²/4（D 为现有直径语义，含 24/32/40 DIP 档、笔速 0.5D–5D、手掌直径）。 |
| R3 | 实际擦除区域为无圆角矩形（矩形段为两端矩形的扫掠）；光标与所有预览为圆角矩形，圆角 6 DIP（随缩放；动态尺寸等比缩放），且不超过短边一半。 |
| R4 | 着色器新增/扩展对应擦除与光标类型，抗锯齿与圆形橡皮一致；同步正式 CSO 与 Win7 兼容字节码。 |
| R5 | 橡皮笔划在 UInk 私有字段记录形状；同版本扩展；旧文件缺省圆形；旧版程序忽略字段按圆形重放；undo/redo、自动保存、白板存储与历史均正确重放形状。记录 UInk 1.1 官方化。 |
| R6 | 橡皮光标外观 = 形状 × 纹样（经典抓手〔默认〕/ Inkeys 方块橡皮图标 / 星光 D1）× 明暗（浅色〔默认〕/ 深色），参数见 design.md §4；纹样与明暗全局共用；光标按外观烘焙为缓存纹理精灵，绘制时等比缩放，不每帧计算。 |
| R7 | 设置“绘制 → 光标”页新增“橡皮光标”内联块：明暗下拉 + 可点击预览按钮（左三形状 | 分割线 | 右三纹样），选中项 WinUI3 强调色环，无下拉；控件供 custom 子任务的手掌形状选择复用。 |
| R8 | 主栏-橡皮-橡皮属性中的橡皮大小预览、命中区、选中环与焦点适配当前形状、纹样与明暗；圆角 6 DIP 随缩放。 |
| R9 | i18n 覆盖全部语言；配置新增项严格校验并有默认值。 |

## 验收

- AC1：三形状在 24/32/40 DIP 及笔速变尺寸下擦除区域与等面积公式一致（数值测试），矩形段覆盖等于两端矩形凸包；单点（无移动）擦出完整矩形。
- AC2：光标轮廓与实际擦除边界一致（差异仅在圆角内侧）；纹样显隐：抓手始终、星光 <20px 隐藏且 ≥40px 才有小星、Inkeys <24px 隐藏；位置移动与动态尺寸不触发重新栅格化，外观/基准尺寸/DPI/设备重建才重建。
- AC3：保存/重开、撤销/重做、白板切页后形状重放一致；旧文件按圆形读取；构造“旧版读取新文件”的解析用例确认字段被忽略且回退圆形。
- AC4：设置新增项在 20 语、七种缩放、浅深主题、窄/宽布局下无截断重叠（`--setting-eraser-only`）；配置非法值回落默认。
- AC5：主栏预览按当前形状、纹样、明暗显示且 DPI 缩放正确，圆角 6 DIP 随缩放（不超过短边一半）。
- AC6：Win7 兼容字节码同步并通过既有检查；完整构建与相关 Headless 通过；GUI/实机/Win7 未测项单列。
