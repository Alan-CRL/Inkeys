# 设置窗口禁用触摸右键与点击反馈

## Goal

设置窗口不再出现系统的触摸长按右键（press-and-hold → 右键）以及系统触摸/笔点击、长按的视觉反馈，与主栏窗口的观感一致。父任务：`11-26-setting-pointer-input`。

## 背景

- 设置窗口现由 ImGui Win32 backend 消费系统派生的兼容鼠标消息；触摸按住约 1 秒后系统派生 `WM_RBUTTONDOWN/UP`，在组件页长按起拖时最易误触。
- 主栏不出现这些行为，是因为接触阶段 `WM_POINTER*` 由 `Touch::HandlePointer` 消费并 `return 0`，系统不再派生长按右键与兼容鼠标。该完整接入属于子任务 `setting-pointer-route`；本子任务先用窗口级开关独立消除右键与视觉反馈，使其在 pointer-route 落地前后都成立（Win7 回退路径也依赖它）。

## Requirements

- R1 设置窗口客户区内触摸长按不再生成右键语义（不派生 `WM_RBUTTONDOWN/UP`、`WM_CONTEXTMENU`），触摸/笔点击仍正常工作。
- R2 设置窗口内不显示系统触摸点击涟漪、长按圆环、双击/右击反馈；笔点击、笔桶键反馈同样关闭。
- R3 Win8+ 与 Win7（Tablet 服务路径）都生效；所需 Win8+ API 动态获取，缺失时静默跳过。
- R4 不影响标题栏拖动窗口、标题栏按钮、缩放边框的触摸操作；不影响鼠标右键（设置窗口现无右键功能，但鼠标行为保持原样）。
- R5 不改主栏、分页、画布等其他窗口的设置。

## 约束

- 最小修改，只动设置窗口创建/窗口过程相关的几行；`.cpp/.cppm/.h` 保持 UTF-8 BOM + CRLF。
- 兼容 Windows 7 SP1 + KB2670838。
