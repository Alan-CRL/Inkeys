# C5 主栏预览共享真实主栏内容编排

> 父任务：`11-20-settings-bar-component-editor`。本任务修正 C2/C3 的预览实现方式，并补齐 2026-11-20 实机反馈的组件页交互问题。技术设计见 `design.md`，执行计划见 `implement.md`。

## Goal

设置 → 组件页的主栏预览是真实主栏内容（不含主按钮/Logo）的 1:1 复刻：布局、动画、More 面板（含 X）、悬停/按压反馈、按钮图标文案变化与真实主栏完全一致；状态与真实主栏独立（沙盒），默认处于绘制模式。为此把真实主栏的内容编排抽成两边共用的代码，而不是在预览里另写一套。

## 背景（实机问题与根因）

- 预览只复用了绘制函数和 UI3 按钮视觉，动画编排在 `BarContentInstance::Advance` 里另写了简化版：底板宽度与按钮位置不共享批次时间轴；缩放每帧随当前宽度与 More 进度变化，吃掉 More 的回弹并让图标在伸缩中缩放；隐藏按钮直接移出列表，没有收拢动画；没有按压反馈。
- More 面板 X 不可见：预览从未推进 X 的 SVG，宽高当前值恒为 0（实栏在 `Bar.RenderLoop.cpp` 统一推进 `svgMap`）。
- 点击“选择”不能收窄：预览投影固定为绘制模式，宿主只处理 More/X 点击。

## Requirements

### R1 共享内容编排（复刻的前提）
- 真实主栏与预览调用同一份：按钮显示投影（尺寸/隐藏/状态）、按钮内容样式（绘制/橡皮/图形/选择等图标与文案）、布局批次决策（展开 Back、收起平滑、中途加入/后半程重开）、按钮/底板/More 目标写入、隐藏按钮锚定收拢、按钮与 SVG 推进、小尺寸悬停提示门禁与定位。
- 真实主栏行为零变化：golden 逐字节一致，且新增的动画轨迹基线一致（见验收）。
- 预览特有部分只保留：沙盒状态、无主按钮的居中锚点、预览相机、编辑叠加（抓起、插入缝、幽灵按钮、提示）。

### R2 沙盒状态与点击
- 默认绘制模式（软笔），无画布内容、非白板、非放映，设置页可见（设置按钮为选中态）。
- 只切换工具模式：选择/绘制/橡皮/图形点击后切换选中态；点击“选择”后与真实主栏一样收起一点（无内容的选择态隐藏橡皮、图形、撤回等并播放收拢动画）；再次点击已选中的绘制不打开属性面板。
- 绘制选中显示软笔图标与“软笔”文案、图形选中显示当前图形工具图标，规则与真实主栏一致。
- 其他按钮只有按压反馈，不执行任何功能。
- More 与 X 按真实规则开合：点 More 切换；点 X 收起；点 More 面板内按钮后按 `closeMoreAfterAction` 收起；在面板与 More 按钮之外按下（左/右键）收起。
- 悬停提示与真实主栏一致：只在小尺寸下显示。

### R3 预览区布局（More 空间）
- 预览区上沿紧贴页面标题，主栏上方常驻预留足以让一行 More 面板（含回弹峰值与阴影）向上展开的空间；More 内容达到两行及以上时，预览区再向下扩展。
- 展开/收起 More 时主栏位置与大小不变；预留空间只随 More 行数（编辑结果）变化。
- 主栏下方到下一条目的间距增大到约一行，与上方对称（具体数值实现后再调）。
- 大小尺寸显示高度相近；过宽时等比缩小，缩放只随目标布局变化，不随动画中间值变化。

### R4 垃圾桶
- 删除区放在主栏下方居中（即下方预留间隙内），样式为长条胶囊：图标 + 文字；悬停可删除时变红。

### R5 拖放语义
- 可删除的主栏按钮（B1/More 中的组件、用户分割线）：拖入垃圾桶或拖出预览区域时提示“会被删除”，松手即删除。
- 不可删除的按钮（A1/A2 默认按钮、设置）：拖出原区域提示“只能在原区域内调整”，松手回到原位。
- 从组件库拖入的按钮：没有落在可插入位置时松手即放弃添加（提示相应文案）；也可拖入垃圾桶放弃。
- 分割线：卡片没有“+”，但必须能拖入 A1/B1/A2（当前拖入失败，需定位修复），不能放入 More。

### R6 拖动幽灵按钮配色
- 选中态（青色）按钮拖动时背景与页面不协调，非选中态勉强可用；需优化为在主栏材质上呈现的观感（两种状态都协调）。

### R7 合成后整体透明度与页面动画
- 预览纹理合成时支持整体透明度；进入/离开组件页时与其他控件一样参与开场/退场动画（位移与透明度）。
- 透明度作用于合成好的纹理整体，不能逐部件改透明度。

## Acceptance Criteria

- [ ] 真实主栏：golden 35/35 与 HEAD 基线逐字节一致；动画轨迹基线（展开/收起、前半程加入、后半程重开、换边中重排、More 正反向、折叠）逐帧一致；几何/橡皮/第二宿主/属性脏区/headless 全通过。
- [ ] 预览：展开 More 的过程中面板出现超过终点的回弹峰值，同时预览相机缩放与主栏位置保持不变；X 可见可点。
- [ ] 预览：底板边缘与末端按钮在布局批次中同曲线同相位（离屏逐帧断言）。
- [ ] 预览：点击选择后橡皮/图形/撤回收拢到锚点并淡出，命中与插入缝只含可见项；点击绘制恢复；绘制选中显示软笔。
- [ ] 预览：按下有按压缩放，越过拖动阈值时按压先恢复再抓起；点击与拖放不会对同一次抬起重复生效。
- [ ] 预览：大尺寸无悬停提示，小尺寸有。
- [ ] 组件页：垃圾桶胶囊位于主栏下方居中；R5 各分支（删除/回位/放弃添加/分割线拖入 A1、B1、A2）有离屏或无窗口测试覆盖。
- [ ] 组件页：进入/离开时预览随页面动画整体淡入淡出与上浮。
- [ ] 新增文案 20 种语言齐全，`i18n.ps1 check` 通过。
- [ ] `InkeysRepo.sln` `Debug|ARM64` 构建通过；最后由用户实机验收。
