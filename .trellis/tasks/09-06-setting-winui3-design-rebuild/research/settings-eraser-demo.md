# 笔速橡皮动态演示

用户已批准直接实现，并允许为展示调整粗细变化；轨迹、直径及擦除时序提前计算，运行时着色器只播放，降低设备负载。本设计替代先前暂缓素材/静态对比图以及实时控制器计算方案。

## 页面与内容

- 详情页顶部沿用统一外框的大卡，固定橡皮与笔速橡皮左右等宽，窄窗上下排列。浅色白板 #F7F8FA，深色白板 #123B32；保留现有介绍、尺寸提醒及设置。
- 两段循环：“精细修改”和“大面积擦除”，原始笔迹→擦除→结果停留→淡出/下一段淡入；UI 显示本地化标签、说明和轮播圆点。
- 同一场景两侧使用相同手写化学笔迹和轨迹，固定直径32与演示预计算的笔速直径作对照。手写墨迹由代码编排平滑圆头曲线，包含苯环、交替双键及正确连接的化学式，不调用图像生成服务。
- 粗细为教学演示编排，不称为硬件实录；不改变实际笔速算法、配置或主画布。

## 预计算与播放

- 每场景768×432；每段8秒、30fps，共240帧。生成脚本输出两个 PNG atlas 和 constexpr 光标/直径/播放帧表，生成过程可复现。
- 每张 PNG 三列依次为透明彩色墨迹、固定橡皮时间遮罩、笔速橡皮时间遮罩。遮罩 R/G 为首次/完成擦除时刻，B 为最终覆盖率。离线擦除使用软件一致的圆形变半径胶囊与覆盖语义。
- 产品只解码静态资源一次，运行时不执行笔速控制器，不构造笔画、不逐像素查找整条擦除路径。小型播放 shader 采样墨迹与时间遮罩，按主题合成纯色背景及软件同款圆盘/双条握持光标。
- 只生成一张有界双画布不透明 SRV，按实际展示宽度分档且单侧不超过768像素。ImGui 使用普通 Image 显示两个 UV 区域；不新增用户 callback。
- 按预计算播放帧/主题/尺寸决定是否重画，真实时间最高30次/秒。静止结果重复使用纹理，全局动画速度只缩放播放时间。

## 生命周期与失败边界

- 借用 Setting 共享 D3D11 device/context，在现有渲染线程执行；不新增设备、渲染线程、HWND 或 swapchain。保存恢复使用过的 GPU 状态。
- 仅演示可见时推进；离页/隐藏/滚出可见区暂停，无休眠追赶。禁用动画显示静态结果，不持续重画。
- FrameSubmissionKey 增加演示 revision，纹理内容变化可实际提交，相同帧仍保留现有省提交路径。
- 资源随既有设备 epoch/session reset 释放重建。演示资源为可选，失败不阻止设置操作；负缓存避免反复分配失败或编译失败。
- 不触及两张预有改动的主墨迹 CSO，不扩展 InkRenderer 或实时 Controller。

## 验证

- 离线遮罩验证精细目标清除、相邻笔画保留、大块清除及固定橡皮残留；检查生成 PNG。
- 真实 WARP 无窗口离屏读回，验证背景、擦除、光标、循环、主题、资源重建与缓存；导出 PNG 作视觉审阅。
- 三语言/浅深/窄宽/DPI 的 ImGui 页面与现有控件回归。检查关闭动画、暂停、重复帧及性能上限；报告实际测量，不推断硬件帧率。
- 复用 InkeysRepo.sln Debug|ARM64、ARM64 MSBuild 和 PATH 处理。独立 Trellis check、i18n、编码/diff/保护文件核对。
- 不启动 GUI，不 commit/push，父 Trellis 任务保持 in_progress。
