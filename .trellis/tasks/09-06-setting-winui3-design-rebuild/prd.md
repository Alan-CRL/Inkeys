# Setting WinUI 3 桌面视觉重建与设计审查

## Goal

重建设置界面的布局与页面组织，使其具备用户参考图中的 WinUI 3 桌面应用质感：间距稳定、文字可读、图标与控件居中、操作靠右、主页美观而有实际入口。继续使用内嵌 HarmonyOS Sans 与 ImFluent，保持原有功能、配置和共享 D3D 渲染基础。

设计稿 v1 已获用户大体认可；用户随后明确批准开始写代码。当前批准实现的首批范围是左侧导航、主页和常规页，字体与控件校准随这一批推进。其余页面保持现有实现，后续再逐批迁移。

## Background

- 关联既有任务 `08-13-setting-fluent2-responsive-ui`。原任务混合了窗口样式、DWM 材质和生命周期改造，本轮新建独立后续任务保留其历史。
- 初始 HEAD 为 `b67c4f9c`，工作区干净；迁移主要提交为 `791058df`、`82928330`。
- `Setting.cpp` 4444 行，页面、状态与业务动作仍在大型会话/switch 中。`Setting.Widgets.cpp` 的右侧控件列只定位列左端，缺少按实际 action 尺寸靠右的合同。
- 内嵌 SC/TC Regular/Bold 的 ascent/descent 总高度为 1.213 em；默认 STB pixel-height 语义与设计字号存在差异。图标使用正文合并与独立偏移。证据与边界见 `research/findings.md`。

## Requirements

- R1 视觉目标：以 Windows 设置与 WinUI 3 桌面应用为参照，统一浅色页面底、卡片、文字、边框和强调色层级；不以控件库 demo 默认值代替整体设计。
- R2 导航：展开与收起使用稳定图标轴和对称内边距；汉堡始终表示导航展开/收起；自动模式与用户偏好分别管理；窄窗展开覆盖内容；主菜单可滚动、底部动作固定且同轴。新排序是 v1 审查提案，所有原入口保留。
- R3 内容布局：页头、分组、卡片共用内容边界；按可用宽度排版；标签左对齐，按钮/开关/选择器/滑块按实际 action 右对齐；长文本和按钮组可增高/换行，不能重叠或靠缩小字号挤入。
- R4 字体：保留 HarmonyOS Sans 简繁体与实际可用字重；以 Windows 语义字号/行高为基准校准字面和基线，图标独立度量；在控件、卡片、导航间保持一致，不依赖每页补丁。
- R5 主页：重组为静态产品引导、已有功能入口、常用设置、作者/反馈区域，保留现有教程和外链；现代而克制，不添加虚构统计、账户或搜索功能。
- R6 内容完整：保留现有 14 个顶层实际页面 case 与 4 个插件详情页面的功能、信息、状态、条件禁用和提示；快捷键页目前仅说明，不扩展完整编辑器。
- R7 配置兼容：原有 setlist/Inkeys::config 字段、范围、默认、保存时机、异步 FIFO、PPT 同步、确认/重启提示与实时反馈行为保持。示例稿的开关状态不是产品默认值。
- R8 实现结构：允许为设置页建立新的 Shell/RowLayout/Typography/Pages/Actions 边界，逐页搬入现有内容；保留共享 D3D11、RenderPipeline、resident session、Show/Hide、device epoch 与窗口公开接口。库缺口仅做可追踪的小范围适配。
- R9 未来扩展：稳定 ID、纯布局数据与独立交互状态为未来动画等预留边界，不在本轮实现那些功能。
- R10 设计阶段交付：Trellis 规划三件套、官方/代码证据、真实内嵌字体的可审查页面稿，覆盖宽窗、默认窗、导航收起和最小窗；明确浏览器稿与原生已实现截图的区别。

## Out Of Scope

- 当前 HWND/标题栏/边框/窗口样式与 DWM Mica 失效问题。
- 深色背景、主题跟随/高对比扩展。
- 新动画实现、触摸支持、动态脏区或帧调度优化。
- 迁移到 WinUI XAML、更换 D3D 后端、另建 renderer/device、GIF/视频运行库。
- 新增搜索、账户、推荐/统计服务、完整快捷键编辑器或更改产品配置默认值。
- 自动 commit/push 或原生窗口/桌面操作。

## Review Decision

v1 的 248 DIP 导航、900 DIP 自动阈值、72 DIP 设置行最小高、浅灰/白色层级、主页三入口和侧栏排序作为首批实现基线。官方规范与项目选值在 design.md 中区分。用户明确批准开始写代码；首批范围与接受条件见 research/approved-first-batch.md。
