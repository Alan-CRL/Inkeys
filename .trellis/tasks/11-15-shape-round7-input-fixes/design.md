# 修改边界

行为差距集中于第六轮输入接入：原生触摸路由、已呈现控制点身份、逐样本预测/编辑与队列、UI 停靠变换。
预计必要文件：Bar.ShapeEditor.cpp（命中、翻转可见、控件停靠及离屏回归），SelectionOverlay.cpp（输入分类/采样），Bar 的已呈现快照和触摸探针（几何面板命中），Draw3 形状动作消费（仅在证据证明积压源时）。沿用现有测试，不改存储格式、构造参数、3D 投影或构建系统。

先从真实入口定位根因，再分别验证生产路径。连续输入可合并绝对位置但不能丢终态、跨接触合并或丢失旋转的绕圈语义。胶囊位置消除镜像对 UI 坐标轴的影响，同时保留正常旋转和平移。圆隐藏按钮由同一布局/呈现/命中快照控制。
