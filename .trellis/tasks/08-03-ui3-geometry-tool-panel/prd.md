# UI3 几何工具面板

## Goal

恢复 UI3 主栏几何按钮，并提供与绘制属性一致的动画面板，用于选择 Draw2 直线、矩形和三档硬笔粗细。

## Requirements

- 几何按钮在初始选择模式隐藏；进入绘制后显示，切回选择再次隐藏。
- 几何、绘制和橡皮保持顶级互斥；首次进入几何模式时只选中工具，不展开面板，再次点击才切换面板展开状态。
- 模式切换失败时保持原模式，并且不得错误展开几何面板。
- 面板展开尺寸固定为 `335x100`，复用绘制属性的表面、边框、圆角、换边和动画曲线。
- 面板收起态以几何按钮中心为锚点，宽度为 `60`，高度等比缩放；子控件、文字、线宽和光影同步缩放。
- 上排预留六个 `50x50` 槽位，本期只实现直线和矩形；下排实现三个 `30x30` 粗细按钮并右对齐。
- 分割线支持强度 `0.30` 的第三光源，不响应第一光源。
- 子按钮支持悬停、驻留淡出、按下缩小、拖出取消、抬起后悬停抑制和选中高亮。
- 面板右上角提供 `30x30` 关闭按钮，复用粗细按钮的悬停、按压缩小和拖出取消交互。
- 几何主栏按钮在选中时切换为当前直线/矩形图标和文字，离开几何模式后恢复“几何”；图标与文字使用内容缩放、淡出、中点替换和回弹显现动画。
- 绘制主栏按钮在选中时将文字切换为当前“硬笔”或“荧光笔”，离开绘制模式后恢复“绘制”。
- 擦除主栏按钮选中时将文字切换为“面积擦”，离开擦除模式后恢复“擦除”；所有主栏动态图标和文字共用同一内容跳变动画。
- 直线和矩形主栏图标使用独立 SVG；矩形 SVG 分离边框色和填充色占位，为后续填充开关预留语义。
- 主栏默认顺序中 Geometry 位于 Eraser 之前，并迁移旧版默认顺序；其他合法自定义顺序保持不变。
- 几何面板的直线和矩形复用主栏 SVG，选中几何时主栏形状图标适度放大。
- 形状选择写入现有 `ShapeModeSelectEnum`；粗细继续写入 `stateMode.Pen.Brush1.width`，三档为 `{1,3,6} DIP x dpiZoom`。
- 不修改 Draw2 绘制、历史、PPT 墨迹或 Draw3 接口；除既有主栏默认顺序及旧默认迁移外，不新增配置字段或持久化结构，不增加对外 API。

## Acceptance Criteria

- [ ] 选择模式隐藏几何，进入绘制后显示，切回选择再次隐藏。
- [ ] 点击几何成功进入 `IdtShape` 但不展开；再次点击展开，再次点击或点击右上角关闭按钮收起并保持几何模式。
- [ ] 绘制、几何、橡皮互斥高亮，离开几何、折叠主栏或切回选择时关闭几何面板。
- [ ] 面板布局、缩放、换边和动画符合固定尺寸与 5px 间距要求。
- [ ] 直线、矩形及三档粗细可选且各组记忆选中项，Draw2 使用对应形状和宽度。
- [ ] 子按钮交互、Accent 选中态、第三光源、脏区和设备资源重建无遗漏。
- [ ] 主栏绘制/几何/擦除文字和几何图标随当前工具切换，动画中点替换内容且快速切换无闪烁。
- [ ] Geometry 与 Eraser 默认位置完成交换，几何面板和主栏使用相同形状 SVG。
- [ ] `InkeysRepo.sln` 的 `Debug | ARM64` 使用 ARM64 Host MSBuild 完整构建通过。
- [ ] `git diff --check` 通过，静态检查枚举、初始化、动画、渲染、命中和脏区覆盖。

## Notes

- 修改范围仅限 UI3 Bar；传统 `IdtFloating` 保持不变。
- 面板文字沿用 UI3 的中文硬编码风格，空槽不显示禁用占位。
