# UI3 Bar 底栏吸附视觉反馈与残影修复

## Goal

修复自由主栏进入底栏捕获区时因窗口尺寸或源映射跳变产生的重复上半栏残影，并为吸附过程提供稳定、可感知且不会点击穿透的视觉反馈；在此基础上增加可与竖向吸附叠加的底栏居中模式。

## Background

- 本任务是 `08-14-ui3-bar-bottom-dock-elastic` 的独立后续任务，依赖该任务已有的底栏状态机、捕获阈值和弹性形变。
- 当前分层窗口在 viewport source、窗口尺寸或渲染目标容量改变时仍携带局部 dirty 矩形提交，旧窗口像素可能未被替换。
- 底栏拖动需要一个位于主栏内容上方、可阻止点击穿透的本地化模式指示器。

## Requirements

### R1. 呈现残影修复

- 呈现事务记录上一次成功提交的 source、窗口尺寸、target capacity 和 device generation。
- 当上述任一值改变时，完整清除本帧候选窗口范围，并用空 `prcDirty` 执行整窗 `UpdateLayeredWindowIndirect`。
- 仅映射稳定的帧允许使用局部 dirty；提交失败不得推进成功快照。

### R2. 底栏交互指示器

- 指示器位于全部主栏和面板内容上方、调试覆盖层下方，允许遮挡主栏。
- 指示器以正常形态下主按钮、主栏及可见描边的联合外接矩形为基准水平居中；竖直中心始终位于主栏实际可见上边框并跟随底栏形变，高 30 DIP、圆角 6 DIP。
- 文本显示本地化“底栏模式”或“底栏模式 · 居中”，复用主栏标准 2x2 按钮的 `HarmonyOS Sans SC`、13 DIP、粗体字重和未选中内容色 `TextPrimary`，水平和垂直居中；深色主栏下文字为白色。
- 宽度按当前实际文案的 DWrite 宽高测量结果解析；文案变化复用主栏按钮的“淡出缩小—中点换字—回弹淡入”，变宽在换字前完成、变窄在换字后完成，任何阶段不得裁字。
- 背景与主栏使用同一 `Surface` 色和 80% 峰值不透明度，边框使用同一 `SurfaceFrame` 色、1 DIP 宽度和 18% 峰值不透明度；深色主题下表现为半透明黑底与灰色边框。
- 边框复用主栏 PointLight 路径，同时接受第一光源和第三鼠标光；基础边框透明度、光源透明度、光色与第三光源比例均须与主栏一致，不得使用按钮专用的更亮配置。光源变化、中心缩放和主栏形变都必须纳入 dirty 范围。
- 仅当本次拖动从最后成功呈现的非底栏状态开始、主栏已展开且随后进入底栏捕获时淡入；从已固定底栏开始的拖动永不显示。主栏仅剩主按钮、抬手或脱离底栏后淡出。动画时长与绘制属性笔类型菜单中问号提示浮窗一致，显示使用 `EaseOutBack`、隐藏使用反向中心缩小曲线，透明度与中心等比缩放同步；动画关闭时立即切换。
- dirty 与 viewport 预测必须覆盖显示/隐藏全程的旧新边界、Back 顶端超调、缩放描边、固定 Gaussian 外扩和抗锯齿余量，吸附首帧不得让指示器最上缘落在 dirty 外。
- 指示器只要仍有可见像素，包括淡出阶段，就必须阻止其区域内的鼠标、触摸、双击和滚轮消息穿透，并清除下层控件的 hover/pressed 候选。
- 命中边界与可见状态只能来自最后一次成功呈现的快照，不能领先于屏幕上实际显示的像素。

### R3. 底栏居中模式

- 新增与竖向 `Floating / BottomDocked` 正交的 `Free / Centered` 水平状态；阶段独立复用 `Stable / Capturing / Dragging / Detaching / Recovering`。
- 居中对象只包含主按钮、主栏及可见描边的联合外框，不包含绘制属性、更多面板等扩展内容；目标为当前显示器 `monitorBounds` 的水平中心。
- 仅在竖向已吸附、主栏展开且联合外框中心进入 20 DIP 捕获带时允许水平捕获；边界值可捕获，严格超过阈值立即脱离。
- 水平捕获使用与竖向相同的弹簧和 24 DIP 视觉限值，围绕联合外框中心对称形变；横纵形变可叠加，捕获、脱离和恢复均不得发生像素跳变。
- 折叠时退出居中但不移动主按钮；底栏重新展开时，若最终展开外框仍在捕获带内，则无提示地动画恢复居中。启动时现有中置展开底栏直接属于稳定居中模式。
- 居中状态下打开或关闭扩展面板不得改变基础主栏中心；扩展面板只按其按钮锚点刚性跟随，不参与水平拉伸。

### R4. 国际化

- 新增 `UI.Bar.BottomDock.Mode` 与 `UI.Bar.BottomDock.Centered`。
- 提供简体中文、繁体中文和英文翻译，并通过 `Scripts/i18n.ps1 sync` 更新其余语言、快照和生成键。
- 不手工修改生成的 i18n 头文件。

## Acceptance Criteria

- [ ] 自由主栏从上下方进入捕获区、快速跨越阈值及不同 DPI 下，不再出现重复上半栏或未擦除残影。
- [x] source、窗口尺寸、target capacity 或 device generation 改变均选择整窗替换；稳定映射帧仍可选择局部 dirty；失败重试保持上一成功 tuple。
- [ ] 指示器满足 30 DIP 高度、四边等距动态宽度、主栏上边框中心锚定、主栏样式和第一/第三光源要求。
- [ ] 指示器只在从非底栏开始的展开主栏拖动进入底栏时出现；底栏起始拖动、启动和自动居中均不出现。
- [ ] 普通/居中文字按主栏按钮内容时间线切换，指示器动态宽度全程不裁字。
- [ ] 指示器可见或淡出时，实际缩放覆盖区域不会触发主按钮、普通按钮、面板、悬停、双击或滚轮交互。
- [ ] 展开的基础主栏可从浮动或普通底栏进入居中模式，严格超过 20 DIP 后连续脱离；折叠禁用居中，重新展开可按阈值无提示恢复。
- [ ] 横向果冻、竖向果冻和两轴叠加均保持成功呈现快照、脏区、光源及扩展面板锚点连续。
- [x] 底栏反馈不创建额外 D2D target，Bar 全流程仍只有一次最终 GDI/ULW 提交。
- [x] `Scripts/i18n.ps1 check`、全部 Headless 测试、`git diff --check` 和 `InkeysRepo.sln` 的 `Debug | ARM64` 构建通过。

## Out Of Scope

- 不增加用户配置项。
- 不改变竖向 20 DIP 吸附阈值、竖向果冻算法或主栏换向规则；水平居中复用同一阈值和弹簧常量。
- 不拆分为父子任务，也不重开或改写原底栏弹性任务。
- 不在自动验证阶段启动可见 GUI。
