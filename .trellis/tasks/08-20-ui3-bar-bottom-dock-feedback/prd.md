# UI3 Bar 底栏吸附视觉反馈与残影修复

## Goal

修复自由主栏进入底栏捕获区时因窗口尺寸或源映射跳变产生的重复上半栏残影，并为吸附过程提供稳定、可感知且不会点击穿透的视觉反馈。

## Background

- 本任务是 `08-14-ui3-bar-bottom-dock-elastic` 的独立后续任务，依赖该任务已有的底栏状态机、捕获阈值和弹性形变。
- 当前分层窗口在 viewport source、窗口尺寸或渲染目标容量改变时仍携带局部 dirty 矩形提交，旧窗口像素可能未被替换。
- 现有捕获提示直接绘制在主目标中，随后绘制主栏时可能被清空或覆盖，且固定几何不能表达完整主栏范围。

## Requirements

### R1. 呈现残影修复

- 呈现事务记录上一次成功提交的 source、窗口尺寸、target capacity 和 device generation。
- 当上述任一值改变时，完整清除本帧候选窗口范围，并用空 `prcDirty` 执行整窗 `UpdateLayeredWindowIndirect`。
- 仅映射稳定的帧允许使用局部 dirty；提交失败不得推进成功快照。

### R2. 底栏吸附背景板

- 背景板覆盖正常形态下主按钮、主栏及可见描边的联合外接矩形。
- 外接矩形左、右、上各外扩 10 DIP，下边不外扩，并贴住任务栏上沿。
- 样式为 10 DIP 圆角、无描边、Windows 蓝 `#0078D4` 填充，峰值不透明度 18%。
- 背景板在真实 `Floating -> Capturing` 时淡入，并保持到本次拖动结束且吸附回弹稳定；中途脱离底栏则淡出。
- 沿用 160 ms 淡入和 200 ms 淡出；全局动画关闭时立即切换。
- 背景板在同一 HWND、同一渲染线程内的 premultiplied D2D 离屏层绘制，不增加第二条 GDI 或 ULW 提交链。

### R3. 底栏交互指示器

- 指示器位于全部主栏和面板内容上方、调试覆盖层下方，允许遮挡主栏。
- 指示器水平居中，上边距背景板顶部 5 DIP，高 20 DIP，圆角 6 DIP，使用不透明 `#0078D4` 填充。
- 文本仅显示本地化“底栏模式”，使用现有字体集合、12 DIP 白色文字并水平和垂直居中。
- 宽度按当前语言测量，左右各留 12 DIP；最小宽度应容纳当前语言的“底栏模式 · 居中”。
- 拖动已吸附主栏，或从悬浮状态进入 `Capturing` 后淡入；抬手或脱离底栏后淡出。沿用 160 ms/200 ms 动画，动画关闭时立即切换。
- 指示器只要仍有可见像素，包括淡出阶段，就必须阻止其区域内的鼠标、触摸、双击和滚轮消息穿透，并清除下层控件的 hover/pressed 候选。
- 命中边界与可见状态只能来自最后一次成功呈现的快照，不能领先于屏幕上实际显示的像素。

### R4. 国际化

- 新增 `UI.Bar.BottomDock.Mode` 与 `UI.Bar.BottomDock.Centered`。
- 提供简体中文、繁体中文和英文翻译，并通过 `Scripts/i18n.ps1 sync` 更新其余语言、快照和生成键。
- 不手工修改生成的 i18n 头文件。

## Acceptance Criteria

- [ ] 自由主栏从上下方进入捕获区、快速跨越阈值及不同 DPI 下，不再出现重复上半栏或未擦除残影。
- [x] source、窗口尺寸、target capacity 或 device generation 改变均选择整窗替换；稳定映射帧仍可选择局部 dirty；失败重试保持上一成功 tuple。
- [x] 背景板三边为 10 DIP 间隙、底边零间隙并贴任务栏，样式和动画符合 R2，且不会被主栏清空。
- [x] 指示器满足 5 DIP 顶距、20 DIP 高度、自适应宽度、显示时机和动画要求。
- [x] 指示器可见或淡出时，覆盖区域不会触发主按钮、普通按钮、面板、悬停、双击或滚轮交互。
- [x] D2D 装饰层随 target/device 丢失正确释放和重建，全流程只有一次最终 GDI/ULW 提交。
- [x] `Scripts/i18n.ps1 check`、全部 Headless 测试、`git diff --check` 和 `InkeysRepo.sln` 的 `Debug | ARM64` 构建通过。

## Out Of Scope

- 不增加用户配置项。
- 不改变 20 DIP 吸附阈值、果冻形变、底栏横向拖动或主栏换向规则。
- 不拆分为父子任务，也不重开或改写原底栏弹性任务。
- 不在自动验证阶段启动可见 GUI。
