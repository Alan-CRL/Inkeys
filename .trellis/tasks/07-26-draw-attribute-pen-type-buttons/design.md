# 技术设计

## 边界

- 仅修改 UI3 Bar 的绘制属性控件：`Bar.Main.cpp/.cppm`、`Bar.State.cppm`，以及必要的 `Inkeys.rc` 与 `Inkeys/src/UI/*.svg`。
- 不修改 `PenModeSelectEnum`、绘制引擎或配置；激光笔和刷子只建立禁用 UI 对象。
- 不接入 i18n。中文仍为实际显示内容，布局常量按未来英文参考标签留出宽度。

## 布局

- 绘制属性展开尺寸由 `335×120` 调整为约 `335×150`，紧凑态继续根据展开宽高比统一缩放。
- 右侧笔型列使用四个独立圆角按钮，不再依赖父级滑槽：
  - 从上到下：刷子、激光笔、荧光笔、画笔。
  - 每项采用主栏 `twoOne` 的视觉结构：约 30px 高，左侧 18px SVG，右侧 12px 文字。
  - 按钮宽度使用右侧可用列的最大值，文字区按 `Highlighter` 或清晰缩写的宽度预留。
- 左侧颜色区和粗细区仅做随面板增高所需的纵向分离，保持颜色顺序、粗细逻辑和横向尺寸不变。
- 笔型列顺序不随绘制属性位于主栏上方/下方而翻转；“从下到上画笔、荧光笔、激光笔、刷子”始终成立。

## 控件模型

- 在 Shape/SVG/Word 枚举中加入 `Laser` 与 `Brush` 对象，并保持各组连续范围，现有按枚举区间推进动画、脏区和渲染的循环可覆盖四项。
- 删除 `DrawSelect`、`DrawSelectGroove` 及 `drawAttributePenSelectProgress`；选中态直接由可用按钮自身的填充透明度与图标/文字青色表达。
- 为四按钮使用统一的布局/颜色计算辅助逻辑，减少四份状态分支：
  - 可用且选中：青色内容和青色按钮填充；
  - 可用且未选中：透明背景、主文字色；
  - 禁用：灰色图标和文字、透明背景，禁止悬停及按压状态。

## 交互

- 画笔、荧光笔继续使用现有点击逻辑与状态字段。
- 按压缩放复用主栏 `BarButtonPressScale`、`buttonPressCurve` 和 `buttonReleaseCurve`，缩放中心为各按钮中心，并同时影响背景、图标和文字。
- 悬停沿用现有独立按钮的 `StartHover` / `StopHover` 流程；禁用项不加入命中测试和悬停目标。
- 激光笔和刷子不创建点击状态或回调，鼠标消息直接穿过其禁用分支，不改变当前笔型。

## 动画与渲染

- 四按钮的 x/y/w/h、SVG 尺寸、文字尺寸和透明度都进入绘制属性统一动画批次。
- 收起态尺寸通过新的展开宽高比计算，不单独写固定缩放倍率；上下换边中点仍使用相同紧凑宽高。
- 渲染与脏区区间扩展到新增枚举末项，确保动画中的真实新旧范围均被清理。
- SVG 颜色在属性栏隐藏时直接同步，避免首次展开从黑色过渡。

## SVG 与资源

- 复用现有 `barHighlighter1.svg`。
- 新增原创 `barBrush2.svg`，使用与现有 SVG 相同的透明占位色 `rgba(10,0,7,0)`，由运行时主题设色。
- 激光笔优先复用仓库可表达指示/激光含义的现有 SVG；若没有合适资源，则新增同风格的原创 `barLaser.svg`。
- 新 SVG 作为 `UI` 资源登记到 `Inkeys.rc`，不引入第三方许可。

## 风险与回滚

- 主要风险是连续枚举范围遗漏、继承锚点改变后命中区错位，以及按压缩放未纳入脏区。
- 静态核对所有枚举区间、初始化、布局、动画、渲染、脏区、悬停和输入分支。
- 回滚只需恢复 UI3 Bar 文件及新增 SVG/资源项，不涉及数据迁移。
