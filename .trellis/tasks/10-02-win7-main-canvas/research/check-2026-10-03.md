## Source review

- RTS 的 Down/Up arrival 位于原参数验证之前，读取的是该回调有效期内的 `StylusInfo`；decoder/cache/binding 的读取都位于原 writer 或 packet reader guard 内。Up 删除 active binding 后保留的 decoder 指向独立 cache slot，诊断没有悬空 binding 访问；坏包取消路径在 erase 前完成 decoder resolve。
- Packets 限频用独立原子 CAS，只尝试一次，不增加 gate 等待；先检查 tick 单调性，避免并发旧 tick 的无符号下溢。关闭 Cursor 诊断时不读取 throttle clock、不格式化、不入队。
- 复用既有 1024 条、每条 320 字节的 Cursor 队列。格式截断有显式标记，队列溢出报告 dropped；队列锁只保护内存入队/出队，控制台输出在绘制线程且位于锁外。此次没有引入 RTS 回调控制台或文件 I/O。
- ULW presenter 状态由唯一 Draw3 绘制线程使用，不需要给 sampler 的普通字段增加原子。首次及一秒门只控制统计，不改变 Map、逐行复制、底层合成、Unmap、dirty 参数或 API 提交。未采样使用 `InspectPixels=false` 实例，没有逐像素诊断统计。
- source BGRA 从 mapped staging 读取；finalDib 从底层合成后的 DIB 读取。alpha=1 命中底层、纯黑墨 RGB=0、原始预乘异常与最终底层修正可分别识别。最高源 alpha 样本、全画布坐标半开 bounds、RowPitch 与 dirty 限制一致。
- ULW 的 GetLastError 在格式化/日志前锁存；不会把日志产生的错误冒充 API 错误。统计输出明确不能替代桌面实际可见证据。
- 8 个新增 benchmark 统计断言覆盖非原点 dirty、带 padding 的 RowPitch、透明、黑墨、白光标、原始非法预乘及 underlay 开关；比较源不被修改、诊断与普通路径输出一致、Unmap 回调执行、计数/最大值/bounds/样本和原观察值。用例可发现区外/padding 混入和底层 alpha 掩盖原始透明等错误，有实际验证价值。
- 本轮没有修改 HWND、DComp/ULW fallback、FLIP_SEQUENTIAL、输入 producer、shader 或文档/history 行为。源码 BOM 保留、工作文件全部 CRLF，diff 局部，没有全文件格式变更。
- 后续 console 修补识别 stdout/stderr 的 disk/pipe HANDLE，双路已重定向时跳过 AllocConsole 与 CONOUT$ 重绑。单路重定向时保存该 Win32 HANDLE，在分配控制台后恢复，只对未重定向的 C stream 执行原 freopen；原双路控制台路径保留。已静态检查该增量及 IdtMain BOM/CRLF，未发现具体缺陷；真正 GUI 子系统的继承输出仍需非交互 harness 或用户采集验证，不能只凭代码条件宣称所有启动器已验证。
