# 脏区调试帧率显示改造

## Goal

把脏区调试里的「显示帧率」改成一眼就能看懂的刷新指示：
- 默认关闭。
- 显示每一帧的实时帧率。
- 文字以红/绿高亮显示在主栏正中。
- 文字下方有 10 个轮流缺一个的指示点，用来快速判断界面是否还在刷新。
- 和红框/绿框一样，即将休眠的最后一帧变绿。

## 背景与现状（读码）

- 配置项 `Experimental.Inkeys3.UI3.Debug.ShowFrameRate` 缺省值为 `true`（`Inkeys/Inkeys/Other/Other.Config.cppm:600`）；主栏全局 `BarUiDebugFrameRateEnabled` 初值也为 `true`（`Bar.Main.cppm:72`）。生效条件是「脏区调试开启且显示帧率开启」（`Bar.RenderLoop.cpp:8009`）。设置页开关在 `Setting.cpp:4759`，读取配置在 `Setting.cpp:2370`。规范 `configuration-i18n-and-assets.md`「UI3 脏区调试与帧率显示配置合同」记录的默认值是 `true`。
- 帧率目前按 1 秒窗口取平均：`UI3::OneSecondFrameRate`（`UI3.FramePacing.cppm:147`，Headless `frame_pacing_tests.cpp:72` 有测试），每满 1 秒锁存一次。
  - 实际帧率 = 帧数 / 时长。
  - 无限制帧率 = 帧数 / 工作时长（排除节拍等待）。
  - 采样在帧尾 `Bar.RenderLoop.cpp:13124`，只计入成功呈现的帧（`frameRateSamplePending`）；从休眠恢复时重置（`Bar.RenderLoop.cpp:8037`）。
- 文字格式取自 i18n `UI/Bar/Diagnostics/FrameRateFormat`：`帧率: {:.2f} FPS | 无限制帧率: {:.2f} FPS`，共 22 种语言；不可用时显示 `FrameRateUnavailable`。
- 文字现在画在主按钮下方（下方空间不够时翻到上方）：12 DIP、白色 50% 透明度，按主栏所在侧左/右对齐（`Bar.RenderLoop.cpp:11404`、`12401`）。文字包络并入可见内容范围，会参与窗口尺寸计算；上一帧的文字包络 `lastPresentedDebugTextBounds` 会在下一帧擦除。
- 帧率文字不驱动空转：只随真实渲染重绘（`Bar.RenderLoop.cpp:8013`、`12400`）。
- 红框/绿框颜色由 `ResolveDebugFrameColor(debugFrameSleepLatch.IsPending())` 决定，绿色表示本帧是休眠前的最后一帧（`Bar.RenderLoop.cpp:12447`）。
- 主栏（`BarUISetShapeEnum::MainBar`）展开时位于主按钮一侧，宽度等于按钮总宽；收起时宽 80 DIP、居中在主按钮上、透明度为 0（`Bar.RenderLoop.cpp:3886`）。底栏吸附形变时，主栏底板经 `TransformBarBottomDockBodyRect` 映射。
- 翻页控件没有帧率显示。

## Requirements

- **R1 缺省值**：配置中缺失「显示帧率」时为关（schema 缺省改为 `false`，已保存的值照旧）；主栏全局初值同步改为 `false`。设置页卡片的显示规则不变：只在脏区调试开启时出现。
- **R2 实时帧率**：显示最近一帧的实时值，每帧刷新，允许快速跳变。保留两项（用户选定）：
  - 帧率 = 1 / 相邻两次成功呈现的间隔。
  - 无限制帧率 = 1 / 该帧工作耗时（排除节拍等待）。
  
  格式和多语言文案沿用现有的 `FrameRateFormat`。休眠恢复后的第一帧没有有效间隔，显示 `FrameRateUnavailable`。
- **R3 颜色**：平时文字与 10 个点都是不透明红色 `rgb(255,0,0)`；绿框帧（休眠前最后一帧）文字与 10 个点都是不透明绿色 `rgb(0,255,0)`（用户选定）。判定与红/绿框共用同一个休眠锁存。
- **R4 位置**：文字中心与主栏中心重合（水平、竖直居中），包括收起状态（收起时主栏即主按钮位置，文字和点叠在 Logo 上），展开/收起动画中跟着主栏中心平滑移动（用户选定）。文字和点画在主栏全部内容之上。文字与点宽于主栏的部分伸出主栏两侧，仍计入可见内容范围；调试模式下窗口可以因此变宽。
- **R5 指示点**：文字正下方有 10 个水平并列的圆点。按成功呈现的帧序号轮转：第 n 帧隐藏第 ((n−1) mod 10)+1 个点。呈现失败、重试的帧不推进序号。
- **R6 脏区**：开启时，每个成功呈现的帧都把本帧文字与点的包络（以及上一帧的包络）并入刷新范围；包络变大属于预期。显示本身不驱动渲染，静止后不再出帧。关闭显示帧率或脏区调试时，旧文字与点会被擦除（沿用现有的覆盖层清理）。
- **R7 规范**：更新 `configuration-i18n-and-assets.md` 中帧率显示的缺省值、位置与颜色、实时计算，删除已过时的「为采样维持的连续帧」说法；`rendering-and-ui.md` 调试覆盖层条目补充文字与指示点的规则。

## Acceptance Criteria

- [x] **AC1（R1）**：配置中删除 `ShowFrameRate` 后启动，开启脏区调试时设置页「显示帧率」为关，主栏没有帧率显示；已保存为 `true` 的配置仍然显示。
- [x] **AC2（R2）**：开启后持续交互，两项数值逐帧变化，不再每秒才跳一次。
- [x] **AC3（R3）**：平时文字与点为红色；绿框出现的那一帧，文字与点同为绿色；下次活动开始后恢复红色。
- [x] **AC4（R4）**：展开、收起以及动画过程中，文字与点都居中在主栏上。
- [x] **AC5（R5）**：连续刷新时 10 个点依次缺一个，每 10 帧轮转一圈；静止后画面不再变化。
- [x] **AC6（R6）**：关闭显示帧率或脏区调试后，没有残留的文字或圆点。
- [x] **AC7（R6）**：调试关闭时行为不变——golden 35 与基线逐字节一致，属性脏区测试 0/0/0。
- [x] **AC8**：构建 0 错误；Headless 退出码 0（含实时帧率计算的单元测试）。
- [x] **AC9**：用户实机确认显示效果。

## Out of Scope

- 翻页控件、白板等其他窗口的帧率显示。
- 节拍与渲染频率本身的调整；多语言文案内容（格式串不变）。
