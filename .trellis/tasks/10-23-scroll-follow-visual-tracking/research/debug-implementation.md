# Debug / recording implementation review

2026-10-23, validation_research implement role. Main owns compilation, test runs and GUI; this agent performed source review and git diff checks only.

## Implemented

- Business Debug Channel owns optional recorder. Off by default; explicit Arm Next Session waits for a strictly newer business session and its actual Initialize input. Producer calls RecordInput independently from the three-slot preview lease and UI consumption, including AwaitTracking with no fabricated MotionResult.
- Full-resolution tight Gray8 is copied from each original input. BGRA uses the same OpenCV COLOR_BGRA2GRAY conversion before resize as production; original layout, identity, timestamp, operation, low-information flag, quality, geometry and returned result are retained. Borrowed capture/preview storage never escapes.
- First of 64 inputs, 256 MiB grayscale pixels, or 10 seconds seals the prefix. Time checks cover original timestamp span and wall clock; UI polling seals even when no new input arrives. A gap, identity change, invalid layout, allocation failure or producer contention fails the recording explicitly. completePrefix denotes the contiguous Initialize-rooted bounded prefix, never an entire session.
- UI adds Arm Next Session / Stop recording, current memory/count/stop reason, immutable export sharing, and blocks re-arm while an export owns the previous buffer. Explicit existing Export folder picker writes the existing raw.png/preview.png/snapshot.json and optional input-N.pgm + recording.json; no recorder disk writes occur before Export. Recording-only exports also work. Lossless P5 PGM matches the historical standalone replay dependencies; no new codec/build dependency.
- Target id/Discovering-Locked-Recovering phase, support, provisional/certified points, evaluated local patches, their peaks/selected score/independence, ambiguity margin and reference/recovery age are displayed and serialized. Blocks replaces the legacy whole-frame grid overlay; old raw cell fields remain export-compatible without advertising obsolete global coverage gates.
- Patch arrow uses selected current/reference bounds rather than assuming peaks[0] was chosen. All patch/point geometry remains processing pixels and divides actual scaleX/scaleY once; target/result total stays original pixels.
- Capture Update/Analyze/completed Callback and backend Redraw/PrintWindow/GdiFlush/pixelWork preserve observed validity; Frame callback timing is explicitly labeled with its previous completed sequence. LowInformation delivery counter is distinct from rejection.
- LiveStatus OwnerTiming contains sequence and readCompletedAt/publishedAt/appliedAt/presentedAt. Applied and presented identities remain separate; JSON and UI only derive intervals from one timing record. Successful Present return is explicitly not a measurement of actual physical screen visibility/latency.

## Interface and manifest

- Channel: RecordInput(metadata, frame, MotionResult*), ArmRecording(), FinishRecording(), ReadRecording(), TakeRecording(). Main integrates every Initialize/Process/AwaitTracking and drains before final stop sealing. terminal UpdateStatus also seals recording.
- UI Probe appends button index 10 and armRecordingButton, recordingState (Off=0, Armed=1, Recording=2, Complete=3, Failed=4), recordedFrames; prior indices 0..9 unchanged.
- recording.json schema Inkeys.ScrollFollowRecording.v1; root state, stopReason, completePrefix, businessSession, frameCount, pixelBytes, durationSeconds, limits; frames[] contains file=input-N.pgm (1-based), seq, operation, timestampSeconds, width/height/strideBytes, format=Gray8, originalFormat/StrideBytes/SizeBytes, captureValid/inputLowInformation/copyMs, motion (null for AwaitTracking), identity, geometry, quality, statistics, roiInCapture, captureWidth/Height/StrideBytes, sourcePixelsPerPixelX/Y, sampledAtUs/sampleIntervalUs. Manifest is created after all input files.
