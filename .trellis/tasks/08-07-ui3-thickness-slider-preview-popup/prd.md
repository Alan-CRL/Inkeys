# UI3 粗细滑块预览浮窗

## Goal

在 UI3 绘制属性的连续粗细滑块进入 Thumb 状态时，显示一个跟随 Thumb 的自适应墨迹粗细预览浮窗，使用户在拖动、轨道点击和快捷值变化时同时看到真实设备像素直径与准确数值，并保持属性栏现有动画、光影和触摸手势行为。

## Requirements

### 范围与生命周期

- 仅修改 UI3 Bar；传统 `IdtFloating.cpp` 只作为“细圆外置数字、足够大后移入圆内”的设计参考，不修改其代码。
- 浮窗可见性直接跟随现有 Slider Thumb：轨道完全拉直并开始显示 Thumb 时展开，Thumb 退场或 Hold-lock 隐藏 Thumb 时收起。
- 直接触摸 Preview 拖动不激活 Slider Thumb，因此不得显示浮窗；触摸轻点固定并完成 Preview -> Slider 后才显示。
- 折叠属性栏、切换不支持的笔型、打开颜色选择器/More、捕获丢失和退出继续依赖现有 Slider 清理路径，不增加独立关闭状态。

### 浮窗视觉与布局

- 浮窗绘制于绘制属性全部普通内容之上、Slider Thumb 之下，不受粗细 Preview 裁剪区限制；无关闭按钮、命中区或独立 HWND。
- 使用主题 Surface、SurfaceFrame、4 DIP 圆角和 0.95 表面透明度；仅接受第三鼠标光，禁用第一光源。
- 使用 0.40 秒可中断回弹，从 Thumb 中心沿动画几何推导的 `previewSide` 向属性面板外侧展开；稳态与面板外缘保持 5 DIP 间距，收起走对应反向动画。
- 默认浮窗中心 X 与 Thumb 中心严格对齐并一对一跟随。按当前动画中的笔类型按钮联合边界检查整个展开扫掠区域；发生覆盖时只施加最小水平偏移，冲突解除后平滑恢复居中。
- 不使用显示器、工作区或 Bar 窗口边缘夹取浮窗位置。

### 墨迹圆与数值

- 白色圆形的最终物理直径等于当前候选或动画中的真实墨迹设备像素粗细，不受属性栏 Preview 高度限制，也不额外设置最大尺寸。
- 拖动期间复用现有候选粗细直接反馈；非拖动变化复用 `drawAttributePenThickness` 的动画值。
- 使用 DWrite 实测当前整数文本尺寸。圆形无法容纳文字时，数字显示在圆形右侧并使用主题文字色；圆形足够大后，数字以可逆动画移入圆心并过渡为白底可读的黑色。
- 浮窗尺寸根据圆形、数字、8 DIP 内边距和 5 DIP 外置文字间距连续调整；过渡中不得裁切圆形或文字。

### Hold 提示控制行交换

- 将“保持并固定粗细”文字和进度环移到三个快捷粗细按钮及小三角所在控制行，整体靠粗细区域右边缘对齐；左侧“粗细 + 数值”继续显示。
- Hold 提示出现时先让三个快捷按钮和小三角退场，再显示右对齐的提示文字与圆环；消失时先隐藏提示，再恢复四个控制。
- Hold-lock 后保留现有圆环淡出和文字变亮行为，直到提示会话结束后才恢复控制行。

### 渲染约束

- 浮窗表面、白色圆形、数值与后移的 Thumb 绘制必须纳入 predicted/current 旧新脏区并集，避免移动、缩放和收起残影。
- 复用现有 Shape、Word、DWrite 测量、画刷和 PointLight 遮罩缓存；稳定帧不得新增 D2D 资源创建，不增加第二组主绘制提交。
- 保持目标源码编码、CRLF、局部风格和关键路径中文注释。

## Acceptance Criteria

- [ ] 鼠标 hover、点击固定、小三角固定、轨道点击和 Thumb 拖动时，浮窗与 Thumb 同步出现、移动和消失。
- [ ] 直接触摸 Preview 拖动全程不显示浮窗；触摸轻点固定后正常显示。
- [ ] 硬笔、荧光笔最小/最大值、快捷预设和 1/2/3 位数值均显示准确，圆形屏幕直径与真实墨迹设备像素一致。
- [ ] 数字在外置与圆内状态间平滑、可打断地迁移，表面尺寸连续变化且不裁切内容。
- [ ] 属性面板向上/向下展开时浮窗始终朝外侧出现；Thumb 全行程保持居中跟随，只有避免笔类型按钮展开扫掠区时才水平偏移。
- [ ] 显示器边缘不触发位置夹取；深浅主题下圆形恒白、圆内数字可读，边框只有第三光源响应。
- [ ] Hold 提示与三个快捷按钮/小三角严格分阶段交换，不重叠、不闪烁；左侧粗细读数保持可见。
- [ ] 颜色选择器、More、Tooltip、模式切换、折叠、捕获丢失和设备资源重建无残留状态或脏区残影。
- [ ] `git diff --check` 通过，修改文件保持 CRLF；ARM64 host MSBuild 完整构建 `InkeysRepo.sln` 的 `Debug | ARM64` 通过。

## Out of Scope

- 不修改传统悬浮栏、绘制引擎、粗细范围/预设、配置、i18n、资源文件或公共 API。
- 不为新浮窗增加交互、关闭按钮、监视器约束、独立窗口或新的光影模型。
