# UI3 粗细滑块预览浮窗

## Goal

在 UI3 绘制属性的连续粗细滑块进入 Thumb 状态时，显示一个跟随 Thumb 的自适应墨迹粗细预览浮窗，使用户在拖动、轨道点击和快捷值变化时同时看到真实设备像素直径与准确数值，并保持属性栏现有动画、光影和触摸手势行为。

## Requirements

### 范围与生命周期

- 仅修改 UI3 Bar；传统 `IdtFloating.cpp` 只作为“细圆外置数字、足够大后移入圆内”的设计参考，不修改其代码。
- 浮窗可见性直接跟随现有 Slider Thumb：轨道完全拉直并开始显示 Thumb 时展开，真实 Pointer Up 触发现有 Thumb 退场时收起；Hold-lock 只冻结当前粗细，不隐藏 Thumb 或浮窗。
- 直接触摸 Preview 拖动不激活 Slider Thumb，因此不得显示浮窗；触摸轻点固定并完成 Preview -> Slider 后才显示。
- 直接触摸 Preview 超过 5 DIP 阈值后，以按下点为零原点做相对粗细映射；相同粗细变化需要 Slider 行程映射的 3 倍水平位移，既有取整与范围夹取保持不变。有效改值后复用现有 Hold-lock：静止 0.5 秒显示控制行提示、再 1.5 秒锁定；锁定值冻结到真实触摸抬起并只提交一次，全程不得激活轨道、Thumb 或粗细预览浮窗。
- Slider Thumb 完全出现后，在其朝面板外侧的留白中提供精细相对拖动区；该区与 Thumb 的垂直间距等于 Thumb 到内侧控制行的当前间距，宽度等于完整可见 Slider 轨道，右侧需扣除可见 Overflow Hint 按钮，预览浮窗不参与命中或避让。
- 精细区按下与轻点不得按绝对位置跳转粗细；左右位移以按下点为零原点，复用直接触摸 Preview 的 3 倍行程映射、取整、夹取、视觉候选、Hold/lock、capture 与 Pointer Up 清理。
- 折叠属性栏、切换不支持的笔型、打开颜色选择器/More、捕获丢失和退出继续依赖现有 Slider 清理路径，不增加独立关闭状态。

### 浮窗视觉与布局

- 浮窗绘制于绘制属性全部普通内容之上、Slider Thumb 之下，不受粗细 Preview 裁剪区限制；无关闭按钮、命中区或独立 HWND。
- 使用主题 Surface、SurfaceFrame、4 DIP 圆角和 0.95 表面透明度；仅接受第三鼠标光，禁用第一光源。
- 使用 0.40 秒可中断回弹，从 Thumb 中心沿动画几何推导的 `previewSide` 向外展开；稳态浮窗近侧边缘与 Thumb 圆形外缘保持 10 DIP，允许局部覆盖属性面板，收起走对应反向动画。
- 浮窗中心 X 始终直接读取 Thumb 当前帧最终绘制使用的视觉中心；拖动、快捷值、程序化跳变及快速重定向均共享 Thumb 的唯一 X 动画。随后再按当前笔类型按钮的真实动画左边界限制，并对最终回弹矩形执行同一硬边界，右侧不得侵入笔类型区域。
- 不使用显示器、工作区或 Bar 窗口边缘夹取浮窗位置。

### 墨迹圆与数值

- 白色圆形的最终物理直径等于当前候选或动画中的真实墨迹设备像素粗细，不受属性栏 Preview 高度限制，也不额外设置最大尺寸。
- 拖动期间复用现有候选粗细直接反馈；非拖动变化复用 `drawAttributePenThickness` 的动画值。
- 使用 DWrite 实测当前整数文本尺寸。圆形无法容纳文字时，数字显示在圆形右侧并使用主题文字色；圆形足够大后，数字以可逆动画移入圆心并过渡为白底可读的黑色。
- 浮窗尺寸根据圆形、数字、8 DIP 内边距和 5 DIP 外置文字间距连续调整；过渡中不得裁切圆形或文字。

### Hold 提示控制行交换

- 将“保持并固定粗细”文字和进度环移到三个快捷粗细按钮及小三角所在控制行，整体靠粗细区域右边缘对齐；左侧“粗细 + 数值”继续显示。
- Hold 状态变化后立即更新提示可见内容，以一次短促透明度交换替代旧的两阶段等待；提示文字复用主栏文字的 `EaseOutBack` 缩放回弹快速稳定，不得等大部分动画结束后才可读。
- 提示文字与进度环共享同一组显隐透明度和缩放生命周期：出现时同步回弹，消失时同步执行可感知但短促的收缩/淡出；快速显示/隐藏必须从当前视觉值平滑重定向。
- 进度环的圆弧长度继续只读取 Hold 业务进度；锁定后的圆环淡出可以保留独立抑制因子，但不得再作为普通提示显隐的第二套动画。
- 进度环位于文字左侧并保持紧邻，文字右端对齐粗细控制区域右边缘。
- Hold-lock 后保留现有圆环淡出和文字变亮行为，直到提示会话结束后才恢复控制行。

### 渲染约束

- 浮窗表面、白色圆形、数值与后移的 Thumb 绘制必须纳入 predicted/current 旧新脏区并集，避免移动、缩放和收起残影。
- 复用现有 Shape、Word、DWrite 测量、画刷和 PointLight 遮罩缓存；稳定帧不得新增 D2D 资源创建，不增加第二组主绘制提交。
- 保持目标源码编码、CRLF、局部风格和关键路径中文注释。

## Acceptance Criteria

- [ ] 鼠标 hover、点击固定、小三角固定、轨道点击和 Thumb 拖动时，浮窗与 Thumb 同步出现、移动和消失。
- [ ] 直接触摸 Preview 拖动全程不显示浮窗，且相同粗细变化需要 Slider 的 3 倍水平位移；触摸轻点固定后正常显示。
- [ ] 直接触摸 Preview 有效改值后静止可触发 Hold 提示与锁定；无新 MOVE 时使用最后触点推进计时，锁定后候选值和 Preview 数字不再变化，真实触摸抬起只提交锁定值一次并继续保持 Preview。
- [ ] Thumb 出现后，鼠标、WM_TOUCH 合成触摸与笔均可在外侧留白精细相对拖动；轻点不改值，Overflow Hint 占位被扣除，预览浮窗覆盖该区时不影响命中。
- [ ] 硬笔、荧光笔最小/最大值、快捷预设和 1/2/3 位数值均显示准确，圆形屏幕直径与真实墨迹设备像素一致。
- [ ] 数字在外置与圆内状态间平滑、可打断地迁移，表面尺寸连续变化且不裁切内容。
- [ ] 属性面板向上/向下展开时浮窗始终位于 Thumb 外缘 10 DIP；Thumb 全行程保持居中跟随，只有避免笔类型按钮、扩展区或菜单扫掠区时才水平偏移。
- [ ] 显示器边缘不触发位置夹取；深浅主题下圆形恒白、圆内数字可读，边框只有第三光源响应。
- [ ] Hold 状态变化后提示文字几乎立即可见，并带短促回弹；不存在两阶段追赶造成的后 1/4 才显现，左侧粗细读数保持可见。
- [ ] Hold 提示的文字与进度环同步弹入并同步短促退场；动画结束前继续绘制，快速 show/hide 从当前视觉状态自然反向，圆弧业务进度不参与组件显隐计算。
- [ ] Hold 成功锁定后，Thumb 与浮窗保持在锁定瞬间的位置和值；后续 Pointer 移动不再修改 logical thickness、Thumb 或浮窗数字，直到真实 Pointer Up 才进入既有退场与清理流程。
- [ ] 未触发 safe bound 时，浮窗 X 在连续拖动、快捷值、程序化跳变和快速重定向中始终与 Thumb 当前视觉中心同步，不存在独立 easing；触发边界后允许浮窗提前停止，向左离开边界时自然恢复跟随。
- [ ] 颜色选择器、More、Tooltip、模式切换、折叠、捕获丢失和设备资源重建无残留状态或脏区残影。
- [ ] `git diff --check` 通过，修改文件保持 CRLF；ARM64 host MSBuild 完整构建 `InkeysRepo.sln` 的 `Debug | ARM64` 通过。

## Out of Scope

- 不修改传统悬浮栏、绘制引擎、粗细范围/预设、配置、i18n、资源文件或公共 API。
- 不为新浮窗增加交互、关闭按钮、监视器约束、独立窗口或新的光影模型。
