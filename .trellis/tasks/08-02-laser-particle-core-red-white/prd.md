# 激光粒子核心红偏白

## Goal

把激光粒子中间填充从接近纯白改为红偏白，并加入微小随机，使白底背景上仍清晰可辨。

## Requirements

- 粒子核心目标色为红偏白，不得在最亮时变成纯白。
- 每粒核心白度有微小随机抖动，避免整片均匀死白。
- 不改变辉光色、发射率、尺寸与运动语义。
- 同步 CPU helper 与 PS 的 coreColorMix 公式，并更新过期默认值断言。

## Acceptance Criteria

- [ ] 白底上粒子核心仍可见，偏红白而非纯白。
- [ ] 不同粒子核心色相有轻微差异。
- [ ] 构建 Debug|ARM64 通过；相关粒子测试与当前默认配置一致。
