# P2 基础图形绘制与 UI3 面板
用户已批准实施本轮P2：11类单笔创建、完整预测、UI3属性与UInk恢复。类别：直线/开放箭头/矩形/圆角矩形/圆/椭圆/等腰三角形/平行四边形/菱形/等腰梯形/正多边形。
面板：既有视觉，最多6列；图形区→按需参数区→样式|线型|粗细，隐藏不适用组。复用颜色和宽度策略。
圆单按钮，默认圆心模式，次级区切换外接正方形(取较长拖距)。正多边形中心到顶点，3–12边快捷按钮，默认3；未选中/稳定展开/动画开启每1.8秒轮播带中心点SVG，选中固定真实边数。轮播不修改业务边数。
一个Up只提交一个对象；取消无历史；参数/样式/ID保存恢复。逐点折线/任意多边形转P3后；P3追加主栏上方提示和完成/回退/取消。本轮不实现选择及编辑窗口。
验收：CPU/生产无HWND离屏/ARM64 solution/Headless/i18n；不启动GUI，不commit/push。保持格式和minimal diff。
