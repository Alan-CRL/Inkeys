# 修复绘制属性笔型与激光预览动画

## Goal

修复 UI3“绘制属性”窗口中笔型扩展入口与激光粗细预览的动画状态机，使笔型切换具备连续、可反向且无闪现的视觉交接，并按笔型显示正确的标注线说明文案。

## Background

- 当前扩展入口由单一进度和单一锚点绘制；支持扩展的笔型互切时进度目标始终为 `1`，导致三角和分割线瞬移。
- 当前 Laser 同时启动白芯宽度、语义形状和红壳动画，且白芯只在红壳 overlay 中出现，Highlighter 与 Laser 互切时会闪现白色胶囊。
- 现有 HeadlessTests 只验证独立动画值的连续性，没有验证复合状态的阶段顺序。

## Requirements

1. SoftPen、HardPen、Highlighter 各自保存扩展入口视觉进度；选中时渐显，取消选中时在原按钮锚点渐隐。渐显/渐隐与按钮青色背景在同一帧提交目标，并使用相同 `0.4s` 时长和 easing。
2. 旧扩展入口在退场开始时立即失去命中；只有当前选中且支持扩展的笔型拥有菜单、Hover 和 Press。Laser 始终没有三角、分割线、菜单或命中区。
3. 三种笔型的一级菜单行统一显示 `标注线`。问号二级浮窗按锁存的菜单锚点决定标题：SoftPen 为 `标注线（粗细固定，暂未支持）`；HardPen/Highlighter 保持 `启用标注线（暂不可用）`。正文与禁用状态不变。
4. 主粗细预览使用显式 Laser 阶段：NonLaserStable、EnteringCore、EnteringShell、LaserStable、LeavingShell、LeavingCore。
5. 进入 Laser 时，先用 `0.4s` 将当前语义层的宽度、颜色、曲线/圆角和 Highlighter 渐变连续变为白色内芯；全部到位后，再用 `0.4s` 从白芯下方展开红色外套。
6. 离开 Laser 时，先用 `0.4s` 将红色外套收窄到白芯宽度并隐藏，期间白芯保持 Laser 端点；随后用 `0.4s` 将白芯连续变为目标非 Laser 笔型。
7. 红壳先绘制、白芯后绘制；红壳进度控制从芯宽到外宽的揭示，进度为零时红壳完全被白芯遮住。预览包络只读取阶段化芯宽/壳宽，不能提前读取新工具的逻辑粗细。
8. 任一阶段中途反向必须从当前视觉值续接。Laser 稳态下切换 `3/5/7 DIP` 仍保持内外宽同步动画。
9. Slider、FineDial、快捷预设、真实笔宽、Draw3 Bridge、配置格式和工具语义保持不变。
10. Laser 白芯与红壳始终共享由阶段化 outer thickness 决定的两端圆心；从更细/更粗的非 Laser 笔切入时，白芯水平长度随 outer thickness 连续收窄/拓宽，Slider 展开时端点直径与芯宽一起连续趋向轨道粗细。

## Acceptance Criteria

- [ ] 支持扩展的笔型互切时，旧三角/分割线在原锚点渐隐，新三角/分割线同时渐显；两者时长和曲线与各自按钮背景一致。
- [ ] 支持笔型与 Laser 互切时，Laser 没有扩展入口，旧入口平滑退场或新入口平滑入场，退场视觉不可命中。
- [ ] 一级菜单和三种二级浮窗标题符合已确认文案，菜单关闭或切换笔型时不发生内容跳变。
- [ ] SoftPen/HardPen/Highlighter 进入 Laser 时，红壳仅在白芯阶段完成后出现。
- [ ] Laser 退出到任一非 Laser 笔型时，白芯仅在红壳完全隐藏后开始改变。
- [ ] Highlighter 与 Laser 双向切换时，宽度、颜色、圆角和渐变连续，不出现渐变矩形瞬切白色胶囊。
- [ ] 快速反向、面板关闭重开和 Laser 稳态粗细切换不跳回端点、不残留动画或交互状态。
- [ ] Laser 白芯与红壳在壳进度 `0`、中间值和 `1` 时两端圆心一致；细笔/粗笔切入及 Slider morph 期间水平长度连续。
- [ ] ARM64 Debug 完整 Solution 构建、无窗口 HeadlessTests 和 `git diff --check` 通过。

## Out Of Scope

- 不实现标注线绘制功能，不改变其禁用状态。
- 不修改 Draw3 笔迹、光标、压感、宽度所有权或持久化。
- 不重构 Bar 其他面板、动画框架或渲染管线。
