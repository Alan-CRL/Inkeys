# 阶段 B · 画布分层传递、窗口交接与着色器

本任务属于 Inkeys3 中期重构，与 A2 同级。早期调查基线为 `refactoring/draw@0f17910e`；实施基线为 A2 归档后的 `refactoring/draw@cd942ed0`。2026-11-22 用户审阅并批准了下面的范围和 [实施计划](implement.md)，任务进入实现。

## 用户目标

在 4K 和旧集显上省掉没有可见收益的清空、拷贝和重画，保持书写、终态、撤销和回放一致。有墨迹时绘制与选择／穿透互切的画面连续。为阶段 C（中期能力第六步：脏区与白板平移）留下可靠的层内容登记。

## 已定的产品决定（2026-11-22）

- L0 局部清除的分界线从半屏改为 1/16 屏。不支持 ClearView 的设备整屏清，不为它们新增着色器或拷贝路径。
- 所有 L0 清除走同一个登记入口；写域登记支持多个矩形；初始化时记录设备是否支持 ClearView。
- 抬笔的路径 A 与路径 B 同时制作并完整接入所有入口。
- 单层合成用主像素着色器的新分支（类型 25）实现，同步重新生成 Win7 保护版。
- 着色器优化只做两项：两层都空时跳过合成、图形临时层按图形矩形清。独立小合成着色器、激光距离共用中间量本轮不做。
- 激光粒子本轮不启用，也不改粒子代码；只保证帧内顺序和脏区为它保留位置。后续另开任务优化并启用。

## 需求与验收

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| B1.1 | L0、L1 的清除按写域登记决定：没写过不发命令；写域未知或无 ClearView 整屏清；面积之和超过 1/16 屏整屏清；否则 ClearView 清矩形。 | 无窗口像素回读：矩形内 Add=0、Retain=1，矩形外哨兵保留；多矩形、阈值两侧、无能力回退、重复清除跳过均覆盖。初始化日志含 ClearView 能力。 |
| B1.2 | 抬笔不再无条件整屏清两层并重画。路径 B：L0 作隔离工作区重画最终整笔，单层合成进 L2。路径 A：L1 只含这一笔且前缀未被定稿改动时，只画最终尾段，L1 与 L0 一次合并进 L2。 | 在支持 ClearView 的设备上，单笔抬笔整屏清除从 12 次降到 0 次（笔画超过 1/16 屏时每层至多 1 次）；不支持 ClearView 的设备每层至多 1 次。纯激光抬起从 8 次降到 0 次。路径 B 的 L2 与整笔重放逐像素相同；路径 A 与整笔重放相差不超过 1 级。 |
| B1.3 | 各工具语义不变：画笔、硬笔、荧光笔、橡皮、图形、激光；同帧多笔按现有遍历顺序（触点接纳顺序）进 L2；预测永不进入 L2 和文档。 | 覆盖单笔、同帧两笔、另一指仍在写、边擦边写、取消、断触续接、重做、图形抬起、自动进入编辑的图形、多步构造中间步骤。撤销、重做结果一致。 |
| B1.4 | 上屏合成按层内容选择：两层都空跳过；只有一层有内容用单层合成；都有内容用现有双层合成。图形临时层的清除和合成收进图形矩形。 | 三种情况的上屏结果与现有双层合成逐像素相同。图形自检中矩形外哨兵不被改动、矩形内无残留。 |
| B2 | DComp 与 Win7Dwm 下有墨迹的绘制↔选择／穿透切换：先只显示新的一方，确认上屏后再隐藏旧的一方；失败时保留仍有效的一方并有界重试。 | 无窗口状态用例证明操作顺序与版本复核。真实画面无整幅墨迹消失，由用户在 DComp 和 Win7Dwm 实机验收。 |
| B3 | 主像素着色器新增类型 25 后，已有类型的输出不变；保护版同步。 | 生产版与保护版的比对矩阵通过并加入类型 25 用例；记录新哈希。Win7 WARP 与兆芯由用户实机复验。 |

## 范围外

激光粒子启用与优化、激光烘焙的整图拷贝、独立小合成着色器、可信 L2 快照的整图拷贝、分块合成、白板平移复用、多脏矩形呈现。后四项属于阶段 C。

## 证据与限制

- 清除方式的离屏计时见 [L0 清除探针](research/l0-clear-probe.md)，只有本机 Adreno 与 WARP 两组数据。旧 Intel 核显、兆芯、Win7 实机的耗时和画面本任务无法测量，依赖用户实机验收。
- 早期调查见 `research/` 下的 layers、handoff、shaders、offscreen 四份文档，其中与上面决定不一致的方案描述以本文件和 [设计](design.md) 为准。
