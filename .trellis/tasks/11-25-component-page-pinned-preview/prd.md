# C6 组件页固定预览区与卡片长按起拖

## Goal

调整设置 → 组件页的布局与拖动手势：主栏预览区固定在页面上方，下方组件库独立滚动；组件库新增“内置组件”Tab，“全部”不再分小节；卡片需长按抓起后才拖动，否则按页面滚动处理；固定区让拖动目标始终可见，因此取消拖动时的边缘自动滚动。

挂在父任务 `11-20-settings-bar-component-editor` 下，是 C4（组件库）与 C5（共享编排与交互）合同的修订。

## 来源需求（用户原话要点，2026-11-25）

1. 上方显示主栏的区域（包括下方的垃圾桶按钮等）固定在页面上，不随滚动上移；真正的滚动视口从其下方开始垂直滚动。
2. 下方 Tab 新增“内置组件”类，把分割线放进去。
3. “全部”下方的卡片不按类别分类，直接排列在一起。
4. 卡片拖动需要先按住静止（或移动不超过某个大小，参考主栏的拖动操作），抓住后才支持向上拖动；否则识别为页面滚动。
5. 上方区域固定后，下方组件拖动过程中不再支持靠近滚动边缘辅助滚动。

## Requirements

### R1 固定预览区

- R1.1 组件页分为上下两部分：上方固定区包含主栏预览块（含其上方 More 回弹预留、下方垃圾桶胶囊所在预留区）；下方为独立的垂直滚动视口。
- R1.2 固定区不随下方滚动移动；下方滚动视口的上沿紧接固定区下沿，滚动条只出现在下方视口。
- R1.3 固定区内容：页面标题“组件” + 主栏预览块。快捷方式行、恢复默认行、“添加组件”分区及组件库都在下方滚动视口内。
- R1.4 More 展开为多行时，固定区高度随预览块（按现有相机过渡）增高，下方滚动视口相应变矮，不遮挡卡片；固定区高度设上限（约为内容区高度的一半，超过时预览按现有规则受高度限制）。
- R1.5 固定区仍参与页面入场/退场动效（与当前预览块一致）。
- R1.6 预览内按钮的拖动不变（固定区内没有页面滚动，仍按现有阈值直接起拖）。

### R2 组件库 Tab 与“全部”

- R2.1 Tab 顺序：全部、内置组件、桌面操控、IslandCaller、SecRandom、NamePicker、ClassIsland，默认“全部”。
- R2.2 “内置组件”Tab 与其他专属 Tab 一致：整行条目、完整说明；本轮只有“分割线”（只能拖动添加、没有“+”，有用户分割线时显示删除键）。
- R2.3 “全部”：不再显示分类小标题，所有卡片按 Tab 顺序（内置 → 桌面操控 → … → ClassIsland）连续排成一个网格；卡片样式、尺寸不变。

### R3 卡片长按起拖

- R3.1 组件库卡片（“全部”网格）与专属 Tab 条目：按下后在规定时间内保持静止（位移不超过容差），才进入“抓起”，此后跟随指针拖动，可拖向上方预览放下。
- R3.2 按住期间位移超过容差、或在抓起前松开：不起拖。超过容差时转为页面滚动（与在空白处拖动一致，滚动包含已发生的位移）；抓起前松开视为普通点击（卡片本身无点击动作，操作键仍可点击）。
- R3.3 抓起瞬间幽灵按钮出现在指针处作为反馈，此后沿用现有拖放反馈（插入提示、收纳提示、垃圾桶、跟随浮窗）。
- R3.4 时间与容差参数：默认参考主栏粗细滑块“按住静止”（5 px / 500 ms），本任务取约 400–500 ms、约 8 DIP（触摸），具体值待实机手感确认。
- R3.5 适用的输入类型：只对触摸与笔要求长按；鼠标保持现状（按下后越过 4 DIP 阈值即抓起，鼠标主要用滚轮滚动）。
- R3.6 操作键（“+”/垃圾桶）区域不参与长按起拖，点击行为不变。

### R4 取消边缘自动滚动

- R4.1 删除拖动中“指针靠近滚动视口上/下边缘时自动滚动页面”的行为（原 R2.8 / spec §3.2 边缘滚动条款）。
- R4.2 拖动期间下方滚动视口保持不动；拖动中滚轮是否仍可滚动：默认允许（不额外拦截）。

### R5 不变项

- 放下语义表（预览可删除项拖出预览区=删除、固定项回位、库项区外放弃）、垃圾桶位置与样式、More 停留展开、快捷方式行与两段式重置的行为均不变。

## 约束

- 兼容 Windows 7 SP1 + KB2670838；MSVC v143 / C++20；不引入新依赖。
- 最小化修改：只动组件页布局、卡片起拖与组件编辑器拖动相关代码；设置页通用滚动宿主仅在必要时做局部扩展，不影响其他页面。
- 改动的 `.cpp/.cppm/.h` 保持 UTF-8 BOM + CRLF。
- i18n：新增文案（“内置组件”Tab 名可复用现有 `BuiltinSection` 键或新增键）走 i18n，zh-CN 为基准，其他语言 `pwsh Scripts/i18n.ps1 sync` 后补译。

## Acceptance Criteria

- [ ] 组件页下方内容滚动时，主栏预览与垃圾桶区域保持固定；滚动条只在下方视口。
- [ ] Tab 含“内置组件”，分割线只在该 Tab 与“全部”中出现；“全部”无小节标题，卡片连续排列。
- [ ] 触摸在卡片上直接滑动时滚动页面、不起拖；按住静止达到时限后抓起，可拖入预览完成添加/收纳。
- [ ] 抓起前松开不触发拖动；操作键点击照常。
- [ ] 拖动靠近下方视口边缘时页面不再自动滚动。
- [ ] 原有拖放语义、垃圾桶、More 停留、重置与快捷方式行为不回归。
- [ ] `setting_design_tests`、`drag_session_tests` 等相关 headless 用例按新合同更新并通过；`InkeysRepo.sln` `Debug | ARM64` 构建通过。
- [ ] spec `settings-component-editor.md` 更新为新合同（固定区、Tab、长按起拖、删除边缘滚动）。

## 已确认决定（2026-11-25）

- 固定区 = 页面标题 + 主栏预览块（含垃圾桶预留）；其余内容在下方滚动。
- 长按起拖只对触摸/笔生效，鼠标保持越阈值即抓起。
- More 多行展开时固定区增高并挤压下方视口（设上限）。

## 按默认处理

- “内置组件”Tab 放在“全部”之后。
- 长按参数取 450 ms；静止容差使用与页面拖动滚动相同的原生拖动阈值（6 物理像素），实机手感验收时可调。
- 拖动中滚轮不额外拦截。
