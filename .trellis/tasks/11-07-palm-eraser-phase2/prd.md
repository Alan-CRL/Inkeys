# 手掌橡皮第二阶段：屏蔽修复、擦除样式与自定义（父任务）

## 目标

在第一阶段（坐标与接触尺寸修正，已归档 `archive/2026-11/11-06-palm-eraser-phase1-coordinate-size`，提交 ba76c4ec）基础上，修改手掌橡皮上层行为：修复边擦边写时邻近触点误写，新增橡皮擦除形状与新光标，并为手掌橡皮和普通橡皮提供自定义设置。

## 用户原始需求摘要（2026-11-07）

- A 修复：大屏开启“边擦边写”时，手掌橡皮附近其他触摸点写出墨迹（前面在擦、后面在写）。明确屏蔽范围；激活手掌橡皮后让范围内其他书写触点抬笔（原抬笔行为），过程中不接受范围内落笔。
- B-a 形状：新增竖直长方形擦除样式（类似希沃白板橡皮）及圆角正方形；光标/预览为极小 px 圆角（不随 DIP 缩放），实际擦除为无圆角矩形；适配着色器。重新设计圆形与矩形橡皮光标中心纹样（替换像“猪鼻孔”的两个抓手），设计由 Claude（Opus 5.5）完成并先经用户确认。
- B-b 手掌自定义：设置中新增手掌橡皮擦除样式（三形状预览 + 内联下拉，跟随默认/三形状）；手掌橡皮大小分组（粗细计算方式、大小计算方式、动态倍率滑块 + 无文字重置）。
- C 附加：设置-绘制-橡皮分组最上方新增擦除样式；主栏-橡皮-橡皮属性中的橡皮大小预览适配三种形状（圆角 px 不随缩放）。

## 已确认的产品决策（2026-11-07，经会话提问确认）

| ID | 决策 |
| --- | --- |
| D1 | 屏蔽范围沿用现公式：圆形 `R = r + max(0.15r, 4px)`，r 为画布 px 半径。 |
| D2 | 仅在手掌橡皮**激活瞬间**让范围内其他书写触点按正常抬笔结束（保留已画墨迹）；之后手掌移动覆盖到其他正在书写的触点不再截断。激活期间持续拒绝范围内**新的落笔**。 |
| D3 | 抬笔与落笔屏蔽只作用于 Touch；笔、鼠标不受影响。 |
| D4 | 矩形/正方形手掌的屏蔽范围随形状：橡皮矩形每侧外扩 `max(该方向半边长×0.15, 4px)`。 |
| D5 | 橡皮形状存于 UInk 私有字段，同版本扩展；旧文件缺省圆形；旧版程序忽略该字段并按圆形擦除重放（近似）。**记录：UInk 1.1 时将形状升级为官方字段。** |
| D6 | 尺寸 D 与矩形映射采用等面积：形状面积 = πD²/4。竖长矩形宽:高 = 2:3。 |
| D7 | 光标中心纹样采用“微光”：中心实心四角星 + 右上小星；外黑边、内灰边、半透明填充保留，轮廓即擦除边界。 |
| D8 | 手掌“粗细计算方式”三项：动态粗细（默认，跟随接触面积，可叠加倍率）／固定粗细（跟随默认橡皮：默认大小，全局自动粗细开启时按笔速）／固定粗细（不支持笔速橡皮：恒为默认大小）。全局“自动粗细”是笔速橡皮总开关。 |
| D9 | 动态倍率作用于边长/直径，范围 25%–300%，默认 100%。 |
| D10 | 大小计算方式各形状有各自推荐默认：圆形=接触矩形内切椭圆等面积（推荐，即现行为）；竖长矩形=矩形等面积；正方形=内切椭圆等面积。 |
