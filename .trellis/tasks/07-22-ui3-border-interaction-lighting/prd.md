# UI3 边框点光追光效果

## Goal

为 UI3 Bar 的指定 1px 圆角矩形和超椭圆边框提供稳定的双点光追光反馈：保留主按钮中心常驻光和不受窗口边界影响的全局鼠标光，删除点击残光，并让远端始终保留原灰色边框。

## Background

- UI3 Bar 已使用 `ID2D1DeviceContext`、WARP、预乘 Alpha 分层窗口和脏区更新。
- 当前主按钮、主栏、绘制属性栏以及 11 个颜色块均有 1px 边框；颜色块需保持上一任务确定的尺寸、圆角、间距和柔和主题灰色。
- 鼠标与触摸最终都进入 `BarUISetClass::Interact` 的客户区消息路径，主按钮拖动由 `Seek` 处理。
- 三光源版本已经完成并通过构建；维护者确认不再需要点击位置残光和主光点击脉冲，并要求不同控件采用明确的画笔染色策略。

## Requirements

- 仅修改 UI3 Bar，不修改传统 `IdtFloating`，不新增配置、新线程或独立动画系统。
- 圆角矩形和超椭圆提供 `Solid`、`PointLight` 两种内部边框绘制模式，默认保持 `Solid`，现有构造函数及外部接口不变。
- 主按钮、主栏、绘制属性栏外框和 11 个颜色块显式使用 `PointLight`；其他边框继续使用原纯色路径。
- 同时最多存在两个光源：跟随主按钮当前中心的稳定常驻光源，以及实时全局鼠标光；点击和拖动不再创建边框光源或主光明暗脉冲。
- 所有 PointLight 边框先按现有 `frame`、`framePct` 和边框宽度绘制完整纯色底边；光照半径为 480 逻辑像素且两束光末端均衰减到 0，范围外严格只剩原灰边。
- 每个控件先把两束同色、带 480px 空间衰减的 1px 光边记录为 D2D1.1 CommandList，再通过内置 Gaussian Blur 向轮廓内外连续扩散约 3px，最后绘制原 1px 清晰层。
- 同一控件每帧只解析一种光色，主光和鼠标光复用该颜色；Gaussian 单次输出在中心线附近以默认灰光 30%、生效后的画笔光 20% 为基准，并将同一输出用 `SOURCE_OVER` 合成两次，使近端有效透明度非线性增强到约 51%/36%，远端仍沿连续高斯尾部平滑归零。
- 主光强度固定为 100%，鼠标光最大强度为 60%；删除交互光的 1.8 秒时间线和主光 300ms/1.5s 点击脉冲。
- 全局鼠标光最大强度为 60%，位置严格跟随系统鼠标；鼠标从窗口外或其他显示器移近时依靠 480px 空间衰减连续变亮，不增加位置缓动。
- UI 动画从关闭切换到开启时，鼠标光按当前速度倍率淡入 300ms；移动不会重复启动淡入。
- UI 动画关闭时移除鼠标光，只保留完整基础灰边和强度稳定的主光。
- 使用 UI3 窗口的 `RIDEV_INPUTSINK` Raw Input 接收全局鼠标移动，不复用或修改传统 `IdtFloating` 的低级鼠标钩子。
- 增加默认 `Frame` 的内部光照颜色策略；主按钮、主栏和绘制属性栏显式使用 `PenWhenDrawing`，11 个颜色块保持 `Frame`。
- 非穿透绘制模式（`StateModeSelect == IdtPen && !penetrate.select`）下，三类可染色外框的主光和鼠标光均使用动画中的当前画笔色；颜色块的两束光均使用自身 `SwatchFrame`。其他模式全部恢复自身边框色。
- 同一控件的主光和鼠标光必须同色，重叠时只增强亮度；基础灰边允许作为底层被强调光自然覆盖。
- 11 个颜色块使用独立 `framePct`：收起时为 0%，完整展开时为 18%；基础灰边继续使用该值，点光显现度改为复用填充 `pct` 的 0%/100%，两者共享现有属性栏动画批次和完成时刻。
- 鼠标静止且其他光影动画结束后补绘最终状态并恢复现有渲染休眠。
- D2D 渐变资源失败时回退到纯色边框；CommandList 或 Gaussian Blur 失败时保留基础边与 1px 清晰追光、仅跳过柔光，并避免逐帧重复日志。
- Raw Input 注册失败时只记录一次错误并禁用鼠标光，不影响基础灰边、主光和纯色回退。
- 光影外扩必须进入脏区，移动、展开、淡出后不得留下残影。
- 保留文件原编码、CRLF、现有格式，并为关键状态和兼容回退添加简短中文注释。

## Acceptance Criteria

- [x] `Solid` 是默认模式，原 `DrawRoundedRectangle` / `DrawGeometry` 纯色边框仍可用。
- [x] 仅主按钮、主栏、绘制属性栏外框和 11 个颜色块显式启用追光。
- [x] 常驻光以主按钮当前中心为准；鼠标光在窗口外移动时仍能实时更新，点击和拖动不产生边框残光或主光脉冲。
- [x] 动画关闭时只保留完整基础灰边和稳定主光；开启时鼠标光按现有 300ms 时间线淡入。
- [x] 非穿透绘制模式下，主按钮、主栏和绘制属性栏的两束光均为动画画笔色，颜色块的两束光均为默认灰色；其他模式全部使用默认边框色。
- [x] 两束光在同一控件上不发生异色混合；480px 外保持原边框颜色和原透明度。
- [x] 颜色块展开时填充与点光显现度由 0% 到 100%，基础灰边由 0% 到 18%，鼠标光在稳态灰边上具有可见亮度差。
- [x] 默认灰光/画笔光的单次 Gaussian 中心强度为 30%/20%，双次 `SOURCE_OVER` 后有效近端强度约为 51%/36%；柔光从 1px 光边向内外连续衰减并在约 3px 外平滑透明，外延完整进入脏区且无残影或透明度台阶。
- [x] 光影只影响边框，深浅主题、颜色块主题灰、填充、布局、命中与原动画行为保持不变。
- [x] 鼠标静止且光影动画结束后渲染线程恢复原静止等待，且柔光脏区无残影。
- [x] `git diff --check` 通过，完整 `InkeysRepo.sln` 的 `Debug | ARM64` 后台构建通过。
- [x] 未启动程序、未打开窗口或执行屏幕操作；维护者已于 2026-07-22 完成人工验收并授权提交、归档。

## Out of Scope

- 传统悬浮栏、设置窗口和画板渲染。
- 点击/拖动边框光、主光点击脉冲、右键关闭、触摸的全局跟随光或无屏幕鼠标坐标的程序化指针变化。
- 自定义 Direct2D Effect、显式离屏位图、DirectComposition、配置化视觉参数和自动化截图对比。
