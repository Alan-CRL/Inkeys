# UI3 边框点光追光效果

## Goal

为 UI3 Bar 的指定 1px 圆角矩形和超椭圆边框增加实时双点光追光反馈，让主按钮中心形成常驻明暗渐变，并在点击或滑动位置产生短暂交互光，同时保留可供其他控件使用的原纯色边框绘制方式。

## Background

- UI3 Bar 已使用 `ID2D1DeviceContext`、WARP、预乘 Alpha 分层窗口和脏区更新。
- 当前主按钮、主栏、绘制属性栏以及 11 个颜色块均有 1px 边框；颜色块需保持上一任务确定的尺寸、圆角、间距和柔和主题灰色。
- 鼠标与触摸最终都进入 `BarUISetClass::Interact` 的客户区消息路径，主按钮拖动由 `Seek` 处理。

## Requirements

- 仅修改 UI3 Bar，不修改传统 `IdtFloating`，不新增配置、新线程或 UI 动画。
- 圆角矩形和超椭圆提供 `Solid`、`PointLight` 两种内部边框绘制模式，默认保持 `Solid`，现有构造函数及外部接口不变。
- 主按钮、主栏、绘制属性栏外框和 11 个颜色块显式使用 `PointLight`；其他边框继续使用原纯色路径。
- 同时最多存在两个光源：跟随主按钮当前中心的常驻光源，以及最近点击/滑动位置的交互光源。
- 光照半径为 480 逻辑像素；使用边框自身主题色和 `framePct`，不改变任何填充。
- 每个光源绘制 3px 微弱扩散层和原 1px 清晰层；扩散层强度为清晰层的 12%。
- 交互光在最后一次位置更新后 450ms 内平滑衰减；主光在交互开始后的前 100ms 降至 35%，再于剩余 350ms 恢复。
- 主按钮拖动持续更新交互光位置但不重启主光脉冲；重复按下创建新的交互过程。
- 光影时钟独立于 UI 动画开关和速度倍率；活动期间维持渲染，结束后补绘静态帧并恢复休眠。
- D2D 渐变资源失败时回退到纯色边框并避免逐帧重复日志。
- 光影外扩必须进入脏区，移动、展开、淡出后不得留下残影。
- 保留文件原编码、CRLF、现有格式，并为关键状态和兼容回退添加简短中文注释。

## Acceptance Criteria

- [ ] `Solid` 是默认模式，原 `DrawRoundedRectangle` / `DrawGeometry` 纯色边框仍可用。
- [ ] 仅主按钮、主栏、绘制属性栏外框和 11 个颜色块显式启用追光。
- [ ] 常驻光以主按钮当前中心为准，边框随距离变暗；交互光随点击和主按钮拖动位置更新。
- [ ] 主按钮、主栏按钮、颜色、画笔和荧光笔的左键/触摸按下均能触发交互光。
- [ ] 光影只影响边框，深浅主题、颜色块主题灰、填充、布局、命中与原动画行为保持不变。
- [ ] 光影结束后渲染线程恢复原静止等待，且柔光脏区无残影。
- [ ] `git diff --check` 通过，完整 `InkeysRepo.sln` 的 `Debug | ARM64` 后台构建通过。
- [ ] 不启动程序、不打开窗口、不执行屏幕操作；不提交 commit、不归档任务，等待人工验收。

## Out of Scope

- 传统悬浮栏、设置窗口和画板渲染。
- 右键关闭、悬停或无客户区坐标的程序化状态变化。
- Gaussian Blur、DirectComposition、配置化视觉参数和自动化截图对比。
