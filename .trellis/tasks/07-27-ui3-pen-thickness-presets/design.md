# 技术设计

## 边界与数据

- 改动集中在 `Bar.Main.cpp/.cppm` 与 `Bar.State.cppm`，继续通过现有 `GetPenWidth()` / `SetPenWidth()` 访问共享画笔状态。
- 使用文件内单一 `constexpr` 三档数组 `{ 1.0, 3.0, 6.0 }`；渲染与交互均通过同一换算函数乘 `barStyle.dpiZoom` 并取整。
- 不修改 `IdtDrawpad` 的默认值和记忆逻辑；当前值不匹配三档时自然没有选中项。

## 控件与布局

- 属性栏宽度设为 `370`，高度增至 `185`；紧凑态继续按 `60 / 370` 统一缩放，高度随相同比例重算。
- 粗细区为 `240×95`：颜色位于上半部时粗细区放在 `y=75`，颜色位于下半部时放在 `y=5`；后一布局中的颜色两行整体下移 `35px`。
- 右侧笔型列移动到 `x=250`；现有颜色坐标不变，`x=215` 一列留给未来自定义颜色。
- 笔型列新增 `y=145` 的软笔行；复用 `barBrush2` 毛刷轮廓，设置为与激光笔一致的灰色禁用项，不注册悬停、按压或模式切换。
- 原画笔行仅把显示文字改为“硬笔”，继续映射 `IdtPenBrush1`，行为不变。
- 下排粗细按钮恢复使用 `30×30` 命中区，位于粗细区 `y+60` 并保持底部 `5px`；标签与按钮共享水平中心线。
- 上方预览左端对齐标签左端，右端使用灰色区域的对称内边距；竖直方向复用按钮到底边的安全间隙，在灰色区域顶端与按钮顶端之间居中。

## 渲染

- 当前粗细动画仍复用 `drawAttributePenThickness`，并新增归一化圆角动画值；标签、预览高度和圆角读取同一帧的连续动画状态。
- 预览先把逻辑边界乘总 UI zoom 得到设备坐标，再把粗细高度直接作为设备 px 使用：
  - 两种笔型始终填充同一个圆角矩形；
  - 画笔目标圆角为当前高度的一半，荧光笔目标圆角为 `0`。
  - 最大高度和中心均由 `95px` 灰色区域顶端、按钮顶端及上下对称安全间隙推导，新增高度全部提供给预览，不使用额外位置偏移。
- 三档圆形同样只把中心位置和按钮内边界乘 UI zoom，圆形直径直接使用 DPI 换算后的设备 px。
- 超限圆形按按钮内边距裁剪直径，并在圆内显示真实数值；数字根据圆形填充色选择黑/白高对比色。
- 箭头使用新增 `barThicknessAdjust.svg` 资源并在按钮中心以 `18×18` 视口显示，随按钮 UI zoom 和按压矩阵缩放；其实际可见轮廓约为原手绘箭头的 `75%`。

## 状态、动画与光影

- Shape/Word 枚举追加连续的粗细按钮对象，现有属性栏动画和脏区循环扩展到新末项。
- `BarUISetClass` 保存四个独立悬停阶段，`BarStateClass` 保存四个按压状态；渲染线程为四个按钮维护独立 `BarUiValueClass` 按压比例。
- 画笔模式显示全部四项；荧光笔模式把三档透明度、光影和命中入口关闭，只保留箭头。
- 三档选择按当前显示整数与实际档位整数精确比较；选中档使用 `Accent` 内容与 `0.20` 背景，按下时背景透明度切换为 `0.10` 并缩放至 `0.95`，其他内容使用 `TextPrimary`。
- 所有按钮复用 `StartHover` / `StopHover`、按压 `0.95` 和释放回弹；选中档不叠加悬停。
- 主栏路径保持不变；绘制属性中的笔型按钮和四个粗细选择器共用主栏悬停状态机：驻留时按 `5s` 自然淡出，鼠标移出使用主栏的快速退出曲线。
- 按下时保留悬停层的当前透明度和填充色，再连续过渡到按下态，禁止先清零后重建造成闪烁或颜色跳变。
- 属性栏批次同步跳过 `animateWhenDisabled` 的独立悬停值，避免把显现或 5 秒淡出覆盖回默认操作时长。
- 三档配置 `PointLight` 且关闭主光，只在选中时设置 `frameLightPct`；箭头始终不启用边缘光影。
- 软笔对象插入现有连续 Shape/SVG/Word 枚举范围，使展开、收起、上下换边和脏区循环自动覆盖，但不进入输入命中分支。
