# 技术设计

## 边界与数据

- 改动集中在 `Bar.Main.cpp/.cppm` 与 `Bar.State.cppm`，继续通过现有 `GetPenWidth()` / `SetPenWidth()` 访问共享画笔状态。
- 使用文件内单一 `constexpr` 三档数组 `{ 1.0, 3.0, 6.0 }`；渲染与交互均通过同一换算函数乘 `barStyle.dpiZoom` 并取整。
- 不修改 `IdtDrawpad` 的默认值和记忆逻辑；当前值不匹配三档时自然没有选中项。

## 控件与布局

- 属性栏宽度设为 `370`，高度增至 `185`；紧凑态按 `60 / 370` 统一缩为 `60×30`，初始化、收起终点和上下换边中点的根面板都以绘制按钮中心为 `(0, 0)`。
- 粗细区为 `240×105`：颜色位于上半部时粗细区放在 `y=75`，颜色位于下半部时放在 `y=5`。
- 统一使用 `5px` 布局间隙：颜色在下方时两行位于 `y=115/150`，最后一行底边为 `180`；颜色在上方时两行仍位于 `y=5/40`，粗细区从 `y=75` 开始并在 `y=180` 结束。
- 右侧笔型列移动到 `x=250`；现有颜色坐标不变，`x=215` 一列留给未来自定义颜色。
- 笔型列新增 `y=145` 的软笔行；复用 `barBrush2` 毛刷轮廓，设置为与激光笔一致的灰色禁用项，不注册悬停、按压或模式切换。
- 原画笔行仅把显示文字改为“硬笔”，继续映射 `IdtPenBrush1`，行为不变。
- 粗细按钮使用 `30×30` 命中区并与标签共享水平中心线：属性栏在主栏上方时位于粗细区 `y+70`；换到主栏下方时位于 `y+5`。
- 预览左端对齐标签左端，右端使用粗细外框的对称内边距；正常方向在区域顶端与控件顶端之间居中，倒转方向在控件底端与区域底端之间居中，两侧均保留 `5px`。

## 渲染

- 当前粗细动画仍复用 `drawAttributePenThickness`，以 `drawAttributePenPreviewMorph` 取代单一圆角值：`0=硬笔 S 形`、`0.5=圆头直线关键帧`、`1=方头荧光笔`。
- 硬笔阶段创建一段 cubic Bezier，四点为左下、`1/3` 上、`2/3` 下、右上；振幅为 `min(可用高度×0.22, (可用高度-显示粗细)/2)`，并乘硬笔形态比例和面板展开比例。
- D2D 路径只在控制点变化时重建，稳定帧复用 geometry 与圆头 stroke style；`0.5` 时路径与圆头矩形外轮廓完全重合，再切换到矩形分支继续动画。
- 普通笔型继续使用完全不透明的 SolidColorBrush；荧光笔使用横向 LinearGradientBrush，左端透明度随形态从 `1.0` 连续变为 `0.35`，右端保持 `1.0`，画刷整体透明度继续乘属性栏内容显隐动画。
- 荧光笔渐变画刷按当前前景色复用，稳定帧只更新起止点和整体透明度；创建失败后本设备会话退回纯色预览并停止逐帧重试，设备资源重建时再恢复尝试。
- 静止展开态的色带高度和预设圆点直径继续使用真实设备 px；属性栏几何动画期间额外乘当前面板宽度相对 `370` 的倍率，使它们与按钮、文字及容器同步等比收拢。
- 预览先把逻辑边界乘总 UI zoom 得到设备坐标，再把粗细高度直接作为设备 px 使用：
  - 两种笔型始终填充同一个圆角矩形；
  - 画笔目标圆角为当前高度的一半，荧光笔目标圆角为 `0`。
  - 最大高度和中心均由 `105px` 粗细外框、控件行边界及上下对称安全间隙推导；换边时上下边界镜像，不使用额外位置偏移。
- 三档圆形同样只把中心位置和按钮内边界乘 UI zoom，圆形直径直接使用 DPI 换算后的设备 px。
- 超限圆形按按钮内边距裁剪直径，并在圆内显示真实数值；数字根据圆形填充色选择黑/白高对比色。
- 箭头使用新增 `barThicknessAdjust.svg` 资源并在按钮中心以 `18×18` 视口显示，随按钮 UI zoom 和按压矩阵缩放；其实际可见轮廓约为原手绘箭头的 `75%`。
- 属性栏位于主栏下方时，在现有按压缩放矩阵内围绕按钮中心追加 `180°` 旋转，仅改变箭头朝向，不改变命中框。

## 状态、动画与光影

- Shape/Word 枚举追加连续的粗细按钮对象，现有属性栏动画和脏区循环扩展到新末项。
- 属性栏及内部 Shape 的圆角和边框厚度与宽高使用同一紧凑倍率；上下换边时也写入相同中间关键帧，避免只有宽高收缩。
- 普通收起和展开直接从最终展开坐标计算单一目标：上方颜色行直接使用 `115/150`，隐藏态只乘固定 `60 / 370` 倍率；禁止先提交基础坐标、再用第二次 `SetTar()` 追加颜色或方向偏移。
- 上下换边中点固定为以绘制按钮为中心的 `60×30` 根面板；直属 Shape 的 `x/y`、宽高、圆角和边框均按最终展开目标乘固定紧凑倍率，嵌套 SVG/Word 的局部坐标与尺寸也使用同一倍率。根面板负责对齐绘制按钮，内部保留完整布局的等比微缩关系；中点不读取运行中的 `val` 或当前面板宽度。
- 直接由 D2D 绘制的墨迹预览不读取瞬时切换的上下方向标志；其中心、可用高度和水平内边距由正在动画中的粗细区域与调节按钮几何连续推导，确保先收缩到关键帧，再从关键帧镜像展开。
- `BarUISetClass` 保存四个独立悬停阶段，`BarStateClass` 保存四个按压状态；渲染线程为四个按钮维护独立 `BarUiValueClass` 按压比例。
- 画笔模式显示全部四项；荧光笔模式把三档透明度、光影和命中入口关闭，只保留箭头。
- 三档选择按当前显示整数与实际档位整数精确比较；选中档使用 `Accent` 内容与 `0.20` 背景，按下时背景透明度切换为 `0.10` 并缩放至 `0.95`，其他内容使用 `TextPrimary`。
- 三档圆点渲染使用各自 Shape `frame.val` 的当前动画色，不直接根据 `selected` 读取目标主题色，确保白色到青色与按钮其他视觉状态同步过渡。
- 所有按钮复用 `StartHover` / `StopHover`、按压 `0.95` 和释放回弹；选中档不叠加悬停。
- 主栏路径保持不变；绘制属性中的笔型按钮和四个粗细选择器共用主栏悬停状态机：驻留时按 `5s` 自然淡出，鼠标移出使用主栏的快速退出曲线。
- 按下时保留悬停层的当前透明度和填充色，再连续过渡到按下态，禁止先清零后重建造成闪烁或颜色跳变。
- 属性栏批次同步跳过 `animateWhenDisabled` 的独立悬停值，避免把显现或 5 秒淡出覆盖回默认操作时长。
- 三档配置 `PointLight` 且关闭主光，只在选中时设置 `frameLightPct`；箭头始终不启用边缘光影。
- 粗细区 Shape 不设置 `fill`，基础边框使用 `SurfaceFrame`、`framePct=0.18`，与绘制属性窗口保持一致；同时配置 `PointLight`、默认 `Frame` 光色并关闭第一主光源。
- 粗细区可见时独立设置 `frameLightPct=1.0`，第三光源强度系数使用与笔类型按钮相同的 `BarButtonCursorLightIntensity=0.30`；动态光影关闭后渲染器只绘制基础灰边。
- 软笔对象插入现有连续 Shape/SVG/Word 枚举范围，使展开、收起、上下换边和脏区循环自动覆盖，但不进入输入命中分支。

## 提示浮窗

- 使用内部描述表统一管理标注线和超限提示的徽标、叹号命中区、浮窗 Shape、文字、关闭 SVG 及 hover/pinned 状态。
- 标注线徽标高 `24px`，文字为 `13px`，叹号为 `14px`；超限徽标为 `24×24`。两者位于动画中的预览区域左上角和右上角，并保持 `5px` 内边距。
- 浮窗文字为固定两行、`12px`，通过 `IDWriteFactory::CreateTextLayout` 和 `GetMetrics` 计算逻辑宽高；统一使用 `8px` 内边距并始终预留 `14px` 关闭图标区域。
- 浮窗展开进度使用 `EaseOutBack / EaseInBack`，从叹号中心缩放；上下方向与预览一样从动画中的区域和控件相对位置推导。
- 两个目标矩形相交时，超限浮窗沿当前方向再平移自身高度加 `5px`；平移量随展开进度增长，起点仍为自己的叹号。
- 固定浮窗正文只消费点击，关闭图标在松手仍命中时关闭；hover 浮窗离开叹号后立即进入收起动画。
- `CloseDrawAttributeTooltips()` 统一清除 hover/pinned，供主栏/属性栏收起和未来粗细调节态调用；当前空箭头不调用。
- 新浮窗继续绘制在 Bar 的全屏 layered HWND 内，不新增窗口。`predicted` 在 `BeginDraw` 前包含浮窗当前边界与光影外扩，`current` 枚举覆盖新对象，旧/新并集负责清除收起残影。
- 叹号资源改用 Bar 主题色占位符；关闭 SVG 去除 SMIL 与 dash 动画，使用等价静态圆头 X。
