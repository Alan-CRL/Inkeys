# 实施计划

1. 扩展粗细 Shape/Word 枚举、悬停状态和按压状态，并加入单一三档 DPI 换算入口。
2. 将属性栏保持为 `370×185`，粗细区调整为 `240×105`；把颜色区下置坐标调整到 `y=115/150`，使窗口边缘、颜色区和粗细区的相关间隙统一为 `5px`。
3. 初始化三档与箭头按钮，添加调节箭头 SVG 工程资源，配置主题色、PointLight 参数和文字对象；粗细区取消填充，使用属性窗口同款 `SurfaceFrame` 基础灰边，并接入关闭第一主光、强度为 `0.30` 的默认色第三光源。
4. 重写粗细区渲染：以 `0 / 0.5 / 1` 连续形态值实现硬笔 S 形、圆头直线关键帧和方头荧光笔；曲率随粗细及面板展开比例衰减，荧光笔左端透明度连续变到 `0.35`。缓存稳定路径、圆头 stroke style 和渐变资源。
5. 扩展笔型连续 Shape/SVG/Word 枚举和统一布局/渲染列表：把原“画笔”改为“硬笔”，在其下新增复用毛刷轮廓的灰色禁用“软笔”占位项，不接入输入与绘制模式。
6. 将笔型和四个粗细按钮接入主栏一致的悬停状态机：驻留 `5s` 自然淡出、移出快速退出，并让按下态从当前悬停视觉连续衔接；三档圆点读取 Shape 当前动画色，避免选中时白色瞬间跳为青色；三档调用 `SetPenWidth()`，箭头保持无业务动作。
7. 核对硬笔/荧光笔切换、软笔禁用、自定义粗细无选中态、选中光影门禁、隐藏控件命中及现有记忆行为。
8. 核对属性栏初始化、收起终点与上下换边中点的根面板均为 `60×30` 且位于绘制按钮中心；颜色、粗细区和笔型控件每个动画属性每帧只提交一次最终目标，隐藏中点不读取运行中的 `val`；真实 px 预览仅在属性栏几何动画期间乘同一倍率，圆角和边框同步缩放。
9. 添加标注线和超限徽标、两个独立 hover/pinned 浮窗、静态关闭 SVG 与 DWrite 两行测量；实现锚点弹性展开、换边方向、同时显示错位、点击阻挡和统一关闭入口。
10. 将面板外浮窗及其第三光源加入 `predicted/current` 脏区，验证显示和收起均无裁剪或残影。
