# UI3 画笔粗细快速调节

## Goal

完善 UI3 绘制属性栏中尚未完成的粗细区域，提供三档画笔常用粗细、真实设备像素预览和未来连续调节入口，同时为后续自定义颜色与横向滑条保留稳定空间。

## Requirements

### 范围与布局

- 仅修改 UI3 Bar，不修改传统 `IdtFloating`、绘制引擎、配置和 i18n 资源。
- 绘制属性栏展开尺寸由 `335×150` 调整为约 `370×150`；现有色块坐标和右侧笔型按钮尺寸保持不变。
- 左侧粗细填充区扩大为约 `240×70`，内部保留约 `230px` 的横向预览/未来滑条行程，并在颜色区右侧预留一列自定义颜色空间。
- 收起、展开、上下换边、脏区和命中区域必须跟随新尺寸同步更新。

### 预览与文字

- 上半部按当前 `GetPenWidth()` 显示真实设备像素粗细，不乘 UI 配置缩放。
- 画笔显示横向圆头色带；荧光笔显示横向方头纯色色带。
- 粗细超出预览区时保留一圈内边距并撑满，不改变下方显示的真实数值。
- 下半部左侧显示“粗细 数值”，预留约 `90px`，按未来 `Thickness 999` 校核；本期不接入 i18n。
- 预览和标签使用主题前景色，兼容深浅主题。

### 三档与调节提示按钮

- 画笔模式显示 `1 / 3 / 6px` 三档和一个最右侧调节提示按钮，均使用 `30×30` 圆角命中区。
- 三档实际值为 `max(1, round(基础值 × barStyle.dpiZoom))`，只乘系统 DPI 倍率。
- 三档按钮内部圆形直径使用实际设备 px，不受 UI 配置缩放影响；超出按钮时缩到内边界，并显示真实数值。
- 调节提示按钮显示尖角向上箭头；本期仅提供悬停、按压缩小和取消反馈，松手不修改粗细。
- 荧光笔模式隐藏三档，只保留调节提示按钮。

### 状态与交互

- 当前显示整数等于某档实际值时选中该档；自定义值不匹配时三档均不选中，不覆盖现有记忆粗细。
- 三档在鼠标松手且仍位于按钮内时调用 `SetPenWidth()`；拖出取消。
- 未选中内容使用主题前景色，选中内容使用主题青色；不增加常驻选中填充。
- 仅选中档启用现有 Cursor PointLight 青色边缘光影；未选中档和箭头不显示边缘光影。
- 悬停、`0.95` 按压缩放、释放曲线和悬停抑制复用主栏按钮机制。

## Acceptance Criteria

- [ ] 属性栏约为 `370×150`，粗细区约为 `240×70`，现有色块与笔型按钮不被挤压或重排。
- [ ] 画笔圆头预览、荧光笔方头预览和下方数值正确反映当前实际粗细，且 UI zoom 不改变其设备像素粗细。
- [ ] 画笔三档按 `1 / 3 / 6 × 系统 DPI` 设置粗细；自定义粗细可保持三档均未选中。
- [ ] 荧光笔不显示三档，仅显示无业务动作的调节提示按钮。
- [ ] 四个按钮具备约定的悬停、按压、拖出取消行为，三档只有松手命中时修改粗细。
- [ ] 仅选中档显示青色内容和 Cursor PointLight 边缘光影；未选中档与箭头无边缘光影。
- [ ] 深浅主题及属性栏展开、收起、上下换边过程中无截断、重叠、残影或隐藏控件误命中。
- [ ] 完整 `InkeysRepo.sln` 的 `Debug | ARM64` 编译通过。

## Out of Scope

- 不实现未来 `1px–30px × 系统 DPI` 连续滑条或点击上方区域调节。
- 不增加自定义颜色，只保留一列空间。
- 不新增配置字段、i18n key、资源文件或公开 API。
- 编译与静态验证完成后不提交、不归档，等待人工视觉与手感验收。
