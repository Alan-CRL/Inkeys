# UI3 画笔粗细快速调节

## Goal

完善 UI3 绘制属性栏中尚未完成的粗细区域，提供三档画笔常用粗细、真实设备像素预览和未来连续调节入口，同时为后续自定义颜色与横向滑条保留稳定空间。

## Requirements

### 范围与布局

- 仅修改 UI3 Bar，不修改传统 `IdtFloating`、绘制引擎、配置和 i18n 资源。
- 绘制属性栏展开尺寸调整为约 `370×185`，新增高度等于一行 `30px` 笔型按钮加 `5px` 行间距；现有色块横向坐标和右侧笔型按钮尺寸保持不变。
- 左侧粗细区调整为约 `240×105`，与窗口边缘及颜色区统一保持 `5px` 间隙，并在颜色区右侧预留一列自定义颜色空间。
- 粗细区内部保持透明，不再绘制灰色填充；外框使用与绘制属性窗口相同的 `SurfaceFrame` 灰色基础边框。
- 右侧笔型列从上到下显示刷子、激光笔、荧光笔、硬笔、软笔；原“画笔”更名为“硬笔”，软笔位于其下方并与激光笔一样使用灰色禁用态，本期不接入绘制模式或点击。
- 属性栏位于主栏上方时，颜色区两行位于 `y=115/150`，使最后一行底边到窗口底边的距离与颜色块左边距同为 `5px`；粗细区增高后仍与颜色区保持 `5px`。
- 收起、展开、上下换边、脏区和命中区域必须跟随新尺寸同步更新。
- 收起态按 `370:185` 等比缩为 `60×30`，中心与绘制按钮中心重合；面板、内部控件、圆角、边框和粗细预览在动画中使用同一几何倍率。
- 收起和展开时，内部控件的最终坐标与尺寸按 `370:185 → 60:30` 的固定倍率等比变化；每个动画属性每帧只提交一次最终目标，不得通过连续 `SetTar()` 追加偏移。上下换边的隐藏几何必须限制在绘制按钮中心的 `60×30` 紧凑面板内，不使用运行中的 `val` 反推中点。

### 预览与文字

- 上半部按当前 `GetPenWidth()` 显示真实设备像素粗细，不乘 UI 配置缩放；静止展开态保持点对点，展开、收起和换边动画期间随面板统一缩放。
- 硬笔及未来软笔、激光笔显示完全不透明的横向 S 形墨迹；四点依次为左下、`1/3` 上、`2/3` 下、右上。
- S 形曲率随墨迹变粗和面板收起逐步减小，超出可用高度时成为撑满预览区的圆头直线。
- 硬笔与荧光笔切换使用连续形态值：硬笔先变成圆头直线，再连续改变粗细、圆角、位置和透明度渐变成为荧光笔；反向切换和中途反转不得跳变。
- 荧光笔显示横向方头色带，透明度从左端 `0.35` 线性渐变到右端 `1.0`。
- 粗细超出预览区时保留一圈内边距并撑满，不改变下方显示的真实数值。
- 属性栏位于主栏上方时，下半部左侧显示“粗细 数值”并与粗细按钮共享水平中心线，控件距粗细区底部 `5px`；墨迹位于上方。
- 属性栏换到主栏下方时，粗细区内部上下镜像：“粗细 数值”和按钮移到顶部并距边缘 `5px`，墨迹移到下方；调节提示箭头旋转 `180°` 朝下。
- 墨迹左端与粗细文字左端对齐，右端按粗细外框取相同内边距，使墨迹水平居中；竖直方向在控件行与另一侧边缘之间按相同安全间隙居中。
- 预览和标签使用主题前景色，兼容深浅主题。

### 三档与调节提示按钮

- 画笔模式显示 `1 / 3 / 6px` 三档和一个最右侧调节提示按钮，恢复使用 `30×30` 圆角命中区；按钮右端继续与墨迹预览右端对齐。
- 三档实际值为 `max(1, round(基础值 × barStyle.dpiZoom))`，只乘系统 DPI 倍率。
- 三档按钮内部圆形直径使用实际设备 px，不受 UI 配置缩放影响；超出按钮时缩到内边界，并显示真实数值。
- 调节提示按钮使用随程序打包的 Material Symbols Expand Less SVG，实际可见大小约为原手绘箭头的 `75%`；本期仅提供悬停、按压缩小和取消反馈，松手不修改粗细。
- 荧光笔模式隐藏三档，只保留调节提示按钮。

### 状态与交互

- 当前显示整数等于某档实际值时选中该档；自定义值不匹配时三档均不选中，不覆盖现有记忆粗细。
- 三档在鼠标松手且仍位于按钮内时调用 `SetPenWidth()`；拖出取消。
- 未选中内容使用主题前景色；选中档使用主题青色内容、半透明青色背景和现有 Cursor PointLight 边缘光。
- 粗细预设圆点从未选中白色切换到选中青色时，必须读取 Shape 的当前动画色连续过渡，不能在按下或选中判定生效时瞬间跳色。
- 仅选中档启用现有 Cursor PointLight 青色边缘光影；未选中档和箭头不显示边缘光影。
- 粗细区外框关闭第一主光源，并始终支持默认边框色的 Cursor PointLight；第三光源最大强度与笔类型按钮一致，动态光影关闭时只保留基础灰边。
- 悬停、`0.95` 按压缩放、释放曲线和悬停抑制复用主栏按钮机制。
- 绘制属性中的笔型按钮、三档粗细按钮和调节箭头使用与主栏一致的悬停状态机：驻留时按 `5s` 自然淡出，鼠标移出快速退出。
- 悬停转按下时必须从当前背景颜色和透明度连续过渡，不得先清零造成闪烁或颜色跳变。

### 预览提示与浮窗

- 预览区左上角显示半透明“标注线”徽标，仅硬笔、荧光笔及未来软笔可见；徽标保持禁用笔型颜色，本期不实现标注线功能。
- 预览区右上角仅在真实设备像素粗细超过完全展开容量时显示白色叹号徽标；收起和换边临时缩放不得误触发该提示。
- 两个叹号分别支持 hover 临时浮窗和点击固定浮窗；固定后显示关闭 SVG，点击关闭、主栏收起或绘制属性收起时消失。
- 浮窗允许超出绘制属性边框，但必须限制在 Bar 全屏窗口内；上下方向从动画中的锚点位置推导，换边过程不得跳变。
- 两个浮窗可以同时显示；相交时第二个沿当前弹出方向错开一个浮窗高度加 `5px`。
- 浮窗使用固定两行文案并由 DWrite 实测宽高，不做自动换行；正文不得把点击穿透到下层按钮。
- 绘制属性窗口、两个徽标和浮窗均使用 `0.80` 背景不透明度；徽标与浮窗使用与绘制属性窗口相同的 `Surface` 背景色，保留 `SurfaceFrame × 0.18` 基础边框及笔型按钮同强度第三光源。
- 浮窗完整位于叹号徽标上方，倒转布局时完整位于下方，并与徽标外边缘保持 `10px` 间隔。
- 浮窗以 source-over 叠加绘制，不得先把圆角区域擦为透明；徽标最后覆盖浮窗，使展开动画从按钮下层出现。
- 粗细超限徽标在本轮视觉验收期间临时常显，验收完成后恢复为仅真实粗细超限时显示。
- 本期粗细调节箭头仍无业务动作，也不关闭浮窗；只预留未来进入滑块调节态时统一关闭浮窗的入口。

## Acceptance Criteria

- [ ] 属性栏约为 `370×185`，粗细区约为 `240×105`；颜色块外边距、粗细区外边距及两区间距在上下两种方向均为 `5px`。
- [ ] 上下换边后粗细文字、按钮和墨迹预览完成镜像布局，箭头方向旋转 `180°`，没有重叠或错位。
- [ ] 笔型列包含灰色禁用的软笔占位项，位于硬笔下方；硬笔仍映射原画笔模式，软笔不可命中。
- [ ] 画笔圆头预览、荧光笔方头预览和下方数值正确反映当前实际粗细，且 UI zoom 不改变其设备像素粗细。
- [ ] 硬笔预览为四点横向 S 形，变粗或收起时平滑变直；与荧光笔双向切换及中途反转没有形态、圆角、位置或透明度跳变。
- [ ] 荧光笔预览从左端 `0.35` 透明度平滑渐变到右端 `1.0`；其他笔型预览保持全段 `1.0`。
- [ ] 画笔三档按 `1 / 3 / 6 × 系统 DPI` 设置粗细；自定义粗细可保持三档均未选中。
- [ ] 荧光笔不显示三档，仅显示无业务动作的调节提示按钮。
- [ ] 四个按钮具备约定的悬停、按压、拖出取消行为，三档只有松手命中时修改粗细。
- [ ] 点击未选中的粗细档位时，圆点从主题前景色连续动画到青色，不发生瞬时跳色。
- [ ] 仅选中档显示青色内容和 Cursor PointLight 边缘光影；未选中档与箭头无边缘光影。
- [ ] 粗细区内部完全透明，基础灰边与绘制属性窗口一致；动态光影开启时显示与笔类型按钮同强度的默认色第三光源，关闭时仍保留基础灰边。
- [ ] 深浅主题及属性栏展开、收起、上下换边过程中无截断、重叠、残影或隐藏控件误命中。
- [ ] 收起态为 `60×30` 并位于绘制按钮中心，展开、收起及换边中点没有旧 `60×60` 初值、非等比粗细预览或圆角跳变。
- [ ] 属性栏位于主栏上方时，展开和收起过程中颜色块始终从上方收拢，不穿过绘制按钮出现在主栏下方；上到下与下到上的换边关键帧轨迹对称。
- [ ] 完整 `InkeysRepo.sln` 的 `Debug | ARM64` 编译通过。
- [ ] 两个叹号徽标、临时/固定浮窗、关闭按钮、同时显示错位和收起关闭行为符合约定，面板外浮窗无裁剪或残影。

## Out of Scope

- 不实现未来 `1px–30px × 系统 DPI` 连续滑条或点击上方区域调节。
- 不实现标注线方向约束，只显示禁用入口和说明。
- 不增加自定义颜色，只保留一列空间。
- 除调节箭头、叹号和静态关闭 SVG 外，不新增配置字段、i18n key、其他资源文件或公开 API。
- 编译与静态验证完成后不提交、不归档，等待人工视觉与手感验收。
