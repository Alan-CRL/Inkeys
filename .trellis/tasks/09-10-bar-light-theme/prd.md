# Bar 浅色主题与收展材质过渡

## 目标

延续现有布局、尺寸、圆角、SVG 和交互，以冷雾白、石墨灰、青绿色建立浅色 Bar；主栏收起为单个入口时，在同一动画过程中自然变为深色悬浮主按钮。用户可在设置的“常规 > 外观”中持久化选择深色或浅色模式，并让运行中的 Bar 立即完成动态主题过渡。

## 背景与约束

- 用户同意创建任务，并确认从 draw 的 `4478887cbafe5aaad2a23d76ca5a5490f1c1e655` 创建 `theme`，排除当时 draw 未提交改动；随后按用户要求删除临时 `theme-worktree`，当前在 `Inkeys-draw` 工作树的 `theme` 分支继续实施。
- `Bar.Theme.cppm` 已有深浅角色，`Bar.State.cppm` 通过 `requestedDarkStyle` 向串行渲染线程发布主题目标；当前 `Bar.Initialization.cpp:230-255` 从 Windows `AppsUseLightTheme` 初始化并响应系统主题消息，尚未接入产品配置。
- `Other.Config.cppm` 的 schema 已支持 `IdtAtomic<int>` 自动读写，现有 UI3 配置位于 `Experimental.Inkeys3.UI3`；`IdtMain.cpp:1372-1405` 在 Bar 启动前完成 `config.ReadAll()` 和 UI3 选项绑定。
- 设置页“常规 > 外观”位于 `Setting.cpp:3142-3359`，已有 `Widgets::combo`、`QueueConfigWrite()` 和 Bar 实时设置入口可复用；三份 i18n JSONC 已有未投入使用的 `Appearance.Theme` 文案槽。
- 当前主按钮用 logo1/logo2 和 Frame94 叠加，Frame94 会同时着色笔和屏幕；PointLight 直接从边框色生成光色。
- 本地未找到 UI(4).zip；现有 `Inkeys/src/UI/` 包含所述 logo、Frame 94 和整套 Bar 图标，以这些现有资源为几何基准。
- 保持原文件编码、BOM、换行，关键步骤使用简短中文注释。仅静态检查、完整构建与无窗口测试，不启动 GUI、不操控桌面、不提交 commit。

## 需求

### R1 浅色角色与配置入口

表面约 `#F4F6F7`，提高不透明度；普通图标约 `#53616A`、主文字约 `#3D474D`、选中内容约 `#006F68`、选中底板约 `#D7EEEA`。边框和分隔线为浅中性灰。表面、边框、分隔线、图标、文字、选中底板/内容、动态光、静态阴影分别拥有角色。Hover/Pressed 延续既有交互，只调整配色与必要透明度。

在 `Inkeys.Other.Config` 的 `Experimental.Inkeys3.UI3` 注册整数主题模式，JSON 路径为 `Experimental.Inkeys3.UI3.ThemeMode`：`1` 表示深色，`2` 表示浅色，默认值为 `1`。启动时以该配置为唯一主题来源；缺失、类型不符或超出 `1/2` 的值按深色 `1` 处理，Windows 系统主题改变不覆盖用户选择。

设置页“常规 > 外观”新增一个与现有卡片样式一致的下拉框，只提供“深色模式”和“浅色模式”。打开设置时显示当前配置；选择后立即更新内存配置、请求 Bar 主题动画并异步写回配置文件。该入口切换 Bar 及其所属浮层材质，不重做设置窗口本身的主题系统。

### R2 普通 SVG

选择、绘制、清空、更多、定格及其余普通 SVG 只 recolor，不改 d/points/viewBox/原始几何，不换图标族或改用位图。

### R3 主按钮颜色指示

- Light 下整支笔显示真实当前画笔 RGB，不加小色块/圆点、不只着色局部；黑、白、浅黄和自定义色均可辨认。
- 主笔允许为分层和外轮廓调整 SVG 结构，但保留造型与分段空隙；细深色边只沿完整 silhouette 的真正外轮廓，内部断开处不能出现横向黑线，黑笔避免显得过粗。
- 后面的屏幕独立为中性浅灰，不随笔色改变。
- Dark Floating 使用适合深色表面的明亮饱和对应色，真实绘图色和颜色预设不变；普通笔、荧光笔、图形、激光的颜色来源不能相互污染。选择/橡皮状态的入口保留记忆笔色；图形工具明确使用 Brush1，不能被记忆激光色污染。

### R4 全材质收展

Light 展开时主按钮和主栏统一雾白；完全收起时主按钮呈现与既有 Dark 基本一致的半透明背景、边框、静态光影、鼠标动态边缘光及 PointLight。背景 RGB/alpha、边框 RGB/alpha、阴影、高光、动态光 RGB/强度、笔色表现均随收展动画连续变化，展开反向执行。不得最后一帧突变。快速反向、动画关闭、首次显示、运行中切换主题有一致端点，不能被逐帧重设 target 阻滞。保持换边、拖动、DPI、底部吸附、命中和成功呈现事务。

### R5 光影

Light 使用细浅灰轮廓、弱近距离方向阴影、柔和环境阴影和少量顶部高光；鼠标光为白色/浅灰反射，只轻混笔色。不以深色边框生成光源、不产生黑色 glow 或饱和笔色整圈污染。每对象决定材质，主按钮收展不能误染其他浮层/分页。光影边界纳入 dirty/viewport，静止恢复 idle，设备重建可恢复。

### R6 设置文案与兼容

简体中文、繁体中文和英文均提供主题名称、说明及两个选项；通过现有 i18n 生成脚本同步 `IdtI18nKeys.g.h`。旧版没有 `ThemeMode` 的配置自然采用默认深色；不复用旧 `SetSkinMode`，避免把 Bar 明暗主题与历史皮肤选择混为同一持久化合同。

## 验收标准

- AC1：Light 角色色和较高表面不透明度正确，Dark 原有端点保留。
- AC2：除主按钮相关资源外，普通 SVG 几何与基点一致。
- AC3：黑、白、浅黄、红、蓝及自定义笔色下整笔色正确、屏幕不染色、内部空隙无横向描边。
- AC4：收展 0%、25%、50%、75%、100% 时背景、边框、阴影、高光、PointLight、鼠标光、指示器连续；反向从当前值接续。
- AC5：ARM64 host MSBuild 完整构建 InkeysRepo.sln Debug|ARM64 通过，超时至少五分钟；InkeysHeadlessTests.exe --no-window 通过。
- AC6：静态和必要的无窗口生产策略/离屏资源检查覆盖角色、真实色/显示色隔离、材质端点/插值、反向/禁用动画、光效范围、SVG 几何、编码和换行；未做 GUI 视觉验收如实说明。
- AC7：本次差异仅位于当前 `Inkeys-draw` 工作树的 `theme` 分支，不提交 commit。
- AC8：`ThemeMode` 缺失时为 `1`；有效值 `1/2` 可完整读写，非法值归一到 `1`，且启动结果不受 Windows `AppsUseLightTheme` 影响。
- AC9：“常规 > 外观”显示深色/浅色下拉框；选择 `1` 或 `2` 后无需重启即可触发已有连续主题动画，并异步写回配置。
- AC10：中、繁、英文文案和生成键一致；主题切换不改变主栏收展、笔色指示、动态光影、设置页其他选项及历史 `SetSkinMode` 行为。

## 范围之外

不重设计布局、普通图标或动画节奏，不改变真实笔迹/算法、底部吸附、窗口/输入架构或设置窗口自身外观。分页仅维持共享接口兼容，不主动扩展独立主题改造；不新增“跟随系统”第三个选项，也不迁移或删除历史 `SetSkinMode`。
