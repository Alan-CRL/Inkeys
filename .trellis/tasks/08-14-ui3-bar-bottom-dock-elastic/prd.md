# UI3 Bar 底栏模式与弹性吸附

## Goal

让 UI3 Bar 每次启动都以稳定、美观且高性能的底栏形态出现，并在悬浮与底栏之间提供连续、无坐标跳变的双向弹性吸附。

## Requirements

- 每次启动默认为底栏模式、主栏展开；主按钮位于左侧，主栏向右展开，完整可见主体在活动显示器上水平居中。
- 底栏模式以实际绘制边框的外侧底端对齐底部任务栏上沿；没有底部任务栏或任务栏自动隐藏时对齐显示器底端，不以窗口、viewport、dirty 或阴影边界定位。
- 底栏可折叠；折叠不退出底栏。底栏横向拖动只保证主按钮完整可见，允许展开主栏越出显示器；抬手后主按钮越过活动显示器中轴线时，主栏按悬浮窗同一关键帧换向。
- 悬浮栏可从 dock 线两侧进入 20 DIP 捕获区；底栏抓取点离开稳定位置超过 20 DIP 后进入悬浮模式。阈值按 `barStyle.zoom` 转换一次。
- 吸附和脱离保持鼠标、触摸、窗口直移、ULW 提交及渲染线程布局吸收之间的屏幕位置连续，快速跨阈值和 x 反向不得跳变。
- 捕获时上边界连续、下边界弹向 dock 线；从上方接近拉伸，从下方接近压缩。底栏内向下拖动压缩、向上拖动拉伸，脱离后连续恢复正常高度。
- 主栏、主按钮及普通按钮的背景、图标、文字统一纵向形变；主图标不再作为刚性抓手单独绘制。
- 已打开的绘制属性、更多、颜色和粗细等次级面板保持打开、位于主体上方，仅刚性平移而不形变。
- 弹性阶段保留既有边框光效与阴影语义，只更新相关局部 dirty；不得逐帧重建图形资源或扩缩渲染 capacity。按住拖动时即使鼠标静止也不得收缩 HWND，抬手后才允许按最终形态收敛并恢复 idle。
- 显示器、DPI、配置 zoom 或 work area 改变时，底栏保持当前 x 并重新对齐新的 dock 线；悬浮模式沿用现有显示过渡。
- 不增加配置项或位置持久化，不恢复 UI2，不专门处理自动隐藏任务栏 AppBar 状态。

## Acceptance Criteria

- [x] 底部、顶部、侧边、无任务栏和自动隐藏等 work-area 组合均得到正确 dock 线，稳定态可见边框误差不超过 0.5 物理像素。
- [x] 100%、150% DPI 与配置 zoom 下，吸附 `<=20 DIP`、脱离 `>20 DIP`，阈值无重复缩放。
- [x] 启动主体居中、主按钮在左、主栏展开向右；折叠/展开不改变 dock 状态或 x。
- [x] 上下方向吸附/脱离分别产生规定的拉伸或压缩；主按钮与普通内容随主体形变，次级面板保持刚性。
- [x] 鼠标与触摸对相同屏幕采样产生相同状态；跨阈值、反向、viewport 改变和直移吸收不产生位置跳变。
- [x] 吸附或脱离手势不会误判为主按钮点击；普通小位移点击行为保持不变。
- [x] 弹性阶段只预留一次包络并局部重绘；回弹达到距离/速度阈值后不再请求帧。
- [x] `git diff --check`、全部 `InkeysHeadlessTests --no-window` 和完整 `InkeysRepo.sln` `Debug | ARM64` 构建通过。
