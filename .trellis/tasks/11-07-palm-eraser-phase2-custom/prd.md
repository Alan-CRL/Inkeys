# 手掌橡皮擦除样式与大小自定义设置（子任务 B-b）

父任务：`11-07-palm-eraser-phase2`（决策 D4、D8、D9、D10）。**依赖** `11-07-palm-eraser-phase2-shapes` 的形状枚举、几何、光标与 `EraserStylePicker` 控件；在其完成后实施。

## 需求

| ID | 要求 |
| --- | --- |
| R1 | 设置-手掌橡皮新增“擦除样式”：三种样式预览 + 内联下拉，选项“跟随默认”（默认）/圆形/竖长矩形/正方形。“跟随默认”取普通橡皮的擦除样式。 |
| R2 | 新增“手掌橡皮大小”分组，条目一“粗细计算方式”：动态粗细（默认；选中时下方 i 提示“跟随接触面积计算”）／固定粗细（跟随默认橡皮：默认大小，全局“自动粗细”开启时按笔速变化）／固定粗细（不支持笔速橡皮：恒为默认大小）。全局自动粗细是笔速橡皮总开关，关闭时第二项即固定默认大小。 |
| R3 | 条目二“大小计算方式”（动态粗细时有效），选项随生效形状变化，各自推荐项标注“（推荐）”并为默认：见下表。每种形状分别记住选择。 |
| R4 | 条目三：滑块 + 无文字重置按钮，仅动态粗细时显示；倍率作用于边长/直径，25%–300%，默认 100%。 |
| R5 | 识别逻辑与阈值不变（识别面积 W×H、阈值/倍率语义、长宽比 ≤3.5、观察窗、锁定、续接）。新倍率命名须与现有“识别面积倍率”区分。 |
| R6 | 手掌为矩形/正方形时，屏蔽范围（子任务 A 的接口）随形状：橡皮矩形每侧外扩 `max(该方向半边长×0.15, 4px)`。 |
| R7 | 配置新增项严格校验、有默认值；i18n 覆盖全部语言。 |

大小计算方式（W、H 为已换算的接触矩形画布 px 宽高）：

| 形状 | 选项（首项为推荐默认） | 结果 |
| --- | --- | --- |
| 圆形（直径 D） | 接触矩形内切椭圆等面积 / 矩形等面积 / 内切圆 / 外接圆 | `√(WH)` / `2√(WH/π)` / `min(W,H)` / `√(W²+H²)` |
| 竖长矩形（宽 w，高 1.5w） | 矩形等面积 / 接触矩形内切椭圆等面积 / 内切矩形 / 外接矩形 | `√(WH/1.5)` / `√(πWH/6)` / `min(W, H/1.5)` / `max(W, H/1.5)` |
| 正方形（边 s） | 接触矩形内切椭圆等面积 / 矩形等面积 / 内切正方形 / 外接正方形 | `√(πWH)/2` / `√(WH)` / `min(W,H)` / `max(W,H)` |

## 验收

- AC1：各形状各方法对给定 W×H 的尺寸数值正确（含 100×100、160×90、极端长宽比边界）；倍率 25%/100%/300% 线性作用于长度。
- AC2：三种粗细方式行为正确；全局自动粗细关闭时“固定粗细（跟随默认）”为固定默认大小。
- AC3：“跟随默认”随普通橡皮样式即时生效（下次 Down 锁存）；手掌光标与擦除形状一致。
- AC4：矩形手掌的屏蔽范围随形状；圆形保持原公式。
- AC5：识别阈值、预览矩形、既有手掌行为回归通过。
- AC6：设置在 20 语、七种缩放、浅深主题、窄/宽布局下无截断重叠；条件显示正确；配置非法值回落默认。
- AC7：完整构建、Palm/设置 Headless、`--draw3-palm-eraser-test` 通过；实机未测项单列。
