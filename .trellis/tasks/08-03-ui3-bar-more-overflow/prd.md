# UI3 主栏更多溢出区

## Goal

为 UI3 主栏 B 区增加固定的“更多”入口，使主栏只保留最多两个普通 B 区按钮，其余按钮在紧凑浮层中继续可用，并把“设置”默认放入该浮层。

## Background

- 当前 UI2/UI3 并行期，UI3 的 B 区由 16 个旧组件开关投影，运行时明确忽略持久化 `UI.Bar.ExtensionButtons`。
- A2 当前 required 集合包含 `Pierce`、`Freeze`、`Setting`；本任务需要把 `Setting` 移出 A2。
- 主栏已有绘制属性和几何浮层、2x2 按钮网格、SVG 动画、PointLight 边框及关闭按钮实现可复用。

## Requirements

- 在 B 区末端、A2 前固定一个硬编码“更多”按钮；它不进入配置或普通按钮注册表，主栏折叠时隐藏。
- B 区最多显示两个普通按钮；多出的标识前按钮进入强制溢出组，标识后的按钮进入显式更多组。
- 增加无实体布局标识 `Inkeys.Bar.MoreBoundary`。配置允许没有标识；标识最多一个且不能产生可点击按钮。
- 新配置默认 `ExtensionButtons` 为 `MoreBoundary + Setting`，A2 默认和 required 集合只保留 `Pierce + Freeze`。
- 当前运行时仍使用旧组件开关，并虚拟组成“旧组件 + MoreBoundary + Setting”；不得读取、规范化或写回用户现有 `ExtensionButtons`。
- 旧组件首次按稳定注册顺序排列；运行中关闭后移除，新增或重新启用的按钮追加到末尾。
- “更多”内越晚加入的按钮越靠近主栏；设置默认位于最远端。仅在标识存在且强制溢出组、显式更多组都非空时显示横向分割线。
- 浮层采用 70x70 标准单元和主栏相同的 `twoTwo/twoOne/oneTwo/oneOne` 子网格排布，近方形布局，最多五列。
- 浮层不因主栏左右换边而反转逻辑顺序；上下展开时调整物理行方向，保持最新项靠近主栏。
- 浮层复用现有 UI3 Surface、PointLight、关闭按钮和绘制属性面板的默认操作时长；几何使用 Back 回弹、透明度使用 Sine 曲线，并在主栏下层从 More 按钮中心展开；点击外部、X、折叠主栏、打开互斥面板或执行默认按钮动作时关闭。
- 按钮结构增加 `closeMoreAfterAction`，默认 `true`，允许未来按钮保持浮层打开。
- 关闭 X 位于按钮网格右侧窄栏的右上角，不增加顶部高度，并具有悬停填充和按下缩小效果。
- “更多”按钮的内嵌 SVG 三角略微缩小且保持固定朝向；打开时入口使用 Selected 状态与青色高亮。

## Acceptance Criteria

- 旧配置启动后设置不再位于 A2，且仍能从“更多”执行；用户已有 `ExtensionButtons` 内容保持不变。
- 0、1、2 个旧组件启用时主栏分别显示 0、1、2 个普通 B 按钮；3 个及以上时仅前两个上栏，其余出现在浮层。
- 组件关闭后主栏自动补位；重新开启后该组件位于更多栈的最新位置。
- 默认仅设置时浮层紧凑且无分割线；同时存在强制溢出和显式更多项时显示一条整行横线。
- 混合小按钮按主栏子网格排列，面板列数不超过五，按钮不会重叠或因左右换边反序。
- X、外部点击、主栏折叠、互斥面板和默认按钮动作均按要求关闭浮层；覆盖元数据为 false 的按钮不会关闭。
- 三角保持固定朝向且尺寸略小；打开时入口显示 Selected 状态和青色高亮，快速连续切换不出现旋转或颜色跳变。
- 浮层按钮在隐藏时完成 Selected 青色同步，展开过程不再从旧颜色渐变。
- 浮层内容在展开与收起过程中保持等比缩放；收起后按钮停留在 More 入口下方，主栏补位时不从远端飘入。
- 两组之间的分割线延伸到面板最右侧内边距，不因 X 侧栏缩短，左右间距一致。
- `git diff --check` 通过，ARM64 host MSBuild 完整构建 `InkeysRepo.sln` 的 `Debug | ARM64` 通过。

## Out Of Scope

- 本任务不实现用户拖拽、排序、显隐或尺寸编辑 UI。
- 不启用持久化 `ExtensionButtons` 的运行时消费，不改变 UI2 的组件容量与行为。
- 不新建 UI 自动化测试框架，不重构无关的 UI3 渲染、线程或资源生命周期。
