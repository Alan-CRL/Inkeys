# Inkeys3 中期重构总任务

## Goal

统筹 Inkeys3 中期重构的六步路线：先建立可诊断的日志基座，再逐步整理 UI3 分层、Win7 ULW 呈现、输入后端、多画布与窗口架构以及 Draw3 4K 性能。总任务持有来源需求、任务地图、跨子任务约束和最终集成验收；本身不直接作为实现目标。

## 跨子任务约束

- 兼容性：Windows 7 SP1 + KB2670838；MSVC v143 / C++20；PptCOM 保持 .NET Framework 4.0、AnyCPU。
- 依赖稳定：不在重构中顺带升级 vcpkg baseline / spdlog / fmt；一次只变动一个变量。
- 最小化修改：每个子任务只改自身范围，发现的其他问题记录到对应步骤，不顺手修复。
- 性能：Draw3 绘制/输入热路径不得因日志或诊断引入阻塞。
- 构建验证：`InkeysRepo.sln`，`Debug | ARM64`，ARM64 原生 MSBuild。

- [ ] 每个已建子任务都有可独立验证的验收标准，并在完成后归档。
