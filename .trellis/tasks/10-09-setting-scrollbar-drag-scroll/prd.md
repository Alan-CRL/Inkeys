# 设置侧栏滚动条与旧版按住拖动复用

## Goal

在父任务 setting-winui3-design-rebuild 下完善设置窗口滚动体验：侧栏中段使用统一垂直滚动条，设置中的可滚动区域复用 settingui2 的触摸/鼠标按住内容拖动。

## Requirements

- 侧栏中间树形导航段仅在有竖直滚动范围时显示垂直滚动条，沿用设置界面的统一主题与样式。
- 滚动条出现时，中段普通导航按钮、通用父项及子项的绘制与可点击区域同时缩短，并与滚动条保留间距；无滚动条时保持当前宽度。
- 顶部与底部固定区域保持现有布局和操作，滚动条只属于中段；展开、紧凑及覆盖导航均适用。
- 设置界面所有实际可滚动区域支持触摸/鼠标按住内容拖动，原样复用 settingui2 的已有实现；不得自行新增 Win32 消息、触摸转换或新手势算法。
- 保留旧算法对点击、控件操作和拖动的处理规则，保持当前滚轮、滚动条、键盘导航、侧栏蓝条以及页面路由与配置保存兼容。
- 直接在当前 fluent 工作区最小修改，保持原编码、BOM、换行和格式，在关键边界添加简短中文注释。

## Acceptance Criteria

- [ ] 竖直溢出时侧栏中段出现统一滚动条；没有竖直滚动范围时隐藏，不出现额外横向滚动。
- [ ] 滚动条与全部中段导航按钮/子项的实际命中范围之间有间距，不会点击滚动条同时激活导航项。
- [ ] 动态展开/折叠、窗口高度变化及多个缩放倍率中，滚动条显隐、按钮宽度和末项可达性正确；固定顶部/底部不随中段滚动。
- [ ] 明确记录 settingui2 原实现的文件/版本、原代码及现有对应调用路径；最终算法与旧代码一致，仅进行必要命名/调用上下文迁入。
- [ ] 当前设置中的实际可滚区域都使用该旧实现，触摸/鼠标按住内容拖动、释放和边界行为有真实 ImGui 无窗口回归；保持原点击/控件行为。
- [ ] 侧栏蓝条与实际滚动同步；普通导航与 Debug 的既有切换回归继续通过。
- [ ] 完整 InkeysRepo.sln Debug|ARM64、完整 --no-window、国际化、编码/换行及 git diff --check 通过，并由 trellis-check 独立核对。

## Validation Boundaries

不启动 GUI 或 Computer Use，不自动 commit/push。本轮触摸输入验证复用 ImGui 现有无窗口输入路径；真实桌面触摸/鼠标观感留待人工验收并单独记录。父任务继续 in_progress，本子任务先完成研究和设计审查再进入实施。
