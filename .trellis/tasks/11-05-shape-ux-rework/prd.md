# 图形交互与样式整改

## Goal

P3/P4 推进过快，图形功能在实机上问题很多。本任务先解决用户提出的几项大问题，并顺带做一些相关优化：

- 主栏图形面板过大；
- 编辑拖动跟不上手；
- 编辑框、浮条、提示的样式与动画不符合主栏 UI3 规范；
- 各图形的控制点交互不合理；
- 深浅主题和常驻透明度没有适配。

## 跨子任务要求

- X1 深色、浅色主题都要适配，所有新增或修改的视觉元素在两种主题下都要验收。浅色主题接入 lightMaterial、themeSurface 和投影规则。
- X2 常驻透明度（用户确认 V4）：
  - 编辑浮条、绘制提示：背景透明度和内容透明度都跟随设置（`Experimental.Inkeys3.UI3.BackgroundOpacity/ContentOpacity`）。
  - 外框、控制点、旋转钮：只跟随内容透明度。
  - 色板层、取色器层，以及主栏图形面板：按弹出层处理，固定 0.95。
  - 设置变化或主题切换后要立即重绘。
- X3 统一按主栏 UI3 规范绘制：按钮、list、分割线、0.4s 动画批次、回弹面板 motion 都复用主栏实现，不另写局部样式。
- X4 能用图标看懂的按钮只显示图标，以免文字放不下。
- X5 不新增 HWND，不新增窗口线程；保持 Win7/10/11 兼容；普通笔的性能路径不退化。
