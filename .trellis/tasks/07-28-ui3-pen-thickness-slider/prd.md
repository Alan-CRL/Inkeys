# UI3 墨迹粗细连续滑块

## Goal

在 UI3 绘制属性的既有粗细预览区中加入可悬停预览、可固定、可全局相对拖动的连续粗细滑块，让硬笔和荧光笔能快速、线性地调整实际设备像素粗细，同时保持现有布局、提示徽标和形态动画连续、美观。

## Requirements

### 范围与依赖

- 仅修改 UI3 Bar，不修改传统 `IdtFloating`、绘制引擎、设置页、配置结构、i18n 或墨迹粗细记忆规则。
- 本任务是 `07-27-ui3-pen-thickness-presets` 的独立后续任务；复用其粗细区域、硬笔/荧光笔连续预览、三档按钮、调节箭头、提示徽标和统一浮窗关闭入口，不回写前序任务的范围。
- 滑块只对当前可用的硬笔和荧光笔显示；未来软笔、激光笔接入不属于本任务。

### 出现、固定与恢复

- 滑块激活区域为粗细框中的预览区域，不包含“粗细 数值”和下方按钮行；上下倒转后命中区域随镜像布局移动。
- 指针进入激活区域时临时显示滑块；未固定且未拖动时，指针移出后恢复普通墨迹预览。
- 点击预览区域或点击调节小三角会固定滑块，并让小三角进入与既有选中按钮一致的青色选中态。
- 点击小三角再次取消固定；绘制属性或主栏收起时也取消固定、悬停和拖动状态。点击已固定的预览区域不会关闭滑块。
- 单击预览区域且不发生水平拖动时只固定滑块，不改变当前粗细。
- 进入滑块态时关闭已经打开的标注线和粗细超限提示浮窗；两个徽标仍保持原位置和可见性，本任务不重新设计其视觉。

### 相对拖动

- 在预览区域按下后不松手并左右移动时，以按下瞬间的粗细和屏幕横坐标为基准按相对位移调整；滑块圆点不跳到指针位置，也不要求始终位于指针正下方。
- 按下后的同一次手势既可完成固定，也可直接开始相对拖动；没有位移的点击不改值。
- 拖动期间捕获当前鼠标/触摸序列，指针移出粗细区域或 Bar 窗口后仍继续接收位移，直到抬起、捕获丢失、模式切换或属性栏收起。
- 相对位移映射到完整滑轨行程并在线性范围内钳制；到达端点后继续向外移动不越界，反向移动可立即离开端点。
- 拖动中即时更新粗细和预览，但不在每个移动事件写入记忆；手势结束时只提交一次最终值。

### 数值范围

- 硬笔范围为 `1px–30px × barStyle.dpiZoom`。
- 荧光笔范围为 `30px–100px × barStyle.dpiZoom`，与现有设置页 `100px` 上限保持一致。
- 两种笔型都使用线性映射，并取最近的整数设备像素；UI 配置缩放只改变滑轨和圆点的视觉尺寸，不改变数值范围。
- 进入滑块态时若当前值在范围外，只把圆点显示位置钳制到最近端点，不因悬停或固定自动改写当前值；首次实际拖动后才进入有效范围。

### 视觉与动画

- 普通预览到滑块轨道使用同一套连续几何动画，不切换为会跳变的独立预览分支。
- 硬笔预览逐步拉直并变为水平居中的 `4px` 高圆头强调色轨道；荧光笔同时把渐变平滑收敛为纯色，并变为相同的 `4px` 高圆头轨道。
- `4px` 为 UI 逻辑尺寸，随 Bar 总 UI 缩放和绘制属性展开/收起几何一起缩放；滑块数值仍只随系统 DPI 变化。
- 轨道复用主题 Accent 浅青色；Rest、Hover、Pressed 分别使用 `100%`、`90%`、`80%` 强度，兼容深浅主题，不硬编码系统蓝色。
- 圆形滑块采用接近 WinUI 3 的灰色圆底、细灰外缘和强调色内圆；出现和消失具有透明度与轻微回弹动画。内圆在 Rest、Hover、Pressed 分别为 `12px`、`14px`、`10px`，外圈及滑块整体不缩小。
- 固定态的小三角复用既有选中填充、青色内容和动态边缘光；仅悬停临时显示时不进入选中态。
- 显示、隐藏、笔型切换、上下换边及绘制属性展开/收起可以在任意时刻互相打断，轨道、圆点、徽标和现有预览均不得跳变、越界或残影。

## Acceptance Criteria

- [ ] 硬笔和荧光笔的预览区域悬停显示滑块，未固定时移出恢复；点击预览或小三角后保持，只有再次点击小三角或收起属性栏/主栏才恢复。
- [ ] 单击预览不改值；同一次按下后左右拖动按相对位移调节，圆点不会跳到按下位置。
- [ ] 鼠标或触摸移出控件及 Bar 窗口后拖动仍连续，抬起或捕获丢失后可靠结束且不遗留按下状态。
- [ ] 硬笔按 `1–30 × DPI`、荧光笔按 `30–100 × DPI` 线性调整为整数设备像素；不同 UI zoom 不改变数值范围。
- [ ] 拖动过程即时反馈，结束时仅提交一次记忆；范围外旧值在仅悬停/固定时不被自动覆盖。
- [ ] 硬笔 S 形连续拉直，荧光笔渐变连续变为纯色，两者最终形成水平居中的 `4px` 圆头浅青强调色轨道。
- [ ] 滑块圆点具有灰色圆底、细灰外缘、强调色内圆及 Rest/Hover/Pressed 三态动画，按下时整体尺寸不缩小。
- [ ] 固定时小三角进入既有青色选中态，临时悬停显示时不选中；动态光影开关行为与其他选中按钮一致。
- [ ] 滑块态关闭已有提示浮窗但保留两个徽标显示；恢复普通预览后原提示功能没有静态回归。
- [ ] 深浅主题、正常/倒转布局、展开/收起、笔型切换和动画中途反转均无跳变、越界、误命中或残影。
- [ ] 完整 `InkeysRepo.sln` 的 `Debug | ARM64` 构建通过，并完成鼠标、触摸、不同 DPI/UI zoom 的手工验收。

## Out of Scope

- 不新增数值输入框、刻度、最小/最大文字或键盘方向键操作。
- 不修改设置页现有默认粗细范围，也不迁移或钳制已保存的范围外值。
- 不实现软笔、激光笔的粗细调节，不改变标注线和超限徽标的文案、样式或功能。
