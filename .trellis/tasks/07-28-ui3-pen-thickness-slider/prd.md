# UI3 墨迹粗细连续滑块

## Goal

在 UI3 绘制属性的既有粗细预览区中加入可悬停预览、可固定、可全局捕获拖动的连续粗细滑块，让硬笔和荧光笔能快速、线性地调整实际设备像素粗细，同时保持现有布局、提示徽标和形态动画连续、美观。

## Requirements

### 范围与依赖

- 仅修改 UI3 Bar，不修改传统 `IdtFloating`、绘制引擎、设置页、配置结构、i18n 或墨迹粗细记忆规则。
- 本任务是 `07-27-ui3-pen-thickness-presets` 的独立后续任务；复用其粗细区域、硬笔/荧光笔连续预览、三档按钮、调节箭头、提示徽标和统一浮窗关闭入口，不回写前序任务的范围。
- 滑块只对当前可用的硬笔和荧光笔显示；未来软笔、激光笔接入不属于本任务。

### 出现、固定与恢复

- 滑块激活区域为粗细框中的预览区域，不包含“粗细 数值”和下方按钮行；上下倒转后命中区域随镜像布局移动。
- 指针进入激活区域时临时显示滑块；未固定且未拖动时，指针移出后恢复普通墨迹预览。
- 点击预览区域或点击调节小三角会固定滑块，并让小三角进入与既有选中按钮一致的青色选中态。
- 点击小三角再次取消固定；绘制属性或主栏收起时也取消固定、悬停和拖动状态。点击已固定的预览区域不会关闭滑块。
- 预览区域原地点击固定后，紧接着点击已选中的小三角必须直接取消固定并收起，不得再次进入选中态。
- 滑块尚未显示时，单击预览区域且不发生水平拖动只固定滑块，不改变当前粗细。
- 只有滑块圆点完全出现后，点击滑轨或拖动圆点才会改候选值并在抬起时提交；悬停/固定进入过程中、轨道动画未完成或圆点尚未完全出现时，鼠标/触摸按下与滑动都不改位置，仅可固定。
- 滑块显示且未拖动圆点时，点击下方粗细快捷按钮后，圆点位置应随新粗细做与数字相同的平滑动画过渡，不得瞬移。
- 进入滑块态时关闭已经打开的标注线和粗细超限提示浮窗；两个徽标仍保持原位置和可见性，本任务不重新设计其视觉。
- 指针离开标注线或粗细超限徽标/提示浮窗后等待 `100ms` 再结束悬停；宽限期内进入对应浮窗会取消收起。徽标、浮窗正文和宽限期均属于粗细调整悬停区域，浮窗正文不得把点击穿透给下层滑块。

### 绝对跟随拖动

- 在预览区域按下后不松手并发生水平移动时，将当前指针/触点的屏幕横坐标投影到滑轨：若初次按下落在圆点内，则保持按下点与圆点中心的相对偏移；若初次按下在圆点外，则把圆点中心对齐到触点 X。范围外位置钳制到最近端点。关闭 UI 动画时拖动也必须实时刷新圆点位置。
- 按下后没有发生有效水平拖动时才视为点击并固定；从临时悬停直接拖动只调节候选值，不让小三角进入选中态，抬起后移出预览区即恢复普通预览。
- 触摸等没有悬停进入的直接拖动，抬起后需要固定滑块并让小三角进入选中态，避免再次点击小三角才出现“假选中”再取消。已经固定的滑块仍可继续拖动且保持固定。
- 拖动期间捕获当前鼠标/触摸序列，指针移出粗细区域或 Bar 窗口后仍继续接收位移，直到抬起、捕获丢失、模式切换或属性栏收起。
- 绝对位置映射到完整滑轨行程并在线性范围内钳制；到达端点后继续向外移动不越界，反向回到轨道后可立即离开端点。
- 拖动中只更新滑块圆点的候选位置，不调用 `SetPenWidth()`，因此真实墨迹、超限徽标与真实粗细记忆均保持不变；左下角“粗细”数字在拖动中即时显示候选整数，不做过渡动画。手势正常结束且候选值变化时才调用一次 `SetPenWidth(final, true)`，抬手后恢复平时的数字动画过渡。

### 数值范围

- 硬笔范围为 `1px–30px × barStyle.dpiZoom`。
- 荧光笔范围为 `30px–100px × barStyle.dpiZoom`，与现有设置页 `100px` 上限保持一致。
- 两种笔型都使用线性映射，并取最近的整数设备像素；UI 配置缩放只改变滑轨和圆点的视觉尺寸，不改变数值范围。
- 进入滑块态时若当前值在范围外，只把圆点显示位置钳制到最近端点，不因悬停或固定自动改写当前值；首次实际拖动后才进入有效范围。

### 视觉与动画

- 普通预览到滑块轨道使用同一套连续几何动画，不切换为会跳变的独立预览分支。
- 硬笔预览逐步拉直并变为水平居中的 `4px` 高圆头强调色轨道；荧光笔同时把渐变平滑收敛为纯色，并变为相同的 `4px` 高圆头轨道。
- `4px` 为 UI 逻辑尺寸，随 Bar 总 UI 缩放和绘制属性展开/收起几何一起缩放；滑块数值仍只随系统 DPI 变化。
- 轨道复用主题 Accent 浅青色；Rest、Hover、Pressed 分别使用 `100%`、`90%`、`80%` 强度，兼容深浅主题，不硬编码系统蓝色。
- 圆形滑块采用接近 WinUI 3 的灰色圆底、细灰外缘和强调色内圆；出现和消失具有透明度与轻微回弹动画。内圆在 Rest、Hover、Pressed 分别为 `12px`、`14px`、`10px`，外圈及滑块整体不缩小。
- 滑轨目标中心位于“粗细”文字外侧一个间隙与“标注线”徽标外侧一个间隙之间的可用区域中心；上下倒转时使用同一动画几何镜像推导。
- 圆点只在墨迹预览完全拉直为滑轨后开始出现；退出时先让圆点完整消失，再恢复普通墨迹预览。
- 固定态的小三角复用既有选中填充、青色内容和动态边缘光；白色/主题文字色与青色之间必须连续动画。仅悬停临时显示、或从悬停态直接拖动时不进入选中态；无悬停进入的触摸拖动抬起后进入选中态。
- 标注线与粗细超限徽标位于预览命中层之上，悬停和点击优先由徽标消费；滑块激活时关闭已有提示浮窗，但之后仍可从上层徽标重新激活提示。
- 显示、隐藏、笔型切换、上下换边及绘制属性展开/收起可以在任意时刻互相打断，轨道、圆点、徽标和现有预览均不得跳变、越界或残影。

## Acceptance Criteria

- [ ] 硬笔和荧光笔的预览区域悬停显示滑块，未固定时移出恢复；点击预览或小三角后保持，只有再次点击小三角或收起属性栏/主栏才恢复。
- [ ] 滑块未显示时单击预览不改值并固定；已显示后点击滑轨位置可快速跳值并在抬起时提交。随后点击已选中的小三角直接收起。同一次按下后发生水平移动时，圆点按指针/触点在滑轨上的绝对位置跟随。
- [ ] 触摸直接在粗细调节器上滑动后小三角进入选中态；再次点击小三角可一次取消固定，不会出现“先假选中再取消”的二次点击问题。
- [ ] 鼠标或触摸移出控件及 Bar 窗口后拖动仍连续，抬起或捕获丢失后可靠结束且不遗留按下状态。
- [ ] 硬笔按 `1–30 × DPI`、荧光笔按 `30–100 × DPI` 线性调整为整数设备像素；不同 UI zoom 不改变数值范围。
- [ ] 拖动过程只移动候选圆点，不修改真实粗细或超限提示；左下角“粗细”数字在拖动中即时显示候选值，抬手后恢复动画过渡；有效拖动结束时只提交一次最终值，范围外旧值在仅悬停/固定时不被自动覆盖。
- [ ] 硬笔 S 形连续拉直，荧光笔渐变连续变为纯色，两者最终形成水平居中的 `4px` 圆头浅青强调色轨道。
- [ ] 滑块圆点具有灰色圆底、细灰外缘、强调色内圆及 Rest/Hover/Pressed 三态动画，按下时整体尺寸不缩小。
- [ ] 滑轨在粗细文字和标注线徽标之间正确居中；进入时线完全拉直后圆点才出现，退出时圆点先完整消失再恢复预览。
- [ ] 固定时小三角以动画进入青色选中态，取消时以动画回到主题文字色；临时悬停或从悬停态直接拖动不选中，触摸无悬停拖动抬起后选中，动态光影行为与其他选中按钮一致。
- [ ] 滑块激活时关闭已有提示浮窗但保留两个徽标；徽标命中层高于预览区，之后仍能正常悬停、点击和固定提示浮窗。
- [ ] 指针离开徽标或提示浮窗后具有 `100ms` 收起缓冲，缓冲内进入浮窗不收起；徽标、浮窗正文和缓冲期内移出预览区不会恢复普通墨迹预览。
- [ ] 深浅主题、正常/倒转布局、展开/收起、笔型切换和动画中途反转均无跳变、越界、误命中或残影。
- [ ] 完整 `InkeysRepo.sln` 的 `Debug | ARM64` 构建通过，并完成鼠标、触摸、不同 DPI/UI zoom 的手工验收。

## Out of Scope

- 不新增数值输入框、刻度、最小/最大文字或键盘方向键操作。
- 不修改设置页现有默认粗细范围，也不迁移或钳制已保存的范围外值。
- 不实现软笔、激光笔的粗细调节，不改变标注线和超限徽标的文案、样式或功能。
