# 实施计划

## 前置条件

- `07-27-ui3-pen-thickness-presets` 已提交并归档；本任务直接基于其已验收的预览、徽标和浮窗实现，启动前再次确认没有其他任务正在修改同一组 UI3 Bar 文件。
- 启动任务前重新加载 `trellis-before-dev`，复核 `native-desktop/rendering-and-ui.md`、`cpp-conventions.md` 与完整 Solution ARM64 构建约束。

## 实施步骤

1. 在 `Bar.State.cppm` 和 `Bar.Main.cppm` 增加滑块悬停/固定/拖动/按压状态、动画值、圆点 Shape 枚举及捕获清理入口，保持连续枚举范围和现有批次循环完整。
2. 提取当前动画几何中的预览区域和滑轨端点计算，统一供预览渲染、圆点定位、命中、相对映射与脏区使用；上下换边不读取瞬时方向标志。
3. 将硬笔曲线、荧光笔渐变/方头、粗细、圆角和主题颜色接入 `sliderProgress`，实现到 `4px` 浅青强调色圆头轨道的可逆连续形变。
4. 绘制 WinUI 式灰色圆底、细灰外缘、强调色内圆及 Rest/Hover/Pressed 三态动画，并把固定小三角接入既有选中填充和 PointLight 状态。
5. 在交互线程加入预览区域 hover、点击固定、小三角切换与浮窗关闭；按下时记录屏幕坐标和起始值，使用相对位移线性更新。
6. 接入鼠标捕获、捕获丢失结束事件和触摸同序列映射；所有退出路径统一释放捕获、清理按压，并仅在发生拖动时提交一次最终记忆值。
7. 扩展 predicted/current 脏区、动画唤醒和设备资源重建覆盖，确认稳定帧无新增画刷/geometry 创建。

## 验证

- 静态检查状态清理、连续枚举、布局批次、渲染分支、命中优先级、捕获生命周期、脏区和 `SetPenWidth(..., false/true)` 调用次数。
- 手工覆盖硬笔与荧光笔：悬停进入/移出、单击固定不改值、同次按下拖动、第二次拖动、小三角打开/关闭、拖动到两端后反向。
- 把鼠标和触摸分别拖出粗细框及 Bar 窗口命中区域，并让鼠标跨到相邻窗口或显示器，验证相对位置连续、抬起可靠结束、圆点不跳到指针下方。
- 覆盖当前值低于/高于范围、拖动中切换笔型、主栏/属性栏收起、捕获被其他窗口夺取和程序退出，确认无残留按下态或未提交的最终值。
- 在 `100%/125%/150%/200%` 系统 DPI 及多个 Bar UI zoom 下核对范围、整数显示、端点、轨道 `4px` 视觉缩放和拖动精度。
- 覆盖深浅主题、动态光影开关、属性栏上下布局、展开/收起、换边、形态动画中途反转；检查徽标保持显示、浮窗关闭、无裁剪和残影。
- 运行 `git diff --check`，并使用 ARM64 host MSBuild 构建完整方案：
  - `C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\arm64\MSBuild.exe`
  - `InkeysRepo.sln /m /p:Configuration=Debug /p:Platform=ARM64`
  - 超时不少于 5 分钟。
