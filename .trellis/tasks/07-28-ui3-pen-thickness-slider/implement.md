# 实施计划

## 前置条件

- `07-27-ui3-pen-thickness-presets` 已提交并归档；本任务直接基于其已验收的预览、徽标和浮窗实现，启动前再次确认没有其他任务正在修改同一组 UI3 Bar 文件。
- 启动任务前重新加载 `trellis-before-dev`，复核 `native-desktop/rendering-and-ui.md`、`cpp-conventions.md` 与完整 Solution ARM64 构建约束。

## 实施步骤

1. 在 `Bar.State.cppm` 和 `Bar.Main.cppm` 增加滑块悬停/固定/拖动/按压状态、动画值、圆点 Shape 枚举及捕获清理入口，保持连续枚举范围和现有批次循环完整。
2. 提取当前动画几何中的预览区域、粗细文字/标注线徽标间的滑轨中心和滑轨端点计算，统一供预览渲染、圆点定位、命中、绝对投影与脏区使用；上下换边不读取瞬时方向标志。
3. 将硬笔曲线、荧光笔渐变/方头、粗细、圆角和主题颜色接入 `sliderProgress`，实现到 `4px` 浅青强调色圆头轨道的可逆连续形变。
4. 绘制 WinUI 式灰色圆底、细灰外缘、强调色内圆及 Rest/Hover/Pressed 三态动画，加入线先圆后/圆先线后的阶段门控，并把可着色小三角接入既有选中填充和 PointLight 状态。
5. 在交互线程按视觉层级处理提示徽标、浮窗正文、`100ms` 离开宽限、预览区域 hover、点击固定和小三角切换；按下时记录屏幕坐标、轨道屏幕端点、原悬停/固定态，已显示时按下即绝对投影跳值，未显示时仅固定不跳值，发生水平移动后继续绝对投影更新候选值。
6. 接入鼠标捕获、捕获丢失结束事件和触摸同序列映射；所有退出路径统一释放捕获、清理按压。悬停态直接拖动不选中小三角，触摸等无悬停进入的拖动抬起后固定选中；仅在正常抬起且候选值变化时调用一次 `SetPenWidth(final, true)`。
7. 扩展 predicted/current 脏区、动画唤醒和设备资源重建覆盖，确认稳定帧无新增画刷/geometry 创建。

## 验证

- 静态检查状态清理、连续枚举、布局批次、渲染分支、上层徽标命中优先级、捕获生命周期、脏区和拖动路径中的 `SetPenWidth()` 调用次数。
- 手工覆盖硬笔与荧光笔：悬停进入/移出、未显示时单击固定不改值、已显示后点击滑轨跳值、悬停直接拖动不选中、触摸直接拖动后选中、固定后第二次拖动、小三角打开/关闭、拖动到两端后反向。
- 验证预览区域原地点击固定后立即点击小三角会收起；触摸直接滑动后小三角为选中态，再点一次即可取消；拖出取消三角点击时恢复原固定态。
- 验证标注线和超限徽标覆盖滑块预览时仍能悬停、点击和固定提示；验证进入时线完全拉直后圆点出现，退出时圆点消失后线恢复，小三角颜色双向连续动画。
- 验证离开问号/叹号或其浮窗后 `100ms` 才收起，宽限期内进入浮窗会取消收起；徽标、浮窗和宽限期均维持滑块态且正文阻止点击穿透。
- 把鼠标和触摸分别拖出粗细框及 Bar 窗口命中区域，并让鼠标跨到相邻窗口或显示器，验证绝对投影连续、端点钳制和抬起可靠结束。
- 覆盖当前值低于/高于范围、拖动中切换笔型、主栏/属性栏收起、捕获被其他窗口夺取和程序退出，确认无残留按下态或未提交的最终值。
- 在 `100%/125%/150%/200%` 系统 DPI 及多个 Bar UI zoom 下核对范围、整数显示、端点、轨道 `4px` 视觉缩放和拖动精度。
- 覆盖深浅主题、动态光影开关、属性栏上下布局、展开/收起、换边、形态动画中途反转；检查徽标保持显示、浮窗关闭、无裁剪和残影。
- 运行 `git diff --check`，并使用 ARM64 host MSBuild 构建完整方案：
  - `C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\arm64\MSBuild.exe`
  - `InkeysRepo.sln /m /p:Configuration=Debug /p:Platform=ARM64`
  - 超时不少于 5 分钟。
