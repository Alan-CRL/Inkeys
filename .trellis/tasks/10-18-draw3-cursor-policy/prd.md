# Win7 触摸光标修复与绘制光标设置

## 目标与用户价值

让画布在触摸、笔、鼠标及绘制/穿透切换时显示正确且唯一的光标，解决 Win7 单指擦除重影、抬笔系统光标残留和触摸落笔闪现；提供鼠标荧光笔粗细预览与符合鼠标指向习惯的笔形光标。

## 当前阶段与授权

- 2026-10-18 首轮限定调查和规划；该阶段历史记录保留在 implement.md。
- 2026-10-19 用户明确“继续同时批准开始实现”，授权本任务代码实施、必要静态检查、命令行构建与无窗口测试。
- D1-D4 已按本轮最新规则修订，详见 research/cursor-policy-revision.md。本次实施保持 minimal diff、原编码/换行，不启动 GUI、Computer Use 或窗口 harness，不 commit/push。
- Win7 真机现象尚无本次对应现场序列；可修复源码已确认的隐藏/终态缺口，并补诊断，不凭未知来源猜测修改兼容 Mouse 接管规则。真机验收作为未完成验证单列。
- 来源 Unknown/Conflict 的视觉回退采用数位板的高可见外观，仅用于光标选项路由，保持真实输入身份 Unknown；不提供高亮选项；ScreenPen 固定关闭边缘高亮，Digitizer/Unknown/Conflict 固定开启。此实现选择不修改橡皮响应或设备分类。

## 验收标准

以下是验收目标。实现与本机验证逐项记录在 implement.md 和 research/verification.md；尚无本次 Win7 真机验收，不能将源码或 headless 结果替代桌面可见效果。

- **AC1 → R1**：Win7 单指擦除只见一枚属于该触点的有效橡皮；多指按有效擦除触点显示，不增加错误 primary 或系统指示。
- **AC2 → R2**：Touch 最后 Up/Cancel 后无旧指示回弹；实体 Pen Up 清除旧接触态，新 hover 样本可以正常显示，OutOfRange/取消后不残留旧笔光标或系统箭头。普通笔、荧光笔、橡皮/笔尾和 Laser 分别检查。
- **AC3 → R1/R2**：触摸中或结束后，真实 Mouse/TouchPad 移动、点击、从窗外按键拖入及新的 Pen hover 能及时接管；不以固定延迟或吞掉所有未知来源事件换取消重影。
- **AC4 → R3**：本应用画布中的系统触摸光标持续隐藏，无设置开关或可关闭隐藏的配置；首次启动、重启及 HWND 重建后均保持策略。旧 Beta 值不能影响结果；Win7 从首次 Down 起无多余系统反馈、额外小光标或终态残留，须由真实设备序列证明，未覆盖就标为未验收。
- **AC5 → R4**：鼠标荧光笔默认在悬停/按下均显示屏幕笔同款粗细预览并带高亮边缘；鼠标两种类型选择不改变其矩形，静止调宽、切换工具和 DPI/显示器变化后及时更新，无双箭头或旧尺寸残影，实际墨迹透明度不变。
- **AC6 → R5**：笔形方向正确，笔尖热点与实际墨迹起点重合；多种 DPI、屏幕边缘和负屏坐标无裁切/偏移。鼠标/笔两类型选择互不影响；固定设备边缘规则不改变对应工具几何或热点。
- **AC7 → R6**：原版/新式设置与运行时、重启后的选择一致；绘制→穿透→绘制及静止时更改选项均正确，穿透不向下层应用遗留自绘光标或覆盖其鼠标方案。
- **AC8 → R1-R6**：各场景的外观偏好不改变触摸擦除尺寸、Pen 接触/悬停生命周期、笔尾橡皮 Hover/Contact alpha、Laser 尾迹或墨迹保存/撤销；瞬态光标不写入持久内容。
- **AC9 → R3/R6**：隐藏触摸光标没有 UI 控件和新持久化字段，旧 HideTouchPointerBeta 的 true/false/缺失/非法值均被忽略并继续按现合同清理。可选的鼠标/笔类型正常处理缺失、非法值和重启，退役高亮键被忽略并在保存时清理，UI/运行时/磁盘一致，无设置卡死且三语完整。
- **AC10 → R1-R6**：后续最小静态/构建/headless 验证和 Win7 硬件视觉分别记录；ARM64 或纯逻辑通过不替代 Win7、真实 Touch/Pen 或首次落笔可见效果。
- **AC11 → R4/R6**：鼠标和笔类型各自即时生效并持久化，默认分别是系统/圆形；修改其中一个、切换设备和重启不覆盖另一个。鼠标荧光笔与形状不受类型设置影响，固定设备高亮不读取历史高亮键。

- **AC12 → R4/R6**：活动笔画锁存旧工具期间，光标按实际工具维持荧光笔预览或形状系统光标；抬起后再应用新工具，原始MouseStyle不丢失，不通过结束笔画纠正视觉。

- **AC13 → R4**：荧光笔高亮状态下左右边缘厚度为修订前一半、上下不变，内部颜色预览面积增加；Mouse/Digitizer/Unknown/Conflict高亮、ScreenPen不高亮的固定规则与实际墨迹alpha保持。
- **AC14 → R5**：笔形的笔侧/笔尾四个拐角为明显圆角（24 DIP图标半径3 DIP，随DPI缩放），笔头仍尖角；24 DIP、左上笔尖热点、朝向、外框及脏区合同不变，正式与Win7兼容shader同步。

## 约束与非目标

- 本轮已获代码实施授权；技术实现、验证顺序与实际结果记录在 design.md / implement.md。
- 以 minimal diff、原编码/BOM/换行为原则，不整理无关代码，不升级依赖或改构建系统。
- 保持当前唯一 Draw3 Host、Window Service HWND 所有权和单输入 producer；不恢复已停用 Draw2/IdtFloating，不新装全局 hook。
