# 设置页面滑动封装与触摸/笔惯性

## Goal

把设置页“按住内容拖动滚动”的 ImGui 代码封装成独立模块；鼠标不再拖动滚动（鼠标用滚轮与滚动条）；触摸与笔拖动滚动跟手，抬起时按甩动速度产生惯性并自然减速，手感参考 WinUI3 与主流软件；拖动或惯性越过页面边界时内容硬停，越界量学习文件资源管理器，以窗口整体位移表示阻力并回弹。父任务：`11-26-setting-pointer-input`。

依赖：`11-26-setting-pointer-route`（可靠的 `io.MouseSource` 与带时间戳的接触样本轨迹）。

## 来源需求

- 用户 2026-11-26：封装页面滑动部分 ImGui 代码，并屏蔽鼠标滑动；对触摸和笔滑动提供滑动惯性支持，参考其他软件和 WinUI3 的惯性。
- 用户决定：边界处 ImGui 内容硬停，越界学习文件资源管理器，通过窗口位置移动体现阻力（折中方案）。

## Requirements

### R1 封装

- R1.1 现有 `DragEligible`、`CaptureDrag`、`BeginDragScrolling`、`ApplyDragScrolling`、`AllowContentDrag` 及其 `StateStorage` 键协议（`##drag-scroll-*`、`##scrolldraggingoverlay`、`##content-drag-button`）从 `Setting.Controls.cpp` 移入独立的设置滚动模块；`ScrollbarStyleScope`、`BeginScrollChild` 只通过该模块的小接口读取/重置拖动状态。
- R1.2 对外入口签名与调用点保持不变（`Setting.cpp` 帧首/帧尾两处调用、各页 `AllowContentDrag`），不改各页面代码。
- R1.3 惯性与速度估计为不依赖 ImGui/Win32 的纯逻辑，可在无窗口测试中验证。

### R2 设备策略

- R2.1 鼠标（`io.MouseSource == Mouse`）在正文、导航、弹层内容上按住拖动不再滚动页面；滚轮、滚动条拖动、键盘导航滚动不变。
- R2.2 触摸、笔按住内容拖动滚动，越过原生拖动阈值后跟手（保留现有 1:1 位移与“内容型按钮越阈值转滚动”的规则，组件卡片 0.45 s 长按抓起合同不变）。
- R2.3 鼠标不能拖动后，原先依赖鼠标拖动滚动的场景（如组件卡片鼠标越 4 DIP 即抓起）行为不变。

### R3 惯性

- R3.1 触摸/笔抬起时按最近一段时间的真实移动估计释放速度，超过最小甩动速度才启动惯性；抬起前明显停住（约 0.1 s）不产生惯性。
- R3.2 惯性按指数衰减减速（WinUI3 `InteractionTracker` 位置惯性衰减模型，默认衰减率参考 0.95/s），速度设上限；衰减与位置按真实时间解析计算，不受帧率影响。
- R3.3 惯性中：任一触摸/笔/鼠标按下立即停住，且这次按下不激活下方控件；滚轮、键盘滚动、滚动条拖动、页面切换、滚动宿主重置/未提交、设置隐藏、接触取消时立即停止。
- R3.4 惯性期间持续请求设置帧，结束后回到按需渲染。
- R3.5 只作用于纵向滚动（与现有拖动滚动一致）。

### R4 边界与窗口位移阻力

- R4.1 ImGui 滚动位置始终在 `[0, ScrollMax.y]` 内，内容不越界。
- R4.2 手指/笔拖动越过边界时，越界量按阻尼换算为窗口整体位移（资源管理器同款系统 panning feedback），松手后窗口回弹。
- R4.3 惯性撞到边界时，按撞击速度产生一次有上限的窗口位移并回弹，惯性随即结束。
- R4.4 窗口位移只是视觉反馈：不改变保存的窗口位置、不触发设置的移动/缩放交互状态、不影响外置缩放边框的最终位置。
- R4.5 最大化窗口、Win7 下同样可用；若系统 API 不可用则只硬停、无窗口位移。

## 约束

- 兼容 Windows 7 SP1 + KB2670838；MSVC v143 / C++20；不引入新依赖。
- 最小修改：搬移为主，不改变其他页面布局与滚动条视觉；`.cpp/.cppm/.h` UTF-8 BOM + CRLF。
- 参数（衰减率、最小/最大速度、阻尼、最大位移）集中为常量，实机调整。

## Acceptance Criteria

- [x] 鼠标按住正文空白/卡片拖动不滚动；滚轮与滚动条正常。
- [x] 触摸/笔慢拖跟手无跳变；快甩有惯性且减速自然；停住再抬起无惯性。
- [x] 惯性中轻点立即停住且不触发点下的控件；惯性中滚轮/切页立即停止。
- [x] 拖过顶部/底部：内容不越界，窗口按阻尼位移，松手回弹；惯性撞边界有一次回弹。
- [x] 回弹后窗口位置与改动前一致，重开设置窗口位置不漂移；最大化窗口下可用。
- [x] 组件页内层滚动视口、导航树、弹层（下拉/浮层）滚动与惯性均正常；组件卡片长按抓起不受影响。
- [x] 新增纯逻辑测试（速度估计、停住判定、指数衰减解析解、上限、越界阻尼/回弹）与 `setting_design_tests` 相关用例通过；`InkeysRepo.sln` Debug|ARM64 构建通过。
- [x] Win7 回退登记到父任务实机验证项。
