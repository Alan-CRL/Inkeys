# 主栏属性/更多窗口文字展开收起动画未等比缩放

## Goal

调查并修复真实主栏与组件页预览主栏中，属性窗口、更多窗口展开/收起时文字缩放与窗口缩放不等比（到位后二次放大、收起前偏小）的问题。

## 用户报告的现象

- 范围：真实主栏与设置 > 组件页中的主栏预览（复刻实例）都出现。
- 属性窗口（绘制属性面板）与更多窗口（More 面板）展开时：窗口到位后，文字还有一段继续放大的过程。
- 收起时：收起开始前后，文字看起来比按窗口等比缩放应有的大小更小。
- 用户初步推测：文字动画与窗口缩放的曲线不匹配；希望结合组件页编辑器相关 commit 定位问题位置。

## 调查结论

- 根因已定位（`research/`）：字号整数像素修正把收起端（紧凑倍率约 0.16）当作取整目标，系数在两端之间用另一条曲线插值。
- 不是组件页提交引入；组件页把 More 定位共享给预览，所以两边同时出现。

## Requirements

- 展开、收起全过程中，属性窗口（绘制 / 橡皮 / 撤回 / 几何）、颜色选择器与更多窗口内文字的绘制大小与窗口内容缩放保持等比。
- 真实主栏与组件页预览统一修复，走同一份代码，不为预览写单独分支。
- 不改变窗口本身的展开/收起曲线、时长与回弹手感。
- 展开静止时文字仍落在整数像素字号上（保留现有字号取整的目的）。
- 为后续“属性窗口 / 更多窗口在主栏缩放之外叠加用户设定的展开倍率”留好落点：字号取整目标只取展开态姿态，用户倍率届时乘在展开态姿态上即可，开合仍保持等比。本任务不实现该倍率。

## Acceptance Criteria

- [ ] 展开过程中窗口到位后文字不再出现二次放大。
- [ ] 收起过程中文字与窗口内容等比，不再偏小。
- [ ] 真实主栏与组件页预览均满足以上两条。
- [ ] 100%/125%/150% 缩放下均满足。
- [ ] 展开静止画面与修复前一致（golden 不变）。
- [ ] spec 记录“开合式面板字号取整目标取展开态”与用户展开倍率的落点约定。
