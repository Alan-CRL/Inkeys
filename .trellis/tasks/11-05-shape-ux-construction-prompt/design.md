# 绘制步骤提示：视觉规格

> 主 Agent（UI/UX 负责人）2026-11-09 定稿。需求见 `prd.md`（P1–P5、R1–R6）。单位 DIP。本文没写到的视觉行为保持原样，不要自行“改进”。

## 1. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ (◔1/2)  第 1 步 · 确定底面   │  ‹   ›   ✓   ✕                │
└──────────────────────────────────────────────────────────────┘
```

| 项 | 值 |
|---|---|
| 面板高度 | 42.5（OneOne 按钮 32.5 + 上下各 5） |
| 圆角 | 6（P1，与底栏模式提示一致） |
| 左内边距 | 9；右内边距 5 |
| 环形进度 | 直径 24，垂直居中；环与文字间距 8 |
| 文字 | 13 DIP Bold，`TextPrimary`，单行不换行；文字与分隔线间距 10 |
| 分隔线 | 主栏 SingleRow Divider 模板（宽 1、高 `OneSide − 4`、`Divider` 色、pct 0.30） |
| 按钮 | OneOne 32.5，间距 5，分隔线后第一个按钮距分隔线 5 |
| 位置 | 主栏可见上边缘之上 5，水平居中于主栏与主按钮并集；上方放不下放到主栏下方 5；主栏手动收起时锚定到主按钮 |

折线、多边形（步数不定）没有环：文字直接从左内边距 12 开始。

## 2. 环形进度

- 轨道：线宽 2.5，`SubtleFill`（浅色 `#E1E1E1` / 深色按现有角色），不透明度 1。
- 进度弧：线宽 2.5、圆头，`Accent`，从 12 点方向顺时针，角度 = 已完成步数 / 总步数；即第 n 步时进度为 (n−1)/N，完成当前步后才增加（第 1 步时只显示轨道）。
- 环内文字 `n/N`：9.5 DIP Bold，`TextPrimary`，居中。
- 步数变化：进度弧角度 0.4 s EaseOutCubic 过渡；环内文字随整段文案的三阶段换字一起切换。

## 3. 文案

- 固定步数：`第 n 步 · <本步说明>`（`·` 前后各一个空格）。
- 不定步数：`已确定 k 个点 · 落笔确定下一顶点`；k = 0 时只显示本步说明。
- 新增 i18n 键（zh-CN / en-US 由实现方写，其余语言由主 Agent 同步补译）：步骤格式、点数格式、上一步/下一步/结束绘制/取消 的无障碍名称和 tooltip。

## 4. 按钮

| 按钮 | 图标 | 显示 | 可用 |
|---|---|---|---|
| 上一步 | `barStepBack`（新增 chevron） | 总是 | 至少已确认 1 步 |
| 下一步 | `barStepForward`（新增 chevron） | 总是 | 可重做栈非空 |
| 结束绘制 | `fluentCheckmark12Filled` | 只在折线、多边形 | 折线 ≥ 2 点；多边形 ≥ 3 点 |
| 取消 | `barCloseSmall` | 总是 | 总是 |

- 禁用：公共 0.30 内容透明度，不响应悬停。
- 显隐与启用切换：主栏 0.4 s 批次 + CanJoin；面板宽度随之同批次变化。
- 物理接触进行中所有按钮禁用（现有规则）。

## 5. 材质与透明度

- 表面：`themeSurface + residentSurface + lightMaterial`，Dark 端点基色，pct `BarMainBarFillOpacity`（渲染器统一解析常驻背景透明度，不在 pct 里再乘），`framePct/frameLightPct = BarMainBarFrameOpacity`，PointLight，主光源开启，鼠标光强度 1.0，`frameLightColor = PenWhenDrawing`——与底栏模式提示逐项一致。
- 内容（文字、环、图标、分隔线）：`SetResidentContentOpacity(GetThemeResidentContentOpacity())` 包裹绘制，结束后恢复 1。

## 6. 动画

- 出现：0.4 s，scale 与 opacity 按 EaseOutBack（opacity 钳到 0–1），绕面板中心缩放；消失：0.4 s EaseInBack。
- 换文案：复用底栏提示的「扩框 → `TransitionToString(0.4, 0.5, 0.8)` → 缩框」三阶段状态机（抽成可复用 helper，底栏提示改用同一 helper 且行为不变）。
- 完全隐藏时直接换字，不播放换字动画。
