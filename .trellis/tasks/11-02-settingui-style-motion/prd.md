# SettingUI 样式与转场修正

## Goal

修复设置窗口开屏、滚动布局、导航材质、缩放性能及最大化过渡问题，并增加短促自然的页面和动态条目动画，使页面在展示和操作时保持连贯。

## Background

- 分支 `feature/i18n`，规划起点 `dbabd500`。本任务由用户明确要求新建，最终完整方案已获用户批准并要求开始实施；状态为 `in_progress`。
- 沿用 SettingUI、共享渲染线程、现有动画开关/速率、背景模糊和会话资源管理；保留刚完成的 20 语、FreeType、字体回退及语言热切换。
- 已完成静态源码、规范和相关历史任务研究。研究证据不等于实际桌面复现；阶段性根因与待定位项见 [current-implementation.md](research/current-implementation.md)。

## Requirements

### R1 开屏标题栏控件

开屏播放以及遮盖层渐隐期间，不显示版本号、深浅主题切换、反馈和程序调测按钮，也不接受它们的鼠标/键盘触发；遮盖层渐隐完成后恢复显示和操作。图标、窗口标题及最小化/最大化/关闭行为保持。开屏取消、禁用及准备失败的回退同样恢复一致终态。

证据：`Setting.cpp:2782`、`:2815`、`:2838`、`:2841` 在开屏状态配置 `:2867` 前提交这些控件；`Setting.Pages.cpp:410` 的开屏过滤保留整份标题栏。

### R2 新长页的滚动布局

首次显示新页面前确定正文宽度和滚动布局，避免垂直滚动条稍后出现使条目右边缘从右向左移动；滚动条视觉显隐不得再次改变已入场正文的可用宽度。短页不显示无效滚动条，不通过缩小字体、截断文字或永久显示滚动条来规避。

证据：`Setting.Controls.cpp:302-345` 以同一进度缩放轨道宽度、padding、thumb alpha；`Setting.cpp:2904-2907` 仅主页开屏使用稳定布局，普通新页没有相同策略。

### R3 导航背景恢复

左侧导航结束悬停/按下且指针移开后回到对应稳定颜色。动态模糊下未选中项不得残留加深叠色，正常选中态及键盘焦点反馈保留。

证据：`Setting.Shell.cpp:187` → `imfluent.cpp:5320` → `AnimateColorU32:823-840`；U32 逐帧指数趋近与 `LerpColorU32:686-700` 的取整存在不能到达透明端点的量化风险。算式探针有残留 alpha 证据，真实控件回放待实施验证。

### R4 连续调整窗口尺寸

优化连续拖动 resize 的流畅性，重点覆盖 Windows 7，保持交互中内容持续更新、松手最终尺寸准确、原有最小尺寸/系统边框/Snap 行为及共享 UI 客户端正常。以实际分阶段数据定位成本，不擅自冻结整窗、降低字体/模糊质量、更换渲染设备或扩大系统依赖。

证据：`Setting.cpp:1790-1803` 发布尺寸，`:5171-5184` 执行 resize；`Setting.Base.cppm:118-124` 释放/重建 RTV；`Setting.SessionState.h:286-292` 已合并为最新目标，但同尺寸仍增加 serial。具体主耗时尚未定位。

### R5 最大化/还原材质连续

点击最大化和还原时，动态背景透明度、着色和模糊程度保持连续，不出现瞬间跳变；正常系统窗口几何动画保留。Win10/11 沿用当前 BlurBehind，Win7/8/8.1 沿用不透明回退。高对比度、composition 改变及真实失败仍可按原策略回退。

证据：`Setting.cpp:266-288` 已统一静止/交互 accent；`:314-332` 会先禁用再启用材质，`:402-423` 为主题入口，`:303-311`/`:1818-1821` 在窗口状态变化时更新边框。需继续区分 DWM 原生过渡与产品提交的失配帧，不能预设单一根因。

### R6 页面依次入场

- 每次实际切换页面都播放，包含子页和返回；重复点击当前页不重播，保留该页原有滚动位置。以实际可见区域的块/条目为序，允许重叠，从下向上浮入并渐显，非线性缓动、总时长适当；到位后再渐显垂直滚动条，离屏条目不能拖长总时长。
- 入场未结束时，正文滚动或点击立即使条目到位，并正常执行这次操作；新页面导航立即响应。键盘/触摸等对应操作遵循相同的可操作性原则，不重复触发业务动作。
- 首页播放现有字标开屏时保留原揭示效果，不叠加或结束后追加逐块入场；未播放开屏、或从其他页返回首页时正常逐块入场。开屏被用户取消时直接落定，不补播一轮。
- 复用现有全局动画开关/速率；关闭动画即刻显示终态，不新增配置字段。主题/语言/字体/DPI/窗口 resize 本身不算导航，不触发重播。

以上重播、操作取消和首页衔接分别由三次会话问题确认。现有 `Setting.Pages.h:50-60`/`:217` 的整页 reveal 需要与新动效统一，不能叠加成双重淡入；现有字标时序为 `Setting.Pages.h:80-85`。

### R7 条件条目显隐

覆盖当前实际页面中按设置或状态动态出现/隐藏的条目、卡片、提示及必要的所属分区标题，包括光效选项、调测帧率、笔速橡皮高级项、物理尺寸警告、快捷键状态和更新状态等。出现时渐显且下方条目平滑下移；隐藏时渐隐且下方条目平滑上移。反向操作从当前进度继续；保持滚动锚点、范围和滚动条连续，不残留不可见命中。首次进入页面已有的条件结果不额外重播动态新增动画，静态文本更新也不触发整页入场。

证据：`Setting.Pages.cpp:608`/`:832`/`:857-876`/`:1053`/`:1074`/`:1128`；`Setting.cpp:3155`/`:4507`。`Details` 仅有 `Setting.Controls.cpp:1401-1424` wrapper 而无实际产品调用，不为此增加新交互；既有导航树展开不改为正文动画。

## Out of Scope

- 不切换 UI 框架、重写渲染管线、更换设备/交换链模式、增加字体、改变排印或20语索引。
- 不新增动画偏好配置、线程/定时器，不修改无关翻译、业务语义、未使用 Details wrapper、其他窗口外观或导航树动画。
- 不取消系统 DWM 动画、不恢复 Mica/Acrylic 路线，不自行改成 resize 冻结或降低视觉质量；若确需上述产品取舍，先回到规划确认。
- 无明确授权不启动 GUI/Computer Use；不把无窗口成功当作真 Win7 性能或 Win10/11 模糊视觉验收。此前任务的 commit 授权不延续至本任务。

## Risks and Validation Boundary

R4/R5 的真实主耗时与 DWM 动画参与仍需实施阶段采样，当前不承诺某一局部修改必然完全解决。先完成同源诊断与保留现有行为的修复；如证据要求扩大到共享管线/呈现架构或调整用户体验，应说明证据并重新确认范围。人工未验证项在交付中明确列出。
