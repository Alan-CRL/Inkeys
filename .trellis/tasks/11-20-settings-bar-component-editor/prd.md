# 设置组件页：主栏拖拽编辑器与组件库

## Goal

把设置 → 组件页从“一列组件开关”改造为可直接操作的主栏编辑器：页面顶部是一条与真实主栏外观一致的 UI3 主栏复刻（A1 | B1 | A2），可抓起按钮拖动排序、收纳进 More、拖到垃圾桶删除；下方是快捷方式块、重置默认块和分标签的组件库卡片，卡片可直接拖入主栏。拖拽能力做成通用 UI3 能力，供下一轮在真实主栏中复用（真实主栏的触发方式本轮不做）。

本任务属于中期重构第1步（UI3 分层封装）的延续，挂在 `11-16-inkeys3-midterm-refactor` 下。

## 来源需求（用户原话要点，2026-11-20）

- 参考图一（ICC CE 组件页：已添加组件 + 组件库卡片网格）与图二（ClassIsland 组件页：组件库 Tab + 卡片），样式需要升级。
- 槽位分三段 A1、B1、A2，与主栏自带顺序一致；默认从左往右显示，若设置中主栏排列方向被固定，则按固定的顺序。
- 有主栏示意（不需要主按钮），能直接抓住按钮：按钮浮起跟随鼠标/触摸，有插入位置提示光标、放入 More 的收纳提示。
- 复刻需要光影；深浅色、大小尺寸与真实主栏一致；有悬停浮窗（同小尺寸主栏的行为）；支持动画：按钮被抓起时主栏动画缩短，放入时动画展开。
- 位置类似居中底栏，保持在页面中居中；尺寸不受桌面缩放影响，保持适中；大尺寸和小尺寸在页面中高度看起来接近，宽度不能超出区域（超出则适当缩小）。
- 主栏中的抓取拖动下一轮再做；本轮把能力做成通用的。设置页中的呈现不应自绘，而是复用已封装的 UI3，只是呈现在 ImGui 中。
- 主栏默认自带的按钮不能删除，但可以调整位置（配置已支持）。默认在 A1 的按钮只能在 A1 内调整，不能删除、不能移到 B1/A2；A2 同理。
- A1/B1、B1/A2 之间原有的交界分割线固定：不能调整也不能删除。
- 预览下方第一个块：快捷方式块（首次出现的新块），样式类似图三（Windows 设置的跳转行），开关位置换成箭头，指向调整大/小尺寸和排列顺序的设置。
- 第二个块：重置默认按钮，与性能页一样需要再次点击确认；重置后与初始化后一致。
- 再下方是新分类“添加组件”：Tab 有“全部”“内置组件”“桌面操控”“ClassIsland”等，默认在“全部”。把原来的开关全部改成图一图二的卡片样式放在这里。
- 卡片可直接拖入主栏，可重复添加（最初设计允许）。主栏中已有该组件时，卡片右侧出现删除键，点击删除主栏中该组件的全部实例。
- 内置组件目前只支持“添加更多分割线”，分割线允许多条相连，也有删除按钮；删除不影响固定交界分割线。
- 新添加的组件可自由拖动；拖动时右下角出现垃圾桶区域，靠近变红并提示，放下即删除。
- 拖动时遇到删除或收纳，出现类似小尺寸主栏的跟随光标浮窗，提示当前操作。

## Requirements

### R1 主栏预览

- R1.1 预览只包含主栏本体（A1、交界分割线、B1、More、交界分割线、A2），不含主按钮。
- R1.2 外观使用真实主栏的 UI3 封装组件渲染（按钮、底板、光影、主题），深浅色与尺寸模式（大/小）跟随当前设置，切换后预览即时更新。
- R1.3 显示顺序为 A1 → B1 → A2 从左到右；若主栏排列方向设置为固定顺序，按该固定顺序显示。
- R1.4 预览在内容区水平居中；尺寸与桌面 DPI 缩放无关，以固定的合适高度显示；大、小尺寸的显示高度接近；宽度超过可用区域时整体等比缩小。
- R1.5 悬停按钮时显示悬停浮窗，行为与小尺寸主栏一致。
- R1.6 预览按钮不执行真实功能（点击不触发按钮动作）。

### R2 拖拽编辑

- R2.1 鼠标与触摸均可抓起预览中的按钮；抓起后按钮浮起跟随指针，原位置收起，主栏动画缩短；放下后主栏动画展开到新布局。
- R2.2 拖动中显示插入位置提示光标；拖到 More 上时显示收纳提示，放下即收纳进 More。
- R2.3 拖动开始时右下角出现垃圾桶区域；指针靠近时变红并提示，放下即删除。
- R2.4 删除、收纳等操作时，跟随光标的浮窗提示当前操作（样式同小尺寸主栏的浮窗）。
- R2.5 区域约束：
  - 默认 A1 按钮只能在 A1 内调整顺序；默认 A2 按钮只能在 A2 内调整顺序；两者都不能删除、收纳或跨区。拖到不允许的位置时给出不可放置的反馈，放下后回到原位。
  - 两条交界分割线不能拖动、不能删除。
  - 从组件库新加入的组件只能放入 B1 或 More，可删除。
  - 用户添加的分割线可放入 A1、B1、A2（不能放入 More），可删除；A1/A2 因此允许混入用户分割线。
  - B1 不设数量上限：放在 B1 的组件全部显示在主栏上，不再有“超过两个自动溢出到 More”的隐式规则。
  - “设置”按钮属于默认按钮：不可删除，可在 B1 与 More 之间移动，且始终恰好一个。
- R2.7 预览中点击 More，或拖动时在 More 上停留约 0.5 秒，展开与真实主栏相同的 More 面板；面板内可排序、可拖出；直接拖到 More 按钮上松手则追加到 More 末尾。
- R2.8 拖动中指针靠近页面可视区顶端或底端时，页面自动向上或向下滚动。
- R2.9 从卡片或条目开始拖动时，跟随指针的是按当前尺寸模式（大/小）样式渲染的主栏按钮，可直接放入主栏。
- R2.6 拖拽能力实现为通用 UI3 能力（不绑定设置页），供下一轮在真实主栏中复用。

### R3 快捷方式块

- R3.1 预览下方第一块为跳转行，样式参考图三：左侧图标与标题，右侧为箭头而非开关。
- R3.2 点击跳转到主栏尺寸模式与排列顺序所在的设置位置。

### R4 重置默认块

- R4.1 第二块为“重置默认布局”按钮，交互与性能页的重置一致：第一次点击进入待确认状态，再次点击才执行。
- R4.2 重置后主栏布局与全新初始化后一致，预览与真实主栏同步更新。

### R5 添加组件（组件库）

- R5.1 新分区标题“添加组件”，Tab 依次为：全部、桌面操控、IslandCaller、SecRandom、NamePicker、ClassIsland，默认选中“全部”。
  - 桌面操控：启动文件资源管理器、启动任务管理器、启动控制面板、显示桌面、锁屏、按下 ESC、按下 Alt+F4。
  - IslandCaller：IslandCaller 1 随机点名、IslandCaller 2 单人点名。
  - SecRandom：SecRandom 1 闪抽、SecRandom 2 闪抽、SecRandom 2 闪抽（兼容）。
  - NamePicker：NamePicker 随机点名。
  - ClassIsland：应用设置、档案编辑、快速换课。
- R5.2 “全部”按后续 Tab 的顺序分小节排列，使用偏矩形的卡片网格（图标、标题、精简说明，过长说明需缩短）；各专属 Tab 使用整行宽度的条目，说明可以是完整段落（保留前置条件说明，如 IslandCaller 插件与 URL 协议要求）。
- R5.2a ClassIsland Tab 顶部保留提示框，提示需要开启 URL 协议。
- R5.3 卡片可拖入预览主栏的任意允许位置；同一组件可重复添加。
- R5.4 组件卡片/条目右侧有一个操作键：主栏（含 More）中没有该组件时为“+”，点击后自动添加——B1 中组件数（不计分割线与设置按钮）少于 2 时追加到 B1 末尾，否则追加到 More；已有该组件时变为垃圾桶图标，点击删除全部实例（含 More 中的）。已有时仍可通过拖动再添加一份。
- R5.5 内置组件本轮只有“分割线”（暂放在“全部”的第一小节，见待确认 Q6）：只能拖动添加，没有“+”；可添加多条且允许相连；存在用户分割线时显示删除键，只删除用户添加的分割线，不删除固定交界分割线。
- R5.6 卡片拖拽与预览按钮拖拽使用同一套反馈（浮起跟随、插入提示、收纳提示、垃圾桶、跟随浮窗）。

### R6 持久化与真实主栏同步

- R6.1 每次放下（或删除、重置）后立即持久化，并使真实主栏同步为相同布局。
- R6.2 原组件开关中已开启的组件迁移到新布局中，不丢失；迁移只发生一次。
- R6.3 重置只恢复主栏布局（及旧组件开关），不改变尺寸模式、排列方向等显示偏好。

## 约束

- 兼容 Windows 7 SP1 + KB2670838；MSVC v143 / C++20。
- 不引入新的第三方依赖；设置页不新增独立渲染窗口。
- 最小化修改：不顺手重构与本功能无关的 Bar/设置代码。
- 改动的 `.cpp/.cppm/.h` 保持 UTF-8 BOM + CRLF。
- i18n：新增文案全部走 i18n 键，zh-CN 为基准，其他语言用 `Scripts/i18n.ps1 sync`（pwsh）后补译。

- [ ] 预览有光影与悬停浮窗；抓起时主栏动画缩短、放下时动画展开；动画关闭时直接到位。
- [ ] 鼠标和触摸都能完成：A1/A2 区内排序、组件在 B1 与 More 之间移动、拖到垃圾桶删除、从卡片拖入新增。
- [ ] 默认 A1/A2 按钮无法删除、收纳或跨区；固定交界分割线无法拖动或删除；设置按钮不可删除，只能在 B1/More 间移动且始终恰好一个。
- [ ] B1 无数量上限，放入 B1 的组件全部显示在真实主栏上；用户分割线可放入 A1/B1/A2 并在重启后保持位置。
- [ ] 预览中可展开 More 面板，面板内可排序、可拖出；拖动停留 More 约 0.5 秒自动展开。
- [ ] 卡片“+”按“B1 已有 ≥2 个组件则进 More”的规则添加；已有实例时变为垃圾桶并删除全部实例。

- [ ] 每次编辑后真实主栏同步更新，重启后布局保持；旧版组件开关的用户选择迁移后不丢失。

## 已确认决定（2026-11-20）

- B1 不设上限；新增组件只进 B1/More；用户分割线可进 A1/B1/A2；A 区后续还会加入多支笔（本轮不做）。
- 预览中可展开 More 面板编辑收纳项。
- 设置按钮不可删除，可在 B1/More 间移动。
- “+”自动添加：B1 已有 ≥2 个组件时进 More。
- Tab 分类与“全部”卡片/专属 Tab 条目两种样式如 R5。

## 按默认处理的事项（2026-11-20 用户要求直接开始实现）

- 分割线卡片放在“全部”第一小节，不单设“内置组件”Tab。
- 键盘操作（无障碍）本轮不做。
- 预览尺度跟随设置页布局单位（随设置窗口 DPI），不受主栏自身缩放与任务栏基准影响。
- 旧组件开关一次性导入：前两个进 B1、其余进 More，导入后开关清零。
