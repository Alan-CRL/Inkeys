# C4 组件页快捷块、重置与组件库

## Goal

完成组件页预览下方的三个区域：快捷方式块、重置默认块、组件库，替换原组件开关。总体设计见父任务 `design.md` §6，需求见父任务 `prd.md` R3–R5。

## Requirements

- 快捷方式块：跳转行（图标、标题、说明、右侧箭头），点击跳到“窗口与显示器 → 窗口”（尺寸模式与图标顺序所在页）。
- 重置块：两段式按钮，首次点击文案变“确认重置”，3 秒内再点执行；超时或离开页面复位；执行 C1 的 `Reset`。
- 组件库：分区标题“添加组件”；Tab 依次为全部、桌面操控、IslandCaller、SecRandom、NamePicker、ClassIsland，默认“全部”。
  - “全部”按后续 Tab 顺序分小节，偏矩形卡片网格，说明精简；专属 Tab 为整行条目，说明完整；ClassIsland Tab 顶部保留 URL 协议提示框。
  - 分割线卡片位置按父任务 Q6 的结论。
  - 右侧操作键：无实例时“+”（分割线没有“+”），执行 `AutoAdd`；有实例时为垃圾桶，执行 `RemoveAllOf` / `RemoveUserDividers`。
  - 卡片/条目可拖动，浮起的是按当前尺寸样式渲染的按钮图标，复用 C3 的拖放与反馈。
- 删除原 16 个组件开关的 UI。
- i18n：新增文案走 i18n 键，zh-CN 为基准，其他语言用 `pwsh Scripts/i18n.ps1 sync` 后补译。

## Acceptance Criteria

- [ ] 快捷方式块跳转正确；重置需二次点击，3 秒超时复位，重置后布局与新装一致。
- [ ] Tab、两种卡片样式、ClassIsland 提示框符合需求；“+”与垃圾桶切换正确，阈值符合“B1 已有 ≥2 个进 More”。
- [ ] 从卡片拖入预览的完整流程可用（鼠标与触摸）。
- [ ] `setting_design_tests` 中组件页相关断言更新并通过；导航用例不受影响。
- [ ] `InkeysRepo.sln` `Debug | ARM64` 构建通过。

## Dependencies

快捷块、重置块、卡片静态布局依赖 C1；卡片拖动依赖 C3。
