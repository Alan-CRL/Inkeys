# 笔速橡皮与 OC 平滑

## Goal

在 draw3 恢复 draw2 的笔速橡皮，并用基于 DIP 路程、方向与时间滞回的 OC 控制器解决左右往返擦除时转折点瞬时速度归零导致的尺寸塌缩。鼠标和笔在 Hover 阶段预演尺寸，触摸从小尺寸起步；触摸及倒转笔尾橡皮发生可修正断触时延续各自的 OC 状态。

## Requirements

- `3` 选择橡皮工具；仅当前工具为橡皮时，`C` 在固定 `50px` 与笔速模式间切换，默认固定模式并忽略自动重复。`3` 不重置已选择模式。
- 一次物理接触批次锁定橡皮模式；活动 contact、后加入的同批 contact 及断触候选不受中途 `C` 切换影响。
- 笔速直径范围固定为 `20 / 50 / 200px`。所有运动特征先除以 `dpiScale` 转为 DIP，输出宽度继续沿用现有物理像素契约。
- OC 使用最近 `64ms` 的累计路径长度，不使用窗口首尾位移；小于 `0.25 DIP` 的输入抖动先累计。`0.75 / 3 / 24 DIP` 分别映射到最小、常态和最大直径。
- 增大以 `900px/s` 追随；目标比当前至少小 `4px` 才进入减小候选。同向慢速确认 `60–90ms`，近零或方向不明确认 `110–140ms`，当前尺寸越大越难减小。
- 确认减小后以 `500px/s` 回落。大尺寸先回到 `50px` 并稳定 `60ms` 才允许继续变小；从 `200px` 回到 `50px` 总耗时约 `390–440ms`，最终必须可以恢复。
- 转向角达到 `135°`、转折前窗口路程不少于 `3 DIP`，且 `110ms` 内反向移动达到 `1.5 DIP` 时保护转折前尺寸。保护最多 `120ms`、连续硬上限 `160ms`，重新触发前必须继续移动 `8 DIP`。
- 每个 Touch contact 拥有独立 OC 并从 `20px` 开始。累计路程 `0–8 / 8–20 / 20–32 DIP` 依次将允许上限从 `20` 放宽到 `50`、再到 `200px`，保证点按和快速短划保持较小。
- Mouse、普通 Pen 橡皮和倒转笔尾分别维护 Hover OC；Down 继承匹配 Hover 的完整状态，正常 Up 后交回。Hover 停止后进行最长约 `600ms` 的有界收敛，稳定后不得持续唤醒绘制线程。
- Touch 橡皮和倒转 Pen 橡皮启用断触修正。OC 在候选期间冻结，成功重连后加入桥接 DIP 路程并续用；普通 Pen 与 Mouse 不新增断触修正。
- 笔速橡皮继续关闭 prediction 与实时笔锋，真实点直接累计到 L1；逐点宽度进入 Stored Stroke、撤回/重做和重放，不改变 GPU/HLSL 数据协议。
- 每个 Touch contact 和断触 Runtime 独立保存状态，不允许多指或普通/倒转 Pen 之间串用 OC。

## Acceptance Criteria

- [ ] 相同 DIP 轨迹在不同 DPI 和 60/120/240Hz 采样下得到近似一致的尺寸。
- [ ] 恒速左右往返在转折点不明显塌缩；明确同向减速在规定确认时间内开始变小，持续慢速短幅往返最终会恢复。
- [ ] Touch 点按和短划保持小尺寸；双指不同速度产生独立尺寸，分别断触后恢复到各自状态。
- [ ] Mouse/Pen Hover 光标实时模拟尺寸，Down 首点与 Hover 尺寸连续；倒转笔尾可断触重连，普通 Pen 不会误重连。
- [ ] 动态宽度正确进入 L1、最终文档、撤回/重做、重放和光标 dirty bounds。
- [ ] ARM64 Debug/Release 完整 solution 构建、两套无窗口测试、`git diff --check` 与编码/换行检查通过。

## Out Of Scope

- 不增加橡皮设置 UI、持久配置或额外快捷键提示。
- 不修改现有 GPU 顶点格式、HLSL、文档存储格式和普通笔速度压感算法。
- 不为普通 Pen 或 Mouse 开启断触修正，不改变 draw3 既有手势/导航优先级。
