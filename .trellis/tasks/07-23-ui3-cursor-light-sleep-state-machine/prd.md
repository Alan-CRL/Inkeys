# UI3 第三光源休眠状态机

## Goal

限制 UI3 第三鼠标光的全局跟踪寿命，避免鼠标在无关区域持续移动时反复唤醒全屏 WARP 渲染，同时保留靠近 UI 时的连续追光体验。

## Requirements

- 仅修改 UI3 Bar 和画布开始输入的通知入口，不修改传统 `IdtFloating`，不重构现有 PointLight、Gaussian Blur 或分层窗口渲染。
- 第三光源初始处于休眠状态；鼠标真正进入 UI3 可接受鼠标消息的可见区域后才激活并从 0 透明度淡入。
- 激活后注册 `RIDEV_INPUTSINK` 全局鼠标 Raw Input；离开可接受消息区域时立即进入最多 5 秒的宽限状态。
- 5 秒计时只在“区域内 → 区域外”的状态转换时启动，区域外的后续移动不能反复重置计时。
- 宽限期内重新进入可接受消息区域时取消超时并保持激活；超过 5 秒未返回时注销 Raw Input、停止位置更新并让第三光源平滑淡出。
- 第三光源只在距离当前可见 UI 外框 50 个逻辑像素内参与渲染；物理阈值为 `50 × barStyle.zoom`。超过该距离时立即淡出并停止因位置变化唤醒渲染，但宽限期内仍保留轻量 Raw Input 以检测返回。
- 进入休眠后，仅进入可接受消息区域可以重新激活；仅回到 50px 邻域不能唤醒。
- 鼠标在画布上开始一次实际按下输入时立即进入休眠语义：注销 Raw Input、淡出第三光源，直到再次进入 UI3 可接受消息区域。
- 第三光源淡入、淡出均从当前强度连续续接；动画开启时沿用现有 300ms 和速度倍率，动画关闭时保持即时隐藏的既有契约。
- 5 秒等待不得通过持续渲染或新增轮询线程实现；使用窗口消息计时和绝对截止时间。
- Raw Input 注册/注销失败只记录一次，失败路径不得影响主光、基础灰边或其他 UI 交互。
- 保持目标文件原编码、CRLF、现有格式，并为状态转换和线程边界添加简短中文注释。

## Acceptance Criteria

- [ ] 启动后在 UI3 外移动鼠标不会启用第三光源，也不会由第三光源唤醒渲染。
- [ ] 进入 UI3 可接受消息区域后第三光源平滑淡入并开始全局跟随。
- [ ] 离开区域后 5 秒内返回会取消休眠；连续在区域外移动不会延长原截止时间。
- [ ] 宽限期内超过 `50 × zoom` 后第三光源淡出且位置变化不再触发 PointLight 重绘；重新靠近 50px 内可恢复，直到 5 秒截止。
- [ ] 超时后 Raw Input 被注销；进入 50px 邻域无反应，真正进入 UI3 可接受消息区域才重新激活。
- [ ] 画布鼠标按下立即触发同一休眠路径，淡出期间重新进入 UI3 时可以从当前强度反向淡入。
- [ ] UI 动画关闭时第三光源保持隐藏且不继续全局跟踪。
- [ ] `git diff --check`、目标文件 UTF-8/CRLF 检查和完整 `InkeysRepo.sln` `Debug | ARM64` 构建通过。
- [ ] 不修改 PointLight 视觉参数、Gaussian 资源策略、传统悬浮栏和无关输入行为。

## Out of Scope

- 渐变画刷跨帧缓存、Gaussian Blur 降本、全屏 target/脏区重构和帧率忙等待调整。
- 新增配置项、设置 UI、性能阈值开关或传统 `IdtFloating` 同步实现。
- 将鼠标第三光源扩展为触摸或数位笔悬停光源。
