# 按设备光标设置页与笔光标(子任务 B)

## Goal

将设置页“绘制→光标”的两个下拉改为入口 + 专页;专页内按设备(鼠标、触摸、屏幕笔、数位板)独立选择光标并内联预览,新增小圆点光标和“笔设备高亮模式”。

## Requirements

### R1 设备与选项

| 设备行 | 可选光标 | 默认 |
| --- | --- | --- |
| 鼠标(含触摸板) | 系统光标 / 画笔图标 / 小圆点 / 高亮小圆点 | 系统光标 |
| 触摸 | 无光标 / 圆形 / 画笔图标 / 小圆点 / 高亮小圆点 | 无光标 |
| 屏幕笔 | 圆形 / 画笔图标 / 小圆点 / 高亮小圆点 | 圆形 |
| 数位板 | 圆形 / 画笔图标 / 小圆点 / 高亮小圆点 | 圆形 |

- “无光标”只出现在触摸行。
- 小圆点:固定小尺寸,不随笔宽;普通=无高亮描边,高亮=固定高亮描边;不受高亮模式影响。
- 圆形、画笔图标保持现有外观与热点规则。
- **荧光笔与激光笔光标保持原样**,不受本页任何设备样式影响(包括荧光笔触摸当前无光标,必须保持无光标)。图形工具、橡皮同样沿用既有专用策略(`draw3-cursors.md` 工具表)。设备样式只作用于软/硬笔。
- 触摸光标(用户已确认):仅在落笔(接触)期间显示,支持多指,每根手指各一个所选光标(类似橡皮逐指圆环);抬起即消失。

### R2 笔设备高亮模式

- 新条目 + 下拉:关闭 / 仅数位板 / 始终,默认“仅数位板”。
- 控制屏幕笔、数位板的圆形与画笔图标的外描边:关闭=都不高亮;仅数位板=数位板与 Unknown/Conflict 高亮、屏幕笔不高亮(即现状);始终=都高亮。
- 鼠标使用自绘光标时保持现状“始终高亮”,不受该模式影响。

### R3 专页与预览

- 在“绘制”页原光标位置改为单个入口,进入“光标”专页(同笔速橡皮/手掌橡皮的 `DrawingSubpage` 导航)。
- 专页每个设备条目内联预览该设备当前光标(含高亮模式效果);下拉变化立即刷新预览。

### R4 兼容与配置

- 旧 `Drawing.Cursor.MouseStyle/PenStyle` 值(0/1)继续有效,升级后:鼠标→鼠标行,PenStyle→屏幕笔与数位板行,触摸行=无光标(行为上相对旧版有意变化:旧版触摸无自绘光标,本就隐藏,故实际外观不变)。
- 非法值恢复各行默认;写盘不遗留矛盾状态。
- 设置通过既有路径:配置→deferred `SyncDraw3State()`→冻结 `QueueConfigWrite()`;不得在 ImGui 锁内访问 Controller/HWND。

## Acceptance Criteria

- [ ] 专页可见,4 个设备行 + 高亮模式行,选项与默认如 R1/R2;“无光标”仅在触摸行。
- [ ] 每行预览与实际绘制一致(圆形/画笔图标/两种小圆点,高亮模式影响屏幕笔/数位板外描边)。
- [ ] 重启后保留;旧配置升级后鼠标/笔外观不变;非法值恢复默认。
- [ ] 触摸选非“无光标”样式时,每根接触手指各显示一个所选光标,抬起消失;荧光笔/激光笔触摸行为不变。
- [ ] Headless、配置往返、i18n、完整 `InkeysRepo.sln Debug|ARM64` 通过;GUI 验收单列。
- [ ] `draw3-cursors.md` 的配置、签名、工具表、验证矩阵按新规则更新。

### R5 非 Ink 数位板识别开关(来自子任务 A)

- 设置页新增开关:“把驱动注入的鼠标当作数位板”,默认关闭。开启后,`GetCurrentInputMessageSource` 为 MOUSE 且 origin=INJECTED 的鼠标消息使用数位板行的光标并隐藏系统鼠标光标;真鼠标(HARDWARE)与触摸板不受影响。
- 依据:M6 非 Ink 日志 1213 条鼠标移动全为 device=MOUSE/origin=INJECTED,Surface 日志真鼠标为 HARDWARE。风险:远程桌面/AutoHotkey 等注入软件会被误判,故默认关;Win7/无 API 时开关无效。
- 页面文案需说明该风险;API 缺失时置灰。

### R6 来源未知的首批样本

- 笔刚进入时 Pointer 消息路径发布的样本无来源信息(Unknown),当前会闪现高亮;B 需定义 Unknown 的显示策略(例如沿用同一设备上一次已知来源,或等待 RTS 来源),并加回归测试。

## 已确认(用户 2026-11-03 补充)

- 触摸光标=落笔光标,多指逐指显示;不新增“悬停”概念。
- 高亮外观沿用现有实现(即荧光笔光标已有的高亮描边),不新设计颜色/线宽;高亮小圆点与高亮模式都复用这组既有常量。
- 荧光笔/激光笔光标与其触摸策略不变。

## 开放问题(设计评审时确认)

- 屏幕笔/数位板被判 Unknown/Conflict 时使用哪一行的样式:暂定数位板行(与现状“固定高亮”一致)。
- 小圆点具体尺寸,实现阶段用预览调整后固化到 spec。
- 依赖子任务 A 的结论:若来源分类被修正,数位板行的实际命中范围随之变化,不影响本任务数据模型。

## 变更(2026-11-03 实机评审)

- “圆形”与“小圆点”合并:不再有固定 6 DIP 的圆点。界面上只有“小圆点”(随笔宽的圆形预览)与“高亮小圆点”(固定高亮描边);选项为 鼠标 4 项、触摸 4 项、屏幕笔/数位板各 3 项。枚举值已随之重排(PenCursorStyle 0/1/2、TouchCursorStyle 0..3)。
- 鼠标行预览的系统箭头改为 Windows 默认箭头的比例(约 12x19 DIP)。
