# 乌克兰语与罗马尼亚语翻译审校记录

- uk-UA、ro-RO 各完成全部 679 个叶子值；以 zh-CN 语义为准并参考 en-US，未机械复制俄语。
- 默认按钮：uk-UA `Гаразд / Скасувати / Так / Ні`；ro-RO `OK / Anulare / Da / Nu`，与根会话默认按钮分派一致。
- 内容使用 NFC；罗马尼亚语使用逗号下标 `Ș/ș/Ț/ț`，未用旧式 cedilla 替代。乌克兰语保留 `Ґ/Є/І/Ї` 等正确字符，词内撇号使用 U+2019。
- 短标签区分撤销/重做、恢复画布、清空、选择和穿透。乌克兰语穿透短标签为 `Наскрізь`、主栏硬/软笔分别 `Тв. перо / М’як. перо`；罗马尼亚语穿透短标签为两行 `Prin\nfereastră`，完整设置说明使用 `Clicuri prin fereastră`，硬/软笔按钮采用 `Stilou / Pensulă`、详情为 `Peniță rigidă / Peniță moale`。
- 全部权限/重启/UAC/安全软件/数据保护条件及快捷键三段说明保留；DDB 的既有声明按中文原义翻译，没有改写合同或提出新保证。
- 与英语相同的值均经检查：品牌/协议/软件原名、RGB/Esc/Arm64、原生语言菜单名、链接或罗马尼亚语正常同形词（Laser、Control、General、Cursor、Conflict、Feedback 等）。并非未译标记。
- 人工母语复核建议：教学笔型的短词与详情对应、穿透模式简短称呼、手掌橡皮的识别窗口/面积阈值、快捷键模态/权限说明、DDB 许可长文。键完成率不等于母语者审校完成。
- 独立检查：679键完整且顺序与基准一致、占位符一致、必要换行一致、无待译标记、NFC、原模板 CRLF。实际字形/字面/固定槽离屏与构建由根会话统一验证。
