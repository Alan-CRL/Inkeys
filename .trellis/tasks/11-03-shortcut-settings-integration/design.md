# 快捷方式整合技术设计

## Scope and Boundaries

只调整当前编译中的设置页、配置合同及快捷方式助手消费者。保留现有 ShortcutAssistantClass/ShellLink 实现边界，不为此次 UI 整合迁移整个插件模块，不修改 PPT/Office、绘图或全局线程架构。`research/current-behavior.md` 为现状证据，`prd.md` 为产品合同。

## UI and Navigation

- 在 `Setting.Design.h` 的 GeneralSection 末尾增加独立 `DesktopShortcuts` 子页；原 Shortcuts 仍指键盘快捷键，原枚举值不复用。
- 同步 GeneralSectionCount、Shell 的子页文案/图标、选中/滚动/转场身份及测试镜像。窗口/控件 ID 固定，不依赖翻译文案。
- `Setting.Pages.h/.cpp` 的 GeneralDraft/GeneralEvents 只描述 UI 草稿与交互事件；名称输入缓冲跨帧保留，不从配置每帧覆盖编辑文本。
- 新页顺序：应用程序标题、创建条目和按钮、名称内联块、快捷方式保障标题、修正开关、补建开关。输入框仅在自定义时显示，沿用已有条件块和卡片动效，不另造布局系统。
- 删除基本页创建/更多入口与插件快捷方式助手总览/详情分支，只清理确实无其他消费者的枚举/状态/i18n 键；其他插件内容保持。
- 使用现有 `TextBox(std::string&)` 和 ComboBox；布局以可用宽度约束左右控件，验证最小窗口及长翻译。无效输入就地提示，禁用本次创建动作。

## Persistent Contract

文件为 `Inkeys/Config/main.json`，在现有 INKEYS_CONFIG_SCHEMA 下新增 `Application.Shortcut`，均为 NoUpload：

| 字段 | 类型与缺省 | 合同 |
| --- | --- | --- |
| NamePreset | int，0 | 0=Inkeys，1=简中品牌，2=批注，3=批注工具，4=自定义；非法值回退 0 |
| CustomName | Unicode 字符串，空字符串 | 只在自定义模式使用；缺失/非法且当前选择自定义时回退有效 Inkeys |
| CorrectLnk | bool，true | 保留旧修正语义 |
| CreateLnk | bool，false | 保留旧缺失补建语义 |

下拉显示顺序与持久化编号分离：zh-CN 为 [1,0,2,3,4]，其他语言 [0,2,3,4]。不持久化翻译结果作为预设身份。

`CustomName` 可使用现有 std::wstring codec；字符串不能用只支持无锁平凡类型的 IdtAtomic 包装。通过 Config 内受现有 rwMutex 保护的专用读取/设置方法访问名称对（NamePreset、CustomName），使 Config 复制、序列化与名称修改不发生数据竞争；不要把私有锁公开给设置页。标量开关沿用 IdtAtomic<bool>。

新配置不导入旧 `PlugIn.ShortcutAssistant`。删除 setlist 的旧结构、ReadSetting/写回/缺省赋值，并在 CaptureSettingJson 清除旧子树以符合 AutoClean=false 的已有退休键合同。同步仍参与编译的生产测试初始化；不为仅保留的历史源码做无关整理。

## Name Resolution and Validation

- 一处纯名称解析负责：稳定预设 ID、当前语言、品牌回退、用途翻译、自定义值及文件名校验，UI、手动创建和启动保障共用。
- 所有语言缺省 ID=0。ID=1 在非简中归一为 0 并经正常配置队列保存，不自动恢复到品牌项。
- 用途预设从当前语言 i18n 文本获得；自定义不翻译、不自动补品牌或括号，不擅自修剪用户内容。
- 输入表示快捷方式的基本名称，文件操作层统一拼接 .lnk。校验考虑实际桌面路径与 ShellLink API 的能力，不凭 UI 长度截断文件名。Windows 文件名规则应在实现时以主系统 API/官方规范核对。
- 进入自定义时冻结切换前的显示名称并种入草稿和已保存的有效自定义偏好；恢复已处于自定义的配置则直接使用其保存值。无效编辑只留 UI 草稿，创建不可用，最后有效持久化值保持。
- 配置恢复还需结合实际桌面目录长度校验；单独合法但超出实际路径预算的自定义名称保留原文，选择并保存 Inkeys。
- 有效文本 Enter/编辑结束/离页/关闭设置时提交，避免逐按键写盘；已保存预设变化可立即排队写配置，但不能附带文件操作。

## Data Flow and Side Effects

```text
页面事件 → 校验/更新名称或两个开关 → QueueConfigWrite 冻结快照 → FIFO 写 main.json
创建按钮 → 同帧冻结解析名称、桌面路径、exe → 现有业务队列 → ShellLink 创建
启动 → config.ReadAll → 解析名称及两个开关 → 现有启动保障入口
开关原有即时应用 → 冻结名称及两个开关 → 业务队列 → 原保障逻辑
```

- 名称/语言变化只走配置写入，不入队保障或创建；点击创建只处理目标名称，旧名按原保障语义在后续动作中处理。
- worker 只消费自有名称、路径和开关快照，不在执行时重新读取用户正在编辑的字符串或当前语言。使用现有业务队列及其 COM 生命周期，不增常驻线程。
- 保障入口调整为可接收解析好的名称/开关快照。启动默认入口可在 ReadAll 后取一次快照；设置即时入口排队执行，保持原开关触发条件。
- 比较所选路径与枚举路径时按 Windows 不区分大小写的身份处理，避免新自定义名只改大小写时创建后又删除同一个文件；不扩大目标识别算法。
- 继续保留两种动作：修正指定名称的错误目标、将指向当前 exe 的其他名称统一；补建处理缺失/目标不符。此任务不扩展历史版本/任意名称的识别策略。
- 失败不得由 UI 伪装成功；按现有返回/日志通道传播文件操作失败，只补充当前路径所需边界检查。

## i18n

为新页、两类标题、短预设、名称选择/自定义提示和输入错误提供基准及各语言资源。预设固定半角括号和所需无空格结构；简中品牌项按语言身份显示。运行已有 Scripts/i18n.ps1 sync 生成头与快照，再 check 并审查各语言差异；禁止手改生成头。不全局改写 Widget.LnkName 或其他产品品牌文案以替代本功能局部预设。

## Risks, Compatibility and Rollback

- 非简中选项数少一项，不能用下拉索引直接当持久化值。
- 字符串与异步全 Config 快照复制必须同步，不能因为 worker 冻结就忽略生产者之间的并发。
- 保留原修正逻辑意味着保障动作仍可能统一已有其他名称；名称编辑本身不触发该动作。
- main.json 新字段缺省工作，无旧配置迁移；回退到旧程序时它仍只认旧配置，不承诺双向保留本次偏好。
- 回滚仅针对本任务代码/字段，不删除用户桌面内容，不改第三方或构建工具配置。
- GUI 外观、真实用户桌面和更新后的启动行为仍需用户人工验收；自动化限定临时目录及无窗口测试，不以编译代替视觉验收。
