# 橡皮属性栏与全局粗细控制

## 目标与基线
在现有 feature/eraser 上实现独立 UI3 橡皮属性栏和全局基础直径/自动粗细/灵敏度，完整需求以 [request.md](request.md) 为准。
基线 HEAD=2f87fe69；已有未提交 Inkeys/PptCOM.dll 必须保留。用户明确授权新建任务并直接实现，全部由主 Agent 顺序完成。

## 产品要求
1. 第一次点击仅切擦除，再点展开/收起；切工具、折叠、画布操作关闭，首笔正常执行。
2. 主栏同高、动态宽度，复用属性 surface/线程/光源；清空 | 16/32/64 DIP | 自动粗细拆分按钮。真实 DIP 圆形光标预览独立于 UI 缩放，竖直居中，只裁上下；倒转、工作区限界和有效命中一致。
3. 全局 B 默认32，灵敏度默认中；五入口原类型和 penResponse 保留。统一自动命令一次写五种 kind；混合态横杠且点击全开，不另存 bool。
4. 固定直径=B；自动范围8/16/80、16/32/160、32/64/320 DIP。仅尺寸标尺派生；中档中灵敏度保留既有动态控制器、面积、非Touch会话。
5. 浮窗含低/中/高及禁用齿轮；大小/自动/灵敏度操作保持打开。主按键与箭头互不触发。提示说明基础尺寸/混合态/暂未开放。
6. 清空唯一业务入口、只当前页批注、保留底图，接受后关闭，保持擦除。空画布禁用，单次撤销恢复。
7. 持久化采用稳定数值，校验非法值。活动接触锁存，兼容性只随有效配置变化。
