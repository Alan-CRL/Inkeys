## CV 源码事实

VisualMotionTracker.cpp 是普通 Pimpl，标准库公开头，不持线程/窗口。Process 顺序为输入检查/灰度半分辨率、Forward、细化、Backward/FB、一致集、NonTranslation、Ambiguity、空间/存活/点数门、Coverage、jump、出生锚点一致性、retained/refill、一次可信提交。最多 320 点。拒绝不换参考，连续三拒绝 Paused，严重错误立即 Paused；外层 catch 会转拒绝，因此 debug 记录必须 noexcept/无分配传播。Result 在提交后覆盖 referenceSequence，所以需单独留住调用前 reference。

各提前路径都有统计未执行的默认 0；不能用 UI 重判阈值。NonTranslation 联合条件、静止主流次流保护和 anchor consistency 的失败都应在生产原位置记录。Capture 失败不一定调用 CV。

## 捕获/业务

FreezeCapture::Frame 为 callback 内有效的 top-down BGRA 借用，含 geometry/source/workArea、原物理映射 1:1、PrintWindow 完成 timestamp、session/sequence、quality/read statistics。正式 tracker Frame 位于 ScrollFollow.cpp，原 Mag worker 同步调用，WorkArea 与实际 frame bounds 取交集后按 stride 偏移输入，不能再次取图。Initialize 与 tracking ACK 之间可能 AwaitTracking；Paused 进入后 control Tick 会 StopCapture，Frame 早退不能把默认 MotionResult 当真实拒绝。

FreezeCapture::Session Pump 锁外读图/回调，锁内计数和截止时间；无效质量帧不发布，API 失败与质量失败计数不同。可读 Snapshot 没有完整采样时间/最近失败 API 细节，增加最小数值只读观测即可，不重构调度。
