# 界面字体非整数像素渲染调查与实验开关

## 目标

缓解主栏和控件UI在自由缩放，尤其大屏默认48DIP基准下的字体模糊。关闭非整数像素字号选项时，文字使用截断小数后的实际像素字号，避免四舍五入使字号变大、文字显示不下。

## 范围与授权

- 用户明确要求新建Trellis任务，并提前批准规划和实现，无需重复等待规划批准。
- 用户后续收窄范围：只修改主栏和控件UI字体；设置窗口只新增开关，不改变其文字渲染。
- 调查字号创建、缩放变换、抗锯齿及字体缓存，选择足以解决问题的最小修改。
- 实验页新增“允许界面字体以非整数像素尺寸渲染”，默认关闭；开启保留原尺寸行为。
- 保持原文件编码和换行、配置持久化机制、简中/繁中/英文资源。
- 不提交commit或push；仅无交互窗口验证，不运行GUI或Computer Use。

## 验收标准

1. 实验页开关可保存；旧配置缺少字段或字段非法时默认为关闭。
2. 关闭时最终像素字号不保留小数且不大于原始值；开启时使用原值。
3. 对DPI、自由缩放、48DIP基准和控件实际变换应用相同策略；可保留现有未截断文字测量作为布局上界，避免提示框和控件随量化字号重排。
4. 切换时受影响UI刷新及字体/布局缓存正确失效；图标和布局继续自由缩放。
5. 必要边界有中文注释，并执行有效的无窗口回归、i18n检查、diff格式检查、完整InkeysRepo.sln Debug|ARM64构建；环境故障单独记录。

## 排除项

不调整设置文字、迁移历史UI、修改第三方库、切换渲染后端或更换字体，不改变整体缩放默认值。真实大屏清晰度观感留待独立人工观察，数值回归不代替观感证据。
