# 自由画布平移与动态渲染

## Goal

让每页墨迹使用稳定的 Canvas 世界坐标，并提供低延迟的键盘/双指平移、自然惯性、笔接管以及随设备性能自适应的动态清晰渲染，为后续 Inkeys3 白板 UI 提供画布内核。

## Requirements

- `InkViewport.x/y` 表示屏幕左上角对应的 Canvas 坐标，当前 `scale` 固定为 1；视口限制为约 `+/-1048576 DIP`。
- 方向键一次移动可见内容 64 DIP，忽略 autorepeat，不产生惯性；每页独立保存/恢复视口。
- 静止批次从零 Touch 开始，前两指在 180ms 内落下才进入平移；首指已经产生的任意工具 L0/L1 内容必须取消并重建。
- 平移中额外 Touch 不绘制；剩余一指可继续拖动；最后一指抬起后进入惯性。
- 惯性中首指等待 180ms 且不绘制；第二指及时到达则继承动量，超时后首指本次不补画，迟到的其他指仍可绘制但不能再组成平移。
- 新手势以约 120ms 混合旧速度；同向加速、反向先制动再反向，速度限制约 24000 DIP/s。
- Pen/Mouse 接触阻止双指手势；Pen hover 加强惯性减速，Pen Down 立即停止平移/惯性并从固定视口绘制。
- Undo 只改变墨迹，不改变视口；视口变化丢弃屏幕相关热前像，但保留 Canvas-local composition cache。
- 平移时按速度方向预建 tile；性能不足时优先保持输入和帧率，以可信旧快照模糊重投影覆盖已有区域，未知区域允许显示真实透明背景。
- 模糊兜底不得写入 L2、文档、history、热前像或 composition cache；Laser、粒子和光标始终按当前视口重画。
- 暂不实现 pinch、rotation、边界拉伸/回弹和 EDID 物理手掌距离判断。

## Acceptance Criteria

- [ ] 键盘和双指能够平移负坐标及远离原点的画布，绘制结果仍固定在 Canvas 坐标。
- [ ] 180ms 边界、触摸接管重建、惯性候选、额外触点、同向/反向接续及 Pen hover/Down 均通过自动或人工验证。
- [ ] 翻页恢复各自视口，离屏 Undo 不移动当前视口，Resize 后能从文档恢复当前视口内容。
- [ ] 低速时可见区逐步保持/恢复清晰；高速或过载时不阻塞输入，可信快照只在覆盖交集内兜底且不会污染权威层。
- [ ] ARM64 Debug/Release 完整解决方案构建成功，两个配置的测试程序通过；未具备的真实 Touch/D3D Debug Layer 场景如实记录。
