# UI3 主栏状态指示器

## Goal

在 UI3 主栏的主按钮上实现"状态指示器"：新状态出现时以指示环呼吸 + 胶囊弹出提示，随后收起为主按钮右上角的常驻小圆形队列；支持多状态堆叠、点击展开/收起、跳转交互。初期接入 PPT 放映、超级置顶、新版本三类状态，并提供设置开关与调试入口。

## 前置条件

- [x] 合并 `theme`（1469722a，主题/透明度设置）与 `feature/i18n`（cf4d9120，八种新语言）最新提交到 `feature/state`；冲突已解决，新增语言补齐合并后新键（i18n check 11 语言 693/693）。
- 指示器必须遵循合并后的主栏浅色/深色主题与统一背景/内容透明度设置，所有新文案走 i18n 并覆盖全部 11 种语言。

## 术语

- **主按钮**：UI3 主栏的主按钮（超椭圆外形）。
- **指示环**：叠加在主按钮超椭圆边框之上的加粗、着色边框。
- **胶囊（展开态）**：从主按钮上端弹出的提示条，左侧文字段 + 右侧填充圆形图标。
- **圆形（收起态）**：胶囊收起后留在主按钮右上角的填充小圆形，半透明常驻。
- **圆形轨道**：多个收起态圆形组成的堆叠队列。
- **持久状态**：注册后一直存在、直到被注销的状态（PPT 放映、超级置顶、新版本）。
- **通知**：只提示一次、不进入圆形轨道的状态。

## Requirements

### R1 层级与归属
- 指示器属于主栏 UI3，主要出现在主按钮上，Z 序高于主按钮。

### R2 指示环
- 新状态出现时，指示环在主按钮边框上方叠加出现：边框变粗、变为该状态的强调色；用户开启光影（边缘光影）时同时带光源漫反射。
- 出现方式：渐显 → 呼吸 → 渐隐。指示环消失时机与胶囊 3s 收起同时。
- 仅在非绘制状态出现（即没有画笔颜色的第一光源光影时），避免遮挡。
- 新版本 + 已开启静默更新：下载开始且进度不为 0% 时出现指示环，把整个超椭圆边框作为进度条（下方原边框为轨道），按下载百分比推进；完成后开始 3s 消失。

### R3 胶囊（展开态）
- 与指示环同时从主按钮上端由小变大、非线性渐显并回弹出现。
- 结构：右侧为填充圆形，内含白色/黑色图标（随主题）；左侧为同色边框 + 黑色/白色填充的文字段，文字与主栏按钮文字同为加粗字体，颜色为该状态强调色。
- 宽度由文字决定；较窄时文字居中；超过上限（比主按钮宽度窄一些）时文字滚动，并保证 3s 内滚动完毕。
- 显示 3s 后：左侧文字段收进右侧圆形下方并消失，圆形移动到主按钮右上角（可超出主按钮边框），透明度变为一半并停留（持久状态）。
- 通知类：不做左侧收起，直接缩小并以反向回弹动画渐隐退场。
- 持久状态被注销：渐隐缩小退场。

### R4 堆叠
- 多个展开态同时存在时按动画向上排列：**旧的在前（最下、最上层 Z 序、文字完整）**，新的依次排在其后向上错开，只露出一点颜色、看不到文字；错开到正常态窗口边界（只比主按钮边框高出一点）后不再继续向上，更多的完全重叠。
- 各自 3s 到期：旧的先到期，向右收起进入下层圆形轨道；其后的展开态依次向下移动补位（有动画）。
- 圆形轨道从左向右堆叠，重合度高：**新的在上层、越新越靠右**，旧的在下层靠左；被遮住的只露出颜色看不到图标；向左堆到正常态窗口边界后不再继续向左/向下错开。某个圆形消失后，其左侧的圆形右移补位（有动画）。
- 数量上限 25 个。

### R5 交互
- 展开态：点击后直接变小进入圆形轨道；通知类则直接消失。
- 圆形轨道（多个）：点击后以主按钮为圆心向上方沿多层同心弧展开排列（每层放满固定个数后向外加一层）；点击某个圆形展开其原先的展开态（可覆盖其他圆形）；再次点击同一个或其他圆形则收起。
- 展开后点击主按钮、主栏其他部分，或 3s 内没有新的圆形点击交互，则自动收起整个轨道回到堆叠。
- 圆形轨道只有一个时可直接点击；即使无跳转功能（PPT、超级置顶）也有按下与悬停交互，规则与主栏按钮一致（点击后不移动则没有悬停态）。
- 新版本圆形：在叠加展开时点击不展开胶囊，而是直接跳转到设置-软件版本页；若满足开屏动画播放条件则播放，开屏动画渐隐后直接到目标页（与主栏橡皮属性"自动粗细"小齿轮的跳转一致）。

### R6 窗口边界与脏区
- 正常堆叠时不得超出原主栏窗口边框（例如圆形从右向左堆满后不再继续向左/向下）。
- 点击展开后允许超出窗口边框；展开前后正确调整窗口边框，并正确处理脏区。

### R7 状态源（初期）
| 状态 | 文案 | 强调色 | 生命周期 |
|---|---|---|---|
| PowerPoint 放映 | "放映模式" | PowerPoint 橘红 `#C43E1C` | 放映开始注册，真正结束放映注销（类似 Inkeys 放映标志）；放映中打开白板不注销 |
| WPS 放映 | "放映模式" | WPS 红 `#E8352B` | 同上，仅配色不同 |
| 超级置顶 | "超级置顶" | 深蓝 `#1F4FB8` | 超级置顶只在启动时确定、运行中不变：启动成功后弹出一次胶囊，随后以圆形常驻到退出；沿用 Inkeys2 大头针图标 |
| 新版本 | "新版本" | 绿 `#2EA043` | 新版本存在期间（发现新版本 / 已下载待重启安装）一直存在。未开启静默更新：检测到新版本即正常弹出。开启静默更新：下载 >0% 时胶囊与进度环同时出现，胶囊 3s 后照常收起，进度环继续反映百分比直到完成后 3s 渐隐 |

- 插件页中超级置顶"是否启用提示"的展示行移除，改为状态指示器勾选项中的"超级置顶"一项。
- 图标：新增主栏 SVG 资源（放映、大头针（参考 Inkeys2 pin 形态）、新版本/下载），调试随机状态从这些及若干通用图标中随机。

### R7.1 外观决策
- 胶囊左侧填充与圆形内图标的黑/白，跟随主按钮当前材质（`mainButtonLightMaterial`）连续过渡：主栏折叠时（含浅色主题）为深色填充 + 白图标，浅色主题展开时为浅色填充 + 黑图标。
- 多个状态排队展开时，指示环颜色跟随当前最前（文字可见）的状态，切换时颜色过渡；每个状态的 3s 从其到达最前位置开始计时（用户已确认）。

### R8 设置
- 位置：常规 → 外观与动画子页末尾新增"状态指示器"分节，包含两项：
  - 状态指示器总开关；
  - 勾选启用哪些状态提示（`CheckboxGroup`，同笔速橡皮）：放映模式、超级置顶、新版本。总开关关闭时隐藏勾选行但保留其值。
- 全部默认开启。
- 存储：全部新增到 `main.json` schema；首次读取时若新键缺失，从旧 `deploy.json` 的 `PlugIn.SuperTop.Indicator` 迁移一次"超级置顶"勾选值，此后旧键不再使用。
- 设置 → 软件调试页：可手动添加一个随机合成状态（随机颜色、随机长短文案含超长触发滚动、随机图标、随机持久/通知），可手动删除一个（移除最新的持久调试状态），用于测试极端情况。达到 25 个时添加按钮禁用。

## Acceptance Criteria

- [ ] 合并 `theme`、`feature/i18n` 后完整 Solution Debug | 本机原生架构构建通过，i18n check 通过。
- [ ] 新状态出现：指示环渐显呼吸渐隐（绘制态不出现），胶囊回弹弹出，3s 后收起为右上角半透明圆形；指示环与收起同步消失。
- [ ] 通知类直接缩小反向回弹退场；持久状态注销时渐隐缩小退场。
- [ ] 多个展开态向上高重合堆叠，到期依次收起，上方动画下移；圆形轨道左→右高重合堆叠，最新在最右最上；上限 25。
- [ ] 长文字在上限宽度内 3s 内滚动完毕；短文字居中。
- [ ] 点击交互：展开态点击收起/消失；多圆形点击沿半径展开、点选展开胶囊、再点收起；点击主按钮/主栏其他处或 3s 无交互自动收起；单圆形有按下与悬停反馈且符合主栏悬停规则。
- [ ] 新版本圆形点击跳转软件版本页，开屏动画规则与橡皮自动粗细齿轮一致；静默更新时边框进度环反映下载百分比，完成后 3s 消失。
- [ ] 正常态不超出窗口边框；展开态可超出，前后窗口尺寸与脏区正确，无残影。
- [ ] 浅色/深色主题、背景/内容透明度、光影开关、动画开关与速率下表现正确。
- [ ] 设置：总开关、按类型勾选（默认全开）、超级置顶提示开关迁移；调试页可增删随机状态；所有文案 11 种语言。

## Out of Scope

- 运行中切换超级置顶（现有能力需重启生效，不改变）。
- 更新流程本身（检查、下载、安装逻辑）不改，只读取其状态与进度。
- 指示器之外的其他通知中心/历史记录。

## Decisions v4（2026-11-07 环单通道与进度让位）

以下覆盖 R2、R7.1 及此前 Decisions 中冲突的环颜色插值、独立进度通道与完成停留规则；胶囊和队首真实 3s 计时保持既有合同。

- 环只有一个目标源。有展开队首时，它在自己的 3s 内独占环，颜色为自身 accent；自身存在进行中的进度周期时显示实时进度段，否则显示普通呼吸环。队列空后恢复任一可见、未退场且 progress.active 的条目；多个进度沿用上次空闲时的 idleProgress，不因其他进度更新而轮换，当前周期结束后才换另一个未完成项。后来出现新队首时让给队首，队列空后再恢复。绘制模式目标为空，环淡出，状态保留。
- 所有 owner、颜色、普通环↔进度段及进度 A↔B 切换统一先淡出旧层（RingOut≈0.20s），延迟 RingGap≈0.12s×旧层剩余 opacity 后淡入新层（RingIn≈0.30s）。允许短暂双层重叠，每层只保留自身原色，不做颜色插值；连续快速换主只保留更显眼的一层淡出，最多两层。animations=false 直接切换。呼吸按层独立，自该层开始淡入的时刻计时。
- SetProgress(complete) 时，只有该条目此刻作为当前目标源在可见层上显示进度，才置 complete=true、进度段平滑走满并停留 ProgressCompleteLinger（3s）后结束周期；其余情况立即 active=false，不能在队列空后恢复。停留中若让给新队首（或不再显示该进度），也在让位当帧结束。多个进度只给当前显示者完成停留，结束后另一个仍未完成才接续。失败（progress<0）结束周期但保留条目；同周期单调不减、回零被吸收、新周期 display 从 0 起算；100% 未确认完成的校验阶段继续呼吸。
