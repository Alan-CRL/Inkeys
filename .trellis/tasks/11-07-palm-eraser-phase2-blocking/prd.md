# 手掌橡皮激活时邻近触点抬笔与落笔屏蔽（子任务 A）

父任务：`11-07-palm-eraser-phase2`（决策 D1–D4 见父 prd.md）。调查证据：`../11-07-palm-eraser-phase2/research/codex-palm-blocking.md`。

## 问题

开启“边擦边写”（`Drawing.PalmEraser.ParallelWriting=true`）时，手掌橡皮附近的其他 Touch 触点（手掌边缘、相邻手指）仍按普通笔绘制，出现“前面在擦、后面在写”。现有屏蔽范围 `PalmNeighborBlocked` 只阻止邻近触点再被提升为手掌，并不阻止其绘制。

## 需求

| ID | 要求 |
| --- | --- |
| R1 | 手掌橡皮**激活瞬间**（候选提升为手掌成功的那一帧），屏蔽范围内其他正在书写的 Touch 触点按正常抬笔结束：保留已画墨迹，等同 Up（非 Cancel/回滚），之后该触点的 Move 忽略，真实 Up/Cancel 正常回收，不能被续接逻辑接回。 |
| R2 | 激活之后手掌移动覆盖到其他正在书写的触点，**不**截断它们。 |
| R3 | 手掌激活期间（含既有续接等待期，沿用 `PalmNeighborBlocked` 现有时间语义），落点位于任一活动手掌屏蔽范围内的**新 Touch 落笔**不产生墨迹；该触点在其真实 Up 前保持隔离，即使移出范围也不开始书写。 |
| R4 | 被拒落笔不能借普通续接绕过屏蔽；手掌自身的续接仍优先且正常。 |
| R5 | 仅 Touch 受影响；笔、鼠标行为不变。并行关闭时的既有行为（中断/拒收全部）不变。 |
| R6 | 屏蔽范围判定提供与形状无关的接口；本子任务落地圆形 `R = r + max(0.15r, 4px)`；矩形/正方形（D4）由 custom 子任务在手掌可为矩形时补齐（2026-11-07 已在 custom R6 实现，见其 validation.md）。 |
| R7 | 修订设置中与新行为矛盾的说明文案（如“不会中断其他输入”），覆盖全部语言。 |

## 验收

- AC1：并行开启，手掌激活时范围内 1–2 个书写 Touch 触点在激活帧结束为正常笔划（墨迹保留、可撤销为独立笔划），后续 Move 不出墨，真实 Up 回收无泄漏；范围外触点不受影响。
- AC2：激活后手掌移向仍在书写的触点，该触点继续书写。
- AC3：激活期间范围内新 Touch Down 不出墨直到 Up（含移出范围）；范围外新 Down 正常；笔/鼠标在范围内落笔正常。
- AC4：被拒 Down 不会续接到附近普通笔划；手掌断触在续接期限内重连仍成功并继续擦除。
- AC5：并行关闭路径行为与改动前一致。
- AC6：RTS 同步回调无新增工作；完整构建与 Palm Headless / `--draw3-palm-eraser-test` 通过；新增用例覆盖 AC1–AC5 的 CPU 可测部分；实机未测项单列。
