# C3 设置页主栏预览与通用拖放

## Goal

在设置 → 组件页顶部嵌入主栏预览，并实现通用 UI3 拖放与全部拖动反馈。总体设计见父任务 `design.md` §5。

## Requirements

- 预览用 C2 的实例渲染到设置页 D3D11 纹理并由 ImGui 合成（预乘混合）；保留阴影边距；设备代次变化时重建。
- 尺度只取决于设置页布局单位，不受主栏自身缩放影响；大/小尺寸显示高度一致；宽度不足时等比缩小；水平居中；`IconOrder` 2/3 按固定方向，其余从左到右。
- `UI3::DragSession`：鼠标与触摸、阈值、捕获、取消、接触 ID 去重；拖动源可为预览按钮或外部（组件库）。
- 反馈：抓起时浮动按钮跟随指针、主栏动画缩短；插入光标；More 停留约 0.5 秒展开、面板内排序与拖出、松手在 More 上追加；右下角垃圾桶（靠近变红）；跟随光标的提示浮窗（收纳/删除/不可放置等）；放下后动画展开。
- 落点由 C1 的约束判定决定；放下后通过 C1 的应用入口持久化并同步真实主栏。
- 拖动时靠近页面可视区上/下边缘自动滚动。
- 预览按钮悬停显示提示（同小尺寸主栏），点击不执行功能；点击 More 展开面板。
- 遵守动画开关与动画速率。

## Acceptance Criteria

- [ ] 离屏测试：大/小、深/浅、窄宽缩放、固定方向下预览布局正确。
- [ ] 拖放状态机单测：阈值、取消、鼠标/触摸去重、外部源。
- [ ] 手工：鼠标与触摸完成 A1/A2 区内排序、B1↔More 移动、More 面板内排序与拖出、垃圾桶删除、不可放置回弹；动画开/关两种情况。
- [ ] Win7 SP1 实机：预览可显示（D2D–DXGI 互操作）。失败时启用回退方案 B。
- [ ] `InkeysRepo.sln` `Debug | ARM64` 构建通过。

## Dependencies

依赖 C1（模型与应用入口）与 C2（实例）。
