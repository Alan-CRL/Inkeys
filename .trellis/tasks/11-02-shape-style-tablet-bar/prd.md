# 形状共享样式与跨场景样式记忆

## 目标

修正形状颜色/粗细未与硬笔、软笔共享的问题，并按用户指定范围管理桌面、PPT 和白板的样式，使切换工具、场景与白板主题时属性保持一致。用户于2026-11-02明确批准最终方案并要求进入实现；任务已激活为in_progress。

## 背景与证据

- 用户测试版本 20261028a；当前分支 bugfix/color，调查基线 HEAD 6df7f43f。发布准备提交 dc8d0a13 与当前核心输入链路一致，IdtState 增量仅掌擦相关；尚未核验用户安装包 hash。详见 research/version-baseline.md。
- 当前硬/软笔共用 Brush，直线/虚线与矩形分别持有独立槽；UI、业务与 Draw3 一致读取这些独立值。证据：IdtState.cpp:1585、1740、1805、2128；research/shape-style.md。旧独立槽合同不符合本轮需求。
- 当前三个工作区保存完整 StateMode，旧宽色会随工作区恢复；新的共享范围要求工具身份记忆与样式权威分开。证据：IdtState.cpp:1483、1267；research/state-lifecycle.md。
- 白板主题按页保存，实际主题/翻页由 Controller 接纳，UI 不乐观更新；同步必须覆盖主题更改、翻页、首次进入与冷恢复。详见 research/style-scope-and-whiteboard-theme.md。

## 需求

- R1a：硬笔、软笔、形状（实线/虚线/矩形）为同一个 Brush 属性组，修改任一工具颜色同步同组；不采用进入形状时复制。
- R1b：同组粗细亦完全共享；保留 Preset/ExplicitDip 身份、double 精度及设备/DPI 解析。
- R3：仅 Brush 颜色分三份：桌面+PPT 共用、浅色白板独立、深色白板独立。浅色首次默认现有红色预设，深色首次默认白色。手动改色后记忆该范围颜色，切回来恢复，不重复重置默认。
- R4：Brush、Highlighter、Laser 每组粗细各自全局共享，跨桌面/PPT/白板及背景类别均不回滚；不同组不合并成一个粗细。
- R5：Highlighter、Laser 每组颜色各自全局共享，跨全部场景和背景。两组互不合并，也不并入 Brush；保留现有默认色、笔触和透明度。
- R6：工具身份及子类型仍按工作区记忆；已有笔迹与活动笔划样式不追改。白板当前有效背景按实际 RGB 分类，纹理不改变分类，同类背景页面共用该类 Brush 颜色。
- R7：保持当前会话内记忆与启动策略，不启用停用的启动偏好恢复，不新增跨进程恢复功能。

## 暂缓项与范围外

- R2：高漫 M6/Windows 11 无法点击主栏但可白板/PPT翻页。用户要求先不修，等待日志；Windows Ink/驱动模式未知，不要求用户切换设置。Bar.Interaction.cpp:3208、9726 过滤笔兼容消息，PageControl.cpp:2844 保留 Pen 会话，属于已确认源码差异；实际设备消息尚未知。证据保存于 research/tablet-bar-input.md 和 research/touch-compatibility-long-press.md。
- 不新增形状类型，不改橡皮、输入来源过滤/会话、PPT翻页、白板页存储/Undo含义、无关 UI 或格式。
- 不启动 GUI/Computer Use；不 commit/push。默认使用无窗口验证。

## 验收标准

- AC1 → R1a/R1b：硬/软/实线/虚线/矩形任意入口改色改宽，再切工具读取同一最新值与选中态；旧独立槽不得反写。
- AC2 → R3/R6：桌面/PPT双向同步 Brush 色；浅白板默认红、深白板默认白，手改后按类恢复。翻页/改主题立即落笔使用正确色；同类页/仅纹理变化不重置颜色；旧笔迹不变。
- AC3 → R4：三组各自的预设/手动粗细从任意场景修改，切往其他场景后保留；切换显示环境按原策略重解，ExplicitDip 不失真。
- AC4 → R5：荧光与激光颜色分别从任意场景修改并全局保留；不受白板主题切换影响，互不污染 Brush/对方。
- AC5 → R6：工作区工具恢复、快捷键返回、PPT异步工具回调、激光选择记忆与活动笔划锁存保持；旧revision的UI提交不得写入新颜色范围。
- AC6 → R3/R6：失败/过期主题请求、cold load失败/stale结果不错误切色；已接纳主题的保存失败不回滚有效色；UI快照与新笔捕获使用同源有效样式，不出现首笔旧色窗口。
- AC7 → R7：全局属性保存快照不被旧工作区值覆盖，白板 Brush 色不污染桌面/PPT 色；维持启动恢复停用与原子存储保护。
- AC8：完整 Solution Debug|ARM64 构建和适用无窗口测试通过；未做真机/GUI验证需明确报告。
