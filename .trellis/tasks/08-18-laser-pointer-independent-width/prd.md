# 独立激光笔粗细与预览

## Goal

将激光笔的线径和三档快捷预设从画笔状态中独立出来，使画笔粗细调整不再影响激光笔；同时令绘制属性栏准确反映激光笔只提供三档调节的交互规则和真实的红白激光外观。

## Confirmed Facts

- `StateModeClass` 当前仅以 `laserActive` 标识激光笔，`GetPenWidth()` 在激光态仍返回当前画笔/荧光笔宽度。
- Draw3 产品状态已发布 `widthDip`，但 `DrawingTool::Laser` 的实际笔迹和光标仍固定为 `5 DIP @ 96 DPI`。
- 当前画笔快捷粗细预设是 `1 / 3 / 6 DIP`；默认硬笔宽度为 `3 DIP`，即中档。
- Draw3 激光实体外套的默认直径为 `5 DIP`，白色内芯直径为外套的三分之一；渲染器还存在散射和辉光，但本任务的 Bar 预览明确不绘制它们。
- 激光快捷粗细预设已确认使用细/中/粗 `3 / 5 / 7 DIP`；默认中档为 `5 DIP`。

## Requirements

1. 在 `IdtState.h` 中为激光笔保存独立的宽度和细/中/粗 `3 / 5 / 7 DIP` 三档预设，默认中档保持现有真实激光外套的 `5 DIP`；切换激光笔、硬笔、荧光笔后，各自宽度互不覆盖。
2. 发布 Draw3 产品状态时，激光笔使用该独立宽度；Draw3 的激光笔迹实体直径和应用内光标必须使用相同宽度，并继续按 DPI 转为画布像素。
3. 激光笔选中时，绘制属性栏显示独立的三档纯色圆形快捷按钮；不显示或响应普通粗细展开按钮、滑条、预览弹窗或精细轮盘。切换到激光笔时，已打开的普通粗细滑条/轮盘必须退出，不能保留命中区域。
4. 非激光墨迹的三档快捷预设保持细/中/粗 `1 / 3 / 6 DIP`；中档仍是默认 `3 DIP`，细、粗分别为 `1`、`6 DIP`。
5. 激光笔选中时，粗细预览线改为无辉光的激光样式：红色实体外套（`RGB(255, 11, 30)`）内嵌白色内芯，二者直径保持 `3:1`，整体粗细随激光独立宽度和当前 DPI/面板缩放一致。
6. 激光笔选中时，硬笔、软笔及荧光笔对应的笔型扩展小三角必须全部隐藏且不可点击；切回普通笔型后恢复既有行为。

## Acceptance Criteria

- [ ] 在激光笔激活时修改硬笔或荧光笔粗细，再切回激光笔，其发布到 Draw3 的 `widthDip`、实际笔迹实体直径和光标直径仍为激光独立值。
- [ ] 在激光笔激活时，显示细/中/粗 `3 / 5 / 7 DIP` 的纯色圆形激光快捷按钮，且中档默认对应 `5 DIP`；普通展开按钮、滑条、预览弹窗和轮盘均不可见、不可命中，切换时不会残留滑条/轮盘状态。
- [ ] 硬笔默认中档为 `3 DIP`，细/粗档为 `1 / 6 DIP`，并且调整后 Draw3 光标与该笔迹宽度一致。
- [ ] 激光预览只由红色外套与白色内芯构成，无散射、渐变或辉光；外套与内芯直径比为 `3:1`，整体对应激光宽度。
- [ ] 激光笔激活时不显示硬笔、软笔、荧光笔的小三角，且对应扩展菜单已关闭；切回普通笔型后小三角及原有菜单行为恢复。

## Out of Scope

- 不新增激光笔的用户可调连续粗细入口；本次只提供三档激光快捷粗细。
- 不改变 Draw3 实际激光笔迹的粒子、散射、辉光或材质参数。
- 不改变形状工具和橡皮擦的粗细流程。

## Risks and Validation

- Bar 的粗细控件存在多条视觉、悬停和命中路径，必须同时禁用，而不是只设为透明。
- 激光宽度跨传统状态、Draw3 bridge、绘制控制器和光标，须验证相同 DIP 值在所有消费者一致。
- 将进行完整 `InkeysRepo.sln` 的 `Debug|ARM64` 构建；本会话不启动任何有窗口程序，运行期手工绘制和真实光标检查将明确标为未执行。
