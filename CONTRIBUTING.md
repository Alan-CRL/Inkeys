# Contributing to Inkeys

Thank you for your interest in helping Inkeys! Code, design, tutorials and promotion are all very welcome.

## Code Contributions

We warmly welcome code contributions. Inkeys has a large and mature user base, so we keep a strict bar on code quality. Please read the following before contributing code:

1. **Contact us before opening a PR**  
   Before you start working on a change or open a Pull Request, please contact [Alan-CRL](https://github.com/Alan-CRL) to describe what you would like to do, and start once the direction is agreed. Pull requests that have not been discussed may not be merged.
2. **Understand the architecture**  
   Make sure you thoroughly understand the architecture and design of the modules you touch. Changes should follow the existing code style and implementation approach rather than introducing a parallel one.
3. **Keep the quality high**  
   Code must be well tested, build and run correctly, and keep changes small and clear. See [BUILDING.md](BUILDING.md) for how to build, and base your work on the `dev` branch.
4. **About AI agents**  
   We do not object to using AI agents during development, but you need to be able to review AI-generated code and be proficient with these tools. Please take responsibility for every line you submit, rather than just getting the feature to run.

Contributed code is released under the project's [GNU General Public License v3.0](LICENSE).

## Other Contributions

Besides code, we also welcome help such as:

- Creating themes, plugins and other extensions;
- Promoting Inkeys and making introduction or promotional videos;
- Writing website content and user tutorials.
